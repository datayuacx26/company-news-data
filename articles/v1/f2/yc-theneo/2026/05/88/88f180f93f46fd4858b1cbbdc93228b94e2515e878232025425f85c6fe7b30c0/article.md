# EU Data Residency for Your API Documentation

As European data regulations tighten, enterprises building developer portals face a growing challenge: most API documentation platforms store and process sensitive data outside the EU. That creates friction in procurement, risk in compliance audits, and gaps in GDPR alignment.


Theneo now offers dedicated EU hosting for Enterprise customers, giving organizations full control over where their API documentation and developer portal data resides. No workarounds, no ambiguity — your workspace data stays in EU data centers.


## Why EU Hosting Matters for API Documentation


If you're building a developer portal or publishing your API hub, you might not immediately think of it as a data residency concern. But modern API documentation platforms handle far more than static pages — they process authentication tokens, API keys, session data, workspace configurations, and collaboration activity, all of which can fall under GDPR and EU data protection requirements.


## What Theneo's EU Hosting Includes


When you enable EU hosting on a Theneo Enterprise workspace, all core platform data is stored and processed within EU-based data centers. This includes:


- API documentation content and version history
- Workspace and project configurations
- User authentication and session data
- API key storage and access tokens
- Team collaboration activity (comments, edits, review workflows)
- Developer portal analytics and usage metrics
- Custom domain and branding configurations


EU hosting applies across the full Theneo platform — including AI-powered documentation generation, Git-synced API specs, interactive try-it consoles, and white-labeled developer portals. Your entire documentation workflow, from import to publishing, stays within EU infrastructure. There is no split where some features process data in the EU and others route through US servers.


Data is encrypted both at rest and in transit. Theneo's EU hosting is designed to align with GDPR requirements and supports organizations that need to demonstrate data residency compliance during procurement reviews, vendor assessments, and regulatory audits. For organizations that require a formal agreement, Theneo provides a Data Processing Agreement (DPA) as part of the Enterprise plan.

Theneo's EU hosting is particularly relevant for teams operating in industries where data residency is non-negotiable.


- **Financial services and fintech** companies subject to EBA guidelines and national banking regulations need to demonstrate that third-party platforms storing access credentials and API data meet EU residency requirements.

- **Public sector and government contractors** often face strict procurement mandates that require all SaaS vendors to offer EU or national data hosting. **‍**
- **Insurance companies** undergoing digital transformation are modernizing APIs while navigating Solvency II and national data protection rules.


If your procurement process includes questions like "Where is customer data stored at rest?", "Can we ensure data residency within the EU?", or "Does the vendor have a DPA?" — Theneo's EU hosting is built to answer them. It's available on the Enterprise plan alongside SSO (SAML), custom branding, role-based access control, and dedicated support.
