# Integrations: drive the tools you already use from the agent | MOVE. Blog

Engineering teams do not want another tool to learn. They want the tools they already trust to stop costing them so much manual effort. So instead of asking you to move your work into MOVEcenter, we are teaching the agent to operate the tools where your work already lives.


Two integrations are part of this release.


## MATLAB and Simulink


The agent writes and runs MATLAB code and Simulink models for you. Describe what you want in plain language and it produces the script or model run, executes it, and reads back the results.


It runs **locally** , so your models and IP never leave the machine. You get the speed of an agent driving your toolchain without sending proprietary models to a third party.


## VI-CarRealTime


The agent sets up and runs VI-CarRealTime simulations directly. Model runs happen inside the loop the agent is already working in, rather than as a separate manual step you context-switch into and back out of.


## Why this matters


Each of these removes the same thing: the manual handoff between a tool and the rest of your workflow. Individually they save time on one step. Together they let the agent carry a task across modeling, simulation, and analysis without you shuttling files between systems.
