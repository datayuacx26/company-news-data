# Introducing Pactory integration

[Pactory](https://pactory.ai/) is an AI Agents Marketplace that enables businesses and consumers to use AI agents to solve their tasks. It also allows agent developers to connect, distribute, and monetize their agents.


Pactory provides agent developers with full billing, UI, and user management. Every agent gets a personal page that can be shared or discovered by marketplace users. Agent developers receive revenue share payments based on their agent's usage, with no hidden fees.


With[Blaxel](https://blaxel.ai/) , developers can create and deploy AI agents in any framework. It provides the dev tools to quickly bootstrap an agent template in Python or JS, and deploy it on a distributed serverless infrastructure.


Now, any agent built and deployed with Blaxel can be easily connected using the agent endpoint and profile API key. A full tutorial on how to connect and monetize a Blaxel agent is available in the[Blaxel documentation](https://docs.blaxel.ai/Integrations/Pactory) .
