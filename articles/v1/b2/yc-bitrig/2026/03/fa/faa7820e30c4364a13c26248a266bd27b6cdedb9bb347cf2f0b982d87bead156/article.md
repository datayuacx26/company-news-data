# Meet Bitrig Agent

From the engineers behind SwiftUI, Bitrig is a vibe coding app purpose-built for the Apple ecosystem. It’s the simplest way to build native Swift apps, and we’ve been expanding it to support increasingly complex tasks.


The[Mac app](https://bitrig.com/blog/meet-bitrig-for-mac) brought Bitrig closer to a professional development environment by compiling with the full Xcode toolchain and showing an inline iPhone Simulator preview.


Now we’re taking the next step with Bitrig Agent.


Bitrig Agent still looks and feels like Bitrig, but under the hood it runs the same professional-grade iOS development stack we use to build Bitrig itself.


That means:


-


Claude Code running locally on your Mac, with the ability to build your project, inspect errors, and search documentation autonomously


-


Multi-file projects, including support for editing project configuration, Info.plist, entitlements, and capabilities


-


Version History backed by Git, so you can browse and restore previous versions of your project with confidence


The result is a Bitrig that’s just as easy to use, but much more capable for building larger, more sophisticated apps.


Upgrade your existing projects to use Bitrig Agent, and enable it for new projects in the[Bitrig Mac app](https://bitrig.com/) today.
