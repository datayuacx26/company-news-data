# The latest updates in the SnapInsights component supplier dashboard

We've updated our supplier dashboard with some new insights to help you better track design-ins of your electronic components.


#### 1. You can now view a breakdown of the PCB design tools your customers use


These PCB design tool formats are the tools your customers use to design with your components. To see it, go to:


1. Select **Design-Ins (Downloads)** on **** on the left navigation bar **** ‍
2. View the chart called **Downloads by Format**


Breakdown of PCB design formats


‍


#### 2. You can now see how engineers discover your electronic components on SnapEDA


Previously, this feature was only available for our media campaigns, but we've now made this feature available on organic downloads too.


1. Select **Design-Ins (Downloads)** on the left navigation bar
2. Look for the **Top Downloads** chart


‍


#### 3. You can now see the top 10 organic product downloads


Again, this feature was previously only available for our media campaign downloads, but we've now expanded this feature so that it's accessible for organic downloads too.


1. Select **Top Search Terms** on the left navigation bar
2. Look for the **Top Design-Ins Search Terms** chart


‍
