# Web Checkout for Mobile Apps is Here

Web Checkout has arrived in Superwall!


Starting today, you can setup a Stripe app in Superwall to start offering your products via web checkout. All the Superwall features you care about – paywall experiments, powerful tests, audience filtering, and more — work right out of the box.


Head[here](https://superwall.com/applications/:app/settings/experiments) to get started, and be sure to check out our[brand new docs](https://superwall.com/docs/web-checkout-overview) !


### Web Checkout, the Superwall way


Creating these types of integrations and flows can be a technical challenge. Superwall has taken care of all of those edge cases, easy-to-miss implementation details, and web-to-app communication pipelines for you. Getting setup does not take long, in fact — I can explain the entire process in four steps.


Web checkout process


### No auth required


Don't have a login system in place? No worries at all. Superwall manages all of that complexity for you, ensuring that users can checkout on the web and get all of their content unlocked right on their iOS device.


Already have auth in place? You don't even need to make any changes if you're using our[existing APIs](https://superwall.com/docs/identity-management) to identify users. As the saying goes, it all "just works."


### Web checkout links


Web checkout is powered by the concept of placements, something you're already familiar with in Superwall. Now, they've got superpowers — each placement in your Stripe app campaign becomes a unique link to offer a paywall. We call them web checkout links, and this setup allows you to run flexible campaigns.


Running an influencer campaign? You'll have a unique URL for that. And in that campaign, you can create audience filters to show users the perfectly tailored paywall, or easily run price tests. No matter if you're running promotional offers, seasonal events, or one-time sales — the full Superwall campaign feature set is at your fingertips.


Each placement in a campaign becomes a web checkout link.


Plus, you can even use query string parameters, too! They work just like[parameter placements](https://superwall.com/docs/using-placement-parameters) do today. This means you can use them in audience filtering (i.e. "Only show this paywall to users who have X coupon, or Y number of times"), and personalize paywall copy (i.e. "Hey there Jordan, we've got a special offer for you!").


### Easy trials


Superwall controls the trial status of your products. While this may seem like a small point, if you've built out robust price tests for essentially the *same* product, you know how long and tedious this process can be. If you wanted to test a different trial length for a $20 annual subscription, you need to make a new product for *each* trial variant.


Not so with our integration. You can reuse the same Stripe product, and create multiple trial terms with it. Then, Superwall will create a unique product for each trial. This saves you tons of time, and opens up an easier way to run critically important price tests.


### Built on top of Stripe


Stripe is, and has been, the leading web payments solution for a long time now. In addition to their reliability, they've also got very friendly fee terms. That rings extremely true if you're coming from the mobile storefronts. Depending on your volume, you could be keeping up to 25% more of your revenue in your pocket!


Even better? Superwall's pricing remains the same as it always has, meaning this whole integration doesn't cost you any additional fees or costs. These are conversions just like they would be from a mobile device, so your first 250 conversions are always free.
