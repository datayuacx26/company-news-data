# User Section Redesign

We're pleased to unveil the new User Panel. At first we weren't so excited about a new Users section, but we found ourselves obsessed with it. Here's why you'll love it as much as we do:


1. Find users who just triggered ANY event, even your own custom events ⚡️
2. Quickly reference event properties to use in Audience rules 📘
3. Double check integrations like RevenueCat are forwarding events properly 🔩
4. Debug any user by their` id` to see why they did ( *or didn't* ) see a paywall 🧐
5. Find device and user properties quickly. A beautiful design, because we care 🎨
