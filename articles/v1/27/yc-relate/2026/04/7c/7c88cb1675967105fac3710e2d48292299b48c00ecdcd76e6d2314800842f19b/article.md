# Relate Notetaker & SMS Sending — Now Available - Relate Changelog

## **Overview**


A new feature is now available in Relate.


Relate Notetaker automates meeting note capture and CRM sync.


## **⭐️ New Feature**


### **Relate Notetaker (Early Access)**


Relate Notetaker is an AI meeting notes feature that automatically joins video calls, records the conversation, and saves meeting notes to Relate's activity feed and calendar.


This removes the need to take notes during meetings and eliminates manual CRM entry after calls.


**Details**


-


Supports **Google Meet and Zoom**


-


Requires **Google Calendar or Microsoft 365 Calendar integration**


**How to Get Access**
Access is currently **being rolled out gradually to applicants** . To request access, please[submit the Early Access request form](https://public.spread.so/p/forms/lj3wyio7if0kms4c) .

## **Feature Improvements & Enhancements**


1.


#### **Docs Form Submission → Auto List Creation**


Emails submitted through a Docs form can now be automatically converted into a list, improving the efficiency of lead capture workflows.


2.


#### **(Spread) Improved Default Value UI for Mail Merge Personalization Variables**


When using personalization variables in campaign or sequence emails, the interface for setting fallback values for empty fields has been updated to be more intuitive.


A popup for configuring the default value now appears automatically when inserting a personalization variable.


## **Relate & Spread: Continually Evolving**


Starting with Relate Notetaker, we will continue expanding automation capabilities across the sales workflow.


**The next update will include the launch of Relate AI, which will handle lead qualification, outreach planning, and follow-ups.** Stay tuned for more updates.
