# How Inscribe protects your financial documents

When you trust a platform with sensitive financial documents, security isn't just a feature, it's foundational.


At Inscribe, protecting customer data is the full-time focus of our dedicated security engineers. From the infrastructure we run on to the way AI is deployed, security is built into every layer of our platform so you can confidently process sensitive financial documents.


## Security built into every request


Inscribe is built on AWS and uses large language models securely hosted on AWS Bedrock. Every document is processed within our private Virtual Private Cloud (VPC), an isolated environment that we fully control.


Sensitive customer data never leaves our secure infrastructure. It is not shared with external model providers and is protected by strict access controls, data encryption, and network security policies.


## Backed by industry-recognized security standards


Our commitment to security is backed by internationally recognized certifications, including:


- **SOC 2** – Independently audited controls covering security, availability, and confidentiality.
- **ISO 27001** – An internationally recognized information security management standard that validates how we protect customer data.


These certifications are supported by dedicated security engineers whose full-time focus is keeping our infrastructure secure, resilient, and continuously improving.


## Built for enterprise security reviews


We know security reviews are a critical part of evaluating any vendor. That's why Inscribe is designed to support enterprise security and compliance teams with features including:


- Role-based access controls
- Audit logs
- Data encryption
- Dedicated support throughout your security review


Whether you're completing a standard vendor assessment or have specific security and compliance requirements, our team is happy to walk through our architecture, security controls, and certifications.
