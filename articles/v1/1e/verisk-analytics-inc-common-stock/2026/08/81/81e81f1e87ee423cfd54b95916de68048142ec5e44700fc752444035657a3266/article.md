# Missouri Delays Mandatory Start Date to Release 3.1 for FROI and SROI

The state of Missouri was originally scheduled to go live with Release 3.1 for both First Report of Injury (FROI) and Subsequent Report of Injury (SROI) on August 20, 2026. On July 7, 2026, the Missouri Division of Workers’ Compensation (MODWC) released an announcement entitled “MODWC EDI Claims Release 3.1 Implementation Date Rescheduled” stating that they are delaying the go-live date to a later date, however, no new date has been specified.


The Missouri MODWC’s new update was released in an[announcement](https://modwcedi.info/documents/MODWC%20EDI%20Claims%20Release%203.1%20Implementation%20Date%20Rescheduled%20(Rev%20063026)%20.pdf) on 7/7/2025 (entitled “MODWC EDI Claims Release 3.1 Implementation Date Rescheduled.)” This announcement is also[posted on its website](https://modwcedi.info/news) within the News and Updates section for your reference.


On this point, the MODWC’s notice states, in pertinent part, as follows:


“The MODWC EDI Claims Release 3.1 implementation date of August 20, 2026, will be rescheduled. MODWC will send a separate announcement to provide the new implementation date when it becomes available. MODWC EDI Claims Release 3.1 implementation date change is needed in order to implement EDI at the same time as the MODWC Work Comp Connect Claims system implementation that requires additional time to finalize for implementation.


MODWC testing will remain open and will be revised along with the update to the new implementation date. Once a new date has been determined, MODWC Claims EDI Release 3.1 Requirement Tables, Implementation Guide, Test Plan, Transition Plan and additional pertinent documents will be updated and become available on the website to reflect the new date.”
