# Garbage Collection Goodies


This was a talk for[The Utah Go Users Group](https://www.meetup.com/utahgophers/events/) . It was focused on coverating the various tools and techniques used to build automatic garbage collection. It also covered how these ideas intersect with technologies like stack based calling convetions and heap allocators. The talk wrapped up with an examiniation of the go garbage collector, how it works, and how to configure it.


## Where
