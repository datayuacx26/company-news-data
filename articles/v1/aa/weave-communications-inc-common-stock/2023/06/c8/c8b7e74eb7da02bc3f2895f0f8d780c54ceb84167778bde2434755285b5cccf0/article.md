# Ending The Data Format Wars

# Summary


This talk was presented at the[DevOpsUT Meetup](https://www.meetup.com/devopsut/photos/33650149/) . It covers 4 different ways to store data in a text format. It compares and contrasts the formats to dispel the common notion that any one format is objectively the best.
