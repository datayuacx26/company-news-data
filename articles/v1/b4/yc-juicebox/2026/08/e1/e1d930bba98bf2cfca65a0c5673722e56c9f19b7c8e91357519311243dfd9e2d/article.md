# Juicebox MCP Server | Product Release

Today, we're excited to introduce the **Juicebox MCP Server** . It connects Juicebox to the AI assistants your team works in every day, so you can spin up Agents, pull usage insights, and build custom reports using plain language.


‍[Watch the launch video](https://www.linkedin.com/posts/david-paffenholz_today-were-excited-to-introduce-the-juicebox-ugcPost-7493337265461678080-n2bK/?utm_source=share&utm_medium=member_desktop&rcm=ACoAABn4XTQBOjylHX-xerUqvLWKY080rZCBDGk) **to see our favorite use cases, featuring our engineer, Tracy.**


Here's a deep dive into what you can do:


## **🔌 What's an MCP Server?**


*A quick primer before we get into the use cases*


MCP (Model Context Protocol) is an open standard that lets AI assistants like Claude and ChatGPT connect directly to Juicebox.


With the Juicebox MCP Server, your team can spin up Juicebox Agents, pull usage insights, and build custom reports using natural language inside Claude, ChatGPT, and any MCP-compatible app.


[👉 Read more in our product docs](https://docs.juicebox.ai/juicebox-mcp)


‍


## **🔗 How to connect the Juicebox MCP Server**


The Juicebox MCP Server is listed in the connector directories for both Claude and ChatGPT, so you can add it the same way you'd add any other app.


### **Connecting in Claude**


1. Open **Settings** and go to **Connectors** .
2. Click **Browse connectors** and search for **Juicebox** .
3. Click **Connect** and sign in with your Juicebox account.
4. Approve the permissions screen. Juicebox will now appear in the tools menu of any new chat.


[👉 Connect Juicebox to Claude](https://claude.ai/directory/juicebox?q=juicebox)


### **Connecting in ChatGPT**


1. Open **Settings** and go to **Apps & Connectors** .
2. Search the directory for **Juicebox** and select it.
3. Click **Connect** and sign in with your Juicebox account.
4. Approve access. You can then enable Juicebox from the tools menu in any conversation.


[👉 Connect Juicebox to ChatGPT](https://chatgpt.com/plugins?show_chat_button=true&q=Juicebox)


‍


### **Other MCP-compatible apps**


The Juicebox MCP Server works with any client that supports the Model Context Protocol, including Cursor, Claude Code, and other AI tools. Add it as a remote MCP server using the URL in our docs and authenticate with your Juicebox login.


[👉 See the full setup guide in our docs](https://docs.juicebox.ai/juicebox-mcp)


‍


## **📊 Build custom insights with Juicebox**


*Answer questions about your searches, shortlists, and outreach*


Starting today, you can connect the Juicebox MCP Server to your favorite AI tools and customize or automate any insight, including:


- **Team usage:** searches, shortlists, and profiles viewed by recruiter
- **Project performance:** how individual role searches are progressing
- **Talent pipeline:** break down a shortlist by location, experience, and more
- **Outreach effectiveness:** reply rates across sequences and projects


You can also combine data across your recruiting tools to build custom reports for hiring managers and other stakeholders.


[👉 Connect the Juicebox MCP Server](https://docs.juicebox.ai/juicebox-mcp)


‍


## ‍ **🤖 Launch a Juicebox Agent with full context**


*Start sourcing with context from across your recruiting stack*


Kick off a Juicebox Agent calibrated with context from your other recruiting tools, including:


- ATS job descriptions and notes
- Intake call notes from notetakers
- Org memory from Juicebox, and more


If you've connected these tools to your AI app, Juicebox takes that context and builds an Agent that starts sourcing. Leads land in your project ready for your approval.


[👉 Connect the Juicebox MCP Server](https://docs.juicebox.ai/juicebox-mcp)


‍


## **🔐 Data access via the MCP Server**


*Your Juicebox permissions carry over, wherever you connect*


Anyone on a paid Juicebox plan can connect the MCP Server with their existing Juicebox account.


Data access mirrors the permissions you already have in Juicebox, so you'll see the same data through the MCP Server that you see in the app. If a shortlist, project, or report is visible to you in the app, it's available in your AI tools. If it isn't, it stays private.
