# Letter spacing animations


You can now animate letter spacing on text: great for kinetic typography, emphasis reveals, and giving titles a bit more personality.


Here's how to use letter spacing animation:


1. Select the text layer you'd like to animate.
2. Click *New Animation* , go to the *Custom* tab, and choose *Letter spacing* .
3. Set the *To* percentage to define the target spacing. Optionally, you can also set an *Initial value* to control where the animation starts.


That's it! Now you have one more simple way to add rhythm and motion to your type.
