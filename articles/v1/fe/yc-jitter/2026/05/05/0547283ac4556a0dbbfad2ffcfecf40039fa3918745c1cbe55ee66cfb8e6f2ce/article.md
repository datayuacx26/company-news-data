# Glass effect


You can now use the glass effect in Jitter: both as a static effect in the *Design* tab and an animation in *Animate* .


Dial in refraction, depth, dispersion, frost, and more settings to get everything from subtle frosted UI to rich, refractive glass. Then animate each of those settings to create fluid, realistic transitions.


Here's how to use it:


1. Select an element in your file you'd like to apply the glass effect to. The effect works best with shapes and text laid over a non-transparent background.
2. Go to the *Design* tab on the right and find *Glass* (or go to *Animate* → *New animation* → *Custom* → *Glass* for the animated version of the effect).
3. Adjust *Refraction* to control how much the glass bends what's behind it.
4. Use *Depth* for the sense of thickness and *Dispersion* for chromatic color separation.
5. Set *Frost* to add blur to the glass surface.
6. Fine-tune *Light intensity* and *Light angle* to control the highlight.
7. Use *Blend* to mix the glass effect with the element's original appearance.
