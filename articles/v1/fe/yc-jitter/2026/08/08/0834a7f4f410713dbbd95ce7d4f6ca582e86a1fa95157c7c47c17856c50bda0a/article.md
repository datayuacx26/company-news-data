# Component overrides

Components just got more flexible. You can now override individual instances of a component without breaking the connection to the rest.


Previously, if part of an instance came from a component, you couldn't make changes to it without updating the component itself. Now you can select that part and edit it directly (swap an asset, tweak text, change colors, etc.) Your change becomes an override on that instance, while everything else stays in sync with the component.


Here's how to use it:


1. Select an instance of a component (or an element inside it) and make an edit: change color, text, or anything else you need.
2. That's it! Your edit becomes an override on that instance only, and the rest of your instances stay in sync with the component.


Want to undo an override and snap back to the original? Right-click the instance in the layer list and hit *Reset instance* .
