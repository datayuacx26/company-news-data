# Displacement shaders


You can now add organic, wave-like distortion to your elements in Jitter. Displacement shaders let you create animation distortion effects using amplitude, offset, and repeat controls for both the initial state and the animated state. It's a powerful way to create fluid motion, organic transitions, reveal animations, and ambient backgrounds.


Here's how to use the new feature:


1. Select the element you'd like to animate on the canvas.
2. In the right-hand sidebar, switch to the *Animate* tab.
3. Click *Add animation* and choose *Displacement* .
4. Set the *Initial value* by tweaking *Amplitude* , *Offset* , and *Repeat* to define where the distortion starts.
5. Below that, set your target values for the same controls — this is where the distortion will end up after the animation plays.
6. Set the *Direction* to *Horizontal* , *Vertical* , or *Both* .
7. Adjust *Duration* and *Easing* to control how the transition feels.
