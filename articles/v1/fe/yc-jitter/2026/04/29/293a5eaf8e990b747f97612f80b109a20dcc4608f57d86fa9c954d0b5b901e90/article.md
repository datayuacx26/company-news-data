# Independent corner radius


You can now adjust each corner radius of a shape separately in Jitter: great for designing playful buttons, cards, speech bubbles, and other elements that aren’t meant to be perfectly symmetrical.


Here’s how to use independent corner radius:


1. Select a shape on the canvas.
2. In the right-hand sidebar, make sure you're in the *Design* tab and find the *Corner* section.
3. Click on the corner radius icon to switch from a linked radius to independent corner editing.
4. Add the radius value for each corner.


That's it! It’s an easy way to make shapes feel more custom without having to recreate them as vectors.
