# New project page design


Today we’re excited to be introducing some new layout changes to the Experiment project pages.


We’re rolling out the new project page design starting today. One new feature is a list of backers visible high up in the project’s header. Backers are an integral part of each successful experiment, and our goal is to create a direct connection when you back a project. We’re pretty excited about this new concept, and we’ve got lots in store in coming weeks to make this better.


Another major aspect of this new push is to introduce great performance improvements. One of the biggest points of feedback we heard from researchers out in the field or through mobile was site speed. With this new project page, we’ve increased page performance by 5X. We hope that this makes the site speedier and more enjoyable to use.


The biggest thing about this change is that it allows us to start introducing new features on the project page in a more modular way. With this new design, our goal is to add more interactive project sections to help convey the story behind the project while keeping it simple and easy to use. We’ve got lots of very exciting new features planned for this new layout, so stay tuned!


Denny
