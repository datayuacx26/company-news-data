# Propexo CEO Explores Opportunities for New Property Management Software Vendors in Interview

Remen Okoruwa, Co-Founder and CEO of Propexo, recently shared expert insights on property management system (PMS) integration challenges in Brad Hargreaves' Thesis Driven newsletter.


In the comprehensive article titled "How to Build a Property Management System from Scratch," Okoruwa highlighted critical issues with current PMS platforms, noting that most major vendors created their APIs and integration programs decades after launching their core products.


He specifically identified three key challenges: incomplete API coverage relative to product functionality, inconsistent API performance and uptime, and a lack of common API features such as webhooks and real-time capabilities.


Okoruwa also addressed user interface concerns across PMS platforms, pointing out that dated interfaces and complicated menu structures often require significant staff training investments from property management firms.
