**Resolved issues**


- **Improved Bates range matching** - Automatically generate near-natives for .webp files during ingest. This feature expands supported formats, ensures correct display within Review, prevents blank images, and reduces manual remediation. (resolved on 6/1)
- **Search History Folder Icon Update** - Fixes an intermittent issue on the Production page where folder icons failed to display in Search History. Searches utilizing folder criteria now reliably show the folder icon, confirming that the parameters were successfully applied. (resolved on 6/15)
- **Automated URL Re-routing** - Redirects users to the relevant landing page when they attempt to access a non-existent URL for stages, groups, or batches. This replaces the previous error page, preventing workflow disruptions caused by broken or outdated links. (resolved on 6/15)
- **Fix to document viewer keyboard shortcut** - Users can now successfully leverage the Enter key to open the document viewer from the workflow stage lists. This keyboard shortcut prevents interruptions during review workflows. (resolved on 6/22)
