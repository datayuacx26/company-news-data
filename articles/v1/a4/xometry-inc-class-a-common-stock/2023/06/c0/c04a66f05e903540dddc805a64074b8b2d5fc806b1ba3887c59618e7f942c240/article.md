# Maximum Print Sizes for 3D Printed Parts

We often receive questions from customers regarding the maximum size of a part that can be printed with Xometry's[3D printing service](https://www.xometry.com/capabilities/3d-printing-service/) . It’s a great question and the answer depends entirely on the process you decided to use. To help inform your decision please refer to the sections below for the maximum build volumes of each additive process we offer.


3D Printing Process Maximum Build Volume Notes


3D Printing Process


[Selective Laser Sintering](https://www.xometry.com/capabilities/3d-printing-service/selective-laser-sintering/)


Maximum Build Volume


13″ x 13″ x 22″


Notes


Glass-filled nylon can extend up to 26" x 15" x 23"


3D Printing Process


[HP Multi Jet Fusion](https://www.xometry.com/capabilities/3d-printing-service/hp-multi-jet-fusion/)


Maximum Build Volume


15" x 11" x 15"


Notes


14" x 11" x 13" is the recommended usable area


3D Printing Process


[Fused Deposition Modeling](https://www.xometry.com/capabilities/3d-printing-service/fused-deposition-modeling/)


Maximum Build Volume


36" x 24" x 36″


Notes


Prototyping PLA build volume is 9.8" x 8.3" x 8.3"


3D Printing Process


[PolyJet](https://www.xometry.com/capabilities/3d-printing-service/polyjet-3d/)


Maximum Build Volume


19.3" x 15.4" x 7.9"


Notes


Pricing and lead-time increase exponentially with Z-height


3D Printing Process


[Stereolithography](https://www.xometry.com/capabilities/3d-printing-service/stereolithography-3d-printing/)


Maximum Build Volume


29” x 25” x 21”


Notes


- High resolution prints are limited to 10” x 10” x 10”
- Formlabs materials are limited to 13.5" x 7.5" x 7.5"


3D Printing Process


[Carbon DLS™](https://www.xometry.com/capabilities/3d-printing-service/carbon-dls/)


Maximum Build Volume


7.4” x 4.6” x 12.8”


Notes


Parts with dimensions exceeding 4” x 4” x 6” will require manual review


3D Printing Process


[Direct Metal Laser Sintering](https://www.xometry.com/capabilities/3d-printing-service/direct-metal-laser-sintering/)


Maximum Build Volume


10" x 10" x 10"


Notes


Build volume may vary slightly between materials


3D Printing Process


[Metal Binder Jetting](https://www.xometry.com/capabilities/3d-printing-service/metal-binder-jetting/)


Maximum Build Volume


15" x 10" x 10"


Notes


- Recommended part size: Less than 4"
- Parts typically shrink 0.8-2.5% overall
