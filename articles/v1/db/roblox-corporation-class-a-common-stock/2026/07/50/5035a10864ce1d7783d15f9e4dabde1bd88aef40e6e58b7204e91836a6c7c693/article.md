# 在 Roblox 上打造無極限


介紹 Build：Roblox 上的「行動優先」AI 創作平台


發佈者


Engine 資深副總裁 Nick Tornow 以及首席創作者生態系統官 Vlad Loktev


發佈日期


2026年7月16日


此刻，某處正有人構思著一款遊戲。他們清楚知道遊玩時會是什麼感覺，只是還不知道該如何打造它。今天，這一切將有所改變。


二十年前，Roblox 以一個簡單的理念問世：「由你來製作遊戲。」當時，這是一個極具顛覆性的主張——大多數遊戲都由遊戲工作室和專業人士製作，而「任何人都能成為創作者」這個概念，在當時還遠非顯而易見。但我們深信不疑。而數百萬在 Roblox 上創作的創作者，也證明了這一點。 展望未來，Roblox 每日 1.32 億活躍用戶中的任何一人都可能創作出下一款爆紅遊戲，我們正將這個最初的理念推向前所未有的高度。在接下來的幾個月裡，我們將發布一系列公告，為每位創作者提供清晰的發展路徑，讓他們能走得更遠，並為比以往更多的人兌現「由你來打造遊戲」的承諾。


今天，我們宣布推出「Build」——這是 Roblox 應用程式內一個以行動裝置為優先的新創作分頁，同時也將在 Studio 中推出一套適用於各級別創作者的全新 AI 驅動工具套件。7 月 28 日起，我們將開始測試這些新的自動化工具。透過「Build」和 Studio，創作者可以將那些不需要他們全神貫注的開發環節交由系統處理。


Roblox 一直以來都為創作者提供強大的工具，讓他們能在數秒內向全球發布作品；我們提供一個能推動作品被發現並實現快速病毒式傳播的平台，讓創作者能輕鬆迭代與擴展，且無需預付費用；同時具備強大的安全系統來保護玩家，並透過我們的遊戲引擎打造出極其豐富的世界。那些在這個平台上建立起真實受眾的創作者，之所以能成功，是因為他們製作了人們真正想玩的遊戲，而我們也始終在 Roblox 上推薦那些遊玩次數最多、互動率最高的體驗。 我們的發現系統旨在突顯具備長期留存率的遊戲，其中並不包含 AI 生成的劣質內容。首頁上遊戲的品質標準並不會改變：如果沒有人遊玩——就不會有人發現它。這些新工具的目標，是持續加速各層級創作者的創作進程。


## 隆重推出「Build」：Roblox 上的全新創作方式


Build 將「行動優先」的 AI 創作功能帶入 Roblox，讓任何人都能直接在 Roblox 行動應用程式中，將文字提示轉化為基礎遊戲。創作者只需輸入「讓我們製作一款以茂密森林為背景、充滿環境障礙的溫馨冒險遊戲」，Build 便會自動生成一個起點，供創作者進行迭代、測試，並與朋友分享或發佈至 Roblox。


Build 將創作者多年來成功使用的 Roblox Studio 功能延伸至 Roblox 應用程式中。透過共享的後端系統、模型及聊天紀錄，創作者可在 Build 中開始創作，並利用 Studio 更廣泛的功能來強化作品；亦可從 Studio 啟動代理程式，並透過行動裝置查看進度。


Build 由一套廣泛的人工智慧模型驅動，包含開源模型與 Roblox 專有模型，可處理遊戲機制、環境、角色、視覺風格、音效等各項內容——且無需離開 Roblox 平台。 由於這些模型是基於規模獨特龐大的 3D 模型集及遊戲專用數據進行訓練，Roblox 的專有 AI 模型能夠生成可運作的 3D 物件，甚至完整的 3D 場景，並能透過現有的創作工具輕鬆整合至運作中的遊戲中。


Build 讓創作者能快速探索並精進創意構想，使其成為迭代設計、與朋友分享以及徵求回饋的強大工具。即將推出的版本將為新進與資深創作者提供更多彈性，讓他們能透過我們的行動應用程式來優化遊戲。


部分 Build 功能（包括發佈遊戲的能力）將自 7 月 28 日起，透過公開 alpha 測試向紐西蘭用戶開放。未來數月內，我們將持續優化核心功能並擴展其能力，逐步將 Build 推廣至更多創作者及地區。在 alpha 測試期間，Build 將開放給通過年齡驗證且年滿 9 歲* 的用戶使用。經我們嚴格安全檢查並通過審核的發佈遊戲，將全球開放給通過年齡驗證且年滿 16 歲的用戶遊玩。 在被加入「Roblox Kids」或「精選」目錄之前，透過 Build 製作的遊戲將經過所有 Roblox 遊戲都必須遵循的延伸審查流程。這些遊戲也將加入相同的候選池，並與所有其他 Roblox 遊戲一樣，由[基於留存率的發現系統](https://about.roblox.com/newsroom/2026/06/optimizing-discovery-great-games-reach-millions-players-roblox) 進行排名。Build 的基礎版本將免費提供給創作者，並為進階使用者提供額外的付費選項。


## Build 與 Studio 的未來發展


未來數月內，我們也將為專業創作者推出一套全新的工具套件。這些工具將適用於 Build 和 Studio 平台，內容包含：


- 一款遊戲測試代理程式，能在任何玩家體驗遊戲之前就偵測到錯誤
- 分析代理程式，讓創作者能以自然語言提出任何關於遊戲的問題，並獲得洞察，無需在儀表板中費力搜尋
- 實驗代理程式，可識別應執行的測試以提升參與度、留存率與變現能力


我們近期推出的「程序化模型」能根據文字提示或圖片生成參數化 3D 資產。創作者可設定參數來重塑與精修，無需手動建模或重新生成。 此外，Roblox 的 3D 基礎模型「[Cube](https://about.roblox.com/newsroom/2026/02/accelerating-creation-powered-roblox-cube-foundation-model) 」能將提示語轉化為可直接用於遊戲的物件，從簡單的道具到可駕駛的載具，乃至能發射子彈的武器皆可生成。即將推出的全新場景生成模型，將能根據單一提示語，建構出完整的可編輯且可遊玩的 3D 場景。隨著這些功能在未來數月陸續上線，我們將分享更多相關資訊。


這些更新共同讓 Roblox 比以往任何時候都更接近「由你打造遊戲」的願景。讓我們一起創作吧。
