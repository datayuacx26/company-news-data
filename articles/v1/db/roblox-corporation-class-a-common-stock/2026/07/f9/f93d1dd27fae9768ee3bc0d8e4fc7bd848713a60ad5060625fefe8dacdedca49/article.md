# 在 Roblox 上尽情创造


介绍 Build：Roblox 上的“移动优先”AI 创作平台


作者


Engine公司高级副总裁尼克·托诺夫（Nick Tornow）和首席创作者生态系统官弗拉德·洛克特夫（Vlad Loktev）


已发布


2026年7月16日


此刻，在世界的某个角落，有人正构思着一款游戏。他们对游戏的玩法了如指掌，只是不知道该如何将其实现。而今天，这一切将发生改变。


二十年前，Roblox 凭借一个简单的理念问世：“由你来制作游戏。”当时，这是一个极具颠覆性的主张——大多数游戏都由工作室和专业人士制作，而“任何人都能成为创作者”这一理念远非显而易见。但我们坚信这一点。而在 Roblox 上创作的数百万创作者也证明了这一点。 展望未来，Roblox 1.32 亿日活跃用户中的任何一位都有可能打造出下一款爆款游戏，为此，我们将这一最初理念推向了前所未有的高度。在接下来的几个月里，我们将发布一系列公告，为每位创作者提供清晰的成长路径，让他们走得更远，并让比以往更多的人实现“你来制作游戏”的承诺。


今天，我们正式推出“Build”——这是 Roblox 应用内一个全新的、以移动端为先的创作标签页，同时在 Studio 中推出了一套面向各级别创作者的全新 AI 驱动工具套件。7 月 28 日起，我们将开始测试这些新的智能代理工具。借助 Build 和 Studio，创作者可以将那些无需全神贯注的开发环节交由系统处理。


Roblox 一直为创作者提供强大的工具，使其能在数秒内向全球发布作品；提供一个能推动内容发现和快速病毒式增长的平台；支持无需前期成本的轻松迭代和规模扩展；配备完善的安全系统来保护玩家；以及由我们的游戏引擎支持的极其丰富的虚拟世界。那些在这个平台上积累了真实受众的创作者，正是通过制作人们真正想玩的游戏才做到的，而我们始终在 Roblox 上优先展示那些播放量最高、参与度最高的体验。 我们的发现系统旨在突出具有长期留存率的游戏，其中不包括低质量的AI作品。首页上游戏的质量标准不会改变：如果没人玩——就没人能找到它。这些新工具的共同目标是继续加速所有水平创作者的创作进程。


## 推出 Build：Roblox 上的全新创作方式


Build 为 Roblox 带来了“移动优先”的 AI 创作功能，让任何人都能直接在 Roblox 移动应用中，将文本提示转化为基础游戏。创作者只需输入“让我们制作一款以茂密森林为背景、充满环境障碍的温馨冒险游戏”，Build 便会自动生成一个起点，供创作者在此基础上进行迭代、测试，并与朋友分享或发布到 Roblox 上。


Build 将创作者多年来成功使用的 Roblox Studio 功能扩展到了 Roblox 应用中。凭借共享的后端、模型和聊天记录，创作者可以在 Build 中开始创作，并利用 Studio 更强大的功能来完善作品；或者从 Studio 启动代理，并通过移动设备查看进度。


Build 由一套广泛的人工智能模型驱动，包括开源模型和 Roblox 专有模型，可在不离开 Roblox 的情况下处理游戏机制、环境、角色、视觉风格、音效等内容。 由于这些模型是在规模空前的 3D 模型集和游戏专用数据集上训练而成的，Roblox 的专有 AI 模型能够生成可运行的 3D 对象，甚至完整的 3D 场景，并可通过我们现有的创作工具轻松集成到运行中的游戏中。


Build 支持快速探索和打磨创意，这使其成为迭代设计、与朋友分享以及获取反馈的强大工具。即将推出的版本将为新晋和资深创作者提供更多灵活性，让他们能够通过我们的移动应用改进自己的游戏。


部分 Build 功能（包括发布游戏的能力）将于 7 月 28 日起向新西兰用户开放公开测试版。未来数月内，随着我们对核心功能的迭代和能力的扩展，Build 将逐步向更多地区的创作者推出。在测试期间，Build 将向通过年龄验证的 9 岁及以上用户开放。* 通过我们严格安全检查的已发布游戏，将面向全球通过年龄验证的 16 岁及以上用户开放。 在被添加到“Roblox Kids”或“精选”目录之前，通过Build创建的游戏将经历所有Roblox游戏都需遵循的扩展审核流程。它们还将加入与其他所有Roblox游戏相同的候选池，并由[基于用户留存率的发现系统](https://about.roblox.com/newsroom/2026/06/optimizing-discovery-great-games-reach-millions-players-roblox) 进行排名。Build的基础版本将免费向创作者开放，同时为高级用户提供额外的付费选项。


## Build 和 Studio 的未来规划


未来数月内，我们还将为专业创作者推出一套全新的工具套件。这些工具将在 Build 和 Studio 平台上提供，包括：


- 一款游戏测试代理，可在任何玩家体验游戏之前就发现漏洞
- 一个分析代理，允许创作者用自然语言提出关于游戏的任何问题，并获取洞察，而无需在仪表盘中费力查找
- 一个实验代理，可识别应运行的测试以提升用户参与度、留存率和变现能力


我们近期推出的程序化模型（Procedural Models）可根据文本提示或图像生成参数化 3D 资源。创作者只需设置参数即可重塑和优化模型，无需手动建模或重新生成。 此外，Roblox 的 3D 基础模型[Cube](https://about.roblox.com/newsroom/2026/02/accelerating-creation-powered-roblox-cube-foundation-model) 能够将提示语转化为可直接用于游戏的对象，从简单的道具到可驾驶的载具以及可射击的武器，无所不包。即将推出的全新场景生成模型将能够根据单条提示语，构建出完整的、可编辑且可游玩的 3D 场景。随着这些功能在未来数月内陆续上线，我们将分享更多相关信息。


这些更新共同推动 Roblox 比以往任何时候都更接近“你来制作游戏”这一愿景。让我们一起创作吧。
