# Product Round-Up

We made a number of updates in February focused on making the product easier to use, easier to manage, and more flexible to work in as projects grow.


Below is a summary of what’s new, what’s moved, and how these changes should improve day-to-day integration work.


### *Gemini Flash 3 is Now Live in the Build Agent*


**Gemini Flash 3** is now available inside the Build Agent, delivering significantly faster performance than Sonnet 4.5 — and outperforming it across many community coding benchmarks.


What this means in practice:


- Quicker responses
- Smoother iteration
- No compromise on output quality


Everything you want from a model upgrade, exactly when you need it.


‍


### *Search Through Tabs*


Finding the right tab shouldn’t slow you down.


You can now search across tabs and jump straight to what you need.


Can’t find something?
Open search.
Type your query.
Go there instantly.


Less scrolling. More building.


‍


### *Changes to Deploy*


We’ve improved Deploy to track differences between your deployed version and any saved changes.


Now when you:


- Deploy your integration
- Continue editing files


We automatically track what’s changed.


No more second-guessing before your next release. Just clean, confident iteration.


‍


### *Chat Deletion*


You can now delete chats inside the platform, giving you more control over your environment.


Remove stale conversations.
Tidy up your workspace.
Stay focused on what matters.


A cleaner experience, built for faster iteration.


‍


### *Logs Filtering: Now More Powerful*


You can now combine multiple filters in the Logs tab to include or exclude specific values.


That means:


- More control
- Faster debugging
- Cleaner workflows


Surface exactly what you need.


### *Connect Tab Vol. 2*


The Connect tab has had a focused redesign, improving usability while adding deeper visibility for teams managing integrations at scale.


New capabilities include:


- Track connection usage across projects and environments
- View deleted authentication methods
- Remove connections from connectors
- Delete connections universally


More visibility and less guesswork.
Built for teams running serious integration infrastructure.


### *Multiple Chat Support in Build*


The Build chat now supports multiple conversations.


Run parallel threads, test different approaches and keep context organised without losing momentum.


Built for teams that iterate fast.
