# Release Notes CodeNOW 7.6 – July 2024


Kubeconfig download for Kubernetes cluster access and other improvements.


## Kubernetes Cluster Access


CodeNOW introduced the ability to download Kubeconfig for Kubernetes clusters, enabling users to manage clusters directly from their preferred tools and command-line interfaces.


### Key Highlights:


-


**Seamless Connectivity** : Users can establish connections to Kubernetes clusters from their preferred management tools, streamlining operational workflows.


-


**Enhanced Flexibility** : The feature allows convenient cluster access according to individual preferences and organizational requirements.


-


**RBAC Integration** : Downloaded Kubeconfig reflects Role-Based Access Control settings configured within CodeNOW, "ensuring that users only have access to cluster resources and operations permitted by their roles" and enhancing security compliance.


## Bookmarks


A new personalization feature enables users to create shortcuts to frequently visited pages and deployed applications, accessible directly from the main menu.


### Key Benefits:


-


**Personalized Navigation** : Users can tailor their experience by bookmarking essential pages and links.


-


**Efficient Workflow** : Eliminates repeated searching by providing quick access to critical resources.


-


**Enhanced Accessibility** : Essential destinations remain instantly accessible without navigating multiple menus.


## External Services Usage Dashboard


The external services functionality received a dashboard upgrade providing comprehensive visibility into service utilization and template usage.


### Key Highlights:


-


**Detailed Usage Insights** : The dashboard displays comprehensive information about external service utilization.


-


**Enhanced Visibility** : Users gain "a clear and comprehensive view of all their external service integrations" for better tracking and troubleshooting.


-


**Improved Management** : Enhanced dashboard features empower more effective service management with intuitive access to statistics.


## Custom Domains Redesign


The Custom Domains feature underwent redesign to enhance flexibility and streamline routing rule management.


### Key Highlights:


-


**Centralized Routing Rule Management** : Routing rules configuration moved to the application dashboard for simplified management.


-


**Extended Routing Capabilities** : Users can now "route traffic from a single custom domain to multiple applications and their respective deployments."


-


**Dynamic Updates Without Redeployment** : Update routing rules without application redeployment, reducing downtime.


-


**Enhanced Flexibility** : Greater control over traffic management tailored to specific requirements.


## Permission Settings Enhancements


New permission configuration options provide greater flexibility and efficiency in managing access controls.


### Key Highlights:


-


**Bulk Permission Configuration** : Set permissions for multiple resources simultaneously, reducing configuration time.


-


**Multi-Identity Permission Setup** : Configure permissions for multiple identities on a single resource at once.


-


**Future-Proof Permission Assignments** : Set permissions "for an identity across all instances of a resource, including any future instances that may be created."


-


**Enhanced Flexibility and Control** : Greater customization options for organizational requirements.
