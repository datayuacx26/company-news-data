## DALL·E: Creating Images from Text


DALL·E is a 12-billion parameter version of[GPT-3](https://arxiv.org/abs/2005.14165) trained to generate images from text descriptions, using a dataset of text-image pairs. It has a diverse set of capabilities, including creating anthropomorphized versions of animals and objects, combining unrelated concepts in plausible ways, rendering text, and applying transformations to existing images.


**More details here:**[https://openai.com/blog/dall-e](https://openai.com/blog/dall-e/)


GPT-3 showed that language can be used to instruct a large neural network to perform a variety of text generation tasks.[Image GPT](https://openai.com/blog/image-gpt) showed that the same type of neural network can also be used to generate images with high fidelity. These findings are extended to show that manipulating visual concepts through language is now within reach.

## CLIP: Connecting Text and Images


Here’s a neural network called CLIP which efficiently learns visual concepts from natural language supervision. CLIP ( *Contrastive Language–Image Pre-training* ) can be applied to any visual classification benchmark by simply providing the names of the visual categories to be recognized, similar to the “zero-shot” capabilities of GPT-2 and 3.


**Blog:**[https://openai.com/blog/clip](https://openai.com/blog/clip/)
