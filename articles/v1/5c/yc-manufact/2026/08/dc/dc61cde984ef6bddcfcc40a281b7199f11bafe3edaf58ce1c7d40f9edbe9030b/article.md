# How to Distribute Your MCP Server Across ChatGPT, Claude, and Cursor

Publishing an MCP server in ChatGPT, Claude, and Cursor makes it available where users already work. Each channel has its own submission process and review requirements.


## Why marketplace distribution matters


Manual installation usually asks the user to paste a URL or edit a configuration file. A marketplace listing replaces that setup with a one-click connection.


App directories in ChatGPT, Claude, and Cursor.


## Progressive discovery


Claude uses progressive discovery to propose a connector when a request matches what it does, even before the user installs it. The user can connect from the conversation and continue the task.


Claude proposes relevant connectors inside the conversation before the user has installed them.


Progressive discovery makes listing content part of distribution. The connector name, description, categories, and tool definitions help the agent decide when it is relevant. If a competing connector is listed and yours is absent, the competitor can be proposed while your product cannot.


## Choose a submission path


The[ChatGPT publishing guide](https://manufact.com/blog/publish-mcp-app-on-chatgpt) covers OpenAI's current submission requirements and review workflow.


The[Claude Connectors Directory guide](https://manufact.com/blog/submit-mcp-server-to-anthropic-directory) covers the organization admin portal, automated community review, updates, and pre-submission checks.


Prepare reusable listing assets once: your description, logo, privacy policy, documentation, authentication instructions, and deployed MCP endpoint. Adapt them to each platform's form and review requirements.


## What about the Cursor Marketplace?


Cursor accepts plugin submissions through its[Marketplace publisher form](https://cursor.com/marketplace/publish) . The current process starts with a publisher application and continues through manual review. Cursor has not published an MCP-specific quality checklist or a predictable review timeline comparable to ChatGPT and Claude.


You can submit an MCP plugin today, but plan for a manual review and an uncertain turnaround. We will publish a standalone guide when Cursor offers a more mature self-serve process and documents its MCP quality standards.
