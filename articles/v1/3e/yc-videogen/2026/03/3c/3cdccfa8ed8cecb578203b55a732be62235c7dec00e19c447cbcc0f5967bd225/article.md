# VideoGen 3.3: Collaborative Editing, Visual Styles, and Script Regeneration


VideoGen 3.3 is now live with real-time collaboration, more control over script-to-video creation, and smoother project production for teams.


VideoGen 3.3 is now live, bringing collaboration and more creative control into the video creation workflow.


This release is focused on a common challenge for growing teams: video work often starts with AI, but finishing the project still requires feedback, iteration, and handoff between multiple people. VideoGen 3.3 makes that process easier by letting teams work together in the same project and refine script-to-video outputs with more control.


## Collaboration Comes to VideoGen


Teams can now edit projects together in real time. That means marketers, creators, editors, and collaborators can review and update the same video without sending separate project files or waiting for one person to finish before another starts.


## More Control from the First Draft


VideoGen 3.3 also improves script-to-video creation with visual styles and script regeneration. Users can guide the look of a generated video earlier in the process, then revise the script without starting over.


Behind the scenes, the release also improves reliability across uploads, previews, transcription, exports, and editing basics.
