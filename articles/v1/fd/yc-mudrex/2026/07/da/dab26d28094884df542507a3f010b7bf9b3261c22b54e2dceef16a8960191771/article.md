# Mudrex is Now Integrated Into CCXT: The World’s Leading Open-Source Crypto Trading Library

Mudrex is now natively integrated into CCXT (CryptoCurrency eXchange Trading Library), live as of version 4.5.64. Any developer, trading bot, or algo platform built on CCXT can now connect to Mudrex simply by selecting it from the exchange list; no bespoke integration work required.


CCXT is used by developers and trading platforms worldwide, and is widely considered the industry standard for programmatic exchange connectivity.


## What is CCXT?


CCXT is an open-source library that gives developers a single, unified way to connect to crypto exchanges; instead of writing custom integration code for every exchange they want to support. It currently supports 100+ exchanges across multiple programming languages, including Python, JavaScript/TypeScript, C#, PHP, Go, and Java. For quant traders, algo-trading platforms, and bot builders, CCXT is often the default layer they build on top of.


## Why Did We Do This?


Mudrex has been building for a more serious, programmatic segment of traders; people and platforms that don’t just want an app to trade on, but infrastructure they can build with. Being part of CCXT is a direct extension of that.


It puts Mudrex in the same catalogue as major global exchanges, and is indicative of a level of technical maturity that matters to a developer and quant audience. But the more important part is what it unlocks: algo-trading platforms, trading bots, and portfolio-management tools that already speak CCXT can now plug into Mudrex out of the box.


That lowers the barrier significantly for anyone building automated or programmatic strategies to start using Mudrex.


## What This Means for Developers and Traders


If you’re building with CCXT, connecting to Mudrex now works the same way as connecting to any other supported exchangel in whichever language your stack uses.


This opens up practical use cases such as:


- **Trading bots** that execute strategies on Mudrex without custom API wrappers
- **Portfolio and tracking tools** that pull Mudrex data alongside other exchanges in one place
- **Quant strategies** that can be backtested and deployed across exchanges, Mudrex included, with minimal rework


Essentially, if your tooling already speaks CCXT, it now speaks Mudrex too.


## Our Commitment


This isn’t a one-time integration. We’ll continue to actively maintain our CCXT contribution as Mudrex evolves: new features, new markets, and new capabilities will be reflected here, so the integration stays reliable for anyone building on top of it.


## What’s Next?


If you’re a developer, quant, or algo-trading platform, this is a good time to explore what building on Mudrex via CCXT looks like. We’re glad to be part of this ecosystem, and there’s more to come as we keep investing in the infrastructure side of Mudrex.
