# Flow Release Notes | Version 3.9.2

improved


This release notes contains updates related to **UPI Collections v3** products.


##


UPI Collections v3


**Release date -** 12-06-2026


**Enhancements** - Payment Link Experience Enhancement - Android


We've enhanced the Payment Link experience to improve compatibility across Android devices and browsers.


**What's changing?**


- Added a new "Any UPI App" CTA on the payment page.
- In scenarios where Android browsers redirect intent links to Chrome instead of directly opening a UPI application, customers can now use this CTA to seamlessly continue their payment using any installed UPI app.


**Benefits**


- Improved payment experience across Android devices and OEM browsers.
- Reduced instances of users getting stuck during the UPI redirection flow.
- Better payment completion rates through an additional fallback payment option.


No integration changes are required from merchants. The enhancement will be available automatically on the hosted payment page experience.
