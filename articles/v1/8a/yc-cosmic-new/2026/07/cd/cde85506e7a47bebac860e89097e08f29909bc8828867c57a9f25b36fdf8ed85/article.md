# Introducing Learn Cosmic: A Hands-On Learning Hub for Agentic Workflows

Today we're launching[Learn Cosmic](https://www.cosmicjs.com/learn) : a hands-on learning hub for developers and content teams who want to run agentic workflows in production.


This is not documentation. Docs cover the API, the SDK, the schema. Learn Cosmic teaches you *how to operate* : how to build an AI agent team, connect your tools via MCP, ship a production site, chain agents in a workflow, and measure what's working. Thirteen lessons across five stages, in the order that actually makes sense.


## Why we built it


The most common thing we hear from teams getting started with Cosmic is that the concepts click quickly, but the jump from "I understand how this works" to "I have this running in production" is steeper than it looks. You need to know how to structure your content model, how to wire your frontend, how to give your agents the right context, and how to read the data afterward.


Learn Cosmic covers that entire arc. Each lesson is scoped to one idea, with a concrete action you take in your own account so you leave with something real, not just notes.


## The five stages


### Stage 1: Agentic Workflows


Start here if you want to understand how Cosmic fits into an AI-first team. Three lessons cover the core patterns:


- **[Build an AI Agent Team That Ships Content](https://www.cosmicjs.com/learn/build-ai-agent-team-that-ships-content)** — the three-agent content team pattern: Researcher, Writer, Publisher. How to give each agent a role, a goal, and the right context.
- **[Connect Cosmic to Cursor / Claude Code with MCP](https://www.cosmicjs.com/learn/connect-cosmic-to-cursor-claude-code-with-mcp)** — wire Cosmic's MCP server into your coding environment so your AI tools can read and write content directly.
- **[Publish Content from Slack with an AI Agent](https://www.cosmicjs.com/learn/publish-content-from-slack-with-an-ai-agent)** — build a Slack-to-CMS publishing pipeline so your team can ship content without leaving the tools they already use.


### Stage 2: Building with Cosmic


The foundation: content modeling and frontend delivery.


- **[Model Your Content: Metafields and Schema](https://www.cosmicjs.com/learn/model-your-content-metafields-and-schema)** — design an Object Type that matches how your content actually works.
- **[Ship a Site on Cosmic with Next.js](https://www.cosmicjs.com/learn/ship-a-site-on-cosmic-with-nextjs)** — fetch and render Cosmic content in a Next.js app, from bucket setup to production deployment.
- **[Ship a Site on Cosmic with Astro](https://www.cosmicjs.com/learn/ship-a-site-on-cosmic-with-astro)** — the same production-ready pattern for Astro, including static generation and image optimization.


### Stage 3: Integrations and Data


Connect Cosmic to the rest of your stack.


- **[Migrate from WordPress or Webflow](https://www.cosmicjs.com/learn/migrate-from-wordpress-or-webflow)** — a practical migration walkthrough: export, map, import, redirect.
- **[REST API Integrations and Webhooks](https://www.cosmicjs.com/learn/rest-api-integrations-and-webhooks)** — trigger external services on content events, and pull data into Cosmic from anywhere.


### Stage 4: Agents and Automation


Where it gets powerful. Build systems that run themselves.


- **[Chain Agents in a Workflow](https://www.cosmicjs.com/learn/chain-agents-in-a-workflow)** — pass output from one agent to the next. Researcher hands off to Writer, Writer hands off to Publisher.
- **[Scheduled and Event-Triggered Workflows](https://www.cosmicjs.com/learn/scheduled-and-event-triggered-workflows)** — set agents to run on a cron or fire on a content event, so your workflows run without a human kicking them off.
- **[Read Your Growth Data with Cosmic Insights](https://www.cosmicjs.com/learn/read-your-growth-data-with-cosmic-insights)** — close the feedback loop. Your agents write content; Insights tells you what's working. Read the data, adjust the plan, ship again.


### Stage 5: Team and Scale


Operating Cosmic at team scale.


- **[Team Roles, Seats, and Permissions](https://www.cosmicjs.com/learn/team-roles-seats-and-permissions)** — manage who can do what. Roles, API key scoping, seat limits across plans.
- **[Localization and Publishing Operations](https://www.cosmicjs.com/learn/localization-and-publishing-operations)** — serve content in multiple languages, schedule publishes, and run an editorial operation across regions.


## The feedback loop is the point


Every stage connects to the next. You model your content so your agents have structured data to work with. Your agents write and ship.[Cosmic Insights](https://www.cosmicjs.com/insights) measures what performs. You read the results and give your agents better goals. The loop runs again.


That closed loop, write, ship, measure, learn, is what separates a content team that compounds from one that just publishes and hopes.
