# Kimi K3 Is Now Available in Cosmic

Kimi K3 is now available in Cosmic, both in the dashboard and via the API. Select it from the model dropdown in your Agent or AI settings, or pass as the model parameter in any AI text generation call.


## What Is Kimi K3?


[Kimi K3](https://platform.kimi.ai/docs/guide/kimi-k3-quickstart) is Moonshot AI's latest open-source frontier model, designed for complex reasoning, coding, and long-context tasks. It joins Cosmic's growing roster of supported models alongside Claude, Gemini, and GPT, giving your team more flexibility to route tasks to the right model for the job.


## Use It in the Dashboard


Head to your Agent or AI settings inside the Cosmic dashboard and select *Kimi K3* from the model dropdown. No configuration, no API calls required. Pick it and start generating.


## Use It via the API and SDK


Cosmic's AI text generation endpoint accepts a parameter. Pass to route your request through Kimi K3. A bucket write key is required for all AI operations.

## Why Model Choice Matters


Different tasks call for different models. You might route long-form reasoning to Kimi K3, rapid generation to a fast Gemini Flash model, and complex editorial work to Claude Opus. Cosmic's model-agnostic API means you can route each task to the best available model without changing your content infrastructure.


The content stays in Cosmic. The model is a parameter.
