# Lately @ Lucid: What’s new for spring 2026

We recently finished our Lately @ Lucid webinar series, where we showcased our latest and greatest features, all intended to help you quickly create visual documentation and accelerate major initiatives at your company, from faster product delivery to AI transformation.


In case you missed it, here’s what’s new in Lucid!


## Lucid AI enhancements


### Enhanced diagram creation


We’ve expanded diagram creation with Lucid AI to include flowcharts with swimlanes and more advanced style options.[Assisted layout](https://help.lucid.co/hc/en-us/articles/34727996594324-Use-assisted-layout-to-organize-content-in-Lucid) will automatically be applied to AI-generated diagrams, making it easy to move shapes into drop zones, adjust spacing, and swap shapes.


Plus, now you can provide Lucid AI with additional context to get better outputs by uploading video files or documents to your prompts or by using voice-to-text to describe what you’re looking for.

## MCP server


The Lucid MCP server connects Lucid with large language models (LLMs) so that you can bring the power of visual collaboration to your AI ecosystems. This means that you can create diagrams, search your existing Lucid library, and create share links without ever breaking your flow or leaving your AI tool.


You can also create a basic “Edit document” API so you can describe changes you’d like to make to a specific document within an LLM and have Lucid AI make those edits automatically.

## Process Agent


Lucid’s[Process Agent](https://help.lucid.co/hc/en-us/articles/46461638983316-Use-Lucid-AI-s-Process-Agent-to-build-complex-diagrams-faster?_gl=1%2Almqqcq%2A_gcl_aw%2AR0NMLjE3NzQyODU2OTYuQ2p3S0NBand5WVBPQmhCeEVpd0FncFQ4UHdnSjZlMzZaQTg2ZGZpSUdPdWxCZ1R4YU1UX283ZVZiZnIyXzc1YUwwN2o0M1otcGVfRFFSb0NXdFVRQXZEX0J3RQ..%2A_gcl_au%2AMTkxOTk2NDg2LjE3NzA5MjI5MzA.&anonId=0.bdb672319a7f9389f1&sessionDate=2026-04-29T20%3A17%3A17.330Z&sessionId=0.16739af919ddae367bd) , a guided creation experience within the Lucid AI chat panel, acts as an AI coworker that helps you develop high-integrity documentation. Alongside a generated diagram, the Process Agent will provide a new context frame, summary, description, and key highly specific to your prompt to ensure the process output is as accurate as possible.

### Context frame


Add documents to a[context frame](https://help.lucid.co/hc/en-us/articles/46461638983316-Use-Lucid-AI-s-Process-Agent-to-build-complex-diagrams-faster#process-context-frame) , and the Process Agent will then reference that context in all conversations with all users who enter the canvas, providing a log of decisions made so all contributors understand the output. Plus, when changes are made, the same considerations will be taken into account.


### Diagram evaluation


Prompt the Process Agent to analyze your diagram and offer intelligent suggestions for improvement by leaving comments. Essentially, this capability is like having a peer review from AI that has seen many industry-standard workflows.


### Process Capture


Coming soon, you’ll be able to screen capture walking through a process, then provide the screen capture to the Process Agent to generate a process diagram.


## Process Accelerator enhancements


The[Process Accelerator](https://lucid.co/enterprise/process-accelerator) can be added to Lucid Enterprise accounts to improve governance and standardization of process documentation, storage, and maintenance.


### Version history


Within the Process Accelerator, you can now view[version history](https://help.lucid.co/hc/en-us/articles/38403744863124-Use-repositories-to-centralize-and-standardize-your-organization-s-documentation#view-repository-document-version-history) and compare the published version of a document to any previous version to understand changes over time, spot meaningful differences, and assess impact. Toggle between versions for fast, intuitive access to historical processes.


### Restricted repositories


Create[restricted repositorie](https://help.lucid.co/hc/en-us/articles/38403744863124-Use-repositories-to-centralize-and-standardize-your-organization-s-documentation#restricted-repositories) s that are invite-only, allowing your teams to store and organize even the most confidential documentation.


### Folder owner roles and sequential approval flows


Repository owners can now[assign folder approvers](https://help.lucid.co/hc/en-us/articles/38403744863124-Use-repositories-to-centralize-and-standardize-your-organization-s-documentation) to approve documents within a specific repository folder. These assignments route reviews to the right stakeholders and reduce unnecessary notifications for repository owners.


You can also enable bottom-up, sequential approval flows, meaning after a process owner signs off, the approval request will be sent to the subfolder or folder owner, and then the repository owner. If a process is denied at any tier, you will need to address concerns and go back to the beginning of the approval flow.


### Object assets


Accelerator managers and repository owners can create standardized, reusable objects with predefined data structures that all users can then drag and drop from the[asset library](https://help.lucid.co/hc/en-us/articles/38403833941908-Use-the-asset-library-to-maintain-documentation-consistency) . The predefined object types include department, role, activity, IT system, document, risk, and control.


An example of using the object asset library within the Process Accelerator


Create standardized object assets within the Process Accelerator.


Coming soon, accelerator managers and repository owners will be able to create their own reusable elements with custom data fields, such as region, product, and compliance tier, to model what matters most to their business.


## Enterprise architecture integration enhancements


Coming soon, using the Process Accelerator and improved integrations for[Ardoq](https://lucid.co/marketplace/8836527a/ardoq) and[LeanIX](https://lucid.co/marketplace/94125ade/sap-lean-ix) , you’ll be able to import data items from your enterprise architecture tools into Lucid documents and create enterprise-architecture-specific shapes for building diagrams. You’ll be able to manually update those shapes when there are updates in Ardoq or LeanIX. Eventually, you will also be able to convert data items into reusable object assets.


## Enhanced planning


[Capacity planning and scenario planning](https://help.lucid.co/hc/en-us/articles/35599195843604-Manage-team-workload-with-enhanced-planning) are now available within the Lucid Visual Collaboration Suite.


With capacity planning, you can visualize your team’s workload using story point capacities. Manually set the capacity for an individual, team, sprint, etc., and the story point totals will automatically be calculated from the cards.
