### Lucid governs documentation to guide execution


When implementing AI at scale, documentation becomes infrastructure, functioning as the context that AI agents need to integrate safely into workflows.


Unlike static process diagrams, Lucid allows you to connect your process documentation to architecture documentation, so it’s clear what systems AI interacts with to complete tasks. If, for example, you’re implementing an agent to automatically process customer refunds, it won’t just read a policy document; it will need live access to your CRM (to verify order history), payment gateway (to issue the credit), and inventory management system (to update stock levels).


Using integrations to[leading enterprise architecture platforms](https://lucid.co/marketplace/enterprise-architecture) , teams can embed LeanIX and Ardoq objects directly into their process diagrams with Lucid's Process Accelerator. These shapes carry the full enterprise architecture data and remain synced with their system of record.


When the documentation is final, you can use the process maps you create in Lucid as direct operating parameters for AI agents. Through the[Lucid Model Context Protocol (MCP) server](https://lucid.co/blog/lucid-mcp-server) , you can use natural language to search, retrieve, edit, summarize, or take action on Lucid documents within your AI tool of choice, including Claude, ChatGPT, Microsoft Copilot, and more. For example, the MCP server can read a Lucid diagram and create Jira Cards based on the tasks shown in a workflow.


You can add another layer of governance by using the[Lucid repositories MCP server](https://help.lucid.co/hc/en-us/articles/50889900701460-Integrate-Lucid-with-AI-tools-using-the-Lucid-repositories-MCP-server) , part of the Process Accelerator. With the Lucid repositories MCP server, AI tools can only access and act on Lucid documentation stored in your approved company repositories. By limiting access to verified enterprise context, you can be confident that AI tools won’t accidentally reference outdated drafts, personal notes, or unapproved workarounds.


Use the MCP server to interact with your Lucid documents directly from the AI tool of your choice and create the foundation for AI agents.
