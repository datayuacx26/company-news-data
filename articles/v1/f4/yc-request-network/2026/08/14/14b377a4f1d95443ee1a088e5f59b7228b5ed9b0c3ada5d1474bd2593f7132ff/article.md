# Request Network Integrates Safe to Bring Multi-Signature Approvals and Mass Payouts Onchain


Organizations enforcing enterprise-grade security using Safe Smart Accounts can now set approval rules, and batch multi-chain stablecoin payments.


Request Network


August 11, 2026


**Zug, Switzerland 11/08/2026.** Request Network today announced it’s integration with Safe, enabling businesses, DAOs, and NGOs to manage multi-signature stablecoin payments directly within the Request Network protocol.


Managing corporate treasury payouts onchain often involves manual offchain coordination, manual approval tracking, and repetitive transaction signing. By combining Request Network’s payment protocol with Safe Smart Accounts, organizations can now embed custom approval workflows directly into their payment pipelines.


With this integration, finance teams can configure precise signer thresholds, route incoming and outgoing transactions through a unified Safe wallet, and enforce compliance before any funds move.


**Key Capabilities Include:**


- **Automated Approval Workflows:** Set required signer thresholds for every outgoing transaction.
- **One-Click Mass Payouts:** Authorize batched stablecoin distributions across both single-chain and cross-chain destinations with a single Safe multi-sig approval.

## Tristan Wallaert, CEO of the Request Network Foundation, said:


> “Managing multi-sig approvals for recurring operational expenses used to mean constant back-and-forth between spreadsheets and signers. By natively pairing Request Network with Safe, we’re giving finance teams the speed of stablecoins alongside the rigorous internal controls required by enterprise treasuries.”


## Rahul Rumalla, CEO of Safe Labs, said:


> “Request Network’s growth in crypto-native payroll makes this a natural integration, and with Safe being the standard for enterprise treasury management, pairing it with the Safe API is a no brainer. Treasury managers can simply connect their Safes and run stablecoin distributions while signing in the familiar Safe{Wallet} interface.”


## **About Request Network**


Since 2017, Request Network has developed, educated about, and promoted the use of open-source, decentralized and permissionless protocols that provide infrastructure for on-chain payments and related financial flows.


Request Network allows anyone to send and receive crypto at scale, across chains, without custodial intermediaries. The protocol is developed by a community-funded foundation whose mission is to make crypto payments accessible while protecting its participants.


To date, more than $2 billion has moved thanks to Request Network technology.
