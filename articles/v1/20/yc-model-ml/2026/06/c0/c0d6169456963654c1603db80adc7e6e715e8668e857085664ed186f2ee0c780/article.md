# Model ML for Wealth Management

Model ML supports Wealth Managers across the full client lifecycle, from the first prospect to a growing portfolio and deepening a relationship with a client.


In practice, that means:


-


**Prospect:** Model ML sources a ranked set of prospects directly from your network and recommends who to call first based upon customised parameters.


-


**Win:** Generate a pitch-book in a few clicks, or pull a client summary ahead of any meeting so you know exactly who you're sitting down with.


-


**Onboard:** Run KYC and Source of Wealth tasks that pulls data from internal and external sources to build a robust profile of the target client, reducing risk and accelerating the process.


-


**Advise:** As the relationship progresses, Model ML drafts the investment proposal itself, built from the client's profile, objectives, and market views.


-


**Grow:** When something changes in a client's world, Model ML flags it and builds client-ready materials for advisors, so they can act on new information rather than finding out about it later.


The work behind every client relationship happens faster, freeing up time for the client rather than the prep.
