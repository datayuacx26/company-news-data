# The Benefits of Single Path Coding & How TruBridge Can Help

Single path coding, also called Dual Coding, is a unified approach to medical coding where one coder performs both the facility coding and the professional coding for the same patient encounter within the same workflow.


Traditionally, hospitals and health systems rely on two separate coding teams: one focused on the technical component (facility coding) and another focused on the professional component (physician or QHP services). In a single path coding model, those responsibilities are combined into a single role known as a single path coder.


This integrated process eliminates duplicate work, improves consistency across claims, and allows for faster and more accurate billing. By having one coding professional manage both parts of the encounter, organizations can reduce costs, improve charge capture, and strengthen alignment between clinical and financial documentation.
