# Markdown and more

### **Release: Markdown support**


Now you can easily type text that looks like **this** *, or this, or* even this *.* You could do that before in the style panel, but now you can easily type it as well.


We now automatically parse markdown on paste. Use` Command/Ctrl + Shift + V` to paste as plain text if you prefer. It’s a big quality-of-life update if you find yourself bouncing between Loops and an external CMS.

### **Updates**


**SOC 2 audit complete**


We wrapped our SOC 2 audit and updated our trust portal with reports. If you’re evaluating vendors, this should make security reviews and procurement faster. We also have a public DPA and we are also listed in the DPF directory.


**Idempotency keys**


Protect against duplicate sends on retries and network hiccups. Include an idempotency key with your API calls so the same request is processed once, even if you try again, resulting in safer sends at scale.


**CC and BCC options added**


BCC and CC options are now available and able to be flipped on in the Settings (Settings → Tracking). You can now create mini-alert system by BCC’ing or CC’ing yourself on critical emails that go out.


**Editor additions**


We added a new vertical alignment in columns along with the ability to hit Cmd/Ctrl+ to duplicate blocks.
