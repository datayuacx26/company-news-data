# LLM Translation

### LLM translation


Translation is now available in the Loop Builder. Create your Loop as you typically would, then click a target language to generate a translated branch next to it.


We also handle specific use cases like retaining your UTM parameters during translation, and dynamic data that you may not want translated. There is no additional charge for translations on Loops.


Translations run through a GPT-5 flavor and are still in beta, so please review before sending.


[Read more](https://loops.so/docs/creating-emails/translating-emails-with-ai#translating-emails)


### Automatic events for incoming webhooks


After setting up an integration with Stripe, Supabase, or Clerk, you will automatically see enabled events flow in without any additional setup on your part. Now you can kick off complex behavioral loops in just a few clicks.


[Read more](https://loops.so/docs/integrations/incoming-webhooks#supported-platforms)


### Converging paths


Converging paths are now available, so experiments and branches can now merge back into a single path after they have been added to a Loop.


Before this, once you branched, you couldn’t extend the Loop on one unified path. This change makes more complex and nuanced loops possible for your team.


[Read more](https://loops.so/docs/loop-builder/branching-loops#converging-branches)
