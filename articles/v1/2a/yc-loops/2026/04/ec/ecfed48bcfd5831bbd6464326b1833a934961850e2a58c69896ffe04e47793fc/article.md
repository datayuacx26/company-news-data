# DNS zone file generation

Zone Files reduces some of the manual work around sending domain setup. You can now export a zone file from the domain records page, and the domain records page can be shared publicly to make DNS setup easier to review and troubleshoot.


You can now download the file for a domain, send the developer email with the DMARC record included, or share the public records page when you need someone else to help get the domain configured. If you need the setup steps or a DNS primer while you work through propagation, use[https://loops.so/docs/sending-domain](https://loops.so/docs/sending-domain) and[https://loops.so/docs/guides/what-is-dns](https://loops.so/docs/guides/what-is-dns) .
