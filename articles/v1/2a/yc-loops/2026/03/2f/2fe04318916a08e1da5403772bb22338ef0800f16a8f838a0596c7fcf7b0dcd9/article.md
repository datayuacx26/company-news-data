# New Stripe Events | Loops

Loops now supports a broader set of Stripe triggers across quotes, subscriptions, and async checkout outcomes. That means you can connect more billing moments to lifecycle messaging instead of waiting for a narrow set of checkout-only events.


For example, you can now send a follow-up when a quote is accepted, start onboarding when a subscription is created, or confirm a purchase when an async checkout payment succeeds. If you want to wire these flows up, start with the[Stripe Integration](https://loops.so/docs/integrations/stripe) .
