# Kimi K2.5 Now Available in BrowserOS — Extended Usage for 2 Weeks

We are excited to announce that **Kimi K2.5 by Moonshot AI** is now available as an AI provider in BrowserOS. Starting today, BrowserOS users can enjoy **extended usage limits** powered by Kimi K2.5 for the next two weeks.


Kimi K2.5 is an open-source, multimodal model with excellent agentic performance — and it is significantly more cost-effective than many other frontier models. We have tested it internally and BrowserOS works great with Kimi K2.5, especially for agent tasks like web browsing, form filling, and multi-step workflows.


## What this means for you


For the next two weeks, BrowserOS is providing extended usage of Kimi K2.5 to all users. This means you can use the BrowserOS AI agent, chat, and other AI-powered features with increased limits — all powered by Kimi K2.5 from Moonshot AI.


Kimi K2.5 is now the **recommended model** in BrowserOS and is set as the default provider. You will see a *"Powered by Kimi K2.5 from Moonshot AI"* badge in the LLM Providers settings.


## Bring your own Kimi API key


You can also bring your own Kimi API key if you want to use Kimi K2.5 beyond the extended usage period, or if you want your own dedicated limits. Here is how to get started:


How to get a Kimi API key


1. Go to[platform.moonshot.ai](https://platform.moonshot.ai/) and create an account
2. Navigate to the API keys section in your dashboard
3. Click "Create new API key" and copy the key


How to configure Kimi K2.5 in BrowserOS


1. Open BrowserOS and go to **Settings → BrowserOS AI** (or` chrome://browseros/settings` )
2. Under **Quick provider templates** , click **"USE"** next to **Moonshot AI**
3. Enter your API key — it will be encrypted and stored locally on your machine
4. The model is pre-configured to` kimi-k2.5` with a 256,000 context window
5. Click **Save** and you are ready to go


The base URL for the Kimi API is` https://api.moonshot.ai/v1` . BrowserOS pre-fills this automatically when you select the Moonshot AI provider template.


## Why Kimi K2.5?


Kimi K2.5 offers excellent performance for agentic tasks at a fraction of the cost of other frontier models. It supports images, has a 256,000 token context window, and delivers strong results on browser automation tasks. Combined with BrowserOS's open-source agent framework, this makes for a powerful and affordable AI browsing experience.
