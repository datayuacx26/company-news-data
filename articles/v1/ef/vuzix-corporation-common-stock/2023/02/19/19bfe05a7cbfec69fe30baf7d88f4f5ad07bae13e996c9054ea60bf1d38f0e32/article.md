# Android 11 is Here - What You Need to Know

Our entire enterprise fleet of Vuzix smart glasses are now fully operating on Android 11. This major update to the M series OS enables a variety of key benefits, some of the most notable being a more secure platform, improved user experience, easier integration with a variety of Mobile Device Management (MDM) software packages, and enablement of advanced android features within third party apps. If your team uses Vuzix M series devices, you do not want to miss out on the new OS and can find instructions for easy updating below. ****


**Improved Security Allows for Ease of Use**


Rolling out Android 11 across our devices allows for a significant increase in security and peace of mind for our enterprise customers. The latest operating system allows users to stay up to date with security patches and Android security updates. Android 11 adds the ability to connect to the WPA3 Wi-Fi protocol, the latest standard in Wi-Fi security, with all products supporting 2.4 and 5ghz frequencies. Use your smart glasses with confidence, knowing that you are operating on a secure platform.


**Updates to the User Interface**


Vuzix is continuously striving to offer our smart glasses users the best user experience in the market. As a direct response to extensive user feedback sessions, the Android 11 OS update = increases ease of use by using voice for streamlined navigation and control selections on the interface. In addition, system icons have been revamped to make it easier to differentiate and discern in any condition. These are only a few examples of how the updated OS offers a more streamlined, highly efficient user experience based on real-world needs.


**Better Device Management for Admin**


Another key feature of the latest update is the improved management of devices configurable across a variety of Mobile Device Management (MDM) software platforms. Such improvements enable enterprise-ready security and performance. Admin can enroll new devices into their platforms with ease, as Android 11 is compatible with a broader set of MDMs, including Microsoft InTune, Workspace One, and many more. This allows for IT departments to easily and quickly configure Vuzix devices, manage compliance, view all hardware properties, and much more; giving enterprise-level companies the security they need to feel safe onboarding potentially large quantities of glasses in a streamlined fashion and manage from one central location.


**How to Update Your Device Now**


Users will automatically be prompted to update the device upon connecting to Wi-Fi. By clicking ‘update now’, the download process will automatically start and then prompt the user when to install the update (the device will reboot during this process). By clicking ‘postpone’, this allows for the user to start the update process at a time most convenient to them. Simply navigate to Settings > System > OTA system update and click ‘Check server for updates now’ to initiate the process.


For users already integrated with an MDM platform, the process is even easier. Once your system administrator verifies the new release, they simply need to push the update through the MDM, and the device will automatically update without any user interaction.


Any questions regarding updating your device, contact[support@vuzix.com](https://web.archive.org/web/20250808163133/mailto:support@vuzix.com) .
