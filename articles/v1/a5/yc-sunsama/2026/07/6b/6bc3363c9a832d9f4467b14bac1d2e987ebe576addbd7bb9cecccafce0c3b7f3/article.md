Added:


- macOS desktop app settings shortcut


: You can now open Settings directly from the Sunsama desktop app menu on macOS with CMD ,


(command comma)
- More supported deep links in task notes


: Task notes now accept links from more apps, including Shortcuts, Logseq, Notion, Craft, Raycast, Zotero, Linear, Figma, VS Code, JetBrains, Discord, Telegram, and Spotify.
- More task details exposed in MCP


: Sunsama's MCP server now returns more information with tasks — when a task was created, when it was last modified, the exact moment it was completed, and its due date — so AI assistants can reason about task age, recency, and deadlines.


Fixed:


- Focus bar progress visibility


: The green progress sliver that appears when you start a task's timer was too small to actually notice, especially in dark mode.
- Archive panel showing tasks that shouldn't be there


: Fixed a bug that could leave certain completed tasks incorrectly stuck showing in the Archive panel.
