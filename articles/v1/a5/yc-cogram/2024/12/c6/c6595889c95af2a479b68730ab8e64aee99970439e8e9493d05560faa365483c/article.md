# Introducing Multiple Templates, Improved Projects, and AI-Assisted Bidding

## Templates: Export Minutes in Multiple Templates


Cogram has expanded its Templates feature for exporting meeting minutes. The platform now enables professionals to set up custom templates for on-site field reports, design meetings, OAC meetings, or create project-specific templates.


Users can access this functionality by opening a meeting and clicking "Download." A new Default Cogram Template is available for users getting started, with the option to upload custom templates by contactingsupport@cogram.com .


## Improvements to Cogram's Meeting Page: Review and Edit Notes Easily


The meeting review interface now offers enhanced functionality. Users can view transcripts alongside Cogram's notes by clicking the Transcript option in the right sidebar for verification purposes.


A new Search and Replace feature allows users to instantly make changes across the entire meeting for correcting transcription errors or updating names.


## Projects: Create and Manage Projects Easily


The Projects feature has received several updates. Users can now configure separate rules for meetings and email threads with automatic assignment based on keywords or participants. Once configured, colleagues can be invited to access, export, and add their own notes.


## Looking Ahead: AI-assisted proposals and RFP review


Cogram is developing AI-powered tools for RFP processing that automatically extract key details including scope and evaluation criteria, then propose bidding strategies. The system will draft a project proposal within minutes, using your firm's portfolio and internal knowledge base for tailored responses.
