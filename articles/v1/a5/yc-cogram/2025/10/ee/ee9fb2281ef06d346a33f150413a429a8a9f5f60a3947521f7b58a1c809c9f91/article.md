# Build Week 6: Cogram Agent, Webex, Procore Integrations, and Global Search

## Overview


Between September 15 and October 17, 2025, we released 123 improvements to help architects, engineers, and builders improve project documentation and cut admin workloads.


## AI Assistant for AEC: SharePoint Integration, Web Browsing, and Firm-Level Control


### What's New


- **SharePoint integration:** Users can search their Microsoft 365 tenant and work with files directly from the Assistant
- **Web browsing:** The ability to pull current data from manufacturer pages, codes, and advisories
- **Organizational controls:** Firms can set Assistant behaviors to control tone, templates, and best practices


### Example Prompts


- "Find the latest structural sketch in SharePoint for Project (ID: ...) and summarize open questions from yesterday's meeting."
- "Scan this manufacturer page and extract facade mock-up specs into our template."


## Meeting Minutes for Webex


Cogram expanded automatic meeting minutes support to include Webex, joining existing platforms like Microsoft Teams, Zoom, and Google Meet. The feature generates detailed meeting minutes using custom firm templates.


## Procore Integration: RFIs & Submittals


Key features include:


- Automatic, reliable synchronization of RFIs and Submittals between Procore and Cogram
- Status tracking for RFIs and Submittals
- Direct access to RFI and Submittal file attachments within Cogram


## Global Search (Ctrl+K)


A unified search function allowing users to find projects, meetings, reports, observations, and emails from a single interface.


## Project Management & Core UX Improvements


- Admin dashboard for project management
- Smarter member suggestions when adding project teams
- Drawings embedded in Site Reports with Reports as first-class navigation items
- Consistent filters and delete patterns across meetings, emails, and reports
- Assistant UI refinements for improved readability
