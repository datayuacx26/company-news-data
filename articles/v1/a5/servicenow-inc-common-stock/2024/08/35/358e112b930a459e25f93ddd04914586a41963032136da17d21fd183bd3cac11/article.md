# Migrating from the Legacy Service Bridge Applications to Version 2.x (August 2024) and Beyond

The[August 2024 release of Service Bridge](https://docs.servicenow.com/bundle/xanadu-service-bridge/page/product/tmt-service-bridge/concept/tmt-service-bridge-both-landing-page.html) introduces a new set of features including Service Bridge configuration versioning, support for mismatched provider-consumer application versions, and introducing consumer flows for Remote Catalog Items. Even more reasons to migrate from legacy Service Bridge to the most current release! However, as you are planning your migration **please consider the following** ...


In a[previous community article](https://www.servicenow.com/community/technology-blog/migrating-from-the-legacy-service-bridge-applications/ba-p/2755812) we describe using the[Service Bridge for Providers (Legacy) Migration Tool](https://support.servicenow.com/kb?id=kb_article_view&sysparm_article=KB1499823) to migrate from legacy Service Bridge, but this migration tool supports migration to Service Bridge application version 1.x. The August 2024 release of Service Bridge is the first application version **2.x** release, and the migration tool **will not** support migration from Service Bridge for Providers (Legacy) to the the new 2.x version or beyond.


If you are planning to migrate from Service Bridge for Providers (Legacy) to the most current 2.x release you should first use the[Migration Tool](https://support.servicenow.com/kb?id=kb_article_view&sysparm_article=KB1499823) to migrate to Service Bridge version 1.x. After successfully migrating the Service Bridge configurations from Legacy to 1.x, then you can visit the App Store and update Service Bridge from the 1.x version to the newly released 2.x version and take advantage of the great new Service Bridge features.
