# Service Bridge v2.1: February25 Store Release

Following the release of the February25 Store on January 30th, we will provide detailed posts over the coming weeks highlighting each of the new Service Bridge features.


1. [Publish catalog items as remote record producers](https://www.servicenow.com/community/technology-blog/service-bridge-v2-1-february25-store-release-publish-catalog/ba-p/3152692) - As a provider, you can copy and publish your local catalog items to


Service Bridge


as remote record producers (RRP). **- *Article Posted***


2. [Add consumer variables](https://www.servicenow.com/community/technology-blog/service-bridge-v2-1-february-2025-store-release-new-feature/ba-p/3168550) - As a consumer, you can add your own variables to a provider's remote record producer (RRP) in your consumer instance. Consumer variables are useful in a Consumer Pre-Flow for adding additional information to complete a flow. **- *Article Posted***


3. **Add scripts to a remote record producer** - Add catalog client scripts, UI policy scripts, and other common scripts in the remote record producer (RRP). The consumer must approve all scripts to use the RRP. You can add multiple scripts to an RRP. **- *Article to be Posted***


4. **Transform Mapping Assist** - Use the


Now Assist for TMT


Transform Mapping Assist feature to generate transform mappings between provider and consumer tables automatically. ***- Article to be Posted***
