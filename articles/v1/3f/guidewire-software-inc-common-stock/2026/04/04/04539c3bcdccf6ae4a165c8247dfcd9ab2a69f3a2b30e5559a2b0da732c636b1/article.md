- Palisades for Developers: Smart Assistance and Hardened Cloud Foundations


With the **Palisades** cloud release, our first of three ski releases planned for 2026, Guidewire provides expanded functionality that gives developers the ability to safely leverage their preferred AI tools to create unique digital experiences. It also drives greater precision across critical financial processes, and gives pricing teams the agility to respond quickly to shifting market conditions.


In this blog post you’ll discover what’s new in Palisades and find resources to help your development teams leverage our latest cloud release. But first, here are a few key Palisades release links you’ll want to bookmark:


- View the[Palisades release page](https://www.guidewire.com/products/technology/guidewire-cloud-platform-releases)
- Watch our[Palisades release highlights video](https://explore.guidewire.com/palisades-video-play/introduction-to-palisades) which includes product demos
- Read the[Palisades release notes](https://docs.guidewire.com/cloud/palisades/whatsnew/topics/introduction.html) on Guidewire Documentation (login required)

## 1. Bring-Your-Own Build Management


The Palisades release empowers DevOps teams through **Bring-Your-Own Build Management** . Integrate your preferred third-party CI/CD tools with Guidewire Cloud Platform applications and manage all the Cloud Platform tools from one place, reducing context switching. Use these new, robust APIs and CI/CD events from your preferred third-party build management tools to achieve a consistent developer experience.


**Learn more about[Build Management API](https://docs.guidewire.com/cloud/buildmanagementapidocs/latest/) on Guidewire Documentation (login required).**


## 2. Developer Assistant (Early Access)


Centering on smart assistance, we have introduced the **Developer Assistant (Early Access)** for Jutro. This AI-powered tool is built to assist developers by providing a standardized, extensible architecture through Model Context Protocol (MCP), enabling better tool integration and enhanced AI agent capabilities.


**Learn more about[Developer Assistant MCP](https://docs.guidewire.com/jutro/documentation/10.13/developer-assistant/developer-assistant-mcp-overview) on Guidewire Documentation (login required).**


## 3. Rules Service and Functions


Palisades brings an update to Automation Services that drive more consistent decisions across complex workflows with built-in integration to Guidewire **Rules Service** and **Functions** . Maintain predictable and compliant behavior with controlled runtime versioning, built-in support policies, and stronger deployment tooling with Functions. Automate and centralize business rules management with Rules Service, enabling insurers to quickly adapt to changing requirements and streamline decision-making across applications, without code changes or deployment delays.


**Learn more about[Rules Service](https://docs.guidewire.com/rules-service/release/topics/c_about-guidewire-rules-service.html) and[Functions](https://docs.guidewire.com/cloud/is/guidewirefunctions/release/Integration/gwfunctions/topics/c_rn_palisades_115.html) on Guidewire Documentation (login required).**


## 4. LOB Agnostic Quote and Buy Template


A newQuote and Buy Foundation Experience template is now available in the Jutro Web Apps template library. This line-of-business (LOB) agnostic Jutro digital solution provides a configurable, end-to-end quote-and-buy flow for any line of business, without requiring a line-specific starting point. Developers can reuse the same high-performance UI components for any digital initiative, reducing the time-to-market for new products.


**Learn more about the[Quote and Buy Foundation Experience template](https://docs.guidewire.com/jutro/palisades/templates/quoteandbuyfoundationexperience/quote-buy-foundation-experience-template/quote_buy_foundation_template_overview.html) on Guidewire Documentation (login required).**
