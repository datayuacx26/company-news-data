- Meet the Guidewire Documentation Assistant


We’re excited to introduce the **Guidewire Documentation Assistant** ! The beta version of this intelligent chatbot is now available on docs.guidewire.com to quickly and intuitively guide you to the information you need. Think of it as a dedicated, 24/7 documentation expert at your fingertips.


*Want more content like this? Subscribe to our monthly[Guidewire Developer Newsletter](https://www.guidewire.com/developers/developer-resources/developer-newsletter) to get updates on AI, code security, and other developer resources delivered straight to your inbox.*


## What the Documentation Assistant can do for you


Ask a question about Guidewire products and features in natural language, and the Documentation Assistant will search Guidewire user documentation to find your answer. You’ll get a concise summary and links to relevant resources so you can dive deeper.


With the Documentation Assistant, you can:


- Get summaries of complex concepts in seconds
- Ask “how do I” questions to get step-by-step guidance
- Find the most relevant documentation faster
- Access details, code samples, and API references using direct source links
- Follow up with more specific questions to gain clarity about a topic


For additional flexibility, you can also:


- Start a new chat when you’re ready to move to a new topic
- Hide the chat panel when you don’t need it
- Reopen your most recent chat with the **Ask docs** icon


The Documentation Assistant complements your existing methods of finding information on the Documentation site. You can still navigate the site as you always have. While you’re navigating manually, you can hide the chat panel, and then reopen it with a single click when you need it.


**We need your help to improve your chat experience**


During this beta phase, we’re relying on your feedback to help us build a Documentation Assistant that works for you. As you use it, please rate the responses:


- Give a quick thumbs up or down: 👍 or 👎
- Tell us why you’re giving that rating
- Don’t forget to rate responses to your follow-up questions


This is a beta version, and it currently provides responses only from English language documentation for Guidewire Cloud products. Some answers might not be fully complete or accurate.
