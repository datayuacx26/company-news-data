# Product Update: September 2025

Welcome to this month’s update of newly released features. In September, we shipped high-impact upgrades to reduce manual work, speed up payroll, and give admins more control across the platform.


You can now track I‑9 and E‑Verify status directly in the Dashboard, helping catalyze onboarding flows. Payroll teams can auto-apply deductions on CSV imports, preview multiple checks in detail, and define earnings per shift with new Shift-Level Earnings controls.


We’ve also released a cross-state tax exemption setting, new YTD reporting in the UI, and a completely rebuilt Dashboard table that supports global sorting and unlimited data.


## Onboard


### **I‑9 Dashboard**


**‍** Admins can now track the status of I‑9s and E‑Verify directly in the Dashboard. See what’s completed, what’s stuck, and what needs attention, making onboarding faster and more reliable.


## Pay


### **CSV Auto‑Deductions**


Deductions now apply automatically when checks are imported via CSV. No more manual entry. This helps eliminate errors and speeds up payroll runs.


### **Transfer from Instant Pay to Bank Account** ‍


Workers can now ACH funds out of Instant Pay. This gives them more control over how they access their earnings.


### **Detailed Preview Payroll View** ‍


You can now view full details for multiple checks in the preview page. See earnings, deductions, and taxes all in one place — before you run payroll.


### **Shift-Level Earnings**


Shift Object lets you define earnings for each check with more control. Each shift can include multiple components like hours, bonuses, or premiums. If no wage is set, we’ll use the worker’s base rate, making payroll inputs cleaner and more flexible.


## Bill


### **Bill rate in the API** ‍


Bill rate data can now be passed via the API. Track revenue by assignment and build stronger margin visibility into your systems.


## Platform


### **Year to Date Report in UI** ‍


View gross wages, deductions, and taxes across any time period. Admins can now run YTD reports directly in the UI for faster reporting and reconciliation.


### **Dashboard Performance Upgrades** ‍


Faster loads, global sorting, and no more data limits. We’ve rebuilt the table infrastructure to support high-volume teams. You can now sort across the entire dataset, navigate with Next / Previous pagination, view all results with no record limits, and experience page loads that are 3x faster.


### **Expanded Tax Reference Files**


Files are now available for all tax types, right after filing. No more waiting weeks. Get local, state, and paid leave reference files immediately after submission, freeing up time for your team.


### **Cross‑State Tax Settings** ‍


Choose how to handle tax withholding when workers live and work in different states. You can now select Default to withhold both states, Work State only, or Resident State only. Only admins can set this, giving you tight control over multistate compliance.


### **Work Week Start in Dashboard** ‍


The work week start setting is now visible and editable. Used for overtime calculations, this setting ensures your OT logic is accurate and auditable.
