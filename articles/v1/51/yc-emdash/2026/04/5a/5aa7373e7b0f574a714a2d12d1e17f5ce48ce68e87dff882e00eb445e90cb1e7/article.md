# Emdash public v1 beta

> **Update:** Emdash v1 is now stable. Read the[v1 launch post](https://emdash.com/blog/emdash-v1-stable) or[download the stable release](https://emdash.com/download) .


Emdash v1 beta is here.


Emdash is an Agentic Development Environment (ADE) for running multiple coding agents in parallel, each in isolation. Review and test changes before you merge them, locally and/or on remote repositories.


v1 beta is close to a full rewrite of the app. We focused on making the core workflow incredibly solid, with consistent design and much better state management. Switching between tasks and terminals is now instant.


A few things are not in this version yet; In-app browser preview (will come back), Best-of-N (might come back).


This is a beta, not the final v1 release. The macOS build is the most tested today. Windows and Linux builds are available too, but should be treated as experimental for now.


The beta installs as a separate app. Your existing tasks and projects will not be imported into the beta, and they will stay in the database used by the current Emdash app. When we release the stable v1 version, we will ship it with a migration path.


We expect to ship the stable v1 release in the next few weeks.

Start on macOS, if you can. If you try Windows or Linux, expect rougher edges and tell us what you run into.
