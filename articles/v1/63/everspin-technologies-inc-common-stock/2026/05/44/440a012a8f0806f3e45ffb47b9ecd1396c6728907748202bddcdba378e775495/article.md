# MRAM for MIL-STD-1553

## MRAM for MIL-STD-1553 Avionics and Space Systems


Mission-critical systems utilizing the MIL-STD-1553 data bus require memory that is as rugged as the platforms they serve. While legacy designs rely on a combination of Rad-Hard SRAM for performance and Flash for non-volatility, the Everspin *PERSYST* Magnetoresistive Random Access Memory (MRAM) product family provides a unified "Universal Memory" solution. It is particularly suited for Bus Controllers (BC) and Remote Terminals (RT) in high-radiation and extreme-temperature environments.
