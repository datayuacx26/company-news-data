# Astro Digital Selects Everspin 64Mb STT-MRAM for Raven Bus Geosynchronous Satellite Program

SatNews covers Astro Digital’s selection of Everspin’s PERSYST 64Mb STT-MRAM as the primary fail-safe memory for the boot process on an upcoming Raven bus GEO satellite mission. The coverage highlights how persistent MRAM supports reliable startup, system recovery and data retention for long-duration satellite operations.
