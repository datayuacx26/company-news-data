# How CAN-Based Modules Support Scalable System Design Across Equipment Platforms

Controller Area Network (CAN) modules process scalable system design by utilizing an extremely robust and self-managing message architecture to provide efficiency across all heavy-duty equipment platforms. The device provides quick and accurate exchange of information to enhance the function and performance across multiple product lines, machine sizes and configuration options.


CAN modules drive scalability by using protocols like CANopen, J1939 and NMEA 2000 that all share similar advantages in reducing weight and cost. While it is reliable in the integrity of information and reduced maintenance and input across all forms of applications. Furthermore, CAN Bus devices utilize an extremely robust and self-managing message architecture that internally detects error and prevents additional faulty messages throughout the system. Although there are many different types of CAN bus devices, they all share similar advantages in reliable communication, error detection, and compact wiring systems.


### Key Points of Scalability in CAN Architectures


Key factors to consider when using CAN bus modules are how it provides flexibility in supporting heavy-duty equipment system by:


**Reducing Wiring Complexity:**


For every component, all devices share the exact same two-wire which helps eliminate the use of complex wire harnesses when expanding equipment platforms.


**Prioritized Messaging:**


Designed to catch and correct or terminate messages with errors, makes CAN protocol an extraordinarily robust system that is very unlikely to fail.


**Network Expansion:**


Supports adding new nodes directly to the network without redesigning the bus communication patterns.


### Typical Applications in Equipment Platforms


CAN Bus Modules support the following applications:


**Automotive and transportation:** Heavy-duty trucks, agricultural machinery


**Industrial automation** : Factory equipments, heavy-duty equipment
