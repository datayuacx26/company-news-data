# New Product Launch: Prompt Builder


With Prompt Builder you can build out text generation prompts, then share your API with a developer.


I'm excited to announce the launch of our new Prompt Builder product. Try it out[here](https://app.uberduck.ai/prompt-builder) .


With Prompt Builder, you can craft a prompt that generates the precise text that you want from a large language model (LLM) like OpenAI's GPT3 or GPT4, then use the prompt via an API.


Prompt Builder lets a product manager, creative director, or brand manager build out the text-generation portion of an AI-powered product or marketing campaign while ensuring high quality and brand safety. Once the text generation is finalized, your developers can use the prompt you ve just built via API.
