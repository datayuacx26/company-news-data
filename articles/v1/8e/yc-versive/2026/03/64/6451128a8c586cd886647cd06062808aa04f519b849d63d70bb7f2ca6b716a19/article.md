# Card Sort v2, a new dashboard, and the Versive API

[Back to updates](https://www.getversive.com/blog)


March 9, 2026 •


Product Updates


### Card Sort v2, a new dashboard, and the Versive API


A redesigned Card Sort with richer analysis, an overhauled dashboard, and a new API that lets developers build on Versive programmatically.


---


We're shipping a completely redesigned Card Sort question type, rolling out a faster, more powerful dashboard, launching the Versive API, and making some pricing updates. Here's everything that's new.


### Card Sort v2


We've rebuilt the Card Sort question type from the ground up. The new version gives researchers significantly richer analysis tools and participants a smoother sorting experience.


**For researchers** , the results dashboard now includes:


- **Matrix view** — a heatmap showing how often cards were sorted into each category
- **Similarity view** — see which cards participants grouped together most frequently
- **Dendrogram** — hierarchical clustering that reveals natural groupings in your data
- **Category breakdown** — detailed stats on how each category was used


**For participants** , the sorting experience is now more intuitive with improved drag-and-drop, tap-to-place on mobile, and the ability to search, filter, and sort cards during the task. Grid and list layout options let participants work the way they prefer.


Card Sort pairs naturally with Tree Testing (which we shipped last month) — use card sorts to discover how users think about your content, then validate the resulting structure with a tree test.


### A faster, more organized dashboard


We've overhauled the main dashboard with server-side filtering, sorting, and pagination. Studies, Snap projects, and folders now appear in a single unified list that loads faster and handles large workspaces better.


New capabilities include:


- **Search and filters** — find studies by name, filter by type (studies, tests, folders), or narrow by creator
- **Sortable columns** — sort by name, date created, or last updated
- **Drag and drop** — move studies and projects into folders directly from the dashboard
- **Keyboard shortcuts** — press` C` to open the create menu,` P` for a new project,` F` for a new folder, and use arrow keys to navigate


### The Versive API


We've opened up Versive as a platform. The new API lets developers programmatically create studies, launch AI-moderated interviews, and retrieve structured results — all from code.


With the API, you can:


- **Create studies from a prompt** — describe the research you want to run, set a mode (chat, voice, or survey), and Versive generates a full study script
- **Launch interviews at scale** — send a participant list and Versive handles scheduling, moderation, and follow-up questions automatically
- **Retrieve transcripts, summaries, and structured data** — every interview produces a full transcript, an AI-generated summary, extracted themes, and structured responses ready for your pipeline
- **Pull insights programmatically** — access study-level and interview-level insights via the API, filtered by type


The API supports typed SDKs for Python and TypeScript, with structured JSON responses designed to fit into existing data workflows. Whether you're building a research automation pipeline, connecting Versive to an AI agent, or embedding research into your product development cycle, the API makes it possible.


Visit[getversive.com/developers](https://www.getversive.com/developers) to see examples and request access.


### Reliability improvements


We've increased reliability for audio recording and shipped several under-the-hood improvements to Snap test reliability. These updates make the platform more robust across the board.
