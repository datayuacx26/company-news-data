# Introducing Publish to GitHub

We just made it easier to publish CodeCrafters projects to GitHub.


## How it works


For every course you start on CodeCrafters (e.g[Redis in Go](https://app.codecrafters.io/courses/redis/overview) ), you'll now find an option to **Publish to GitHub** on the language dropdown.


Every course now has a button for publishing to GitHub


Choosing this option will prompt you to create a new GitHub repo for your project, and install the CodeCrafters GitHub app.


With two clicks, you're all set.


## A tool for accountability


[Hundreds of users](https://github.com/search?q=codecrafters&type=repositories&s=updated&o=desc) have already published their projects to GitHub.


Publishing to GitHub is a great way to showcase your creativity


Publishing is a great way to showcase your implementation and inspire others to learn from your programming style. But it doesn't end there — publishing is also a great way to build accountability for yourself.


## Get started


You can install the CodeCrafters GitHub app today by visiting[any of your in-progress projects](https://app.codecrafters.io/tracks) . It takes a minute to set up, and is automatic thereafter.
