# MIT App Inventor Tutorial for Beginners: Build Your First Android App

Create a step counter app that tracks movement and lets users save step counts as separate records. This project introduces real-time sensor-based thinking, simple data saving, and debugging ideas like using lists for multiple saved entries and avoiding duplicate procedure names.
