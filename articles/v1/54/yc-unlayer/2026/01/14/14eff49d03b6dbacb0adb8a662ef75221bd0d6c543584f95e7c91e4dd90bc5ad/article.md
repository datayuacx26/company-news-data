# 1.339.0

The following fixes and features are available on the[stable](https://docs.unlayer.com/builder/latest/version-management#production-environment) channel:


## Features & Improvements


-


**Accessibility:** Ability to set HTML title in UI


-


**Callbacks** : Expose context object with ids in some callbacks (mergeTag, mergeTagRule, displayCondition)


-


**Table:** new tool with enhanced editing experience


-


**Text → Paragraph** : The **Text** tool (based on TinyMCE) has been deprecated in favor of the new **Paragraph** tool powered by **Lexical** . This provides better inline editing, performance, and customization. Existing designs using the Text tool will remain functional.


## Bug Fixes


-


**Drag-and-drop:** Fix issue after reordering rows


-


**Image:** Fix autoWidth mismatch between Viewer and Preview html output and update calculation to take row padding and borders into account


-


**Sync Blocks:** general bug fixes
