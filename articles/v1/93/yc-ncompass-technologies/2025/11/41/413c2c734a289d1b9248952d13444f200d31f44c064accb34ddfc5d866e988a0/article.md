# 🧭 First Release — nCompass Profiling Tool VSCode Extension

Exciting news! We’ve released the first public version of the **nCompass Performance Optimization IDE** — a VS Code extension to help you analyze and optimize your model performance faster and more intuitively.


[Quick Start Guide](https://docs.ncompass.tech/ncprof/quick-start)


### Current Features


- Open and inspect traces stored on remote systems directly in **VS Code** using **Perfetto**
- Select code regions in the editor and wrap them with **TorchRecord** profile contexts for targeted trace capture
- Jump seamlessly between trace spans and code regions (when file info is available in the trace)


This early release is focused on gathering real-world feedback, so your input will directly influence the next iterations of the tool.
