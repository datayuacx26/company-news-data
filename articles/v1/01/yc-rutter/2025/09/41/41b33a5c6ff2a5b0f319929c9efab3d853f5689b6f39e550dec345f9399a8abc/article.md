# Introducing Smart Data Sync

## Fetch Only What You Need, When You Need It


Building financial products means balancing two competing demands: comprehensive data coverage and operational efficiency. Your underwriting team needs financial statements, but your bill pay feature only requires invoices and vendors. Your compliance team wants minimal data exposure, but your analytics dashboard needs full transaction history.


Today we're eliminating this tradeoff with our new Smart Data Sync feature. Configure exactly which entities sync from each platform you’re using with Rutter, or set custom configurations for individual connections. You can now fully optimize your data pipeline for your specific needs, all while maintaining the simplicity of our unified API.


## Beyond One-Size-Fits-All


Our approach lets you configure data syncing at three levels: organization-wide defaults, platform-specific settings, and individual connection overrides. This hierarchical system means you can set sensible defaults while customizing as needed for specific use cases or customer requirements.


Unlike competitors who require difficult custom configurations through their dashboard (or no configuration at all), Rutter's Smart Data Sync gives you granular control without architectural complexity. Set it up using our straightforward API and enjoy the benefits of programmatic data management.


## The Intuit Catalyst


Intuit's new App Partnership program introduced variable API pricing that affects high-usage QuickBooks integrations. Rather than simply pass costs to customers, forward-thinking teams are using Smart Data Sync to optimize their QuickBooks API usage while improving their overall data strategy.


By setting up a custom sync configuration for QuickBooks, you can dramatically reduce API call volumes without affecting other platforms. For example, you can now sync data from QuickBooks once every 24h, while maintaining 60m syncs for other platforms like NetSuite. This can cut QuickBooks API costs by 60% or more.


This optimization extends beyond cost savings. Faster syncs mean better user experience. Focused data sets mean cleaner analytics. Reduced API load means fewer rate limit issues. Smart Data Sync turns Intuit's pricing change into a catalyst for platform optimization.


## Enterprise-Grade Governance


Enterprise customers increasingly demand data governance features, or the ability to control exactly what data their connections access and how frequently it updates.
Smart Data Sync addresses these governance needs and more. Configure minimal data access by default, then expand scope for specific connections as needed.


## Platform Coverage


Smart Data Sync works across all major accounting and commerce platforms including QuickBooks, Xero, NetSuite, Zoho Books, Sage Business Cloud, and more. The feature integrates directly into our existing connection creation and management APIs, with no new authentication flows or separate configuration systems required.
