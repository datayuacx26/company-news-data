## New Connected Search


**Connected Search** boasts 100% data freshness and eliminates query latency. It delivers a native query experience to your agent while porting the Unity Catalog governance that enterprise IT requires.


Captain may already be indexing your files and data lakes, but what about the SaaS sources the data lives in?


Previously, SaaS data could only be searched after an ETL into cloud storage and then a re-indexing into Captain. But now with **Connected Search** , a simple "Connect" is all that's needed to link services to your Captain-powered agent.


## New: The Odyssey Dataset


The **Odyssey Dataset** is a new, unified, agent-ready API that supercharges agents with comprehensive private-market intelligence. Odyssey looks to expand agent knowledge across financing deals, private companies, investors, fund performance, and projections.


Forward-looking financial institutions are building AI research agents, but most licensed datasets were designed for dashboards rather than autonomous systems. Odyssey allows agents to traverse this knowledge programmatically, with **over 155 normalized attributes** enriched from web crawls and select data sources.


Explore the dataset at[runcaptain.com/datasets](https://www.runcaptain.com/datasets) , and see the Odyssey **Data Dictionary** at[docs.runcaptain.com/odyssey/overview-data-dictionary](https://docs.runcaptain.com/odyssey/overview-data-dictionary) .
