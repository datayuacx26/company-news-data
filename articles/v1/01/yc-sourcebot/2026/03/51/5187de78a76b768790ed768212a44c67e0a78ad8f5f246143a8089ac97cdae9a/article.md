# Changelog - Week of March 21, 2026

What we shipped this week (Mar 14 - Mar 21):


-


Admins can now restrict API key creation and usage to organization owners only. ([#1007](https://github.com/sourcebot-dev/sourcebot/pull/1007) )


-


MCP` search_code` now supports filtering by file path using regular expressions. ([#1008](https://github.com/sourcebot-dev/sourcebot/pull/1008) )


-


Redis TLS is now supported. ([#1011](https://github.com/sourcebot-dev/sourcebot/pull/1011) )


-


Also: agent max step count raised from 20 to 100 ([#1017](https://github.com/sourcebot-dev/sourcebot/pull/1017) ), MCP read-only annotations for Cursor Ask mode compatibility ([#1013](https://github.com/sourcebot-dev/sourcebot/pull/1013) ), ask_codebase hidden when no LLM providers are configured ([#1018](https://github.com/sourcebot-dev/sourcebot/pull/1018) ), and SMTP individual env var support ([#1002](https://github.com/sourcebot-dev/sourcebot/pull/1002) ).
