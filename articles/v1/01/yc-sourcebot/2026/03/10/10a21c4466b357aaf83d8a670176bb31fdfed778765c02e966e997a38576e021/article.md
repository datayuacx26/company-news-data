# Changelog - Week of March 9, 2026


What we shipped this week (Mar 9 - Mar 15):


-


OpenAPI docs are now available for the search, repository, and file browsing APIs. ([#996](https://github.com/sourcebot-dev/sourcebot/pull/996) )


-


JumpCloud is now supported as an SSO identity provider. ([#997](https://github.com/sourcebot-dev/sourcebot/pull/997) )


-


Teams can now have multiple owners, with promote and demote actions. ([#988](https://github.com/sourcebot-dev/sourcebot/pull/988) )


-


Also: MCP now requires explicit invocation for ask_codebase, authentication gated when Ask GitHub is enabled.
