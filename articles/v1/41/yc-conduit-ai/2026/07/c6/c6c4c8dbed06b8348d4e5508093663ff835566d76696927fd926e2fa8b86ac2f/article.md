# Conduit Is Now Available in Claude's Connector Directory

## What changed


Conduit is now available in Claude's connector directory. You can connect Claude to an authorized Conduit workspace through the Model Context Protocol (MCP).


Most teams already work from their Conduit workspace. It is where guest context, agents, workflows, and operating configuration live. The connector lets Claude work with that same layer alongside the documents, email, calendar, and systems the team has already connected.


## How it fits with Conduit


Conduit's native agent remains a core part of the product. It is built to help hospitality teams run guest operations across conversations, reservations, operations, and connected systems.


MCP adds another way to use the platform. A team can use Claude or a custom internal agent when that is the best place to do the work, without losing the connection to the Conduit workspace where the automation is configured and managed.


## What external agents can do


With the appropriate workspace permissions, an external agent can:


1.


**Access hospitality context.** Retrieve contacts, guest conversations, tickets, calls, reservations, knowledge, and other Conduit workspace data.


2.


**Edit the operating layer.** Create and update Conduit agents, workflows, skills, custom tools, and configuration.


3.


**Work with the existing stack.** Combine the company data already connected to that agent with the guest and operational context in Conduit.


For example, a team could use Claude to review recurring guest-request handoffs, inspect the supporting conversations and tickets in Conduit, then draft the agent and workflow changes that would remove the manual work.


Write actions remain subject to Conduit workspace permissions and the approval flow in the client.


## Why this matters


Teams do not need another disconnected assistant. They need their existing agent tools to work with the same workspace where their hospitality data and automation already live.


MCP makes that integration more seamless. It lets Conduit remain the place where hospitality operations are coordinated, while Claude and other authorized agents can help teams analyze, configure, and improve the work.
