# Introducing: new agent-first onboarding for Extend

**TLDR:** We rebuilt onboarding so you can get started faster with out-of-box support for agent-first development and better customization.


- Get an API key without having to generate it separately from Settings
- Ready-to-use agent skill that teaches your agents how to implement Extend
- Templates that match your use case


---


For developer infrastructure, onboarding is about productive friction. You don't want to drop users in cold; that is the tech equivalent of wilderness survival with no map. On the other hand, extensive questionnaires are annoying, especially for builders that just want to play with the product.


When approaching this challenge, we knew a few constraints and premises:


- No extraneous steps that do not serve to improve the product experience for the user.
- Majority of developers work with their coding agents by default. Onboarding should accelerate how devs actually build.
- Document processing has frequently seen edge cases that we can help teams overcome immediately — so we should.


With these parameters in mind, here's what's new.


## Agent-first onboarding


Most developers already have a coding agent open. Onboarding should meet them there.


Right after signup, Extend generates an API key and a prompt you can paste into Claude, Codex, or your preferred coding agent. The agent takes it from there and sets up the integration inside your codebase. No reading docs first, no wiring things up by hand.


If you'd prefer to write code yourself, we also provide you an API key along with code snippets for SDK quickstarts in your preferred language.


## Use case specific playground and templates


Based on your answers to the onboarding questions, we automatically route you to the right starting point. Sign up for extraction and you land in the Extract playground, prompted to upload a document. Same for parsing, classification, splitting, and filling/editing forms.


Plus, the first-time homepage now suggests templates based on the industry you selected. This is powered by our public[template library](https://www.extend.ai/templates) that teaches your agents how to accurately parse, extract, and build workflows around commonly seen document types (and their edge cases).


## Extend Studio improvements


We also included some quality of life improvements to the Extend Studio. During onboarding, we will automatically add your company logo (you can customize this). Additionally, playgrounds now provide a first step popup for a document upload so you can try it against your actual files. Lastly, we improved the look and feel of the Extend Studio globally because we're always trying to make sure you're getting the best possible product experience if you choose to interact with the UI.
