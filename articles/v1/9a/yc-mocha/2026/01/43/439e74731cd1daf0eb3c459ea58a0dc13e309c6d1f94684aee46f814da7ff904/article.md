# Discuss Mode Just Got a Major Upgrade

We've been thinking a lot about planning lately. Turns out, **how you plan your app matters just as much as how you build it** . So we gave Discuss mode a serious upgrade.


It's live now for everyone. Same place you've always found it.


## What's New?


### Same Brain, More Power


Discuss mode used to run on a lighter, faster model. That made sense when it was just for quick questions. But planning and debugging deserve better.


Now it runs on the same smart model as code mode. You get the full thinking power when you're working through complex ideas or tracking down bugs.


### It Can Actually See Your App


This one's a game-changer. Before, Discuss mode could only look at your code. Now it takes screenshots and reads logs to investigate issues in real-time.


When something breaks, it looks at what's *actually* happening — not just what *should* be happening. No more guessing based on code alone.


### Full Context Sharing


This is the big one.


Discuss mode now sees everything the Mocha agent was doing behind the scenes: which files it read, what errors it hit, what it was thinking. So when the agent finishes a turn and you're confused, you can ask "what went wrong there?" and get a real answer.


Works in reverse too. Switch back to code mode and Mocha remembers what you investigated together — not just what was said in chat. Your debugging session becomes context for the fix.


### Multi-Turn Follow-Ups


Discuss mode can now take multiple turns on its own, following threads and digging deeper instead of giving you one response and stopping. It'll keep investigating until it has something useful to say.


## The Tradeoff


Discuss mode now uses dynamic credits (like regular mode) instead of the old flat 3 credits per message. It's smarter, which means it costs more to run.


But here's the thing: better planning leads to fewer mistakes in code mode. You might spend a few extra credits thinking through an approach, then save way more by not having Mocha build the wrong thing three times.


## Try It Out


Next time you're stuck or planning something complex, switch to Discuss mode and talk it through. Ask it to investigate a bug. Have it review what Mocha did.


We think you'll notice the difference.


Build away ☕!
