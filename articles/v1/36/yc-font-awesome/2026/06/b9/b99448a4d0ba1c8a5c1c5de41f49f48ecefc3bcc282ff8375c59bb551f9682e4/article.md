# WA 3.9: AI Design Skill and Checkbox Group

## 🤖 New AI Design Skill


*Hello, Mr. Anderson.* There’s a new Agent Skill on the block.


The[webawesome-design skill](https://webawesome.com/docs/ai/agent-skills) helps AI agents better understand how to design and build UI with Web Awesome. This new skill offers tailored documentation on theming, building with *<wa-page>* , and using layout utility classes, along with guidance on design principles and visual composition.

## ☑️ Checkbox Group


Not every choice is either-or. The new[<wa-checkbox-group>](https://webawesome.com/docs/components/checkbox-group/) wraps related *<wa-checkbox>* (or *<wa-switch>* !) components together with a shared label and hint along with accessible semantics.


## 🕶️ More Anomalies Corrected


There are more fixes and crowd-pleasers in WA 3.9, including:


- New *selection=”leaf-multiple”* for[<wa-tree>](https://webawesome.com/docs/components/tree/#selection-modes) , allowing users to select multiple leaf nodes while parent nodes simply expand and collapse
- Support for native *<button>* elements in[<wa-button-group>](https://webawesome.com/docs/components/button-group/#native-buttons) , as long as you have Native Styles enabled


[Take a look at our changelog](https://webawesome.com/docs/resources/changelog#wa_390) for all of the newest additions and changes in WA 3.9.
