# How to connect different company departments in a single process system

A **unified process system** eliminates data duplication between departments: a customer registered by sales automatically shows up in finance, with no re-typing. That's how **Jestor** connects departments, using relational **Tables** inside an **SMB Management System** .


### Why Do Different Departments End Up Duplicating Data?


When each department uses its own tool, the same information — customer name, order value, contract status — needs to be typed in several places. That creates data mismatches and constant rework.


### How Do You Connect Departments Into a Single System?


- Centralize base data (customers, vendors, products) in shared **Tables** .
- Connect each department's records to those tables, instead of duplicating information.
- Build a single **dashboard** that pulls data from every connected department.
- Set permissions by department, so each team sees only what it needs.


### How Does Jestor Connect Departments in Practice?


- **Tables** work as a relational database: information entered once is available to every connected department.
- The **SMB Management System** already comes with finance, CRM, HR, and purchasing connected by default.
- The **dashboard** brings together metrics from several departments in a single panel, with no need to check separate systems.

### Frequently Asked Questions


### Can I Connect Just Two Departments to Start?


Yes, it's recommended to start by connecting two related departments and expand gradually.


### Do Connected Tables Work Like a Database?


Yes, the data becomes relational, so a change in one record reflects everywhere it's connected.


### Can Each Department Have Different Permissions on the Connected Data?


Yes, Jestor's Security lets you restrict what each department sees, even on shared tables.
