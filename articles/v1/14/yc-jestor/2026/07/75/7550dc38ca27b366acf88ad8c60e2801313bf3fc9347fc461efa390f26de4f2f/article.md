# How Do You Set a Different Homepage for Each Role as Soon as the User Logs In?

In **Jestor** , when editing a role, you can paste the link to a specific page (like a dashboard) into the homepage field, so that every user with that role lands directly there as soon as they log in.


### Why this improves the user experience


Without this setting, everyone would land on the same generic Home screen, regardless of their role. Setting a homepage by role takes each person straight to the panel most relevant to their job, without needing to manually navigate there every day.


### How the homepage-by-role setting works


- Each role can have a different homepage configured
- The page can be a dashboard, a Kanban, or any other screen on the platform
- The link is copied from the desired page's URL and pasted into the role's setting
- As soon as a user with that role logs in, they land directly on that page


### How to set up a homepage by role in Jestor


1. Go to the roles area inside settings
2. Edit the desired role, or create a new one
3. Open the page you want to set as the homepage and copy the URL
4. Paste that link into the role's homepage field and save


### Process automation with direct access to what matters


Setting a homepage by role is a simple adjustment that reinforces **process automation** , since each person sees, first, exactly the panel tied to their job, with no need for training on where to navigate.

## Frequently Asked Questions


**Does every role need a configured homepage?** No, it's optional; roles without this setting take the user to the default Home screen.


**Can the homepage be any screen on the platform?** Yes, it can be a dashboard, a Kanban, or another page, as long as the link is copied correctly.


**Can I change a role's homepage after it's set up?** Yes, just edit the role and paste a new link at any time on[jestor.com](https://jestor.com/?ref=blog.jestor.com) .
