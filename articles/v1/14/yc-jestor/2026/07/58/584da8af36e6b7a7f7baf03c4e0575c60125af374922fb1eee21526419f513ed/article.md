# Where can you activate the builder directly from the Home to quickly access editing mode?

In **Jestor** , you can add the builder block directly to the home page, letting you access construction mode quickly with no need to first navigate to another app.


## How to add the builder to the Home


When personalizing the Home, one of the available blocks is the builder option, which works as a direct shortcut to the platform's construction agent. Once added, that block becomes available on the home screen, giving quick access to edit mode whenever you need to create or adjust something, with no need to open a specific app first.

## How to set up the builder on the Home


1. Go to your Home's personalization settings.
2. Add the builder block among the available blocks.
3. Save the setting and go back to the Home.
4. Use the block whenever you need to quickly enter construction mode.

### Does the builder block replace the build button that already existed inside apps?


No, it's an additional shortcut available on the Home; access to construction mode still exists normally inside each app.


### Is it mandatory to keep the builder block on the Home?


No, the block can be removed at any time, if the user prefers a Home without that shortcut.


### Is this option also available on the mobile version?


Yes, the Home improvements also brought mobile-focused updates, like quick actions to add items rapidly.
