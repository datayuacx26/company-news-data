# What's the difference between an internal and a public update link when asking a client to fill something in?

In **[Jestor](https://jestor.com/?ref=blog.jestor.com)** , an internal update link opens the record inside the platform itself for someone who already has access, while a public update link generates an external URL that anyone can fill out with no login required — ideal for asking a client or vendor to complete missing information.


## Why does the internal-vs-public difference matter for external submissions?


A client or vendor doesn't have a login for **[Jestor](https://jestor.com/?ref=blog.jestor.com)** , so an internal link simply wouldn't work for them. The public link solves that: it points to an external form that automatically updates the existing record, instead of creating a new one — with no need for the person to have any access to the platform.


## How to configure each type of link in Jestor?


1. For the internal link, just generate the update link field, pointing to the record inside the system itself — useful for teammates to edit something specific.
2. For the public link, associate the field with a public form, which can have conditional color, logo, and its own customization.
3. In both cases, the link already comes pre-filled with that specific record's ID, so the response updates the right card instead of creating a new one.
4. Each record has its own unique link, guaranteeing the client only updates their own information.


Link type Who can use it


**Internal link** Users with access to the Jestor account


**Public link** Any external person, no login required


## Why choose Jestor?


Before this field existed, generating these links required manually configured formulas and automations; now **[Jestor](https://jestor.com/?ref=blog.jestor.com)** automatically generates the right update link for each record, saving that manual work every time a client needs to complete some information.


### Frequently Asked Questions


**Can the public link be visually customized?** Yes, you can add conditional color, logo, and other customizations to the linked public form.


**Could a client accidentally create a new record using this link?** No, the update link is tied to a specific record and always updates that same card, never creating a new one.


**Can this link be sent by WhatsApp or email?** Yes, the generated link can be shared through any channel, including WhatsApp or email.
