# Can a text inside a card be shared with only the selected people?

Yes. In **Jestor** , each document connected to a card can be shared with only the specific people added to it, giving individual access instead of automatically opening it up to the whole team.


## How selective sharing works


When creating a document inside a record, you need to manually add the people who should have access to that text. From the moment someone is added, they can view and edit that specific document alongside the card. This lets different texts inside the same card have different audiences — one set of minutes might be visible to the whole team, while another, more sensitive conversation stays restricted to just a few people.


Action Result


**Adding a person to the document** They gain access to view and edit that specific text


## How to share a document with specific people


1. Open the document inside the card you want to share.
2. Add the people who should have access to that specific text.
3. Confirm — only the people added will be able to view and edit the content.
4. Repeat the process individually for other documents on the same card, if needed.


## Why choose Jestor


- **Granular control per document** : each text can have its own group of people with access.
- **Multiple texts per card** : you can organize different minutes, summaries, and conversations within the same record.
- **Flexible reading view** : you can hide the menu for a cleaner view when only one text is needed.


### Does everyone who accesses the card automatically see all its documents?


No, access to each document depends on who was specifically added to that text.


### Can you remove someone's access after already sharing the document?


Access control is managed through the list of people added to the document, and it can be adjusted as needed.


### Can a card have documents with different sharing levels at the same time?


Yes, each document within the same card can have its own group of people with access, independently of the others.
