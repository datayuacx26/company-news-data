# Como definir uma página inicial diferente para cada cargo assim que o usuário faz login?

No **Jestor** , ao editar um cargo, é possível colar o link de uma página específica (como um dashboard) no campo de página inicial, fazendo com que todo usuário daquele cargo caia diretamente ali assim que faz login.


### Por que isso melhora a experiência de quem usa o sistema


Sem essa configuração, todo mundo cairia na mesma Home genérica, independentemente da função. Definir uma página inicial por cargo leva cada pessoa direto para o painel mais relevante ao trabalho dela, sem precisar navegar manualmente todo dia.


### Como funciona a página inicial por cargo


- Cada cargo pode ter uma página inicial diferente configurada
- A página pode ser um dashboard, um **Kanban** ou qualquer outra tela da plataforma
- O link é copiado da URL da página desejada e colado na configuração do cargo
- Assim que o usuário daquele cargo faz login, ele já cai direto nessa página


### Como configurar a página inicial por cargo no Jestor


1. Acesse a área de cargos dentro das configurações
2. Edite o cargo desejado ou crie um novo
3. Abra a página que deseja definir como inicial e copie o link da URL
4. Cole esse link no campo de página inicial do cargo e salve


### Automação de processos com acesso direto ao que importa


Definir a página inicial por cargo é um ajuste simples que reforça a **automação de processos** , já que cada pessoa vê primeiro exatamente o painel relacionado à sua função, sem depender de treinamento sobre onde navegar.

**A página inicial pode ser qualquer tela da plataforma?** Sim, pode ser um dashboard, um **Kanban** ou outra página, desde que o link seja copiado corretamente.


**Dá para trocar a página inicial de um cargo depois de configurada?** Sim, basta editar o cargo e colar um novo link a qualquer momento no[jestor.com](https://jestor.com/?ref=blog.jestor.com) .
