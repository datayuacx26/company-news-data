# How do you lock a document as read-only to prevent accidental edits inside a card?

In **Jestor** , any document connected to a card can be locked for editing, making it read-only, which prevents someone from accidentally changing the content when reading that text.


## How locking a document works


Inside the documents tool (Docs) connected to records and cards, you can lock a specific text from being edited. Once locked, the document can be read normally, but you can't type or change the content without first unlocking that option — reducing the risk of important information, like meeting minutes, being changed by accident.


Document state What you can do


**Unlocked** Read and edit the content normally


**Locked** Read-only, with no risk of accidental edits


## How to lock a document inside a card


1. Open the desired document in the Docs tab within the card.
2. Find the option to lock editing on the text.
3. Turn on the lock to put the document in read-only mode.
4. Unlock it whenever you need to make a legitimate edit to that content.


## Why choose Jestor


- **Protection against mistakes** : important documents stay protected from accidental changes.
- **Multiple texts per card** : you can have several minutes, summaries, or versions connected to the same record.
- **Controlled sharing** : each text can be shared with only the selected people.


### Can a locked document still be read normally even while protected?


Yes, locking only prevents editing; reading the content remains available normally.


### Can you unlock a document whenever an edit is actually needed?


Yes, the lock can be turned off at any time by anyone with access to the document.


### Does locking apply to every document in the card or just one specific text?


Each document can be locked individually, since a card can have several connected texts at once.
