# Why Does Grouping Tables and Apps for the Same Process Into the Same Folder Make Maintenance Easier?

In **Jestor** , grouping tables and applications for the same process into a single folder makes it quick to find everything related to a specific Kanban or flow, saving you from wasting time hunting for scattered pieces across the platform.


### Why folder organization avoids clutter


Just like an unorganized computer desktop, having loose tables and apps with no visual relationship between them makes maintenance harder as the number of processes grows. Folders are a simple way to keep everything related together.


### What you gain by using folders per process


- Easily finding every element tied to a specific Kanban
- Less time wasted hunting for scattered tables and apps
- Clearer organization for anyone joining the process later and needing to understand the structure
- A simpler foundation for future maintenance and adjustments to the flow


### How to group tables and apps into a folder in Jestor


1. Turn on builder mode and create a new folder with the process's name
2. Edit the folder and add the tables related to that process
3. Also add the apps, like Kanban or dashboards, that are linked
4. Use that folder as your starting point whenever you need to work on that process


### Process automation that's easier to maintain long term


Keeping tables and apps grouped by folder is a simple practice that supports **process automation** long term, especially as the operation grows and more people start working on the same structure.

## Frequently Asked Questions


**Can a table live in more than one folder?** The recommended practice is to keep organization clear by process, avoiding unnecessary duplication between folders.


**Do folders affect how the Kanban or automations work?** No, folders are purely visual organization; they don't change how elements work technically.


**Do I need to create the folder before or after building the process?** Either works; many people create the folder first and add elements as they build the process on[jestor.com](https://jestor.com/?ref=blog.jestor.com) .
