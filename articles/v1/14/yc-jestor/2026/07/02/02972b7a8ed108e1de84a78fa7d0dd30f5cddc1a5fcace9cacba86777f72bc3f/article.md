# Where can you view overdue tasks and subtasks by month in a calendar layout?

In **[Jestor](https://jestor.com/?ref=blog.jestor.com)** 's spreadsheet-style task management template, the calendar view shows tasks and subtasks organized by their due date, letting you navigate month by month to quickly spot what's overdue in each period.


## Why does a calendar view show overdue items a list can't?


A task list sorted by priority doesn't make clear which month each deadline fell in. The calendar visually organizes tasks by date, making it easier to see, for instance, that one month had many deadlines and another had few — which helps with planning workload and spotting what's already past due.


## How to use the task calendar in Jestor?


1. Access the calendar view within the task management template.
2. Navigate between months to see tasks with a due date set for that period.
3. Also check the equivalent view for subtasks, which follows the same date-based organization.
4. Combine it with owner and priority filters to focus only on what's relevant to you.

### Frequently Asked Questions


**Does the calendar also show completed tasks?** The calendar organizes by due date; completed tasks remain visible according to how the process is configured.


**Can I filter the calendar by owner?** Yes, the same owner and priority filters used on the Kanban can be applied to the calendar view.


**Does this work for any task template or just this specific one?** The date-based calendar logic can be applied to other task processes within Jestor.
