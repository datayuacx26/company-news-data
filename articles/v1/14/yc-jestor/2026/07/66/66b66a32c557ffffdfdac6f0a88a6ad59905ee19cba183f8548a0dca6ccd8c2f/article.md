# Can two color conditionals be applied at the same time to a single indicator?

Yes. **[Jestor](https://jestor.com/?ref=blog.jestor.com)** indicators accept two simultaneous color conditionals — one for the data and another for the background — letting you, for example, turn the number red when it's below a value and the background a different color when it's above another value, all on the same indicator.


## Why does having two conditionals on one indicator help you read data faster?


An indicator with a single color rule already helps highlight values outside the expected range, but combining two conditionals — one for the text and another for the background — lets you communicate more visual nuance at once, with no need for two separate indicators taking up dashboard space.


## How to configure two color conditionals in Jestor?


1. Access the indicator's style editor.
2. Set the first color conditional for the data — for example, red when the value is below a defined threshold.
3. Set a second color conditional for the indicator's background, with its own independent rule.
4. Both conditionals work at the same time, reflecting the indicator's current value according to the configured formula.


Conditional Applies to


**Data conditional** Color of the number displayed on the indicator


**Background conditional** Color of the indicator block's background


## Why choose Jestor?


Beyond the color conditionals, the same indicator in **[Jestor](https://jestor.com/?ref=blog.jestor.com)** lets you customize format, decimal places, alignment, and font, giving you full control over how data reads visually without needing a separate BI tool.


### Frequently Asked Questions


**Can both conditionals use the same value rule?** It's not required; each conditional can have its own rule and value threshold.


**Does this work on both simple and composite indicators?** Yes, both the simple and the composite indicator get the same style options, including color conditionals.


**Can a conditional be removed after it's applied?** Yes, each conditional can be removed or adjusted at any time while editing the indicator.
