# O layout de um aplicativo pode ser personalizado separadamente para desktop e para celular?

Sim. No **Jestor** , ao entrar no modo de construção de um aplicativo, é possível alternar entre a versão desktop e a versão mobile, organizando os componentes de forma independente para cada uma.


### Por que separar o layout por dispositivo faz diferença


Um layout pensado para tela grande de computador nem sempre funciona bem em uma tela pequena de celular. Elementos que fazem sentido lado a lado no desktop podem precisar ficar empilhados no mobile para continuar legíveis.


### O que pode ser ajustado separadamente


- Posição e ordem dos componentes na versão desktop
- Posição e ordem dos componentes na versão mobile, de forma independente
- Visualização de como o app vai aparecer no celular, direto pelo computador
- Os mesmos dados e funcionalidades, apenas organizados de forma diferente por tela


### Como personalizar o layout mobile no Jestor


1. Acesse o modo de construção do aplicativo
2. Alterne entre a versão desktop e a versão mobile
3. Reorganize os componentes conforme o espaço disponível em cada versão
4. Salve — o app passa a exibir o layout correto conforme o dispositivo de acesso


### Automação de processos acessível em qualquer tela


Ter layouts otimizados para desktop e celular garante que a **automação de processos** continue funcionando bem mesmo quando o time precisa resolver algo urgente pelo celular, sem depender de estar na frente do computador.
