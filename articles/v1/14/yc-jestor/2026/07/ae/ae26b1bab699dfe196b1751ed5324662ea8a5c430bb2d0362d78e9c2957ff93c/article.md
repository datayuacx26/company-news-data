# Can You Duplicate an Entire Application, With All Its Elements, Right From the Action Bar?

Yes. In **Jestor** , the action bar (opened with Ctrl+K or Cmd+K) lets you clone an entire application, with every element it contains, just by choosing the source app and giving the copy a new name.


### Why cloning from the action bar is faster


Manually rebuilding an app from scratch, field by field, is slow — especially when a similar app is already up and running. The action bar lets you make that copy in seconds, without navigating through several menus.


### What happens when you clone an application


- Every element from the original app gets replicated in the copy
- The copy gets the new name set during cloning
- The original app is not affected by the cloning
- The copy can be freely edited afterward, without impacting the source app


### How to duplicate an application from the action bar


1. Press Ctrl+K (or Cmd+K) to open the action bar
2. Choose the option to clone applications
3. Select the app that will serve as the source for the copy
4. Type the new name and confirm — the copy is created with every element


### Process automation with fast reuse


Duplicating a ready-made app, instead of rebuilding from scratch, speeds up **process automation** for companies that replicate the same logic across different areas, like the same control used by different teams.
