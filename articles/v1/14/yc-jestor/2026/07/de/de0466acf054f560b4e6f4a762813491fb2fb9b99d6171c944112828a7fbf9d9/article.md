# Can you create multiple welcome blocks on the Home, one for each team or department?

Yes. In **Jestor** , you can add more than one welcome message block and more than one "start here" block on the Home, letting you organize different welcomes for each team or department in your company.


## How personalization by team works


The Home has two specific onboarding sections: an initial welcome message and a block of suggested apps to get started. Since you can add more than one of these blocks, the Home can be organized by area — for example, one welcome and starter-apps block for the HR team, and a completely different one for marketing — each showing exactly where that team should start.


Block Function


**Welcome message** Welcome text or instructions for the user


**Start here** List of suggested apps for that group of users


## How to set up team-specific blocks on the Home


1. Go to your Home's onboarding settings.
2. Add a welcome message block and a "start here" block for the first team.
3. Repeat the process, adding new blocks for other teams or departments.
4. Define which user groups (new members, viewers, etc.) each Home configuration applies to.


## Why choose Jestor


- **Tailored onboarding** : each team can have a different Home, with specific instructions.
- **Control by user type** : you can set up the Home separately for new members and new viewers.
- **Custom cover** : beyond the blocks, you can set a custom cover for the initial Home.


### Is it mandatory to use only one welcome block per account?


No, you can add more than one welcome-message block and more than one suggested-apps block, organized by team or another criterion.


### Does the initial Home setup apply forever, or can the user change it later?


The defined setup controls the first access; after that, each user can personalize their own Home however they prefer.


### Can you have a different Home for viewers and for members?


Yes, the setting lets you define the initial Home separately for new users, new members, or new viewers.
