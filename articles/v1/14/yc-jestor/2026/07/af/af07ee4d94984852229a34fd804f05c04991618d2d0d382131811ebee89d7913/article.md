# How Do You Know When a Template's Installation Has Finished, and Where Do You Find the Apps It Generated?

In **Jestor** , as soon as a template finishes installing, a notification (an orange dot) shows up in the inbox letting you know the template was installed; clicking it makes a folder with every app and table it generated available.


### Why this notification is useful


Installing a template can take a moment, depending on the complexity of the solution. Without a clear notification, the user might not know whether the process is finished or still running.


### What happens after installation


- A notification shows up in the inbox letting you know the template was installed
- Opening the notification automatically creates an organized folder
- That folder contains every app and table the template generated
- Sample data comes already filled in, ready for the user to explore


### How to confirm the installation and access the generated apps


1. Choose a template from the store and click install
2. Wait for the notification to show up in the inbox
3. Click the "template installed" notification
4. Open the folder to see every app and table ready to use


### Process automation ready in a few clicks


This install-and-notify flow shows how Jestor delivers **process automation** already structured in a few clicks, without requiring the user to manually build tables, fields, and apps from scratch.
