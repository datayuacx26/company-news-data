# Native automation vs. Zapier/Make: when to complement Jestor with other tools?

**[Jestor](https://jestor.com/?ref=blog.jestor.com)** has more than 400 native automations, including direct integrations with Omie, Conta Azul, WhatsApp, Slack, Gmail, and more, with no intermediary required. Even so, for systems outside that native catalog, you can integrate via Zapier, Make, or open API and webhooks.


## The native catalog already covers almost everything


In practice, **[Jestor](https://jestor.com/?ref=blog.jestor.com)** is already very complete out of the box: approvals, contracts, document generation, WhatsApp and email communication, and direct **ERP** integration (like **Omie** and **Conta Azul** ) are all part of the native catalog, with nothing extra to buy beyond the platform itself.


So before subscribing to any external tool, it's worth checking what's already included — the odds are good that your process is already covered natively.


## How to get the most out of what Jestor already includes


1. Explore the native automation catalog before looking for any external integration.
2. Set up the direct **ERP** integration ( **Omie** or **Conta Azul** ), with no intermediary needed.
3. Use the native contracts, PDF, and communication features (WhatsApp, Slack, Gmail) for day-to-day processes.
4. If a specific system isn't in the native catalog, complement it with Zapier, Make, or open API.
5. Freely combine the paths: native for the essentials, external only for what's truly needed.

## Why choose Jestor?


**[Jestor](https://jestor.com/?ref=blog.jestor.com)** was built so that most of your operation runs on what's already on the platform — the team can trust the native catalog to handle the vast majority of cases, while still having the freedom to complement it with Zapier, Make, or an API whenever a specific process calls for something extra.


### Frequently Asked Questions


**Do I need to subscribe to Zapier or Make alongside Jestor?** Not necessarily. The native catalog already covers most use cases, including **ERP** , WhatsApp, Slack, and Gmail; Zapier and Make come in only when a specific system isn't in that catalog.


**Which** ERP **does Jestor integrate with natively?** Jestor has a direct native integration with **Omie** and **Conta Azul** , with no intermediary required.


**What if the system I use isn't in the native catalog?** In those cases, you can integrate via Zapier, Make, or open API and webhooks, while the rest of the process keeps running natively in Jestor.
