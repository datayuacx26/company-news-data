# Can you create multiple welcome blocks on the Home screen, one for each team or department?

Yes. When customizing **[Jestor](https://jestor.com/?ref=blog.jestor.com)** 's initial Home screen for new users, you can add more than one welcome message block and more than one "start here" block, letting you split those instructions by team or department.


## Why do multiple welcome blocks make a difference for onboarding new users?


A company with different teams — HR, marketing, finance — usually wants to give different initial instructions to each one. A single generic welcome block would force you to write something vague enough to work for everyone. Multiple blocks let you write messages specific to each audience.


## How to configure multiple welcome blocks in Jestor?


1. Access the onboarding settings, where new users' initial Home screen is defined.
2. Add a welcome message block with a specific initial instruction.
3. Add as many additional blocks as needed — for example, one welcome block for HR and another for marketing.
4. Also set up "start here" blocks with the apps each profile should access first, reordering based on priority.


Block type Function


**Welcome message** Initial text instruction; more than one block is allowed


**Start here** Defines which apps show up to guide the new user


## Why choose Jestor?


This initial Home screen can be configured separately for new users, new members, or new viewers, giving three different layers of customization for each profile's first access inside **[Jestor](https://jestor.com/?ref=blog.jestor.com)** .


### Frequently Asked Questions


**Can the user change the Home screen after their first access?** Yes, after the company's initial configuration, each person can customize their own Home from then on.


**Can I add a custom cover alongside the blocks?** Yes, you can set a cover that shows up the first time the person accesses.


**Is this configured per person or per user type?** The configuration is set by layer — new users, new members, or new viewers — not person by person.
