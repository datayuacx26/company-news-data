# How to set a language different from the rest of the account just for your own user?

In **[Jestor](https://jestor.com/?ref=blog.jestor.com)** , beyond the default language configured for the whole account, each user can set their own language individually under Settings — letting an entire account be in English, for instance, while one specific user sees everything in Portuguese.


## Why do account language and user language need to be independent?


Companies with teams in different countries might have the account set to one default language, but not everyone accessing it is fluent in it. If the language were fixed for the whole account, every person would be stuck with whatever preference was set the first time the account was configured.


## How to configure individual language in Jestor?


1. Go to Settings and find the language and region section.
2. Find the two separate fields: system language (the account's) and my language (your own user's).
3. Adjust only your own language, without changing the account's general setting.
4. From then on, the interface shows up in the chosen language just for you, without affecting other users.


Setting Scope


**System language** Default applied to the whole account


**My language** Individual, applied only to the user who sets it

### Frequently Asked Questions


**Does changing my language affect what other users see?** No, the change is individual and doesn't alter the account's setting for everyone else.


**Which languages are available?** The platform offers Portuguese and English, plus a beta Spanish version.


**Does this change the language of automations or just the interface?** The individual language setting affects the interface shown to the user.
