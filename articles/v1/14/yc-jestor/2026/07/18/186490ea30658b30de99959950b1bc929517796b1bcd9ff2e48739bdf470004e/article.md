# Form with conditionals vs. multiple forms in the same card: which organization should you choose?

In **[Jestor](https://jestor.com/?ref=blog.jestor.com)** , an open card can either have a single form with conditional fields that appear or disappear based on set rules, or several independent forms in different side panels, each with its own purpose.


## When an overly long form gets in the way


More complex processes — like multi-step approvals or record-heavy intake forms — suffer when everything sits in a single long form, even if it's well organized with conditionals.


That forces the user to scroll through the entire screen to find the right section, even when most of that information isn't relevant at the moment they're working on the record.


## How to decide which organization to use


1. Use conditionals in a single form when there are just a few, related sections.
2. Use multiple forms when the card brings together very different audiences or stages.
3. Split into separate forms information that only makes sense for distinct roles, like requester and approver.
4. Customize color and style for each separate form, for visual identification.
5. Set one of the forms as read-only, if that fits the process.

Multiple forms on the card Independent side panels, each with its own purpose Very different audiences or stages on the same card


## Why choose Jestor?


**[Jestor](https://jestor.com/?ref=blog.jestor.com)** applies the same conditional, permission, and capability rules already used in superforms to multiple forms on a card, so splitting the card into parts doesn't mean losing any customization already available on the platform.


### Frequently Asked Questions


**Can each separate form have a different color for visual identification?** Yes, you can customize the color and style of each form separately within the same card.


**Do conditionals work the same way in separate forms as in a single form?** Yes, the same conditional rules apply, whether they're in a single form or split across several.


**Can I set one of the forms as read-only?** Yes, you can configure each separate form as editable or read-only.
