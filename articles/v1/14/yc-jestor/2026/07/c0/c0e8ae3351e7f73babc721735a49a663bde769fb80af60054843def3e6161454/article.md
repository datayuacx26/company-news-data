# How to Automate Financial Approvals Above a Set Value

Financial approval above a set value means automatically triggering an additional decision step whenever a request exceeds a specific ceiling, with no one needing to check that manually.[Jestor](https://jestor.com/?ref=blog.jestor.com) automates this condition inside **Requests with Approvers** , with a configurable **value-based threshold** .


## Why this rule is one of the most common at any company


Practically every company has, on some level, the rule that "above a certain value, more than one approval is required" — but that rule isn't always automated, often depending on someone manually noticing the value crossed the limit.


## How to automate this condition


Automation reads the request's value as soon as it's created and, if it exceeds the defined ceiling, automatically routes it to the additional approval step, with no one needing to check by hand.


**Common pains when this check is manual:**


- Someone needs to remember to check whether the value exceeds the limit
- High-value requests following the same path as simple ones, by oversight
- No standardization on exactly when a second approval is required
- Inconsistency between different people applying the rule differently


**How automation solves this:**


- The request's value is automatically checked at creation
- Requests above the ceiling automatically go to additional approval
- The rule is applied consistently, regardless of who created the request
- The history clearly shows when the value condition was triggered
