# Ready-made store templates vs. **AI**-guided building: which is faster to get started with?

In **[Jestor](https://jestor.com/?ref=blog.jestor.com)** , you can start a process by installing one of the store's ready-made templates — over 30 configured solutions — or by describing the process in text for the **AI** -guided build agent to put together from scratch.


## Which path is actually faster


Anyone getting started with Jestor often wonders which path is faster: grabbing something ready-made or asking the **AI** to build exactly what the company needs, without having to tweak a generic model afterward.


The answer depends on how closely the company's process resembles a common market case — and getting this initial choice wrong costs unnecessary setup time.


## How to decide which path to follow


1. Use a ready-made template for common processes, like CRM, task management, or fleet management.
2. Use **AI** building when the process is specific to your business, with no market standard.
3. Combine both: install the template and ask the **AI** to adjust whatever's different.
4. Give as much context as possible when asking the **AI** to build.
5. Use the agent's conversation history to keep tweaking the app afterward.
