# How to make app icons in the side menu show up with no background color for a minimalist look?

In **[Jestor](https://jestor.com/?ref=blog.jestor.com)** 's side menu, you can turn off the colored background behind app icons, leaving only the icon visible — a more minimalist look for anyone who prefers a cleaner menu.


## Why does removing the icon background change the menu experience?


By default, every app icon in the side menu comes with a background color, usually matching the color set for that app. For anyone managing lots of apps, that block of color can make the menu feel visually heavy. Removing the background leaves just the icon, creating a visually lighter navigation.


## How to configure this option in Jestor?


1. Access the side menu settings.
2. Find the option that controls whether app icons show a background.
3. Turn that option off to leave only the icon visible, with no color block around it.
4. Combine it with the magnetic menu — which expands on hover — for an even more compact everyday look.


Setting Visual effect


**Icon background on** Every icon shows up with a color block around it


**Icon background off** Only the icon shows up, with no background color


## Why choose Jestor?


This option lives alongside other side-menu style updates, like left- or right-aligned title bars, giving **[Jestor](https://jestor.com/?ref=blog.jestor.com)** users detailed control over the navigation's appearance with no code required.


### Frequently Asked Questions


**Is this configured per user or for the whole account?** The side menu's style setting can be adjusted according to navigation preference.


**Does removing the icon background affect the color set for each app?** No, the app's color still gets used elsewhere; the change only affects the side menu display.


**Does this work with dark mode too?** Yes, the side menu's style options work in both light and dark mode.
