# Why does keeping a subtask's chat isolated from the main task's chat prevent confusion?

In **[Jestor](https://jestor.com/?ref=blog.jestor.com)** , each subtask has its own chat, separate from the main task's chat: a message written inside one subtask doesn't show up if you open another subtask under the same task, keeping every conversation scoped to the context where it was written.


## Why would mixing all conversations into a single chat create confusion?


A main task can have several subtasks in progress at the same time, each with a different team or owner. If every message fell into the same general task chat, it would become hard to tell which comment refers to which specific subtask — the relevant information would get lost among conversations from other contexts.


## How does chat separation work in Jestor?


1. Every main task has its own chat, for general discussions about the project as a whole.
2. Every linked subtask has an independent chat, isolated from the other subtasks and from the main task.
3. A message written inside a specific subtask only shows up to whoever opens that same subtask.
4. This keeps information organized: description, notes, and chat, all specific to that card's context.


Level Chat scope


**Main task** General conversation about the project or task as a whole


**Subtask** Isolated conversation, specific to that subtask


## Why choose Jestor?


This card-by-card isolation adds to other information that's also specific to each subtask — description, notes, and attachments — which keeps the team organized even when several people are working on different subtasks of the same task in **[Jestor](https://jestor.com/?ref=blog.jestor.com)** .


### Frequently Asked Questions


**Can I see every subtask's conversations in one place?** Each subtask keeps its own isolated chat; there's no unified view of all conversations at once.


**Does this affect mention notifications?** Mentions keep working normally within the scope of the chat where they were made.


**Does the main task's owner see the subtasks' conversations?** They need to open each subtask individually to follow the corresponding chat.
