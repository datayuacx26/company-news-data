# Where can you enable the builder right from the Home screen for quick access to edit mode?

When customizing your own Home in **[Jestor](https://jestor.com/?ref=blog.jestor.com)** , you can add the builder as one of the available blocks, giving you quick access to the build agent right on the home screen, with no need to navigate to another menu to start editing.


## Why does having the builder available on Home save time?


Anyone building apps frequently usually accesses build mode several times throughout the day. Without that shortcut on Home, you'd need to navigate to the right place every time. Bringing the builder as a block on the home screen itself removes those extra steps.


## How to add the builder to your Jestor Home?


1. Access your own Home's customization.
2. Add a new tool to the layout and select the builder block.
3. Save the setting and go back to Home — the builder now shows up as one of the available blocks.
4. From there, the build agent can be triggered directly, with no need to open another menu.

### Frequently Asked Questions


**Is the builder block required on Home?** No, it's optional and can be removed if you prefer a simpler Home screen.


**Is this configured per account or per user?** Home customization, including the builder block, is configured at the user level.


**Does the builder on Home work the same as the builder inside an app?** Yes, it's the same build agent, just accessible directly from Home.
