# How to lock a document as read-only to prevent accidental edits inside a card?

Inside **[Jestor](https://jestor.com/?ref=blog.jestor.com)** 's document tool, you can lock editing on a text linked to a card, making it available for reading only — preventing someone from accidentally typing into a document that shouldn't be changed anymore.


## Why do documents linked to a card risk accidental edits?


A document connected to a record, like meeting minutes or a summary of a client conversation, often needs to be frozen once it's finalized. If anyone with access can edit it freely, there's a risk that an accidental change could erase or modify already-recorded information.


## How to lock a document in Jestor?


1. Open the document linked to the card or record.
2. Use the lock-editing option, available in the document's tools.
3. With the document locked, anyone with access can read it but can't type or change the content.
4. If editing is needed again later, simply unlock the document before making the change.


Document state What you can do


**Locked** Read-only, no risk of accidental edits


**Unlocked** Normal editing, with every text tool available


## Why choose Jestor?


Since each card can have more than one connected document — minutes on top, a summary below, for example — locking each one individually lets you control exactly which content can still be edited and which is already finalized in **[Jestor](https://jestor.com/?ref=blog.jestor.com)** .


### Frequently Asked Questions


**Who can unlock a locked document?** Whoever has editing access to that document can unlock it when needed.


**Can a locked document still be shared with other people?** Yes, you can add people with access even while the document is locked for editing.


**Does locking the document prevent viewing the content?** No, locking only prevents editing; reading continues to work normally.
