# Can an App's Layout Be Customized Separately for Desktop and for Mobile?

Yes. In **Jestor** , once you enter builder mode for an app, you can switch between the desktop version and the mobile version, organizing the components independently for each one.


### Why splitting layout by device matters


A layout designed for a large computer screen doesn't always work well on a small phone screen. Elements that make sense side by side on desktop might need to stack on mobile to stay readable.


### What can be adjusted separately


- Position and order of components in the desktop version
- Position and order of components in the mobile version, independently
- A preview of how the app will look on mobile, right from your computer
- The same data and features, just organized differently per screen


### How to customize the mobile layout in Jestor


1. Open the app's builder mode
2. Switch between the desktop version and the mobile version
3. Rearrange components to fit the available space on each version
4. Save — the app now displays the correct layout depending on the device


### Process automation accessible on any screen


Having layouts optimized for both desktop and mobile ensures **process automation** keeps working well even when the team needs to handle something urgent from their phone, without needing to be at a computer.
