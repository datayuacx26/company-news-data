# February Product Releases

From a unified AI agent to new integrations and UI improvements, here's everything we shipped this month.


## Unified Agent Interface


All agents are now available in a single interface on every screen or in a full screen mode.


Choose the one you need, or switch it mid conversation for a different need. The chat sticks as you move across the platform.


The agents share memory and rules, so context is preserved.


## More Agent Improvements


- Agents can now access BI information and data warehouse metadata from the information schema, including volume and freshness metrics and query history, improving their ability to support end-to-end workflows
- Lineage is now available directly inside the agent chat
- Agents have been upgraded to Claude Sonnet 4.6
- Tables returned in agent chat can now be downloaded as CSV


## New Incidents Page


The incidents page has been redesigned with an improved configurable layout. You can now choose which columns to display, so the view works for your team's specific needs.


## Scheduled Incident Digest


You can now create digest rules to control how and when incident notifications are delivered. Configure which incidents to include, and set the delivery cadence that works for your team. Supported on Slack, email and Microsoft Teams.


‍


## Dimension Chips per Asset


Assets now display dimension chips, showing test coverage per dimension and highlighting any dimensions with open issues.


## Linear Integration Improvements


You can now edit incident fields before pushing a ticket from Elementary to Linear.


## Additional UI Improvements


- All tables columns are now flexible, and can be reordered to your needs.
- New filters for saved views and role managements: Filter by DB, schema, and table
