# UI Updates Landing in the Nash Portal


April 2, 2025


These UI updates bring a cleaner, more cohesive experience to the Nash Portal—aligning our brand and product design, improving navigation clarity, and giving key interfaces like tables, tabs, and settings more breathing room and usability. Faster, lighter, and more intuitive.


‍


‍


##### Here's what's new and shiny: **‍**


- Font across the board is updated to Host Grotesk


- Not only does this look cleaner, it aligns both our brand and UI font for complete parity
‍


- Main navigation has a new design


- Adjusted size, breathing room, etc. to the main navigation
- New org switcher!
- Moved the Create button to the bottom (priority is now main nav items)
‍


- Updated top bar area and tabs


- The tab styles have been updated to a text + underline style
- Buttons like filters, views, etc. are updated to a text only style
‍


- Table design updates


- The tables themselves have increased breathing room
- Updated a few UI components like the checkbox
- Updated the coloring of subtexts for better scanning
‍


- Brand color


- The brand color is now applied in a few more areas for a more customized feel
‍


- Settings


- Removed the busy expanding settings menu and replaced with a dedicated menu
