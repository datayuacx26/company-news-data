# Product Update: Search + Document Types + Playbooks

### Document Types & Playbooks: A Major Upgrade


We've completely revamped how you manage document types in your contracting workflows. The new centralized document management system lets you:


-


Access all document types in one place


-


Distinguish between Docsum's standard types and your custom ones


-


Find documents faster with new acronym assignments and search capabilities


A key enhancement is the deeper integration with contract review playbooks. Each document type can now be linked to multiple playbooks, where each playbook contains a set of rules for automated contract review against your standards. We've streamlined the playbook interface to make creating, modifying, and searching through rules more intuitive than ever.


### Coming Soon: Smart Field Extraction


Soon you'll be able to configure Fields within each document type. Fields represent key contract information like:


-


Agreement dates


-


Expiration dates


-


Governing law


-


Other critical contract data


Docsum will automatically extract this data upon document upload, enabling powerful search, filtering, and custom view creation.


### Enhanced Search Capabilities


Our new search functionality works within your custom views, intelligently ranking results by relevance. This means finding specific contract information is now faster and more precise than ever.
