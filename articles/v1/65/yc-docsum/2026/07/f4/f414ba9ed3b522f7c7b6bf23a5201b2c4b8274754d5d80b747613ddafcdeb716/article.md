# 🚀 Product Update: AI Chat in Microsoft Word + Bulk Document Type Changes

We’re excited to announce two new features that make contract negotiation and document cleanup simpler, faster, and more connected.


### ✨ AI Chat for Microsoft Word


Contract negotiation happens in Word, so that’s where Docsum now lives too.


Our new AI-powered chat experience lets users:


-


Ask questions about the active contract


-


Pull terms, clauses, and definitions with context


-


Summarize obligations and changes


-


Stream responses directly into the editor


No tab switching. No context loss. Just faster, more informed negotiations.


This is also the first step toward connecting Docsum’s post-signature repository to pre-signature workflows. Historical agreements and deal context can now inform redlines and drafting in real time.


### 📂 Bulk Change Document Type


Repository cleanup just got easier.


Users can now select multiple documents and update their document type in a single action—ideal for:


-


Cloud sync imports


-


Mixed file uploads


-


Legacy contract cleanup


-


Standardizing data across agreements


Bulk operations are also integrated into the Pending Sync view, making it simple to classify “Unknown” documents as they arrive from cloud storage.


### 🚀 Why This Matters


Future releases will deepen the Word ↔ Repository integration and expand the Add-In toward a Cursor-style workflow with drafting, research, and **precedent awareness** powered by your signed agreements.


If you’d like to enable the Word Add-In or get access to these features, reach out; we’d be happy to help.
