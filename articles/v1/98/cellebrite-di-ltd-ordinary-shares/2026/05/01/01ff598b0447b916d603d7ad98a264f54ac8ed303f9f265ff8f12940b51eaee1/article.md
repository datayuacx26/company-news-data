The amount of mobile data being handled by enterprise teams is growing in both volume and complexity. Corporate investigations, insider threat response, and compliance reviews all hinge on one thing: getting complete, defensible mobile evidence — fast. As device encryption tightens and data volumes climb, enterprise teams need enterprise mobile data extraction software that keeps pace without compromising forensic integrity.


Data from our[2026 Industry Trends Survey in the Private Sector](https://cellebrite.com/en/2026-industry-trends-private-sector/) , private sector teams ranked accessing encrypted data and capturing complete data among their top five challenges.[Inseyets for Enterprise](https://cellebrite.com/en/enterprise/cellebrite-inseyets-for-enterprise/) , Cellebrite’s flagship solution, addresses these needs with full file system extraction and the ability to access necessary data from the widest array of iOS and Android devices, as well as cloud environments.


Inseyets is advancing its capabilities now with the latest version delivering targeted technical enhancements designed to improve access reliability, reduce manual intervention and provide investigators with clearer, more actionable data.


With the latest updates, users can now access iPhone 17 and Samsung devices and can perform selective extraction by user account. Teams also have advancements such as Android file system timestamps and more than 50 decoding fixes.


In short, Inseyets helps investigative teams operate more efficiently and quickly with broader coverage, while maintaining forensic integrity.


**What Devices Does Inseyets Support for Enterprise Extractions?**
Enterprise teams handling digital investigations will encounter a variety of devices. For internal investigations, it may be the employee’s own device, or part of a corporate fleet. Device access is foundational to every investigation, and this latest update delivers broad coverage to the latest iOS devices including the iPhone 17 (26.3) and the latest Samsung devices. The expanded coverage reduces the risk of gaps in data collection.


In addition to having access to these operating systems, teams also need stability. The targeted fixes in Inseyets 10.9 addressed known failures related to Cellebrite Mode loading and specific error codes.


**How Do the latest Inseyets Features Improve Enterprise Data Extraction?**
Teams now have multiple enhancements aimed at improving extraction reliability and analyst visibility into collected data.


On Android, file system analysis supports Creation Time and Access Time timestamps when available, giving additional context that can be critical for validation and reconstructing user behavior. This complements existing modification time metadata and allows for more accurate event correlation.


Selective extraction workflows have also been refined with the introduction of a User Accounts category for iOS and Android. This gives investigators the ability to target account‑specific artifacts more precisely, reducing unnecessary data collection while preserving evidentiary relevance.


For iOS selective extractions, this newest version of Inseyets now displays application names and icons, improving clarity during selection and reducing ambiguity when identifying relevant data sources. Additional workflow optimizations throughout the extraction process improve stability, reduce retries and help ensure faster, more predictable acquisition results.


**Expanded Control Over Face Analysis**


UFDR support for detected faces has been expanded to allow importing and exporting of face detection data. This provides greater flexibility when managing faces of interest across cases, supporting collaborative workflows and external review while maintaining control over analytical outputs.


**Streamlined Case Processing and Data Management**


Conducting an investigation quickly and efficiently is a top priority for enterprise teams. However, speed cannot come at the cost of compromising personal information and sensitive corporate intellectual property. Several workflow enhancements are designed to reduce manual oversight and improve station efficiency:


- Real‑time updates from Inseyets.PA are now delivered through the Notification Center, providing a consolidated view of case processing and reporting activity across both platforms
- Automatic deletion (Beta) enables selective data deletion after report generation once backups are confirmed, helping protect sensitive data while reducing storage and station management overhead


**Decoding Engine Enhancements**


Decoding artifacts such as timestamps, photos and location data provide context and valuable information in an investigation. The updated Decoding Engine 19.1 introduces expanded artifact support and stability improvements, including compatibility with third-party vendor transition from XML to Binary PList keychain formats.


Additional parsing support has been added for Visited Places in Apple Maps and Hotspot events on Samsung devices, along with more than 50 resolved decoding issues to improve overall reliability.


**Why These Updates Matter for Enterprise Investigations**


The latest release reflects ongoing investment in access automation, analytical clarity and operational efficiency. By reducing manual steps, expanding platform support and improving decoding depth, this release helps investigative teams adapt to evolving devices while maintaining defensible, repeatable workflows.
