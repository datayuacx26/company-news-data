# Official AutoSplitter for speedrunning

Finally, we are here to celebrate and elevate the speedrunning community that has supported SWORN since the day we dropped the very first Demo on Steam.


This is the official SWORN Autosplitter for the speedrunning community to utilise from the 1.0 release on Steam. Created in tandem with Nikoheart (Speedrunner) and Windwalk Games (Developers). Please share your fastest runs with us in the


[Community Discord Server](https://discord.gg/PHknEXJsj9) , we’re excited to see them - gotta go fast!


Autostart. Load Removal and Autosplit by


[Nikoheart](https://www.nikoheart.com/) .


###


Instructions


Follow these steps to install and setup the pre-defined Autosplitter settings for running SWORN:


1.


Download the latest build of LiveSplit


1.


Version 1.8.33 at the time of writing this


2.


[https://livesplit.org/downloads/](https://livesplit.org/downloads/)


3.


Extract the .zip file to a location on your PC of your choosing


2.


Download the official SWORN Autosplitter files from


[GitHub](https://github.com/Nikoheartttv/LiveSplit.SWORN)


1.


[Any% Splits](https://github.com/Nikoheartttv/LiveSplit.SWORN/blob/main/Speedrun%20Files/SWORN%20-%20Any%25.lss) \[Press Download\]


2.


[Any% Layout](https://github.com/Nikoheartttv/LiveSplit.SWORN/blob/main/Speedrun%20Files/SWORN%20-%20Any%25.lss) \[Press Download\]


3.


Setup LiveSplit with SWORN Any% Splits and Any% Layout files


1.


Within the extracted LiveSplit folder, open LiveSplit.exe


2.


A new timer should appear on the screen, right-click that and navigate to Open Layout > From File and find the downloaded Any% Layout


3.


Right-click again and Open Splits > From File and navigate to the downloaded Any% Splits


4.


This should also download the autosplitter in the process - You can confirm this by right-clicking and clicking on Edit Splits, and the window should say Deactivate (meaning it is now downloaded and active)


5.


Review the settings of the Autosplitter - by default, it will split on every boss and run completion


6.


Depending on the run, make sure to untick the Final Boss, so that the ‘Run Completed’ setting will handle your ending split - See reference image below.


4.


\[Optional\] Download the asset file for social/stream content hosted on the Team17 Google Drive


1.


[Official Asset](https://drive.google.com/file/d/1pD9tuV-MoHjofbFvwYiR0_kZ0OI1umWA/view?usp=sharing) \[Press Download\]
