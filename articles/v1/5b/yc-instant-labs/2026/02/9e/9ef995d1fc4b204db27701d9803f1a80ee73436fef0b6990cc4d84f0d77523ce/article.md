# We Now Support 800+ Domain Extensions

We've nearly doubled the number of domain extensions you can search. See some of the new ones:


## What changed


For a long time, we only surfaced TLDs that were well-supported across our registrar partners. We had the data for hundreds more, but lacked a reliable way to route searches to the right partners for each extension. So we kept the list conservative.


That's no longer the case. With our[improved smart partner routing](https://instantdomainsearch.com/learn/updates/smart-partner-routing) , we can now correctly match every TLD to the registrars that actually support it. Which means we can finally open up the full list.


## Some highlights


Here's a taste of what you can now search:

Plus hundreds of country-code extensions (` .ar` ,` .dk` ,` .fi` ,` .fr` ,` .hk` ,` .jp` ,` .kr` ,` .nz` ,` .pe` ,` .ro` ,` .se` ,` .vn` and many more), internationalized domains in scripts like Arabic, Hindi, Chinese, Korean, and Japanese, and a big batch of Brazilian` .br` extensions.


The full list of newly supported TLDs is at the bottom of this post.
