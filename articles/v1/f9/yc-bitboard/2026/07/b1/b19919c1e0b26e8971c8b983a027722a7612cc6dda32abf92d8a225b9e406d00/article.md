# Dashboards let users and agents collaborate

Dashboards are now collaborative. Presence indicators show other users and agents using the dashboard. Blocks safely avoid conflicts by locking while users make edits.


We’ve made design improvements to our activity indicators, which better show blocks as locked, running, or stale.


We’re launching our[docs](https://docs.bitboard.work/) for easier human and agent interaction, allowing both human and agent users to use our interface.
