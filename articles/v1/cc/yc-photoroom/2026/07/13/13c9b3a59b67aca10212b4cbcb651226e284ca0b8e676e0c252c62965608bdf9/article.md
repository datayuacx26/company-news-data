## **How to start using the Photoroom API for AI product photography**


There are two main ways to use Photoroom’s API for[AI product photography](https://www.photoroom.com/ai-product-photography) : integrate into your workflow or build user features on top of the API. Smaller teams can use the Batch feature in Photoroom to automate editing.


Photoroom's API is built as a REST API—a widely supported integration style that works with Digital Asset Management systems (DAM) and product platforms for[e‑commerce product photos](https://www.photoroom.com/ai-product-photography/e-commerce) . You can create custom workflows and access technical support from the Photoroom team.


### **1. Integrate the API into your internal workflow**


Connect the API to your DAM, set your brand parameters (image presets, background styles, sizing rules), then upload photos. Your DAM calls the API, and edited images return automatically.


**Real example:** Large sports retailer Decathlon integrated Photoroom's API into its DAM platform to process 35,000 images across 8 countries in three months instead of two years, reducing editing time by 99.8% and saving €150,000 in editing costs.


[Read the API documentation to get started →](https://docs.photoroom.com/)


### **2. Integrate the API into user-facing features**


Build the API into your product as buttons, toggles, or AI photo editing options that your users control. You add your own styling, rules, and UX decisions to match your brand. When users click the feature, your app calls the API in the background.


**Real example:** Japan's dominant C2C marketplace[Mercari](https://www.photoroom.com/customer-stories/mercari) built a custom background blur feature using Photoroom's API with a team of 3–4 engineers, improving seller listings while freeing Mercari's team to focus on product innovation.


[Contact our sales team to learn how the API fits into your stack →](https://www.photoroom.com/contact-sales)


### **3. For non-technical teams: use Batch tool**


The[Batch tool](https://www.photoroom.com/tools/batch-mode) ([Web](https://app.adjust.com/13mku062) and[App](https://app.adjust.com/13mku062) ) is a user-friendly interface for the same backend engine the API uses. Simply upload files, apply edits in bulk (up to 250 images per batch), adjust if needed, and download. You get the same high-quality, consistent results as the API. You can also apply your[brand kit](https://www.photoroom.com/brand-kit) to ensure compliance and easily[collaborate with your team](https://www.photoroom.com/teams) in one account if using the app.


**Real example:** Nonprofit retailer[Goodwill Baltimore](https://www.photoroom.com/customer-stories/goodwill) uses the Batch tool to process over 300 images daily, speeding up their listings and increasing brand recognition on their shared marketplace.
