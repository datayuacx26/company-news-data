## **Recently launched**


### **Save and reuse custom models for consistent brand look**


You can now save and reuse custom[Virtual Model](https://www.photoroom.com/tools/virtual-model) for your products by saving your own model photo and instantly applying it across visuals. Using the same model consistently creates a more human, trustworthy brand presence that helps drive faster sales.

**For:** Max and Ultra users

## API updates


### Virtual model


Fashion catalogs don't scale with manual shoots. Re-uploading the same model image for every SKU, chasing agency turnarounds, inconsistent outputs across channels; it adds up fast in launch delays and cost drag.


Virtual Model is now available via API. Upload a clothing photo, choose a model (preset or custom), a scene, and a pose, and the API generates a lifestyle shot. No photoshoot.


Set` virtualModel.mode` to` ai.auto` . Control the output with` virtualModel.model.preset.name` ,` virtualModel.scene.preset.name` , and` virtualModel.pose` .


Default output is 1K (` 1024x1024` ). 2K and 4K outputs are available on the Enterprise plan only.


View the full parameter reference and try it in the API[here](https://docs.photoroom.com/image-editing-api-plus-plan/virtual-model) .


**Platform:** now available via API. Also available on web, iOS, and Android.
