# Product Updates: July 1, 2026

This release brings a new wave of improvements focused on AI-powered workflows, deeper cloud integration visibility, and smarter cost management tools. From natural language access via MCP to enhanced anomaly detection, and more flexible filtering, these updates are designed to help teams move faster and make better decisions across their cloud environments.


## **MCP Server**


You can access Billing Explorer and other Cloudchipr capabilities directly from your favorite AI tools using natural language. Query cloud costs, analyze billing data, and review savings opportunities without leaving your AI workflow.


## **GitHub Copilot Integration**


You can now connect GitHub Copilot to Cloudchipr and start tracking your AI-related spending alongside the rest of your cloud costs. The integration pulls in Copilot billing data and surfaces it in Billing Explorer, where you can filter and group by repository for a more granular view of usage and spend.


## **Savings Opportunities: Share via Slack and Email**


You can now share Savings Opportunities directly to Slack or via email. Whether you're flagging a recommendation for a teammate or looping in a decision-maker, you can send a direct link right from the recommendation without leaving Cloudchipr.


## **Anomaly Detection History**


Anomaly Alerts now include a full detection history, so you can see every anomaly that was triggered by each alert over time, not just the notification that fired.


## **Filters on Tasks**


The Tasks view now has the same filtering experience as the rest of the platform. You can filter, slice, and find tasks the same way you do in Savings Opportunities and other views, making it easier to manage your workload without switching contexts.


## **VM Attachment Visibility for GCP and Azure**


Live Resources now shows attachment details for GCP and Azure virtual machines. This makes it easier to understand which VMs have unattached or idle disks across your multi-cloud environment.


## **API Key Management Improvements**


The API Keys now includes a Last Used column, making it easy to see which keys are active and which have not been used in a while. The expiration requirement has also been removed, giving teams more flexibility in how they manage long-lived API credentials.


## **Duplicate Dimensions**


You can now duplicate a Dimension directly from the Dimensions page. This saves time when building out similar groupings or making variations of an existing configuration.


## **Budget Message Editing**


Budget messages can now be edited after creation. You can also mention teammates in budget messages, making it easier to loop in the right people when a budget threshold is approaching or has been exceeded.

These are some of the key updates shipping in this release. As always, we've also shipped a range of bug fixes, performance improvements, and usability tweaks, many of them driven directly by customer feedback.
