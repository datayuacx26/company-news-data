# Introducing SIP Trunking Number To Trunk Mapping via API

Plivo SIP Trunking offers fast setup, instant number provisioning, exceptional voice quality, and pay-as-you-go pricing. Users manage SIP Trunking from the same Plivo console they use for our[SMS API](https://www.plivo.com/sms/) and[Voice API](https://www.plivo.com/voice/) — but we’re now adding new ways of managing[SIP Trunking](https://www.plivo.com/sip-trunking/) functions programmatically to help customers streamline their workflows.


Until now, SIP Trunking customers would log in to the Plivo console to map phone numbers to inbound trunks. Managing a large volume of numbers and trunks could become cumbersome and time-consuming.


To address this issue, Plivo has enhanced our Number API to allow mapping numbers to SIP trunks. You can now use the[AccountPhoneNumber object](https://www.plivo.com/docs/numbers/api/account-phone-number#the-accountphonenumber-object) and pass an inbound trunk ID as an application ID to map a number to an inbound trunk. For all of the technical details, see our[API reference documentation](https://www.plivo.com/docs/numbers/api/account-phone-number#update-a-number) .


Using the API lets SIP Trunking customers automate mapping of numbers to inbound trunks programmatically, allowing businesses to manage large volumes of numbers and trunks efficiently. Using the developer-friendly API saves time and effort when mapping multiple numbers to trunks and minimizes the chance of human error. The mapping process in SIP Trunking is now consistent with the same process in our SMS and Voice APIs, making for a smooth and unified experience across the platform.


The new mapping capabilities join our other[recently announced SIP Trunking APIs](https://www.plivo.com/blog/introducing-new-zentrunk-apis/) : the Trunk Properties API, which lets businesses create, modify, and update their SIP trunk configurations programmatically, and the Call Object API, which lets users retrieve SIP Trunking call detail records (CDR).


All of the new SIP Trunking APIs are designed to enhance the user experience for SIP Trunking administrators. And it must be working: global media company TMC named SIP Trunking a 2023[Communications Solutions Product of the Year](https://www.plivo.com/blog/award-tmc-2023/) .
