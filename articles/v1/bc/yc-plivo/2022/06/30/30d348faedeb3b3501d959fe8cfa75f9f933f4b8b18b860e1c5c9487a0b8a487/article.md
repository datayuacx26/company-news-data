# How to Handle SMS and Voice Communications Using .NET

Plivo has a lot of great capabilities built into its cloud communications platform. If you’re a .NET developer, this post is for you: Learn how easy it is to send and receive SMS text messages and make and receive voice calls with .NET , the Plivo .NET SDK, and Plivo APIs.


## How to send and receive SMS messages


If you’re interested in messaging applications, Plivo’s cloud communications platform makes things easy for you.[Sending an SMS message](https://www.plivo.com/blog/send-sms-in-dotnet/) requires just 20 lines of code; receiving messages takes just 23, or you can[create a .NET application to receive and respond to SMS messages](https://www.plivo.com/blog/receive-respond-sms-asp-dotnet-mvc-plivo/) .


## How to send and receive MMS messages


[Sending MMS messages](https://www.plivo.com/blog/how-to-send-mms-in-dotnet-using-plivo-api/) is equally simple, and we’ve written a[guide to receiving and responding to MMS messages with .NET](https://www.plivo.com/blog/how-to-receive-and-respond-incoming-mms-messages-in-dotnet/) .


## How to get set up and make and receive phone calls


Start by reading[how to make a phone call from a Python application using Plivo’s Voice API](https://www.plivo.com/blog/make-phone-calls-in-dotnet/) . That post covers how to install Plivo’s Python SDK, which makes it easier to build applications that use Plivo. The SDK provides objects, functions, and methods to handle common tasks associated with building voice and messaging applications.


Once you have that in place, you can use[PHLO](https://www.plivo.com/phlo/) , Plivo’s visual workflow design studio, to set up the workflow of the call, then trigger the PHLO with a few lines of Python code.


Once you know how to use Python with Plivo to make and receive calls, you can move into specific use cases, such as[call forwarding](https://www.plivo.com/docs/voice/use-cases/call-forwarding/dotnet/#xml) and[interactive voice response](https://www.plivo.com/docs/voice/use-cases/ivr/dotnet/#xml) systems.
