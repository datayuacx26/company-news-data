# Introducing Vesence Compare

## What It Is


Vesence Compare puts two versions side by side and marks every difference between them. You run it on documents, emails, and spreadsheets straight from the Vesence Platform, across Microsoft Word, Excel, PowerPoint, Outlook, and PDFs, and it finishes within seconds.


## How It Works


Compare reads both files natively rather than as plain text, so it catches text edits, formatting changes, table changes down to the row and cell, and swapped images. The result is a proper redline: tracked changes to step through in Vesence, open in Word, or render straight to a PDF you can send. Ask for a comparison in plain language and the agent runs it for you.


## Why It Matters


Comparing versions is where mistakes hide: a quietly reworded definition, a row dropped from a schedule, a figure swapped in a deck. Law firms, banks, and corporate legal teams use Compare to check every turn before it goes out.


We also believe compare has to cover emails, Word files, and PDFs for an agent to take a workflow end to end. A turn arrives as an attachment to an email, gets marked up in Word, and goes back out as a PDF. An agent that can only compare one of those formats hands the work back to you halfway through.
