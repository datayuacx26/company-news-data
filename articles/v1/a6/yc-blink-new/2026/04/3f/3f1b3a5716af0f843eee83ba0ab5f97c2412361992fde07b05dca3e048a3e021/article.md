## Step-by-Step: Build Your Store With Blink


Blink generates the full stack — frontend, backend, database, and auth in one step. No Supabase account. No Vercel config.


### Step 1: Describe Your Store


Open Blink and enter a prompt like:


> "Build me an e-commerce store for \[product type\]. Include product listings with photos and prices, a shopping cart, Stripe checkout, and user accounts with order history."


With Blink, the entire project structure is generated automatically — no separate framework setup needed.


### Step 2: Set Up Your Product Catalog


Ask Blink to generate a product schema:


> "Add a product catalog with categories, inventory tracking, and a product detail page."


With Blink, the database is included automatically — no Supabase account needed. Product data is stored and retrieved from day one.


### Step 3: Add the Shopping Cart


Build cart functionality:


> "Add a shopping cart that persists across sessions and shows item count in the header."


With Blink, session management and cart state are handled automatically — no separate Redis or session store to configure.


### Step 4: Connect Stripe Payments


Wire in payment processing:


> "Add Stripe Checkout for payment processing. Redirect to a success page after payment. Send a confirmation email to the customer."


Stripe integration requires a Stripe account for your API keys. With Blink, the payment flow code is generated — you provide your Stripe keys and it wires everything together.


### Step 5: Add User Accounts and Order History


Build the customer experience:


> "Add user signup and login. Show each user their order history with status and tracking."


With Blink, auth is built in — no Clerk or Firebase Auth to configure. User accounts work out of the box.


### Step 6: Set Up Inventory Management


Add admin controls:


> "Add an admin dashboard to manage products, update inventory, and view all orders."


With Blink, admin pages are protected by role-based auth automatically — no separate admin system to wire.


### Step 7: Go Live


Deploy with one click:


> "Deploy this store to production."


With Blink, hosting is included — no Vercel config, no DNS setup. Your store is live at a real URL immediately.
