# How to Deploy a Cursor or Claude Code App to Production

## The DIY Path (Honest Cost Breakdown)


You can assemble this infrastructure yourself. Here is what that looks like:


Service What it does Setup time Monthly cost


Supabase Postgres database ~30 min $25/mo


Clerk or Auth0 Auth + sessions ~45 min $23/mo


Railway or Render Backend hosting ~20 min $20/mo


Vercel Frontend hosting ~20 min $20/mo


Cloudflare R2 File storage ~30 min $5/mo


Domain + DNS Public URL + SSL ~20 min $12/yr


**Total** **~3 hours** **$90–150/mo**


That is six accounts. Six sets of API keys. Six separate CORS configurations. Six dashboards to check when something breaks at 2am.


Vercel handles frontend deployment beautifully. It does not handle your backend runtime, your database, or your auth. Every service in this table is solving exactly one layer — and you are the glue between all of them.

## The 5 Most Common Deployment Mistakes


Most Cursor and Claude Code apps fail in production for the same five reasons:


**Committing the` .env` file to GitHub.** AI coding tools sometimes write secrets directly into configuration files. Check your git history before making the repo public — or use Blink's secrets manager from the start.


**Missing CORS configuration.** Your frontend on` app.yourdomain.com` and your backend on` api.yourdomain.com` are different origins. You need explicit CORS headers or requests will silently fail.


**Assuming Vercel handles long-running jobs.** Vercel functions time out at 10 seconds. File processing, email queues, and cron jobs need a real backend runtime — not a serverless function.


**No monitoring before your first users.** The first user to trigger an unseen bug will do it silently. Set up basic error logging before you share the link publicly.


**Skipping database migrations.** Your local schema has columns and tables you added during development. Your production database starts empty. Running` prisma migrate deploy` or equivalent is not optional — it is the deployment step most AI-generated apps miss.
