## How to Choose OpenClaw Skills (Don't Install Everything)


Installing too many skills creates conflicts. Skills that need similar permissions — like calendar access or email sending — can interfere with each other.


Start with three to five skills that match your core workflow. Add more only when you hit a specific gap. The OpenClaw community calls this the "essential stack" approach.


**Three rules before you install:**


1. Only install skills you'll use weekly
2. Avoid two skills that touch the same service (e.g., two email integrations)
3. Read the skill's README — it lists permission requirements
