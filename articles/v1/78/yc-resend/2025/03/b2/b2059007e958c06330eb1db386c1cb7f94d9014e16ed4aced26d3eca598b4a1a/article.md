# new.email Public Launch

This project has been discontinued.[Learn more](https://resend.com/blog/sunsetting-new-email) .


Since we[first announced new.email](https://resend.com/blog/introducing-new-email) about a month ago, more than **14,386 people** have signed up for the waitlist.


Today, we're excited to announce **the public launch of[new.email](https://new.email/)** to help you build emails faster and easier.


## What is new.email?


It's always been a challenge to create email templates.


With the rise of AI tools, templating has become both easier and more difficult. Most LLMs can generate templates, but you can't have confidence they'll render correctly in all email clients. Email templates are only helpful if you can trust them.


## How does it work?


[new.email](https://new.email/) is for developers, marketers, designers, and anyone who wants to create beautiful emails using natural language.


Start by creating a template and refine it until it looks great.


## Send test emails


To test how your emails look in real life, you can send them to your own inbox using Resend.


## Export for production


When you're ready to send, you can copy or download the content of your email as:


- React component
- HTML
- Plain text


## Share your templates


All templates are private by default, but you can share any email with individuals or publicly to anyone with a link.


## Ready for mobile


We've taken a fresh view on new.email's mobile experience so you can create on the go.


The floating preview shows your changes in real-time and you can toggle between the code and preview modes.


## Powered by React Email


Every component you see on this editor is powered by[react.email](https://react.email/) , an open-source library developed by Resend to help you build emails using React.


This means that you don't need to worry about your email being compatible with different email clients like Gmail, Outlook, Apple Mail, and others.


## Get started today


You can prompt up to 20 times per month and send 10 test emails a day for free.


We're excited to see what you'll build with[new.email](https://new.email/) .
