# Vercel Integration

We're thrilled to announce a new integration with[Vercel](https://vercel.com/) , designed to speed up the process of managing API keys and environment variables in your Vercel projects.


Starting today, you can integrate your Vercel projects directly within the Resend dashboard. This means that with just a few clicks, you can automatically create a new API key linked to the domain of your choice and have it instantly added as an environment variable in your Vercel project.


## How it works


To get started, head over to the[Resend Integration page](https://vercel.com/integrations/resend) and follow the steps.


You'll be prompted to select your Vercel team and either the project of your choice, or all projects in your account.


Once you're done, a new API key, generated specifically for the integration, will be added as an environment variable in the project of your choice.


No more switching between tabs, manually creating and copying API keys, or worrying about misconfigurations.


This integration does all the heavy lifting for you, so you can focus on building amazing projects.


## One more thing


There's also a[new Vercel template](https://vercel.com/templates/other/react-email-resend) for you to get started with Next.js + React Email.


This includes a pre-configured Next.js project integrated with a real React Email template. Plus, a Resend API key already set up as an environment variable, so you can start sending emails right away.


Go ahead and[give it a try](https://resend.com/settings/integrations) . We can't wait to see what you build with this new integration.
