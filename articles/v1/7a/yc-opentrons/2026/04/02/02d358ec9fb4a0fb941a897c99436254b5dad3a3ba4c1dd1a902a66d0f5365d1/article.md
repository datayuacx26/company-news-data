# What’s New – Opentrons App 9.0

### Miscellaneous Improvements


####


• **Quick Transfer updates** : integrated into the Protocols tab, with pinning and run tracking like standard protocols-


• **Liquid class enhancements** (API 2.28): improved blowout control, efficiency fixes, and expanded configurability


• **Partial tip pickup + return tip support** for more flexible tip usage


• **Protocol visualization improvements** : clearer differentiation of aspirate, dispense, and air gap steps


• **System-level updates** : ongoing improvements to robot performance and execution reliability
