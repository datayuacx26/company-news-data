# Build Universal Apps in Bloom


Preview both mobile and web while you build, toggle between them with one click, and every change updates both in real time.


Bloom now builds for the web, not just mobile. Every app you create works on iOS, Android, and the web from a single codebase. Go mobile-first, web-first, or both.


The preview panel now includes a


**web/mobile toggle**


so you can switch between a browser layout and a phone device frame while you build.


Toggle between web and mobile preview If you're building something people will use on a computer, switch to web preview and make sure the layout takes advantage of the extra space. Available now for all users on web.
