# July 2025 Product Update: Kodex API & View as Law Enforcement

## What's New


### View as Law Enforcement


You can now see what law enforcement sees when logging into Kodex, on your overview page and your customized legal request process form. Go to Settings > Theme Settings > Screen Previews to see more.


### Insights into Reimbursements


New tools to help you collect faster: automated notifications and follow-ups for outstanding payments, plus a dashboard giving a clear view of incoming revenue and budget impact. You can now see how much you are actively getting back in dynamic Insights reports.


### Unlock Possibilities with the Kodex API


A new API workflow for target lookup and data production, along with a dedicated Developer Center to streamline implementation. Key benefits:


- **Efficiency:** Automate routine tasks like selector lookup, "no data" filtering, and data packaging. Up to 30% of requests can be instantly resolved.
- **Accuracy:** Minimize errors in file mapping and query construction, avoiding back-and-forth with law enforcement.
- **Security:** Remove the need to download files locally, reducing insider-threat and unauthorized-access risk.
- **Compliance and auditability:** A complete, traceable chain of custody through secure, immutable activity logs.


### Case Assignments


Now available in the Data Insights module, enabling smart capacity planning and balanced case allocation based on factors like risk, jurisdiction, and complexity, with deeper visibility into individual performance.


## Coming Soon


- **Targets 2.0:** Smarter grouping, bulk uploads, and real-time data validation for law enforcement, plus a streamlined UI for analysts to edit targets, perform bulk actions, and label target IDs.
- **Strengthening the verification feedback loop:** Clearer suspension reasons, real-time status change alerts, and new tools to help law enforcement resolve access issues quickly.
