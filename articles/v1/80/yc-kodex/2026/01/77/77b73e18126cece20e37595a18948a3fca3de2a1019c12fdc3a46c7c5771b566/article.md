# January 2026 Product Update: Targets 2.0 Goes International

## What's New


### Mark all messages as read in one go


A new button at the top of all cases lets you mark all messages and comments as read in a single click, clearing the red-dot indicators.


### New queue and statuses for NDO


Enhancements to the NDO workflow for better request tracking and status accuracy. When a Completed request's associated NDO either expires without action or is extended, the system automatically sets the request status to Reopened so it always reflects the current state of the NDO. Optional auto-tagging can mark reopened requests as "NDO Expired" or "NDO Extended," and the tag is removed automatically once the request returns to Completed. This is configurable at the organization level, contact your CSM to enable.


### Timestamps added to homepage


Timestamps now show on the homepage so you can see exactly when a request was created, updated, and more. Especially helpful for prioritizing time-sensitive investigations.


### Rollout of Targets 2.0 internationally (1/20)


Agent Submission 2.0, the updated flow designed to capture more accurate target information upfront, is now live for all agents internationally.

- **Localized date pickers for agents and analysts:** Launching in February, supporting locale-aware formats.
