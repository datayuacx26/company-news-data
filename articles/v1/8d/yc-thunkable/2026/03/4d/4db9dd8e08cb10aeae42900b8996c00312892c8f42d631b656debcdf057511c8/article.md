# Feature Highlight - Discuss Mode

Our research shows that users who build with Discuss Mode have higher success with their projects than those who don't use the feature.


Discuss Mode lets you plan features, updates, and ask questions about the app without making changes to the app’s code. Planning your next change with the AI agent in Discuss Mode makes your build experience more predictable, lowers the token cost for development and improves the overall quality of your app.


# Why Should I Use Discuss Mode?


Builders who use Discuss Mode experience improved:


- **Planning** - Generate new ideas and understand the best approach to building your app
- **Predictability** - Clarify requirements for feature updates so the next code update meets your vision
- **Speed** - Speed up development by reducing iterations and build time, leading to lower token costs for your app build


Once you’ve planned the next update for your app, you can return to Build Mode to implement the changes or make the changes directly from Discuss Mode.


Implement code change from Discuss Mode


# ‍ **Enabling Discuss Mode**


Click the **Discuss** button in the prompt box to switch to **Discuss Mode** . When it’s active, the button and prompt box will turn **purple** .


Prompts sent in Discuss Mode **won’t change your code** . This lets you explore ideas, ask questions, and plan changes before applying them.


Click the Discuss button to enable Discuss Mode


# ‍ **Planning in Discuss Mode**


Plan the next iteration of your app by asking how to make the next change. Based on your prompt, Discuss Mode will ask clarifying questions or outline the subsequent code change the builder would make.


Continue to refine the requirements until you’re satisfied with the next planned move. When you’re ready to implement the next change, you can do so directly from Discuss Mode or return to Build Mode and make your change.
