# Benchling Product: 2019 Year in Review

With 42 novel drug approvals and $21.5B in new venture financing, life sciences R&D continued to make headlines in 2019. And Benchling continued to serve life sciences R&D by enabling and accelerating breakthrough research and innovation. Over the course of the year, we improved the versatility of our product offering and added powerful, enterprise-class administrative tools to our platform. Below are a few highlights of our 2019 product advances.


### Powerful features packed into the Notebook to make it the cornerstone of your research


Today, life scientists are running experiments and carrying out processes that are more complex than ever. Our hope is to support that complexity, while also simplifying a scientist's workflow. We added several new features to the Notebook to consolidate sample management directly in a Notebook entry.


#### Transfer Tables


Create Inventory items directly from a Notebook entry.[Learn more.](https://help.benchling.com/hc/en-us/articles/9684265943565-Run-a-workflow-transfer-tables)


#### Plate Creation Tables


Create multiple plates and scan plate barcodes into these tables in the Notebook.[Learn more.](https://help.benchling.com/hc/en-us/articles/9684245572749-Use-a-Plate-Creation-Table)


#### More Formulas


Calculate with formulas such as IF, ABS, LOG, ROUND, and SQRT in your Notebook entry.[Learn more.](https://help.benchling.com/hc/en-us/articles/9684235755277-July-2019-New-Notebook-Features)


---


### New tools and streamlined bulk capabilities in our Molecular Biology application


Molecular biology research has evolved significantly with the need for high-throughput design and sophisticated analysis. Benchling’s Molecular Biology application offers industry-leading high-throughput sequence design capabilities and sequence-based analytics. In 2019, we added a new Codon Optimization tool and further improved our marquee Bulk Assembly and CRISPR tools.


#### Codon Optimization


Design DNA sequences whose codon frequencies better match those found naturally in your target organism.[Learn more.](https://help.benchling.com/hc/en-us/articles/9684246819213-Codon-optimize-DNA-sequences)


#### Bulk Assembly Improvements


Organize sequences with Worklists, assemble linear DNA fragments in bulk, and automatically detect homology.[Learn more.](https://help.benchling.com/hc/en-us/articles/9684257314957-Learn-the-basics-of-Bulk-DNA-Assembly)


#### CRISPR Guide Design Enhancements


Export CRISPR guides into Worklists, specify custom PAMs, and toggle SpCas9-specific positional weights on and off.[Learn more.](https://help.benchling.com/hc/en-us/articles/9684282104333-Design-guide-RNAs-gRNAs-)


---


### Improved sample tracking to make using Inventory items effortless


Life sciences R&D relies on accurate and efficient sample management to generate high-quality results. We added several key features to our Inventory and Registry applications to make them more intuitive and allow sample management in bulk.


#### Check-Out / Reservation System


Check-out or reserve Inventory containers while you use them or plan ahead for future use.[Checking out](https://help.benchling.com/hc/en-us/articles/9684235488013-Checking-out-containers) and[Reserving](https://help.benchling.com/hc/en-us/articles/9684226987405-Reserving-containers) .


#### Worklists


Move containers, entities, and batches between Benchling applications and modify them in bulk.[Learn more.](https://help.benchling.com/hc/en-us/articles/9684242570637-What-is-a-worklist-)


#### Computed Fields Over Results


Display schema fields that autocompute results associated with an entity in a Registry entry.[Learn more.](https://help.benchling.com/hc/en-us/articles/9684246747149-August-2019-Product-Release-Notes)

### Advanced platform capabilities for enterprise-class controls and administration


IT teams are looking for flexible and easy-to-use tools that let them fully control and leverage their organization’s systems and data. This past year, we released major features that provide advanced controls for seamless user management on the Benchling platform.


#### Next-Gen Permissions System


Generate user roles and profiles based on highly customizable access policies.


#### Tenant Administrator Console


Manage Benchling usage and access Benchling settings and configurations.[Learn more.](https://help.benchling.com/hc/en-us/articles/9684226943885-Access-the-Tenant-Admin-Console-Industry-)


#### User Provisioning

### Many more features to enable innovative life science R&D teams


These are some of the other highly requested features that were released in 2019.


1.


Improved search and new UI for filters: Search more seamlessly across the entire platform and sort through results with new custom filters.


2.


Registry labeling: Create customized Registry[labels](https://help.benchling.com/hc/en-us/articles/9684225733261-Printing-labels) for any entity that has a Registry ID.


3.


Creating entities directly in Registry:[Create entities](https://help.benchling.com/hc/en-us/articles/9684244090509-Create-and-register-a-single-entity) in a Registry entry without creating samples in a project first.


4.


Archiving Registry schema fields and schemas: Org Admins can now archive outdated schema fields and[schemas](https://help.benchling.com/hc/en-us/articles/9684263149325-Archiving-Registry-schemas) .


5.


Dedicated Warehouse tables for every schema type: Every entity, batch, container, box, location, and entry now has its own dedicated table in the Data Warehouse.


6.


API integrations with code examples: We released a new API that allows users to[update requests directly through the API](https://docs.benchling.com/v2/reference#requests) and several code examples to[upload Results into Benchling](https://github.com/benchling/integration-examples) and to sync Registry entries[into](https://github.com/benchling/integration-examples/tree/master/sync_into_benchling) and[out](https://github.com/benchling/integration-examples/tree/master/sync_out_of_benchling) of Benchling.


7.


Creating requests with entities from toolbar: Create a request in new ways such as with a Worklist, from Registry search, and expanded project list view.


8.


Support for GovCloud: Benchling cloud infrastructure now supports AWS GovCloud.


9.


Barcode printing: Benchling now supports printing of labels by using the[Zebra Browser Print application](https://help.benchling.com/hc/en-us/articles/9684254890381-Creating-label-templates-using-Zebra-Designer) .


10.


Bulk creation of drop down options for registry schemas: Registry schemas can either be imported from a spreadsheet or using API calls.
