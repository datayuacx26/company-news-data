# Diversion Product Updates: June Highlights (06/25)

# ‍


Dear community, Summer’s heating up, and so are our updates! ☀️
We’ve packed in some cool new features to boost your workflow and save you time. Ready to check them out?


##
🎮 **Unreal Engine 5.6 plugin support**


We now support UE 5.6 out of the box! If you’re upgrading, the Diversion plugin is ready to follow you there. UE 5.3 got the latest features and improvements as well![Download UE Plugin. ‍](https://www.fab.com/listings/59d591f2-4026-4e8f-9128-9c8ef1ff9bab)


## 🔒 **Read-only clones**


Need a safe way to share a repo? You can now clone with read-only permission, perfect for teammates who just want to peek without making changes.
‍


## **📊 Organization summary page**


Easily get a high-level view of your organization - members, workspaces, and recent activity - all in one place. Great for admins and curious minds alike!


## ‍
**⚔️ Smarter conflict handling while offline**


No more lost work! If you and a teammate changed the same file while you were offline, Diversion will back up your file instead of replacing it. If that happens, you’ll see a file like Diversion_ftw.png.dv-conflict-4.import so you can review and resolve with confidence. And of course there’s still Diversion's awesome conflict prevention that works while you are online.
