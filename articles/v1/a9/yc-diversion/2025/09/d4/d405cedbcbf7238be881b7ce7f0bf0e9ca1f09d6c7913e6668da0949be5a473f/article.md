# Diversion Product Updates: September Highlights (09/25)

Dear community,
We’ve got a big drop this month - packed with features you’ve been asking for, designed to make your daily workflow smoother than ever. Ready to see what’s new?


### 🎨 Art Previews (yes, really!)


No more blind guesses! You can now preview .uasset, .fbx, .glb, and .obj files right inside Diversion. Just open the file in the app, and the preview pops up instantly. Perfect for quick reviews, sanity checks, or just making sure that model really is what you think it is.


### 🌿 Branch Graph Actions


You can now navigate the branch graph and perform your actions right there: Right-click a commit (or use the new ⋯ on the node) to switch branches, merge, create a branch, cherry-pick, revert, and more - all without leaving the graph.


### 🏢 Better Organization Management


Need a new org? Do it yourself, no ticket required. You can now create and manage organizations directly:


- From **Create New Repository → Create New Organization** in the org dropdown:


‍


- Or via your **avatar → Create Organization:**


And this is just the start - more self-serve org management features are on the way.


### ☁️ Clearer Sync Status


Wondering what your agent is up to? Now you’ll always know. The header clearly shows whether you’re “Syncing…” or “Synced to commit X,” so you can track your exact state.


### 🎮 Unreal Engine - Diversion Status


Branch and sync status now have a dedicated, always-visible area in the UE plugin.
