# Diversion Product Updates: July Highlights (07/26)

Dear community,
Some people are packing suitcases, some are planning long weekends, and we’re over here packing this newsletter with fresh Diversion updates. Ready to see what’s new?


### **🎮 Unreal Engine 5.8 support**


Teams on the latest Unreal Engine, this one’s for you. Our Unreal plugin now supports **Unreal Engine 5.8** , so you can plug Diversion straight into your workflow and keep building without skipping a beat.


If the plugin saved you a few headaches, we’d be grateful for[a review](https://c.vialoops.com/CL0/https:%2F%2Fwww.fab.com%2Flistings%2F59d591f2-4026-4e8f-9128-9c8ef1ff9bab%3Flang=en/1/0100019f84ecbbb5-9b77e5b3-04e8-4d7f-bf96-d265954b4812-000000/HTczBlsvD9eg7PWRAyHIr4u07bU6RxOzfolC_MW6BZM=452) . It helps more Unreal developers find Diversion - and gives our team a very nice reason to smile 💙
‍


### **🎨 Unity support improvements**


Unity assets are getting a clearer preview. We improved support for Unity asset previews, including files like .meta, so it’s easier to understand what you’re looking at before opening anything.[Download Unity integration](https://c.vialoops.com/CL0/https:%2F%2Fassetstore.unity.com%2Fpackages%2Ftools%2Fversion-control%2Fdiversion-connect-for-unity-353134%3Fsrsltid=AfmBOooU48xdrz1kkIKRNRF1H6Sd6SK30CUl-qGMzDvD5AwknPcoPMbi/1/0100019f84ecbbb5-9b77e5b3-04e8-4d7f-bf96-d265954b4812-000000/BICWc3DLwfjKEWB7EJhp4zT7JNSwmTsovIi1LHkSc_Q=452)


### **💬 A smoother review experience**


Reviews got a nice little quality-of-life upgrade. Code review comments now have a real editor, and the whole comment pane is easier to work with - especially when discussions get longer than expected. You know, like they always do.


What’s new:


- Write comments in Markdown with a formatting toolbar and live preview.


- Use a cleaner, resizable comment pane that makes long discussions easier to follow.


- Submit a comment with Cmd/Ctrl+Enter.


‍


### **📈 A sharper commit graph**


Busy repo history? It’s much easier to navigate now. You can filter the commit graph by author to focus on one teammate’s work, and the commit drawer now shows branch names instead of internal IDs - because your brain has better things to do 😇


### **⚡ CLI updates**


A few helpful CLI upgrades landed this month:


- Open a review request with dv review, no web-app detour needed. And yes - if you work with an AI agent, it can now open reviews for you too.
- Use dv view to open your workspace directly in the Desktop app when it’s installed.


### **✨ Small fixes, real workflow wins**


A couple of smaller updates that should make day-to-day work smoother:


- .slnx files are now ignored by default in .dvignore.


- Right-clicking a file in the commit details view now opens a context menu.


Small? Yes. Useful? Also yes. 😌
