### Short Description:


A step-by-step course to learn test automation with the testRigor framework. Perfect for beginners, it starts with basic concepts and moves on to advanced topics. The course follows testRigor and industry best practices for test automation.


### Course Format:


The course consists of 43 pre-recorded video lectures, organized by topic with a logical flow from one lecture to the next. Each lesson ends with a self-assessment to check understanding. After major topics, a practice assignment needs to be submitted for review. Artem Bondar reviews the assignment and provides personal feedback with helpful suggestions.


### What you’ll learn:


- How to write effective prompts to locate web elements on the page using the relative location mechanism of testRigor
- How to interact with different types of UI elements such as input fields, lists, tables, date pickers, and more
- How to use variables and perform data-driven testing
- How to organize scenario prompts into reusable rules
- How to effectively manage reusable rules and shared suites
- How to use Generative AI to generate automated test cases
- How to handle APIs in testRigor
- How to use JavaScript in testRigor and other advanced features
