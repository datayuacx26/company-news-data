## Grab the Count of an Element


Our team has released a new command that will grab the count/occurrences of an element in a given page and store the result in a variable. This command will work with relative locators, and it can also be used in tables (i.e., count the number of rows that fulfill a certain criterion). You can find more details about how to use this command on our documentation page[here](https://testrigor.com/docs/language#grab-count) .


## XAPK File Support


Since our latest update, mobile test suites using Android will now support XAPK files.
