## What is FYI Docs?


FYI Docs is a cloud-based document and[practice management software](https://www.getcone.io/blog/practice-management-software-benefits-for-accountants) designed specifically for accountants by accountants. With automation and tools to manage emails, documents, tasks, and client communications, FYI Docs reduces manual work, giving teams more time to focus on core activities.


## Best Features of FYI Docs


FYI Docs helps accounting practices stay organized with a host of features like:


- **Centralized Cloud Storage:** Secure, cloud-based storage for all documents
- **Auto-Filing of Documents:** Automatically files emails, attachments, and documents to the correct client records without manual effort
- **Email Management:** File and manage emails alongside other client documents for a complete record
- **Document Creation Templates:** Pre-built templates for common accounting documents and client communications to speed up document generation
- **Integration with Practice Management Systems:** Automatically sync client information from Xero Practice Manager or other systems
- **Automated Workflows:** Build and automate multi-step workflows for routine processes, such as compliance jobs or onboarding clients
- **Audit Trails:** Tracks user activity and document history for accountability and compliance


## Who is FYI Docs for?
