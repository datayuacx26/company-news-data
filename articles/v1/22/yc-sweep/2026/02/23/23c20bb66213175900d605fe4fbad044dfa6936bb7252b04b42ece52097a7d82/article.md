# Sweep is now available in Zed!


William Zeng


•


February 04, 2026


*Sweep Autocomplete is now available in the Zed Editor.*


---


We’re excited to announce that Sweep Autocomplete is now available for[Zed](https://zed.dev/) , the high-performance, multiplayer code editor built in Rust.


## Getting Started


Installing Sweep in Zed is simple:


1. Open Zed Settings -> AI
2. Configure Edit Prediction Providers
3. Set your Sweep API Key (found at[https://app.sweep.dev](https://app.sweep.dev/) )


That’s it! You’ll immediately start getting intelligent, context-aware code completions powered by our largest and most advanced next-edit prediction model.


## What’s Next


We’re committed to bringing Sweep’s autocomplete to every editor developers love. With Zed support now live, we’re continuing to expand our IDE coverage while improving the core autocomplete experience.


Try Sweep in Zed today and experience the future of code completion.
