# Update your browser: Security fix for Chrome zero-days CVE 2026-3909 & CVE-2026-3910

Hi everyone!


The latest patches to Opera’s browsers address several recent vulnerabilities, including two zero-day exploits (CVE 2026-3909 and CVE-2026-3910). We recommend updating your browsers to the latest versions or directly downloading them from our website.


Make sure to update your browser to the latest version:


- Opera One: 128.0.5807.77
- Opera GX: 128.0.5807.78
- Opera Air: 128.0.5807.79
- Opera Neon: 127.0.5778.126
- Opera for Android: 96.2


We will be sharing more information as more updates are released. If you have any trouble auto-updating, you can download the latest versions of the browsers[here](https://www.opera.com/download) .


As always, stay safe out there!
