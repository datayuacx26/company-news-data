# Update your browser: Security fix for Chrome zero-day CVE-2026-2441

Hi everyone!


The latest patches to Opera, Opera GX, Opera Air, Opera Neon, and Opera for Android address several recent vulnerabilities, including a zero-day exploit (CVE-2026-2441). We recommend updating your browsers to the latest versions or directly downloading them from our website.


Make sure to update your browser to the latest version:


- Opera One: 127.0.5778.64
- Opera GX: 127.0.5778.67
- Opera Air: 127.0.5778.66
- Opera Neon: 127.0.5778.65
- Opera for Android: 95.1


If you have any trouble auto-updating, you can download the latest versions of the browsers[here](https://www.opera.com/download) .


As always, stay safe out there!
