# Update your browser: Security fix for Chrome zero-day CVE-2026-11645

Hi everyone!


The latest patches to Opera’s browsers address several recent vulnerabilities, including a zero-day exploit (CVE-2026-11645). We recommend updating your browsers to the latest versions or directly downloading them from our website.


Make sure to update your browser to the latest version:


- Opera One: 132.0.5905.37
- Opera GX: 132.0.5905.43
- Opera Air: 132.0.5905.38
- Opera Neon: 132.0.5905.40
- Opera for Android: 99


If you have any trouble auto-updating, you can download the latest versions of the browsers[here](https://www.opera.com/download) .


As always, stay safe out there!
