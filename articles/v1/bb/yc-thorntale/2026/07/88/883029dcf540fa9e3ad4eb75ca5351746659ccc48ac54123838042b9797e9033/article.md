# Import from Google Slides

Several people have reached out asking for the ability to import their decks from Google Slides to Thorntale in order to migrate more easily.


We just shipped that feature;[check out the beta!](https://app.thorntale.com/import)


### How it works


Simple! Just paste your Google Slides presentation url into Thorntale’s[Import Deck](https://app.thorntale.com/import) page.


Follow the the Google OAuth prompts to give Thorntale access to this Google Slides deck, and the import process will start immediately.


Thornale doesn’t try to import the slides directly from Google Slides. Instaed, Thorntale AI analyzes the content of the source slides and translates each slide semantically, using Thorntale styling.


Once imported into Thorntale, your deck can be edited just like any other Thorntale deck.


### Try it out!


This feature is experimental, so as always, shoot us an email atfounders@thorntale.com if you run into any bugs or have any feedback. We’re excited to see what new decks start showing up in our system!
