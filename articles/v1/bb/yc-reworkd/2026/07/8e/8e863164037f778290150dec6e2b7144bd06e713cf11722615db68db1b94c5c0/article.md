# March Product Update

March was a big month at Reworkd. We officially launched our platform, now offering self-service access so anyone can try it out.


# **Platform launch**


Over the past year, we've built our platform by working extremely closely with selected power users.


Now, we’re excited to open the platform to everyone.


We’ve introduced a few subscription tiers:


- **Hobby** ( *$0/month)* – 10 concurrent browsers, 30-day data retention, API access.
- **Pro** ( *$99/month)* – 50 concurrent browsers, 90-day retention, captcha solving, scheduled jobs.
- **Enterprise** ( *Custom)* – Unlimited concurrency, custom retention, dedicated support.


👉[Try the interactive demo](https://app.arcade.software/share/6GkFKiXytq3lXQU3JWAx) to see how you can build your first scraper.


# **Revamped Agent**


We reworked the agent architecture and UX to better handle site-specific quirks.


Previously, the agent's UX was restrictive, making it difficult to provide site-specific context (e.g., indicating that a description is hidden under a dropdown menu).


Now, users can directly guide the agent via a chat interface, making debugging faster and more intuitive.


# **Streaming**


Our platform was previously static — users had to manually refresh the page to see job updates or changes in output.


Now, with streaming:


- Job statuses update in real-time (e.g. from “running” to “succeeded”)
- Output counts and logs appear live as the scraper runs


This makes the platform feel much more responsive and significantly improves the development and debugging experience.
