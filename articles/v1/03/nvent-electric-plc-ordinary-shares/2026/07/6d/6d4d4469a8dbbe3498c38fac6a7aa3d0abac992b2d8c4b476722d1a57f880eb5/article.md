# nVent HOFFMAN ModCenter Now Stocked in North America


We are excited to announce newly created standard ModCenter packages, stocked locally in North America, reducing lead times.


Available in 3 different models: ModCenter 263, ModCenter 280 and ModCenter 293. Each model comes with a standard accessory package that includes the following:


- Integrated busbar preparation capabilities
- Anti-vibration system to ensure stability and precision during operation
- Five-liter tank for lubrication
- Multi-zero-point configuration for enhanced flexibility
- Upper pneumatic clamping and an automatic mode for lower material fixing, supporting efficient and consistent processing
- Selected models include pneumatic door opening and an integrated air conditioning unit to maintain optimal operating conditions for ease of use
- The ModCenter 280 (MA01154585) is available with an optional 90" configuration


For more information, please reference the product pages:
