# Comparison view preview

July 23rd, 2024[Dashboard](https://www.artillery.io/changelog/tag/dashboard)


# Comparison view preview


Edmundo Santos


You can now try our new **Comparison view** . This feature lets you to compare two test runs side by side, making it easier to spot trends and correlations between them. Right now the feature is in open *preview* for all[Artillery Cloud](https://app.artillery.io/) users, so try it out and let us know what you think.


## Bugs fixes & improvements


- Improve performance when creating custom charts and adding notes
- Add pagination to HTTP and Page performance widgets if more than 10 results are available
- Fix a bug with the tooltip on HTTP requests chart would not display correctly
- Improve performance for Chart builder widget and Metrics page navigation for tests with many metrics
- Improve Notes widget responsiveness on smaller screens
