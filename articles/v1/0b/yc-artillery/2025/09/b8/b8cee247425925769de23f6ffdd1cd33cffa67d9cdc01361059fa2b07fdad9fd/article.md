# Artillery CLI v2.0.26


## New features


- Provide a` getStash()` method to access the Stash API from any Node.js script ([example](https://www.artillery.io/docs/reference/stash#using-stash-api-in-an-automation-script) )
- Provide type definitions for Playwright tests written in TypeScript ([example](https://www.artillery.io/docs/playwright#getting-started) )


## Fixes & improvements


- Fix: handle cases when the user does not have a default AWS region configured in their AWS config/profile
- Fix: Check subscription plan correctly in Azure tests
- Routine dependency upgrades for deprecation and security notices
