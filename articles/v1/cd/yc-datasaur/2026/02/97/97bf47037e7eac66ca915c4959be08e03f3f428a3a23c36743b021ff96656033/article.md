# January Feature Updates: Smarter Reviews, Better Search, and Expanded Machine Learning Support


Reviewing data shouldn’t feel like detective work. This release brings clearer signals, smarter search, and more control over machine-generated labels so you can spot issues faster and focus on what actually needs review.


### More Control Over Pre-Labeled Data: Review and Approve Labels in Bulk


When “Require approval for pre-labeled labels” is enabled, users can now view a dedicated list of pre-labeled labels and accept or reject them individually or in bulk via the Labels extension, keeping quality checks fast and explicit even when working with large volumes of pre-labeled data.


[Learn more](https://docs.datasaur.ai/data-studio-projects/pre-labeled-project#labeler-workflow-and-outcomes)


### Smarter Search in Span Labeling: Filter by Label Status


The Search Extension in Span Labeling now includes additional filtering options, allowing users to refine search results by label status and quickly narrow in on labels that need review or verification.


[Learn more](https://docs.datasaur.ai/advanced/extensions/search#filtering-search-results)


### More Flexibility in ML–assisted Labeling: Amazon Bedrock Support


ML–assisted labeling now supports Amazon Bedrock as an LLM provider, giving teams more flexibility to choose models that align with their infrastructure, compliance, or cost requirements.


### Faster Navigation: Search Your Joined Workspaces


The joined workspace list now includes a search function, making it easier to find and switch between workspaces, especially for users who collaborate across multiple teams or projects.


### Clearer Reviews: Visible Answer Count for Multiple-Answer Questions


Multiple-answer questions now display a visible answer count, making it easy to see how many answers exist at a glance.


### Refined Span Labeling Experience: Clearer Selection and Improved Readability


Span Labeling UI improvements include clearer visual feedback when right-clicking to select a line and updated label information tooltip colors, making selections more obvious and label details easier to read during labeling or review sessions.


Most of this release is about clarity: clearer reviews and more precise search. Alongside that, Amazon Bedrock joins as a new Machine Learning provider for ML-assisted labeling.
