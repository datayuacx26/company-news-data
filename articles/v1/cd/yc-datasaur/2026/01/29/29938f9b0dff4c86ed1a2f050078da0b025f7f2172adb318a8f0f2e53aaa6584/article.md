# December Feature Updates: More Flexible Rows, Hybrid Labeling, and Expanded Evaluation Metrics

## Data Studio


### New Mixed Labeling Type: Row + Document Labeling


We’re introducing Row + Document Labeling, a new project type that combines row-level and document-level labeling in a single workflow.


This setup is useful when you need structured answers per row while also capturing context or decisions that apply to the entire document without splitting work across multiple projects.


[Learn more](https://docs.datasaur.ai/data-studio-projects/nlp-task-types/mixed-label-sets#row--document-labeling)


### Delete Rows in Row Labeling


You can now delete rows directly within Row Labeling projects. This makes it easier to remove incorrect, duplicated, or no-longer-relevant data without leaving the project or re-uploading files.


[Learn more](https://docs.datasaur.ai/data-studio-projects/lets-get-labeling/row-and-document-based#delete-rows)


### **Evaluation Metrics: Now Supporting Span Labeling**


Evaluation Metrics now support Span Labeling projects. This allows you to measure agreement and performance for span-based tasks using the same evaluation framework, making it easier to compare quality across different labeling types.


[Learn more](https://docs.datasaur.ai/workspace-management/analytics/evaluation-metrics)


### Custom Report Builder: Saving the Last Report


It now remembers the last report you generated and automatically displays it if it’s still saved in your browser storage. This eliminates the need to repeatedly reconfigure the same report every time you open the page.


[Learn more](https://docs.datasaur.ai/workspace-management/analytics/custom-report-builder)


These updates give you more control over your data, more flexibility in project setup, and broader visibility into labeling quality. They’re now live and ready to use.
