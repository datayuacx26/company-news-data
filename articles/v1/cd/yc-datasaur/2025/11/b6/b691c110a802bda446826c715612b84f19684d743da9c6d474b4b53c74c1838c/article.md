# October Feature Updates: Pre-Label Approvals, Expanded Question Editing, and Smarter Search

This month, Data Studio introduces more control, flexibility, and clarity across your projects. You can now require labelers to manually approve pre-labeled spans, edit additional question attributes mid-project, and search across all label sets in Span Labeling.


### Approval for Pre-Labeled Spans


You can now decide whether pre-labeled spans must be manually approved by a labeler before they’re counted as that labeler’s work. Previously, pre-labeled spans were always automatically counted.


This helps ensure fair and accurate metrics, supports stricter QA, and prevents unreviewed pre-labels from being attributed to labelers.


[Learn more](https://docs.datasaur.ai/data-studio-projects/pre-labeled-project#require-approval-for-pre-labeled-labels-setting)


### Edit Question Set: More Attributes Now Editable


In Document, Line, and Row Labeling projects, you can now make even more adjustments to your questions:


- Modify regex validation in text input fields.
- Adjust the minimum and maximum values accepted in slider inputs.


These updates make all question types supported, enabling you to update any question attributes without needing to restart your project.


[Learn more](https://docs.datasaur.ai/advanced/extensions/document-and-row-labeling#editing-question)


### Search Across All Label Sets in Span Labeling


Search now returns results from every label set, not just the active one, no manual switching needed.


This makes it easier to find what you’re looking for across complex projects that use multiple label sets.
