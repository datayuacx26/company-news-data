# November Feature Updates: Cleaner Span Editor, Better Search, and More Accurate Time Tracking

## Data Studio


### Approval for Pre-Labeled Answers in Row Labeling


Pre-labeled answers only count toward a labeler’s work after they review and approve them. This improves accountability and avoids inflated metrics.


[Learn more](https://docs.datasaur.ai/data-studio-projects/pre-labeled-project#require-approval-for-pre-labeled-label-setting)


### Column Mapping: Now Supported for Grouped Attributes Questions


You can now map child questions inside a grouped attributes question to specific columns in the data table. This allows the question to prefill with the data you already have, so labelers don’t need to re-enter the same information manually.


[Learn more](https://docs.datasaur.ai/data-studio-projects/lets-get-labeling/label-sets/refer-answer-to-table-column#configuring-for-nested-questions)


### Bulk Delete or Reject Labels in Span Labeling Search


Bulk delete or reject labels directly from search results. Clean up in one pass without opening items one by one.


[Learn more](https://docs.datasaur.ai/advanced/extensions/search#delete-search-result-labels)


### Advanced Search: Filter by Label Status and Label Class


New Advanced Search filters for label status and label class help you jump straight to the items that need attention, such as unreviewed labels or a specific class.


[Learn more](https://docs.datasaur.ai/advanced/extensions/search#filtering-search-results)


### Effective Time Spent Adjustment


Time tracking now includes wait time for AI-assisted actions. Reports better reflect the full effort when you use labeling AI features.


[Learn more](https://docs.datasaur.ai/workspace-management/analytics)


### Cleaner Labeling View in the Span Labeling Editor


A collapsible toolbar and a default-collapsed extension sidebar now keep the Span Labeling Editor clear while you work.


The toolbar automatically appears when you sort or filter, then hides when not needed, giving you more vertical space to label comfortably.


### Extension Sidebar Shortcut


Quickly collapse or expand the extension without hunting for UI button


- ‍ **Mac:**` Cmd + \\`
- **Windows/Linux:**` Ctrl + \\`


These updates reduce clutter, speed up cleanup, and make your metrics match the real work being done.
