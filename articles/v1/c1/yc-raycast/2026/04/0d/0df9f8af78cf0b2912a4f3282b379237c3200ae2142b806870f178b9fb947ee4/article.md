# v 1.2.10

[v1.2.10](https://www.raycast.com/changelog/ios/1-2-10) April 7, 2026


Solve complex math expressions, convert time zones, or track the days until Christmas with the Calculator History widget. Raycast Calculator is now available on the go.


## ✨ New


- **Calculator** : New Calculator command
- **Search:** Use Calculator from search bar
- **Widgets:** New Calculator History widgets
- **Keyboard:** Extended the available duration options for keeping the session active
- **Keyboard:** Added the ability to reorder the keyboard tabs
- **Quicklinks:** New setting to open quicklinks directly in-app browser instead of redirecting to default browser


## 💎 Improvements


- **Misc** : Improved snippet and quicklink search to match non-contiguous title words
- **Misc** : Added keyboard shortcut for create new inside list views (⌘+N)


## 🐞 Fixes


- **AI:** Fixed sources count animating on existing chat load
- **AI:** Fixed so chat scrolls to next question on iOS 18
- **Home** : Fixed an issue where pull to search wouldn't work
- **Notes:** Fixed editor menu showing wrong actions for archived notes
- **Misc:** Fixed a crash that could happen on launch
- **Misc:** Fixed icon picker container to avoid colliding with controls on iPad
- **Misc:** Added missing clear button in search bar
