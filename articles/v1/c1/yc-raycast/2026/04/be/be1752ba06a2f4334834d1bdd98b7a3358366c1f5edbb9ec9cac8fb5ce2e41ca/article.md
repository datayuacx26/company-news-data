# v 1.2.11

[v1.2.11](https://www.raycast.com/changelog/ios/1-2-11) April 30, 2026


Access your favorite team Snippets and Quicklinks - seamlessly synced between your phone and Mac.


## ✨ New


- **Team** : Sync and access team Snippets and Quicklinks
- **Calculator** : Interactive currency home screen widget
- **Calculator** : Control center control to launch calculator
- **Calculator** : Calculate intent / shortcut
- **Keyboard** : Calculator support in main search
- **Notes** : A new setting to choose the starting block for a new note between H1 or Paragraph
- **Snippets:** Quickly create snippets from AI chat, composer or notes through the edit menu
- AI: Search models in model sheet
- Misc: Quickly create snippets selecting the text from composer, notes or chat


## 💎 Improvements


- **AI:** Significant performance and stability improvements when streaming in chat
- **AI:** Improved streaming animation
- **AI** : Richer tool call labels for search web and read page
- **AI** : AI widget now support 4 actions for medium size and is fully customizable
- **AI** : Ask AI shortcut will now display responses in plain text instead of markdown syntax
- **Calculator** : Currencies are now refreshed and support force refreshing
- **Misc** : Small reordering of settings for core commands


## 🐞 Fixes


- **AI:** Fixed AI chat message overlap on iPad
- **AI** : Fixed sources count always animating for existing chats
- **AI** : Fixed issue where chat from Ask AI shortcut using a custom preset would be attributed as "ray1” in-app
