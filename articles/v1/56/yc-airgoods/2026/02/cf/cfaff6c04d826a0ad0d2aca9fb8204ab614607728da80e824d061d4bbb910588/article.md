# Seller Product Changelog – February 9

# Seller Product Changelog – February 9


### Here’s what’s new for sellers on Airgoods this week.


[Aaron from Airgoods](https://substack.com/@aaronfa)


Feb 18, 2026


### **Features**


**New and improved ShipStation integration**


We’ve launched a revamped ShipStation integration that’s easier to set up and use. You can add it in the


[Integrations page in your settings](https://airgoods.com/account/seller/settings/integrations) . If you need any help setting it up, email us at support@airgoods.com.


If there are other fulfillment integrations you’d like to see, please let us know!


**New customer segment creation**


You can now create customer segments using a set of filters, including fields like


` Days since last order` and


` Amount in cart` . This makes it easier to target the right retailers at the right time.


### **Improvements**


**Improved local fulfillment experience**


Local fulfillment is now easier to find and faster to complete, reducing the number of steps required by 50%!


**Mobile navigation improvement**


On mobile, the default sidebar view for sellers is now the account navigation – making it quicker to access the tools you use most.


### **Fixes**


**Brand image upload improvements**


Updated the


[My Brand page](https://airgoods.com/account/seller/my-brand) to support in-platform image cropping and editing during uploads.


**Sample box retailer count fix**


Fixed an issue where the retailer count on the Airgoods Sample Box page could show inconsistent values.
