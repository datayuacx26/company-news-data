# Announcing new builds for 26 June 2026, retail launch of new WIP improvements

# Announcing new builds for 26 June 2026, retail launch of new WIP improvements


Written By


- [Stephen Lines](https://blogs.windows.com/windows-insider/author/stlines/)


published


June 26, 2026


Hello Windows Insiders,


We have new releases today with builds across Beta and Experimental, and are excited to begin rolling out the new Windows Insider experience to retail Windows 11 builds this week!


**New Windows Insider Program changes launching into retail**


After validating through the Windows Insider channels, and receiving much feedback from the Insider community, we are excited to begin rolling out the new program changes into retail. This means those on standard retail Windows 11 builds (i.e. non-Windows 11 Insider Preview Builds) will begin seeing the new channel experience in the WIP UI settings. This can be found under **Settings** > **Windows Update** > **Windows Insider Program.**


Please note this will be a gradual roll out, so don’t worry if you are on a retail build and do not see the new channel options just yet – these will roll out to everyone over the coming weeks.


For more information about the changes that the new WIP experiences bring, read the original announcement blog[here](https://blogs.windows.com/windows-insider/2026/04/10/improving-your-windows-insider-experience/) . We have also updated the[Windows Insider Program website](https://www.microsoft.com/en-us/windowsinsider/) , as well as the[Windows Insider Program Documentation Hub](https://learn.microsoft.com/en-us/windows-insider/about/) to reflect the new program changes.


If you are not currently running a Windows 11 Insider Preview Build, there has never been a better time to start flighting – you’ll get early access to new Windows 11 features, enhance your say in the development of Windows, and now in most cases, you will be able to switch channels or exit the program without having to do a full reinstall of Windows if you find it’s not working for you. See the[WIP Documentation Hub for more information.](https://learn.microsoft.com/en-us/windows-insider/flighting)


Thank you to everyone who has provided feedback on the new WIP experiences – we continue to listen to your feedback and look forward to providing more resources and updates in the coming weeks!


**New builds this week**


Today we are releasing new Windows 11 Insider Preview Builds. See your channel release notes here:


- Beta:[Build 26220.8754](https://learn.microsoft.com/en-us/windows-insider/release-notes/beta/preview-build-26220-8754)
- Experimental:[Build 26300.8758](https://learn.microsoft.com/en-us/windows-insider/release-notes/experimental/preview-build-26300-8758)


For those on other specific build versions, here are today’s new builds and release notes:


- Beta (26H1):[Build 28020.2366](https://learn.microsoft.com/en-us/windows-insider/release-notes/beta-26h1/preview-build-28020-2366)
- Experimental (26H1):[Build 28120.2374](https://learn.microsoft.com/en-us/windows-insider/release-notes/experimental-26-h1/preview-build-28120-2374)
- Experimental (Future Platforms) – Including Canary 29600 series:[Build 29617.1000](https://learn.microsoft.com/en-us/windows-insider/release-notes/experimental-future-platforms/preview-build-29617-1000)


- Please note we have not yet launched the new Windows Insider program changes for those in Experimental (Future Platforms), currently Canary 29600 builds. We will be providing an update on this in the very near future.
