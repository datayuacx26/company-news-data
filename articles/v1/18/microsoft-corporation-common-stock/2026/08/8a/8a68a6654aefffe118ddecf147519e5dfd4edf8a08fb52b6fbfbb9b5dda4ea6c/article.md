# Extend Liquid with Server Logic in Power Pages

Since introducing Server Logic in Power Pages, our focus has remained consistent: help you bring business logic closer to the experiences you build, while keeping it secure, reusable, and easy to manage at scale.


In the past, developers working with Liquid in Power Pages were limited to a predefined set of platform-provided objects. While these objects provide powerful capabilities, developers often had to adapt their requirements to available constructs or implement custom logic in other layers.


As the next step in this journey, Server Logic can now be invoked directly from Liquid templates in Power Pages.


### Bring Your Logic to Liquid


With this capability, you can invoke Server Logic directly from Liquid templates, effectively extending Liquid code with your own custom, server-backed capabilities. This removes the constraint of relying solely on built-in Liquid objects, while keeping business logic securely executed on the server. Combined with access to request and website context and Power Pages security capabilities, you can build dynamic, contextual experiences with consistent security and access control.
