# 50 Must-Know Revit Shortcuts for Architects {{year}}

## **Why are Keyboard Shortcuts Essential in Revit?**


****


Keyboard shortcuts become increasingly valuable as projects grow in size and complexity. Instead of repeatedly navigating through menus, they allow architects to focus on designing, reviewing, and coordinating models more efficiently.


-


### **Faster BIM Workflow**


Frequently used commands such as Move, Copy, Align, and Trim can be accessed instantly, helping you complete routine tasks without interrupting your BIM workflow or switching between multiple toolbars.


-


### **Quicker Construction Documentation**


Preparing drawings involves repeated actions like placing dimensions, creating detail lines, and managing views.


[Using Revit shortcuts](https://www.novatr.com/blog/revit-keyboard-shortcuts-and-productivity-hacks) reduces the time spent on repetitive tasks while making construction documentation easier to update as the model changes.


-


### **Better Project Coordination**


Large BIM projects require architects to review linked models, visibility settings, and design revisions regularly. Shortcuts help you navigate between views and coordination tools more quickly, improving project coordination across disciplines.


-


### **Improved Modelling Efficiency**


Searching through ribbons and menus breaks concentration, especially when making frequent edits. Keyboard shortcuts keep your focus on the model, allowing you to make changes more quickly and maintain a smoother design process.


-


### **Greater Productivity Over Time**


As commonly used shortcuts become second nature, everyday tasks require less effort. This allows architects to spend more time refining designs and solving project challenges instead of navigating the software interface.

## **How Can You Create and Customise Revit Keyboard Shortcuts?**


Autodesk Revit allows you to customise keyboard shortcuts, making it easier to access the commands you use most often during architectural design. A personalised setup can improve efficiency and create a smoother experience while working with


[BIM software](https://www.novatr.com/blog/10-best-bim-software-used-by-aec-firms) .


-


**Open the Keyboard Shortcuts Menu:** Go to View → User Interface → Keyboard Shortcuts, or press KS to open the shortcut manager in Autodesk Revit.


-


**Search for a Command:** Use the search bar to quickly find the tool or command you want to customise instead of browsing through the full list.


-


**Assign a New Shortcut:** Enter your preferred key combination in the Press New Keys field and click Assign, ensuring it does not conflict with another command.


-


**Edit or Remove Existing Shortcuts:** Replace shortcuts that you rarely use or remove them completely to keep your workflow organised


-


**Use Consistent Shortcuts:** Create logical key combinations that are easy to remember, helping you work faster and switch between commands with minimal interruption.
