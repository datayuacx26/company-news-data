## **Which BIM Tools, Workflows, and Industry Standards Should an Effective Platform Cover?**


An effective BIM training should offer a holistic understanding of multiple tools, software, and plug-ins. Here’s what it must cover:


**Autodesk Revit:** It is used for creating BIM models, developing detailed documentation, and managing project information throughout the design process.


**Autodesk Navisworks:** This tool combines models from various disciplines, reviews project coordination, and identifies clashes before construction.


**Autodesk Forma:** It supports early design decisions through features such as site analysis, environmental studies, and rapid creative exploration.


**DiRoots:** It reinforces


[Revit](https://www.novatr.com/blog/detailed-revit-guide) tools for managing model data, automating repetitive tasks, and streamlining documentation workflows.


**ProSheets:** It enables batch exporting of Revit sheets and views into formats required for project documentation and sharing.


**EF Tools:** This software upgrades Revit utilities that simplify repetitive modelling, annotation, and documentation tasks across different project workflows.


**Enscape:** It is a rendering software that connects BIM models with real-time visualisation for design reviews, presentations, walkthroughs, and client communication.


**pyRevit:** It extends Revit through custom scripts and tools that automate repetitive tasks and support more efficient project workflows.


**Autodesk Interoperability:** This extension allows information to move between different BIM platforms, supporting collaboration across software and project teams.


**McQuay:** It provides


[BIM-ready HVAC](https://www.novatr.com/blog/bim-hvac-engineers-in-construction) and technical information that can be incorporated into coordinated building services models.
