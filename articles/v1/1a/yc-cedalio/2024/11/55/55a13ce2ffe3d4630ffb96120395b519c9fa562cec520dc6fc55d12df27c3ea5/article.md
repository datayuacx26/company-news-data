# [New Feature] Locations Are Here: Automatically Organize and Optimize Your Consumption Data!

Managing and analyzing utility data across multiple locations just got a whole lot easier! At Cedalio, we understand the challenges sustainability and efficiency teams face when trying to group, filter, and analyze consumption data from various utility providers.


To address this, we’re thrilled to introduce our new **Location Feature** —a powerful tool that allows admins to create, manage, and filter utility data by specific locations. This update accelerates reporting and simplifies how you assign utility data, making your sustainability goals more attainable than ever.


---


### **Key Benefits**


- **Streamlined Reporting:** Organize your utility data by location, enabling faster and more accurate reporting.
- **Enhanced Flexibility:** Create unlimited locations and define custom rules for assigning utility data.
- **Improved Visibility:** Filter data points in the explorer view by location and visualize location-based data directly in your dashboard.
- **Efficiency Gains:** Group and filter consumption data by location to identify trends, optimize energy use, and reduce costs.
- **Customizable Workflows:** Tailor your location rules to match your organization’s unique utility data structure.
- **Enhanced Data Exporting:** Export data points with location information included, ensuring smooth integration with external reporting tools.


---


### **What’s New?**


**1. Location Creation and Management:**
Now you can create and manage locations within the platform. Each location requires a name, address, and rules to bind data points.


- **Flexible Rules:**


- Define as many rules as needed.
- Match data points using the **Meter Number** field.
- Filtering options include **"Is"** and **"Is Not"** conditions.


**2. Post-Creation Insights:**
Once a location is created, the system automatically calculates and displays the number of matching data points—helping you validate your rules at a glance.


**3. Data Point Integration:**


- Every data point now displays the locations it matches.
- Missing locations? The system flags these items for review, prompting admins to create a new location seamlessly.


**4. Information processing:**


- Every time information is processed, the system will run the location rules to identify matching locations. If a match is found, the location will be automatically assigned.
- Additionally, locations can also be automatically assigned for each measurement in a utility invoice.


---


### **Takeaways**


- **Quick Setup:** Create locations with a few clicks, and tailor rules to your utility data structure.
- **Actionable Insights:** View real-time data point matches to validate and adjust rules as needed. Gain clarity by visualizing utility data organized by location.
- **Seamless Data Management:** Handle flagged data points effortlessly by creating new locations on the go. Accelerate sustainability reporting with accurate, location-specific insights.
