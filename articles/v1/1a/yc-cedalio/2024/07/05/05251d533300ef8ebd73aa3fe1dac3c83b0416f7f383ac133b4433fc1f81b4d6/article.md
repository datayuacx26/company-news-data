# We redesigned the uploading review table to display more relevant information.

We have redesigned our file upload flow, focusing on relevant information that our users have requested, such as a consumption breakdown and the total amount paid. Additionally, we have restructured some columns to display the same information in condensed design.


**Consumption Breakdown**


- We can now detect if the consumption is presented as a single kWh number or expanded into Peak, Off-Peak, and Mid-Peak.
- We also identify if the invoice includes EV Charger consumption and differentiate this as a separate type of consumption.


**New Grouping Strategy**


- Each invoice is now represented by one row in our UI.
- If you have multiple invoices or different utility companies in the same file, we will create additional rows with the same file name.
