# Give us feedback on new Optics features!

The team at Apollo has been really happy with the response we’ve gotten after announcing the[1 million query free tier update](https://dev-blog.apollodata.com/apollo-optics-is-now-free-up-to-1-million-graphql-requests-a-month-d759248ea084) to Optics! It’s awesome to see thousands of developers using[Optics](https://www.apollodata.com/optics/) to visualize the execution of their GraphQL queries, monitor performance trends, and track how clients are consuming their API. Right now we’re working on new functionality that we think GraphQL developers will get really excited about, including:


- Optics **support for Java, Scala and Elixir GraphQL servers** using[Apollo Tracing](https://github.com/apollographql/apollo-tracing) — a new spec for including performance information in your GraphQL response
- **Error reporting** : capture each error at the GraphQL layer, and view aggregate error metrics per field and query
- **Notifications** : monitor query performance and error metrics, and get notifications when these metrics exceed a specified threshold


We aren’t quite done yet, and we need your help to test out this new functionality before a wider release.


## [Sign up for early access](https://www.getfeedback.com/r/fYAgLw6X/)


If you’re interested in trying out some of the above features, please[let us know](https://www.getfeedback.com/r/fYAgLw6X/) that you’d like to offer feedback in Early Access!
