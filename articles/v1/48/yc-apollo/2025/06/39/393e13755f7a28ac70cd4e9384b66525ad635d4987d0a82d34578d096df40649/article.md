# Apollo GraphQL Advances AI-Ready API Orchestration Platform with Enhanced MCP Server, Performance Upgrades, and Subscription Plans

Apollo GraphQL Advances AI-Ready API Orchestration Platform with Enhanced MCP Server, Performance Upgrades, and Subscription Plans


*Significant Apollo GraphOS Platform Enhancements Enable Organizations of Any Size to Build and Scale AI-Powered Applications with Graph-Based API Orchestration*


SAN FRANCISCO, June 24, 2025 —[Apollo GraphQ](http://www.apollographql.com/) L, the graph-based API orchestration leader, today announced significant Apollo GraphOS platform enhancements focused on AI-readiness, delivering advanced capabilities that enable organizations of any size to build, deploy, and scale AI-powered applications. The enhancements include major updates to Apollo MCP Server, improvements to Apollo Connectors for REST APIs, and new subscription plans. These product improvements make it even easier for developers to build with GraphQL, as GraphQL and Model Context Protocol (MCP) become the foundation for an agentic future.


**GraphQL Accelerates AI Agent Development with Proven API Orchestration**


Every traditional web or mobile application requires API orchestration – the complex logic that coordinates how APIs are called, sequenced, cached, and secured. Over the last decade, GraphQL emerged as a standard, declarative approach to solve these common problems, eliminating complex sprawling middleware code and accelerating software development for the companies that adopted it. With MCP’s rapid adoption for agentic applications, these API orchestration issues are re-emerging as crucial concerns. GraphQL’s declarative approach to API orchestration positions it as a superior platform for agentic AI applications, and as AI transforms software development, this becomes even more critical.


“AI agents need the ability to retrieve data, modify systems, and take actions in the real world, and that requires a robust API orchestration foundation,” said Matt DeBergalis, CTO and co-founder of Apollo GraphQL. “GraphQL's declarative, schema-driven approach gives developers a scalable foundation that lets them focus on innovation instead of building complex orchestration logic. The rich GraphQL ecosystem means developers can focus on novel AI problems rather than reinventing API integration.”


**Enhanced Apollo MCP Server: Production-Ready AI Integration**


Apollo recently launched[Apollo MCP Server](https://www.apollographql.com/newsroom/press-releases/apollo-mcp-server-launch-positions-graphql-as-the-essential-protocol-for-ai-api-o) to connect graph APIs to AI models using MCP. Today’s announcement introduces more powerful capabilities that make it easier than ever to safely expose APIs to AI applications.


Key enhancements include:


-


Streamable HTTP enables flexible, efficient, and scalable communication


-


Enhanced tool definition capabilities with built-in Collections for seamless workflows


-


Container deployment options with built-in telemetry and advanced authentication


These improvements enable organizations to rapidly build and deploy AI agents with the tools and capabilities they need, dramatically accelerating agent development cycles.


**Apollo Connectors Batch Support: Move Fast with Simplified API Orchestration Infrastructure**


Apollo Connectors for REST APIs now include batch endpoint support that improves REST API query performance. Instead of making multiple individual API calls to fetch related data, the new batch loading capability consolidates requests into efficient batches, reducing network overhead and improving application responsiveness. This enhancement enables developers to bring existing REST APIs into their GraphQL architecture without sacrificing performance, maximizing existing API investments while gaining the benefits of declarative orchestration.


Key benefits include:


-


Reduced network calls through intelligent request batching


-


Improved performance for data-intensive applications


-


Seamless integration with existing REST APIs


**New Subscription Plans for Every Organization**


Apollo's new Developer and Standard subscription plans are designed with developers in mind, removing traditional barriers to GraphQL adoption so developers can focus on what they do best – building great applications. Both plans offer a usage-based pricing model that enables organizations to pay only for what they use as their API workload scales.


"We want to enable developers to experiment, learn, and realize the value of graph-based API orchestration at their own pace,” said Rob Brazier, VP of Product of Apollo GraphQL. “Our new Developer and Standard plans are designed to better meet the needs of organizations just getting started with their first GraphQL API, or their first federated GraphQL platform – enabling them to start small, iterate quickly, and scale when ready without a large up-front expense or paying for features they don’t need."


Plans include:


-


Complete GraphOS platform including Apollo Connectors and Apollo MCP Server for AI-ready API orchestration, plus schema registry, operations monitoring, analytics, and more


-


Flexible usage-based pricing with predictable costs as workloads grow


-


User license bundles, optional user roles, and identity provider integration to ensure safe, collaborative API development


**Proven by Fortune 500 Companies, Now Available for Agentic Future**


The GraphOS platform recently hit a major milestone, orchestrating over 1 trillion operations monthly for users. This same proven infrastructure that powers Fortune 500 enterprises now provides the foundation for AI-ready applications. Whether organizations are starting their AI journey or building toward fully agentic systems, GraphOS now provides the flexibility and scalability to meet their needs at every stage. To support this growth and expanding market opportunity, Apollo recently welcomed[Stuart Wilson](https://www.apollographql.com/leadership) as Chief Revenue Officer to lead the company's global revenue organization and go-to-market strategy.


These GraphOS platform enhancements with MCP Server and Connectors are available to get started today.
