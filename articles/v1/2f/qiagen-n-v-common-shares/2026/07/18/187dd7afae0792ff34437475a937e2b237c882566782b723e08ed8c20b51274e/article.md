# QCI Interpret Summer 2026 Release now available

We’re excited to announce the availability of the latest release of QIAGEN Clinical Insight (QCI) Interpret, QCI Interpret One and QCI Interpret Translational. The[QCI Interpret Summer 2026 Release](https://digitalinsights.qiagen.com/qci-interpret-release) delivers new capabilities designed to further streamline variant interpretation and reporting.


QCI Interpret is leading clinical interpretation platform by case volume, used to analyze and interpret more than 5.5 million NGS tests cases worldwide. Now, with the latest release, the platform now provides enhanced end-to-end variant interpretation and reporting with improved classification workflows, integrated sample QC and multilingual reporting capabilities.


## What's new in the QCI Interpret Summer 2026 Release?


### Built-in comment translation for multilingual reporting


Report comments can now be translated into the preferred language directly within QCI Interpret, eliminating the need for external translation tools. Translation of overall, additional and variant-specific comments are supported. Translated comments can be viewed, edited, saved, compared with the original English and included in both the final report and XML export (not available in QCI Interpret Translational).


→ Request a sample translated QCI Interpret report[here](https://go.qiagen.com/qcii-translated-report) .


### Streamlined Quality Control (QC) assessment


QCI Interpret now supports ingestion of secondary-analysis quality metrics through a structured JSON QC file, making sample quality data available alongside variant interpretation in a single workflow. Standardized QC status tags and a dedicated Sample QC view provide immediate clarity on data quality, and QC metrics can be included in the final PDF report through template-driven reporting (not available in QCI Interpret Translational).


### New Batch Create feature for multiple tests


Now, up to 200 tests can be created in a single step by uploading a CSV sample sheet via the new Batch Create button on the Test List and Sample List pages. A validation page reviews the submission before test creation proceeds, ensuring errors are identified and resolved upfront (not available in QCI Interpret Translational).


### New Previous Occurrences column in the Variant List page


The new Previous Occurrences column on the Variant List page displays how many times each variant was previously seen. The count is captured as a snapshot at test creation, reflects all prior tests accessible to the test creator and is hyperlinked to the corresponding variant-specific page in the Variant Directory. The column is enabled by default and can be toggled off from Settings (not available in QCI Interpret Translational).


### NGS and orthogonal data consolidation in a single report


JSON files and PDF documents can now be uploaded alongside a test via the UI or API. Reports customized through QIAGEN Services can be configured to extract and display data from uploaded JSON files and/or append PDF documents to the end of the final report, enabling fully integrated reporting of NGS alongside orthogonal data results (not available in QCI Interpret Translational).


### Expanded Bulk Assessment tool


The Bulk Assessment tool now provides access to the full range of pathogenicity, actionability and reportability options when assessing multiple variants at once, consistent with what is available for single-variant assessments. A select-all checkbox makes it faster to act on all variants in the current view, and a confirmation page previews all proposed changes before they are applied (not available in QCI Interpret Translational).


### Structural duplications now displayed as a distinct alteration type


Previously, variants encoded as structural duplications were treated and displayed as amplifications. Now, QCI Interpret recognizes structural duplications as a distinct alteration type, displaying them accurately across the platform. Content matching for structural duplications includes "mutation positive" and related specificities in addition to amplification content, supporting more precise variant review in both somatic and hereditary workflows.


### Updated ACMG/AMP classification logic and refined HGVS nomenclature


The QCI Interpret Summer 2026 Release introduces updated ACMG/AMP classification logic and refined HGVS nomenclature. Improvements to criteria logic, default strengths and classification rules may result in changes to computed classifications or actionability designations for a subset of variants. These changes do not impact prior assessments saved by the user.
