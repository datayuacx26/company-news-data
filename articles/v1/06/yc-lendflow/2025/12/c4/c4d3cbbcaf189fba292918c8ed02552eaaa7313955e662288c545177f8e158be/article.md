# Command Bar: Building Intelligence Into Every Lending Workflow

Today, we’re taking an exciting step toward the future of AI lending technology with the launch of Command Bar, a unified interface that represents our vision for an AI-native, agentic-first platform built to automate and simplify processes.


All Lendflow customers can now access Command Bar's Semantic Search functionality. Simply press Command-K to open the search bar and find deals by business name, email, or phone number. The system returns similar deals based on query similarity, allowing you to open multiple deals in the background and pin them for easy reference. This streamlined search experience eliminates the need to navigate through multiple screens and menus, putting the information you need at your fingertips.


Additionally, with Command Bar users can access pre-built agents that handle common platform lending interactions.


- Need a NAICs code for an applicant? Use the Command Bar with the Industry Map agent to instantly assign NAICS codes within the product.
- Data extracted from business documents? Access the Doc Analyzer directly from the Command Bar.
- Need to collect documents from an applicant? Trigger an agent to complete the task.
- Want to send a file to a new bank or lender? Request the agent submit the file and all the necessary tasks.


The Command Bar also includes built-in product support, so your team can ask questions or report issues without leaving the platform.


These agents represent the first examples of the specialized, task-focused capabilities that will expand significantly as we roll out the full Command Bar ecosystem. They're already saving teams time by centralizing support requests and product feedback in one accessible location.

### **The Vision: One Gateway for Lending Tasks**


The lending journey is full of friction: confusing requirements, back-and-forth communications, , and manual processes that slow everyone down. Today, these challenges are handled in silos with separate tools for chat, search, document collection, and outreach. The result is wasted time, poor borrower experiences, and underwriters spending hours on glue work instead of closing deals.


Command Bar changes this paradigm. We're building a single entry point where natural language requests like "collect last year's tax return from Acme LLC" or "ask customer to unfreeze their credit" become instant actions. Behind the interface sits an intelligent orchestrator that helps you execute daily work transparently and automatically.


Imagine a loan officer typing "summarize lender asks on these three offers" and receiving a bulleted explanation with source links, pulled directly from lender emails and documents. Or a lender setting up "start our verification flow when DTI exceeds 40%" with their custom agent running securely within Lendflow's environment. This is the future we're building, where the busywork becomes automated, visible, and seamlessly integrated.


Command Bar isn't a standalone search tool or chatbot. It's the foundation of an extensible platform where composable agents handle specific friction points: document collection, offer explanations, KYC verification, bank connection nudges, and dozens more. These agents work together, orchestrated intelligently based on context and permissions.
