# Making Lending More Conversational: How to Get the Data You Need Faster with Lendflow MCP

### Turning AI Into a Real Operational Tool


Most AI tools are great at generating content and answering general questions, but they don't know what's happening inside your lending operation.


Using the Model Context Protocol (MCP), AI assistants like Claude and Cursor can securely connect to Lendflow and interact with your data through natural language. Instead of navigating menus and searching through records, users can simply ask questions or request actions as if they were talking to a teammate.


Imagine asking:


*"What applications received new offers this week?"*


Or:


*"Show me the current status of Acme Manufacturing and summarize any outstanding items."*


The AI assistant can retrieve the information directly from Lendflow and provide an answer in seconds.


The result is less time spent searching and more time spent serving borrowers, evaluating opportunities, and closing deals.

### Getting Started in Minutes


Getting started with Lendflow MCP is simple.


First, obtain an API token from your Lendflow account representative or generate a Personal Sanctum Token from your account.


Next, connect your preferred AI client, including Claude Desktop, Claude Code, Cursor, or another MCP-compatible application, to Lendflow's hosted MCP endpoint.


Once connected, try a few simple prompts:


- "List my latest applications."
- "Show me all active funders."
- "What offers are currently pending?"


Within minutes, you'll have an AI assistant that can securely access and interact with your Lendflow environment.

### Frequently Asked Questions


**What is the Lendflow MCP Server?**
A hosted Model Context Protocol endpoint that allows AI assistants to securely access and interact with Lendflow using natural language.


**Which AI tools are supported?**
Cursor, Claude Desktop, Claude Code, and other MCP-compatible clients.


**Do I need technical resources to get started?**
Most users can get connected in just a few minutes using an API token and Lendflow's setup instructions.


**Can MCP make changes in my account?**
Yes, depending on permissions and token settings. Read-only access can also be configured.


**How is sensitive information protected?**
Lendflow supports secure authentication, permission-aware access controls, optional PII redaction, and administrative controls to help protect customer data.
