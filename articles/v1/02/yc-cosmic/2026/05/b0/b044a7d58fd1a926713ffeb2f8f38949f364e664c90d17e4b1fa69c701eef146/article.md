# Cosmic Rundown: DeepSeek Reasonix, DOS Source Code, AI Chip Memory Costs

## DeepSeek Reasonix: High Caching, Low Cost


[DeepSeek Reasonix](https://esengine.github.io/DeepSeek-Reasonix/) is a native coding agent built around DeepSeek's models with aggressive caching to cut API costs. The pitch: get reasoning-capable code generation without burning through your token budget.


The project targets developers who want Claude or GPT-4 level code assistance but can't justify the spend. Whether the caching strategy holds up under real workloads remains to be tested, but the approach is worth watching.


[Discussion on Hacker News](https://news.ycombinator.com/item?id=48256953)


## Microsoft Opens the DOS Archives


Microsoft[open-sourced what they call the earliest DOS source code discovered to date](https://arstechnica.com/gadgets/2026/04/microsoft-open-sources-the-earliest-dos-source-code-discovered-to-date/) . This is archaeology for anyone who cares about computing history.


The release gives developers and historians direct access to the code that launched the PC era. Expect deep dives into how much (or how little) has actually changed in operating system fundamentals over four decades.


[Discussion on Hacker News](https://news.ycombinator.com/item?id=48253386)


## Memory Now Dominates AI Chip Costs


Epoch AI published data showing[memory has grown to nearly two-thirds of AI chip component costs](https://epoch.ai/data-insights/ai-chip-component-cost-shares) . The economics of AI hardware are shifting faster than most realize.


This matters for anyone planning infrastructure. Memory bandwidth and capacity are now the bottleneck, not compute. Expect this to influence everything from chip design to cloud pricing over the next few years.


[Discussion on Hacker News](https://news.ycombinator.com/item?id=48258684)


## LLM Agents Struggle with Backend Constraints


A new paper on[Constraint Decay in LLM Agents](https://arxiv.org/abs/2605.06445) examines how AI coding agents handle complex backend requirements. The finding: agents progressively forget constraints as codebases grow.


If you're using AI for anything beyond simple scripts, this research is relevant. Understanding where agents fail helps you build better guardrails.


[Discussion on Hacker News](https://news.ycombinator.com/item?id=48256912)


## 50 Hours to Draw a Line Graph


Sometimes the best posts aren't about new tools. A developer documented[spending 50 hours drawing a single line graph](https://www.dougmacdowell.com/50-hours-to-draw-some-lines.html) , walking through the unexpected complexity of data visualization done right.


The piece resonates because it's honest about how long good work actually takes. Worth reading when you need a reminder that craft matters.
