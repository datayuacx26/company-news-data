# How to Get HelixQL Syntax Highlighting on Cursor

## Introduction


Cursor haven't updated their marketplace (@cursor plz fix). So, you'll need to import your settings from VSCode to have syntax highlighting in Cursor.


## Steps


### 1. To install VS Code run the following command in your terminal:


```text
code --install-extension helixdb.helixql
```


or install the **HQL** extension directly in **VS Code extensions** :


### 2. Next open **Cursor** and go to your **Cursor Settings**


### 3. Now in **General** press` Import` from VS Code


## Conclusion


You should now be able to see your syntax highlighting in both **VS Code** and **Cursor** . If you run into any problems, please get in touch with us via[Discord here](https://discord.gg/2stgMPr5BD) .
