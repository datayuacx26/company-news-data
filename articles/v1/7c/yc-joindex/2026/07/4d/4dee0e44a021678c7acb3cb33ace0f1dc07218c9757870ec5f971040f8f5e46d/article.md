# Important: Update Dex to Continue Usage

Big one today: Dex can now act directly inside your browser. We're calling them browser agents. It requires new browser permissions, so **Dex won't work until you update.**


## How to update


**Option 1: Update from Chrome Extensions.**


1. Go to` chrome://extensions`
2. Turn on Developer mode (top right)
3. Click Update (top left)
4. Toggle Dex back on (Chrome disables extensions that request new permissions)


**Option 2: Reinstall from the Chrome Web Store.** If you don't see Dex in` chrome://extensions` , go to the[Dex page on the Chrome Web Store](https://chromewebstore.google.com/detail/dex/ignaljemchdlmoimaliinmonecgbdnkk) , remove the extension, and add it back.


Chrome may have already updated your extension, but you might need to re-enable it. **If Dex isn't responding after an update,** go to the[Chrome Web Store page](https://chromewebstore.google.com/detail/dex/ignaljemchdlmoimaliinmonecgbdnkk) , remove it, and re-add it to grant the new permissions.


After that, Dex should be back in your sidebar.


## What are browser agents?


Browser agents let Dex interact with web pages the way you do: clicking, typing, navigating. Instead of being limited to its own tools and APIs, Dex can now work inside the apps you already use.


- **Work across any site.** Dex can navigate and take action on any page you have open.
- **Fill out forms.** Type into fields, select options, submit forms.
- **Handle multi-step tasks.** Workflows that span several tabs and sites run end to end.


## Rollout


Browser agents are rolling out in beta. For now, you'll need to turn it on manually to use it. Open the controls menu at the bottom of the chat input and enable **Browser agent** . Dex can now help with anything you can do in a browser tab.
