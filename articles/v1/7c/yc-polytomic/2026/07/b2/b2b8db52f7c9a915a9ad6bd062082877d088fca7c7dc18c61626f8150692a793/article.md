# Introducing Bidirectional ETL with MotherDuck


February 1, 2026


Built in partnership with the team behind the open-source DuckDB database,[MotherDuck](https://motherduck.com/) is a serverless cloud data warehouse designed to make high-performance analytics accessible.


Today we are announcing full, bidirectional ETL and sync support with MotherDuck.


This means that you can use Polytomic for these sync workloads with MotherDuck:


- Ingest data from SaaS platforms like Stripe, Salesforce, Intercom, and[many others](https://www.polytomic.com/integrations) .
- Ingest CDC (Change Data Capture) streaming from storage systems like PostgreSQL, MySQL, PlanetScale, MongoDB, Amazon DynamoDB, and Amazon S3.
- Reverse ETL: sync from MotherDuck to SaaS platforms, databases, data warehouses, spreadsheets, webhooks, and cloud storage buckets like S3.


See our[documentation](https://docs.polytomic.com/docs/motherduck) for setup details. Happy quacking!
