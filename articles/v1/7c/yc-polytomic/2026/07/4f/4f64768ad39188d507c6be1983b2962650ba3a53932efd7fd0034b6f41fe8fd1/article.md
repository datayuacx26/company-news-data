# Announcing the sync status dashboard

Polytomic is often the centerpiece of our customers' data sync infrastructure, supporting all sorts of use cases and departments. With all this activity, sometimes you simply want to answer the question 'Is everything ok?'.


Now you can with the new sync status dashboard. This is a single page that tells you whether all syncs have run successfully, and if not then each errored sync is clearly displayed with a summary tile:


You can thus, at a glance, immediately determine whether everything is ok or not. As in everything we do, we strive to save time on behalf of our customers.


You can see documentation on the new dashboard[here](https://docs.polytomic.com/docs/sync-status-dashboard) .
