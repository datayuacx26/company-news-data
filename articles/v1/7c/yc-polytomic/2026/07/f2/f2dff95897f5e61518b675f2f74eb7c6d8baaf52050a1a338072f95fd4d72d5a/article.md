# Announcing the per-sync Salesforce API call report

Salesforce API call consumption: everyone is rightly precious about this. Wayward integrations often exhaust your Salesforce API quota for the day, harming everyone's productivity.


Thus we are announcing Polytomic's per-sync Salesforce API call report.


You can now, per Polytomic sync, view the exact number of Salesforce API calls consumed in the last 24 hours.


This is available through three methods:


- In-app UI (see screenshot below).
- Polytomic's[Get Connection Usage](https://apidocs.polytomic.com/api-reference/connections/get-usage) API (useful for Polytomic Connect customers to display to your customers in your own apps).
- Polytomic's[MCP server](https://apidocs.polytomic.com/guides/mcp-server) . Your AI agents can retrieve this information with a simple prompt.


Documentation for this is available here:[https://docs.polytomic.com/docs/manage-salesforce-api-consumption#see-number-of-api-calls-per-sync](https://docs.polytomic.com/docs/manage-salesforce-api-consumption#see-number-of-api-calls-per-sync) .


Salesforce admins you will no doubt find this useful. Still, Salesforce aside, please write to support@polytomic.com if you'd like to see this for any other integrations!
