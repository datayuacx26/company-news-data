*Klaviyo can now be provisioned by developers and their AI agents with a single command, joining a roster of category-leading infrastructure providers.*


Today we announced that Klaviyo is now available as a provider in the Stripe Projects developer preview. Stripe Projects is a new command-line workflow that lets developers and AI agents provision services, generate and store credentials, and manage usage and billing without ever leaving the terminal. Klaviyo joins the program as a co-design and launch partner, and is the first and only B2C CRM available through Stripe Projects.


With a single command, a developer or an agent working on a developer's behalf can stand up a Klaviyo account, receive scoped API credentials, and start integrating the Klaviyo platform into their project and business. Credentials are written directly to the project's environment file, and an LLM context file is placed alongside it, so any coding agent immediately knows how to use Klaviyo's APIs. The accounts and dashboards that get created stay in the developer's own name, with the normal access and controls they would expect from any Klaviyo account, so nothing about the existing relationship is handed off or hidden away.


## Built for developers and their agents


AI is changing who builds software and how it gets built and the next wave of consumer brands, apps, services, and communities is going to be assembled by teams sharing a default stack, instead of built from scratch. Klaviyo's integration with Stripe Projects removes the friction for one of the most common building blocks of a modern consumer business: customer data, messaging, and engagement. The same infrastructure that powers email, text messaging, and AI-driven experiences for 196,000+ brands including Mattel, Glossier, Daily Harvest, and Liquid Death is now one command away from any developer's terminal or AI-powered integrated development environment (IDE).


The integration is built on a new set of public APIs that Klaviyo developed for this launch; spanning programmatic account creation, scoped credential management, sending domain provisioning, SMS number registration, plan management and payment via Stripe's Shared Payment Token. Those same APIs and agent skill files extend Klaviyo's broader agent-native strategy across the wider ecosystem. Klaviyo meets builders in the terminal, in the IDE, in the agent surface, in whatever tool turns an idea into a working product. Stripe Projects is the right partner to help us get there, and we're excited to be the first CRM in the cohort.


## How it works


Getting started follows a short, repeatable sequence rather than a one-off onboarding guide that has to be rewritten for every project:


1. Install the Stripe CLI.
2. Run “stripe projects init my-app”
3. Add the Klaviyo service you need from the Stripe Projects catalog.
4. Stripe Projects provisions the resources inside your own Klaviyo account, or creates a new account for you if you do not already have one.
5. Your credentials are returned to your environment file or secret store in a form that both you and your coding agent can read and put to use right away.


## Availability


Klaviyo is available now in the United States in the Stripe Projects developer preview. Two services are available via free email and mobile messaging plans. Developers can get started by installing the Stripe CLI, running “stripe projects init my-app,” and then adding the Klaviyo service they need. During the preview phase, Klaviyo is actively inviting feedback from teams building with AI agents.
