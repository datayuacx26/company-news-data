# Ellipsis Joins Y Combinator

Ellipsis is joining Y Combinator's Winter 2024 batch, which starts in January. Our company profile is at[ycombinator.com/companies/ellipsis](https://www.ycombinator.com/companies/ellipsis) .


Ellipsis is a GitHub app that reviews every pull request your team opens, flagging logical errors, security issues, and style guide violations. Tag` @ellipsis-dev` in a comment and it will make the change, run the code, and push a commit.


We are two engineers, Hunter Brooks and Nick Bradford. If your team reviews code on GitHub and wants a bot to take the first pass, reach us atteam@ellipsis.dev .
