# Exome-to-Genome Reflex Ordering Is Now Available in Epic Aura

## Key takeaways


- Providers can now order **Exome-to-Genome Reflex** directly through Epic Aura and supported P2P EHR integrations.
- Exome-to-Genome Reflex begins with exome analysis on a genome backbone and automatically reflexes to genome and mitochondrial analysis when clinically appropriate—without requiring a new order or additional sample.
- New prior authorization enhancements allow eligible GenomeDx® orders to transition to Exome-to-Genome Reflex when insurance coverage is denied, reducing workflow interruptions.
- These enhancements simplify provider workflows, reduce administrative burden, and help maintain testing continuity.


## New EHR integration enhancements bring Exome-to-Genome Reflex ordering into provider workflows


GeneDx is expanding its EHR integration capabilities with new enhancements designed to help providers order the right test, reduce workflow interruptions, and keep testing moving without unnecessary delays.


Available in the upcoming August EHR release, these updates introduce support for Exome-to-Genome Reflex ordering within[Epic Aura](https://www.genedx.com/health-systems/epic-aura) and supported point-to-point (P2P) integrations, along with new prior authorization workflow enhancements that help maintain momentum when insurance coverage decisions create obstacles.


Together, these updates provide a faster, more flexible path to answers while allowing providers to work within their existing EHR workflows.


## Making comprehensive genetic testing easier to access


As[genomic sequencing](https://www.genedx.com/providers/genomic-sequencing) continues to play a critical role in diagnosing rare and complex conditions, healthcare providers need workflows that support timely decision-making without adding administrative burden.


GeneDx’s August EHR release expands access to one of GeneDx's newest testing options, Exome-to-Genome Reflex, directly through supported EHR integrations. Providers can initiate testing through their[familiar ordering workflow](https://providers.genedx.com/) while preserving a seamless pathway to more comprehensive genomic sequencing when clinically appropriate.


## How Exome-to-Genome Reflex works through EHR integrations


Providers can now order Exome-to-Genome Reflex directly through Epic Aura and supported P2P integrations.


Exome-to-Genome Reflex begins with[exome analysis](https://www.genedx.com/providers/whole-exome-sequencing) performed on a genome backbone. If the exome interpretation does not fully explain the patient's clinical presentation, testing automatically reflexes to genome and mitochondrial analysis without requiring a new order or an additional sample.


This streamlined approach helps providers:


- Start with an insurance-aligned testing strategy


- Maintain access to genome-level insights when needed


- Avoid delays associated with reordering testing


- Reduce administrative burden for care teams


‍


By eliminating the need to restart the process when additional testing is warranted, providers can focus on patient care rather than operational hurdles.


## New prior authorization enhancements help keep testing moving


The release also introduces enhancements to the prior authorization workflow for[GenomeDx® orders](https://www.genedx.com/providers/wjole-genome-sequencing) .


Customers can elect to have eligible GenomeDx orders automatically transition to Exome-to-Genome Reflex if insurance coverage is denied. This creates a built-in alternative testing pathway without requiring providers to place a new order or restart the workflow.


For providers and health systems, this means fewer interruptions, less manual follow-up, and a more efficient path forward when coverage decisions change.


## How prior authorization enhancements help reduce testing delays


When testing plans are disrupted by prior authorization outcomes, restarting the process can introduce delays for both providers and patients. This new workflow helps organizations:


- Reduce administrative complexity


- Minimize care delays caused by denied coverage


- Maintain testing continuity


- Improve provider and laboratory efficiency

In addition to these new capabilities, the release supports broader workflow improvements by helping organizations:

- Simplify Provider Workflows: Leverage a more intuitive ordering experience with fewer manual steps.


- Prevent Lab Holds and Follow-Up Requests: Improve order completeness upfront to help keep testing progressing smoothly.


## Supporting a faster path to answers


The August EHR release reflects GeneDx's ongoing commitment to increase simplicity in the genetic testing process. By bringing Exome-to-Genome Reflex ordering directly into the EHR and introducing flexible workflows that help testing continue when coverage challenges arise, these enhancements help providers spend less time managing logistics and more time caring for their patients.


## Planning for the EHR integration upgrade


To take advantage of these new capabilities, customers will need to update their GeneDx integration.


### **For Epic Aura customers**


Organizations should work with their Epic Technical Services representative to download and install the updated TC packages.


### **For P2P customers**


Updated compendia will be required to enable the new Exome-to-Genome Reflex orderables through supported integrations.
