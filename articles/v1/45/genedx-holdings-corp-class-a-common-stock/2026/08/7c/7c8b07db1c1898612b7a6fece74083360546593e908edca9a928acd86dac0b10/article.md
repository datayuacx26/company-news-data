# GeneDx Launches Easy Order for ExomeDx™ with CMA in the Provider Portal

## Key takeaways


- Easy Order is now available in the GeneDx Provider Portal for eligible ExomeDx™ orders with CMA, providing general pediatricians with a simpler way to order genetic testing for patients with GDD/ID.
- The guided workflow helps providers identify missing information, upload required documentation, select sample collection options, and complete orders more efficiently.
- Providers can add CMA within the same ExomeDx™ order and access commonly used ICD-10 codes without leaving the workflow.
- By reducing avoidable administrative steps and follow-up, Easy Order helps care teams spend more time focused on patient care.


## New guided ordering experience helps providers submit complete exome orders faster and with fewer manual steps


GeneDx has launched Easy Order, a guided Provider Portal experience designed to make it simpler and faster for[general pediatricians to order ExomeDx™](https://www.genedx.com/providers/specialties/general-pediatrics) with chromosomal microarray (CMA) for patients with global developmental delay (GDD) or intellectual disability (ID).


Built to reduce administrative burden and support more complete submissions, Easy Order guides providers through each step of the ordering workflow, helping them upload required documentation, identify missing information, select sample collection options, and add CMA when appropriate—all within a single, streamlined experience. For providers, that means less time spent navigating order requirements and more confidence that the information needed to move testing forward is included from the start.


The benefit is practical: by making the ordering process more guided, organized, and transparent, Easy Order can help reduce avoidable back-and-forth, minimize workflow interruptions, and make it easier for care teams to complete exome orders efficiently. Less time spent on administrative steps means providers can spend more quality time with patients and families, focusing on care conversations, clinical decision-making, and the next steps that matter most.


A faster, easier ordering experience can also help providers move testing forward sooner. By helping teams submit more complete orders from the start, Easy Order supports a smoother path to results—empowering providers to get answers to patients and families faster.


## A simplified workflow for complete orders


[Ordering genetic testing](https://www.genedx.com/providers/how-to-order) can require providers to move between clinical notes, insurance documentation, patient information, and multiple forms. Easy Order helps simplify that process by presenting only the information needed at each step, so providers can move through an order more efficiently and with greater confidence before submission.


## Documentation and checks built into the ordering process


Easy Order allows providers to upload insurance information, medical necessity documentation, and supporting files directly within the workflow. The experience also highlights incomplete sections and prompts providers when additional information may be needed, helping reduce avoidable follow-up after an order is submitted.


## Flexible sample collection options


To support different practice workflows, Easy Order gives providers the option to collect a sample in the office, send a collection kit directly to the patient, or use samples already received by GeneDx without leaving the order.


## **Faster access to common diagnosis codes**


The workflow surfaces commonly used ICD-10 codes to help providers find relevant diagnoses more quickly, while still allowing access to the full code set when needed.


## **ExomeDx™ with CMA in one streamlined order**


When CMA is appropriate, providers can add it to an ExomeDx™ order in the same workflow, eliminating the need to create a separate order or re-enter the same information. As parent or relative sample information is added, Easy Order also updates the order to the appropriate testing code based on the information entered.


## **Available now in the GeneDx Provider Portal**


Easy Order is available now for eligible ExomeDx™ orders in the[GeneDx Provider Portal](https://providers.genedx.com/tests) for general pediatricians caring for patients with global developmental delay (GDD) or intellectual disability (ID). With a more intuitive workflow, built-in prompts, flexible sample collection options, and the ability to add CMA within the same order, Easy Order gives providers a simpler way to complete exome ordering from start to finish. By reducing administrative friction, it helps care teams spend less time managing the ordering process and more time focused on patient care—while supporting a faster, more complete path to the answers patients and families are waiting for.
