# Ditto Blog | Everything you can do with the Ditto MCP

91% of designers now use AI every week. Half have already shipped AI-generated code to production. And as teams come to rely on it, it becomes even more crucial to get the right context into and out of these agent sessions to make sure everyone’s individual output matches the company-wide standards and expectations.


We built the first version of Ditto MCP to make your style guide and your copy library reachable from inside your AI workflow. And now, we’re taking it even further.


Because reachable isn't the same as usable. And the context that lives in Ditto is only as good as the decisions made from it. Now, we've made almost everything you can do as a user in Ditto accessible through the MCP. Now, when you're building product alongside an agent, that agent can work alongside and inside Ditto: Use the system you already built. Refine it as it goes. Add to it as it works.


## New capabilities of the Ditto MCP


An agent connected to Ditto MCP can now:


- Create a new Ditto project
- Create, edit, and delete text items
- Create and edit your copy library
- Create, edit, and delete variants
- Search anything in your workspace — text value, language, dev ID, status, assignee, whatever you need
- Create, edit, and delete folders and text item blocks
- Run reviews and suggest edits on existing text
- Pull in existing style guide rules, or create, edit, and delete new ones
- List our all new notifications


Whoever — or whoever’s agent — takes one of those actions, it shows up in Ditto's running activity log. Every action tied a teammate, or a teammate’s agent.


Here's what it actually looks like to use.


## **What this looks like in practice**


Agents are good at exactly the work that's tedious for a person — doing something in bulk, comparing across dozens of items at once, making a lot of small, low-level calls one after another. An agent can move through that fast. And because it's referencing Ditto as the source of truth and writing back to it, none of that work gets stranded in a chat window or an individual AI prototype. It lands in your actual system of record.


A few real examples of what an agent can do, on your behalf:


- **Spin up a new Ditto project from an AI prototype.** Create a text item for every piece of copy, dev IDs assigned, status set to Work in Progress or handed straight to you. From there, without leaving the session: make edits, ask it to suggest changes against your style guide, or clear out text items you don't need.
- **Draft a new Ditto variant for translated copy.** Translate copy according to that locale's own style guide, and send the whole set to Ditto tagged Work in Progress.
- **Bulk-create text items** , with dev IDs generated automatically. Pair it with the Figma MCP: compare what's new in a design file, dedupe against what already exists in Ditto, and create text items — with the right metadata — for whatever's actually new.
- **Run a global search for near-duplicates.** Find every stray "Continue," "Next," and "Submit" in your workspace, then edit them all to match one approved term and add it to Ditto as a copy component.
- **Clean up after a style guide change.** Find every text item that now breaks the new rule and fix all of them in one pass. Or run it the other direction — if the agent keeps making the same copy mistake, have it add a new style guide rule on the spot.
- **Brainstorm with full context.** Not a blank-page prompt — an agent that already knows what you've written and what your style guide says.
- **Reorganize your component library** into folders that actually make sense.


Every one of those still lands in the activity log. However the work got done, you know exactly who made the change.


—


This is just a few things you can ask an agent to do for you in Ditto. This makes it easier to generate better product copy from the start, which means your team can get to final faster. It also makes it easier to refine and iterate on the system as you use it, so you have living context that improves alongside you. No more one-off skills or manual file updates, just a two-way handoff between Ditto and your AI agent.
