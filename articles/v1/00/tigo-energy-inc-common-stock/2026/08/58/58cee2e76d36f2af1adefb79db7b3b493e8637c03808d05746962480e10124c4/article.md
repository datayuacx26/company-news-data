# Software Update: July 2026 Adds Remote Grid Code and Export Limit Controls

# Software Update: July 2026 Adds Remote Grid Code and Export Limit Controls


The latest Energy Intelligence software release gives installers and system owners more options for remotely managing Tigo inverter and battery systems.


Tigo has released the July 2026 update for the Energy Intelligence (EI) Platform, adding new remote system settings and improvements across the EI Portal and EI Mobile App.


The release introduces the ability to remotely configure grid codes and AC export limits. These capabilities can help installers respond to changing system requirements, resolve configuration issues, and manage system operation without always needing to visit the site.


The EI Portal update is now live, and the updated EI Mobile App is available through the[Apple App Store](https://apps.apple.com/us/app/tigo-energy-intelligence/id906118408) and[Google Play](https://play.google.com/store/apps/details?id=com.tigoenergy.smart&hl=en_US) .


### What’s new


##### Remote grid code configuration


Installers and authorized users can now remotely change a system’s utility or regional grid code through the EI Platform.


Grid codes define how an inverter must interact with the local electrical grid. The new remote setting makes it easier to align system configuration with applicable utility and regional requirements or correct an improperly selected grid code.


Because grid requirements vary by location, installers should confirm the appropriate setting with the applicable utility and local requirements before making changes.


##### Remote AC export limit controls


The update also adds the ability to remotely configure AC export rates and limits.


Installers and system owners can use these settings to control how much energy a system exports to the grid. This can help align system operation with applicable utility export requirements or homeowner energy-management preferences, including prioritizing energy for use in the home.


Export permissions and requirements vary by utility and region. Settings should be configured according to applicable interconnection rules and program requirements.


### Web and mobile enhancements


The July 2026 release also includes several improvements to EI Platform data access and API functionality:


- Improved bulk API data retrieval for greater scale and performance
- Added the ability for authorized manufacturers to query their systems through the API
- Updated version 4 of the EI API developer documentation


### Additional reliability and usability improvements


The release addresses issues across system configuration, battery management, equipment data, developer access, and the EI Platform user experience. Updates include:


- Improved reporting of configuration files from actively connected systems
- Corrected system-page redirects for customers with full access
- Restored Developer page and API documentation access for applicable developer permissions
- Removed an unnecessary EV Charger session-statistics warning
- Corrected missing battery-management information messages
- Prevented overlapping battery-management sliders
- Restored update-attempt information in the legacy update interface
- Standardized TS4 model and type naming across the EI Portal and EI Mobile App
- Improved synchronization of GO Battery module data between the battery management system and individual modules
- Corrected system-list and language-preference behavior in localized demo experiences
- Improved processing of configuration values contained in XML system data
