# Introducing the sync. playground

The fastest way to know whether a[lip sync ai model](https://sync.so/blog/what-is-ai-lip-sync/) fits your work is to actually run it on your video. The sync. playground exists so you can do that without setting anything up.


### Features


- make api requests directly from the browser
- easily test and compare all models
- adjust parameters and save custom presets for quick reuse
- view and copy generated code to drop straight into your projects
- view last 30-days of generation history


Tweak a parameter, run it again, save the preset, copy the code into your stack. That’s the whole loop.
