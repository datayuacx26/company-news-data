# Dictate, don't type

Long, careful prompts are easier to speak than to type. The chat input now has a microphone button so you can dictate instead.


Tap the mic, talk through what you want, and the words appear in the input as you go. Tap again to stop. Edit anything that came across wrong, then send.


It’s faster for the kind of prompt where you’re explaining context out loud anyway: “draft a response to this email, but keep it polite, mention the deadline we agreed in the meeting last week, and don’t commit to a fixed price.” Dictate it once, send it once.


Works in the main chat input across Parachute. Use a quiet room and a decent microphone for best results.
