# Prompt library

The prompts your team relies on shouldn’t live in a scratchpad. Parachute now has a prompt library.


## Save, share, reuse


- Save any prompt to your library and reuse it whenever you need it.
- Type` /` in the chat composer to search and insert a saved prompt without leaving the conversation.
- Create prompts on the fly from the` +` menu, and manage the full library from settings.


## Private or shared


Keep a prompt to yourself, or promote it to the whole organisation. Scope controls are built into the editor, so it’s always clear who can see each one.


## Also in this release


- **Precedents by workstream.** Browse and manage precedents organised by workstream, move them between workstreams, and preview a precedent before using it in a draft.
- **Precedent tags and bulk actions.** Add and manage tags, apply them to several precedents at once, and bulk-delete from the precedents table.
- **AI-generated precedent descriptions** , created and managed directly in the app.
