# The editor, rebuilt

We’ve rebuilt Parachute’s document editor from the ground up. It now behaves much more like Word, and it’s the foundation for a lot of what comes next.


## Multiple documents, one session


A single working session can hold several documents, each with its own independent version history. Your work saves and restores reliably as you move between them, and exported DOCX files come out with cleaner formatting.


## Comments and tracked changes


- Add comments directly in the editor through a dedicated popover.
- Review tracked changes inline, with accept and reject controls that scroll straight to the first change.
- The comments panel and tracked changes stay in sync, so both views always agree.


## Broader Word support


The editor handles a wider range of Word formats, converting them automatically on upload, and preserves style and list formatting - including inline markup and clause structures - far more faithfully.


## Also in this release


- **Richer context for drafting.** The AI can find and reference multiple tagged precedents in a single draft, and you can search for and insert precedents from within a drafting conversation.
- **More document context.** AI responses now draw on significantly more of a document, improving quality on longer files.
