# Sharper prompts

A short, vague prompt is the difference between a useful answer and a generic one. But knowing how to phrase a prompt isn’t anyone’s job, so we’ve added a quick way to sharpen it for you.


Type a rough idea of what you want, hit the improve button, and Parachute rewrites the prompt with the structure and detail the AI works best with. Review the rewrite, edit it if you want, then send.


Useful when you’re starting from a half-formed thought and want a stronger first draft, or when an earlier reply missed the mark and you’d rather refine the question than the answer.
