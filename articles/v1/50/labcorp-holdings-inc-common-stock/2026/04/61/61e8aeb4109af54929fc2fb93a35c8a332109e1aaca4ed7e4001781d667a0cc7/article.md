# Scaling clinical insights at Labcorp with AWS HealthLake

In a recent video from Amazon Web Services (AWS), Bola Oyegunwa, EVP, chief information and technology officer at Labcorp, discusses how Labcorp and AWS collaborated to develop Test Finder, a first-of-its-kind generative AI tool that helps physicians identify the best lab tests for their patients.


Oyegunwa underscores how collaborations and innovative technologies like Test Finder are helping transform patient care by enabling faster, more informed choices at the point of care.[Watch the full AWS video](https://www.youtube.com/watch?v=PIZx1mKE3ME) to learn more about how Labcorp is using generative AI to support smarter diagnostics.
