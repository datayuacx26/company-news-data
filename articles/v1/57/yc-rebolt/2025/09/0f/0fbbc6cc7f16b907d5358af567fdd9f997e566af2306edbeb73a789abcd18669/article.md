# Introducing Github Sync

I bet you’ve faced a moment like this:


When building with AI, you needed help from an engineer on a tricky feature. You tried and tried, but the agent wouldn’t listen.


That’s why we’re introducing GitHub Sync in Rebolt.


Now, you can get help from engineers to finish that remaining 5%.


Here’s how it works:


- Build normally until you get stuck
- Bring in an engineer
- Connect the project to a GitHub repo
- Seamlessly pull and push changes between GitHub and Rebolt


Everyone, from business to engineering, can deliver 10× faster together, without blockers.
