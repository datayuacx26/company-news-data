# BBVA Mexico SWIFT code: How to find and use it

Trying to send money to a BBVA account in Mexico without the SWIFT code is like trying to mail a package without an address. A SWIFT code is a short combination of letters and numbers that informs the international banking system exactly where your money needs to go.


The SWIFT code for BBVA Mexico (BBVA Bancomer) is BCMRMXMM, used to route international transfers to a BBVA account in Mexico. You need it, along with the recipient's account number or CLABE, to send money from abroad. Always confirm the code with the recipient or BBVA before sending.


**BBVA Mexico SWIFT/BIC code: BCMRMXMM**


If you are sending money internationally to a BBVA Mexico account, whether to pay a supplier, support family, or settle a personal transaction, you need this code to route the transfer correctly. This guide explains what the code means, how to find it yourself, and what else you need to complete a successful transfer.


## What is the BBVA Mexico SWIFT code?


BBVA Mexico is Mexico’s largest financial institution, established in 1932 with its headquarters in Mexico City. It is the most profitable overseas subsidiary of BBVA Spain, its parent institution.


BBVA Mexico's SWIFT/BIC code is **BCMRMXMM**
You may also see it written as **BCMRMXMMXXX** , where the XXX identifies the head office. Both formats can be accepted for international transfers.


A SWIFT code is also called a Bank Identifier Code (BIC). It refers to an 8 to 11-character code that identifies a bank when sending money internationally. It tells the sending bank where to send the transfer. It may also specify the branch and location to route the transfer to.


BBVA Mexico was formerly known as BBVA Bancomer until 2019, when the bank rebranded. However, the SWIFT code BCMRMXMM remained unchanged after the rebranding. Only the bank’s name changed from BBVA Bancomer to BBVA Mexico, S.A. So, if you see older documentation referencing "BBVA Bancomer," the SWIFT code shown there is still valid.


BBVA Mexico's code (BCMRMXMM) is different from BBVA Spain’s code (BBVAESMMXXX). These are separate entities, even though BBVA Spain is the parent institution. If you're sending money to a Mexican BBVA account, use the Mexico-specific code. If you use BBVA Spain’s code instead, your money will be routed to the wrong account and may not be recoverable.


## How to find the SWIFT code yourself


If you're unsure which SWIFT code to use, you can check:


- **Through online or mobile banking:** If you or the recipient has access to BBVA Mexico's online banking or mobile app, the SWIFT/BIC code is usually listed under account details or international transfer information.
- **On a bank statement:** Some BBVA Mexico statements include the SWIFT code with your account information.
- **On BBVA's official website:** Check[BBVA Mexico's website](http://bbva.mx/) to confirm the current SWIFT codes for international transfers.
- **Directly from the recipient:** If you're sending money to someone with a BBVA Mexico account, ask them to confirm their banking details before making the transfer. Some branches may have an extended SWIFT code.


## SWIFT code vs CLABE: what is the difference?


If you're sending money to a BBVA Mexico account, you may need both the SWIFT code and CLABE, but they serve different purposes.


- **The SWIFT code (BCMRMXMM)** identifies the bank in Mexico that receives the payment and how to route the transfer from the sending bank to BBVA Mexico. Think of it as the bank's international address that tells the international banking network where to send the money.
- **The CLABE (Clave Bancaria Estandarizada)** is an 18-digit standardised interbank code unique to Mexico. It is required for all electronic transfers within the Mexican banking system. It identifies the specific account within BBVA Mexico where the funds should be paid. Think of it as identifying the specific mailbox at the address the SWIFT code points you to.


For an international wire transfer to a BBVA Mexico account, you generally need both the SWIFT code to route the transfer to the correct bank and the CLABE to ensure the funds land in the correct account.

**Step 2: Initiate the transfer through your bank**


Log in to your bank's online platform or visit a branch. Select international wire transfer and enter the recipient's details exactly as provided, including the SWIFT code and CLABE.


**Step 3: Enter the details**


Enter the recipient's information exactly as provided. Double-check the SWIFT code and CLABE before continuing.


**Step 4: Confirm the transfer currency**

**Step 6: Track the transfer**


Save the transfer reference your bank provides so you can track the payment if there is a delay. Many banks now support SWIFT GPI tracking, which shows where the transfer is in the routing chain and its estimated arrival time.

## Frequently asked questions about BBVA Mexico’s SWIFT code


### **What is BBVA Mexico's SWIFT code?**


BBVA Mexico's SWIFT/BIC code is BCMRMXMM, sometimes shown as BCMRMXMMXXX. This code identifies BBVA Mexico's head office for international wire transfers. Some branches may have extended codes (such as BCMRMXMMPYM), so it's always best to confirm with the recipient before sending.


### **Is BBVA the same as Bancomer?**


Yes, in the sense that BBVA Mexico was formerly branded as BBVA Bancomer before a 2019 rebrand. It is the same institution with the same SWIFT code (BCMRMXMM) as before the name change. If you have older documentation or contacts referencing "Bancomer," the bank details remain accurate; only the name has updated.


### **Do I need the CLABE too?**


Yes. The SWIFT code alone routes your transfer to BBVA Mexico as an institution, but it does not identify a specific account. The 18-digit CLABE (Clave Bancaria Estandarizada) identifies the exact account the funds should be credited to. Both are required for a complete and accurate international transfer to a Mexican bank account.


### **How long does a transfer take?**


International wire transfers to BBVA Mexico typically take one to five business days, depending on your sending bank, the currency used, and whether the transfer passes through one or more correspondent banks in transit.
