## **1 Tech Tip**


### Start Claude’s usage window before you need it


This tweet is obviously a joke…


But also… it *does* really work!


If you use Claude heavily, its usage limits run on a rolling 5-hour window.


This means if you start a tiny Claude session early in the morning, it’ll start the usage limit reset clock sooner too.


**Pro tip** : You can also set up a tiny recurring morning task around 5am so Claude takes a simple action automatically, which helps start the window before you’re even awake.
