## **1 Tech Tip**


### Stop naming files “final_final_ACTUALfinal”


This week’s tech tip steals something from what engineers already do.


When they ship software, they don’t name things:


-


App Update Final


-


App Update Final 2


-


App Update Final FINAL


-


App Update ACTUAL FINAL


-


App Update ACTUAL FINAL USE THIS ONE


They use version numbers.


So next time you’re naming your file, instead of trying to describe the emotional state of the file name, use:


-


Board Deck v1


-


Board Deck v2


-


Board Deck v3


Or, if you want to get a little more precise:


-


Board Deck v1.0


-


Board Deck v1.1


-


Board Deck v1.2


-


Board Deck v2.0


**v1.0 → v1.1** = small edits, copy changes, formatting tweaks


**v1.2 → v2.0** = bigger changes, new structure, major revisions


This makes the file history way easier to follow, especially when multiple people are reviewing the same deck, proposal, event plan, or board packet.


Perhaps more importantly, it also saves you from ever creating a file called: Q3 Planning FINAL FINAL REAL ONE USE THIS PLEASE.pdf
