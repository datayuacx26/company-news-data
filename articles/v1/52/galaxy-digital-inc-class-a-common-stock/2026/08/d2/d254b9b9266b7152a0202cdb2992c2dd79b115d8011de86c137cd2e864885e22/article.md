# Written in Code: This code is building rails for the world's banks.

*Institutional-grade onchain infrastructure for traditional financial institutions. Programmable rails.*


The economy that runs on code needs rails. Galaxy is building them with some of the largest institutions in finance.


Code already rewrote how information moves. It is now rewriting how value moves. **That is the code economy.** Money, markets, and ownership become programmable, and the infrastructure beneath them becomes software.


For a financial institution, that means the plumbing changes while the products stay familiar. A fund is still a fund. A dollar is still a dollar. What changes is the speed and the hours. Rails that settle in seconds. Markets that do not close on a Friday. Assets that carry their own instructions, so interest can pay itself and compliance can be enforced at the moment of transfer rather than weeks after it.


Leading institutions have made their choice. BNY. State Street. Morgan Stanley. BlackRock. Invesco. Each is building on Galaxy infrastructure.


Custody is the layer everything else plugs into. An institution cannot trade, stake, tokenize, or report on an asset it is not holding safely. Get that right and the rest of the stack has something to attach to.


Galaxy builds that layer. The institution holds its own keys. Vaults stay offline. Signing runs through multi-party computation, so no one person can move anything alone. A policy engine enforces the institution’s own controls, jurisdiction by jurisdiction.


That technology does not only run inside Galaxy. Regulated custodians have standardized their own platforms on it. Their clients log in and see their name. The code underneath is Galaxy’s.


Staking shows what that foundation buys. It once meant moving assets out of the vault and trusting whoever received them. Now they stay where they are and earn.


Whoever runs the validator still has to run it well. Blockchains penalize failure automatically. A validator that drops offline stops earning. One that signs the wrong thing is slashed, and the stake absorbs the loss. Galaxy runs its own, has operated one of the largest Solana validator operations in the world, and puts slashing protection and institutional insurance behind them.


Tokenization sits on the same foundation. Galaxy’s technology powers[SWEEP](https://am.galaxy.com/galaxy-state-street-sweep-fund) , the tokenized liquidity fund launched with State Street Investment Management.[Galaxy was the first public company to tokenize its SEC-registered shares directly on a public blockchain](https://www.galaxy.com/newsroom/galaxy-superstate-launch-glxy-tokenized-public-shares) . Not a wrapper. The actual stock, moving onchain.


That record is why institutions ask Galaxy to build theirs. Engineers deploy into the institution’s own environment and build on its systems. At handover, the institution owns the platform outright. Galaxy stays to run it and extend it.


The names on these platforms will vary. The rails underneath will not. The more of this economy gets built, the more of it runs on Galaxy.


**Grow the economy that runs on code.**
