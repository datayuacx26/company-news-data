# 🐣 Toko for Beginners 初學快速指南

想開始英文練習卻不知從哪起步？這篇 Toko 初學者指南 帶你快速熟悉 AI 英文學習 App 的核心功能，從調整語速、選擇課程到實戰英文口說，5 分鐘內就能完成第一次練習，開口說出自然英文。無論你是零基礎新手、久未開口的學習者，或想提升口說自信，都能在這裡找到最輕鬆有效的入門方法。


## 💡 提示 & 中翻英表達


**用途** ：對話卡住時立即獲得提示句子；輸入中文也能得到 4 種自然英文說法。


**操作方式**


-


開始任何AI 對話


-


點 右下角提示💡符號 → 取得四種不同回答方式


-

-


需要輸入中文？使用 左下角翻譯功能，AI 會提供三種自然英文說法，可直接跟讀錄音


```text
🔑小技巧：將常用詞與存入「已儲存的」，系統會自動排入記憶練習。
```

## 📚 腳本對話


**功能介紹**


腳本對話是進入 AI 真實對話前的預習工具。你可以跟著腳本練習對話，系統會提供即時發音回饋，還能點選單字儲存，方便日後複習。


Toko 提供兩條路徑至腳本對話：


**方法一：從「學習計畫」進入**


1.


開啟 App → 頂端點選目前的系列名稱（如「家教系列 1」）


2.


向下滑至頁面底部 → 點「學習計畫」


3.


任選一話題點右側的書本符號


**方法二：從單一話題直接進入**


1.


開啟 App → 「探索」頁面→ 下滑選擇任一話題


2.


進入該話題頁面 → 點畫面下方「腳本對話」


**使用教學**


進入腳本對話後，依序完成以下步驟：


1.


**選擇練習模式**


-


對話練習模式：跟著腳本逐句練習


-


只聽模式：僅播放對話音檔，適合通勤或純聽力訓練


2.


**跟讀並獲得發音回饋**


-


練習時系統會即時偵測發音


-


若看到淺紫色單字，代表該字需要加強，可點進查看音節解析並重練


```text
🔑小技巧：通勤時可選「只聽」模式，當聽力練習。
```


## 🌱 初級友善內容


Toko 內建多樣適合初學者的系列，讓你循序漸進、無壓力學英文。


**依學習目標選擇系列**


-


想強化單字量：可選「詞彙專攻家教」（初級家教 1–3、以及初級家教：職場）。

**如何切換或找到更多系列**

2.


在「瀏覽系列」頁面往下 **滑** ，即可在不同家教及故事線系列之間切換與挑選

## ⚙️ 對話設定：語速＆難度


**預設設定**


若你在註冊時選擇 A1（🥚）或 A2（🐣）等級，系統將自動套用初學者預設值：語速「慢」、難度「初級」。


**如何修改設定**


即使一開始沒有選擇初學者等級，也能隨時將對話調整得更簡單：


-


進入 「我的」頁面


-


點 左上角⚙️ 齒輪 → 設定


-


對話設定 → 聲音設定 → 速度 → 選擇 慢


-


對話設定 → 聲音設定 → 對話難度 → 選擇 初級

## 📌 FAQ｜首次使用 Toko 用戶


1.


### 第一天該怎麼開始？


建議三步驟：


-


我的頁面 → 左上角設定 → 對話設定 → 聲音設定 → 調成「慢」


-


首頁 → 學習計畫 → 從第一個話題開始


-


首頁 → 學習計畫 → 瀏覽系列 → 詞彙專攻家教 → 初級家教 1–3，從第一單元開始


2.


### 聽不懂或跟讀跟不上怎麼辦？


在對話設定中可以：


-


**調整語速** ：先把語音速度設為「慢」。


-


**降低難度** ：在對話設定裡將 **對話難度調成「初級」** ，句型與用字會更簡單。


-


**使用提示** ：點右下角提示功能，選擇更短的範例句。


-


**只聽模式** ：先用腳本對話的只聽模式練聽力，再開始跟讀。


3.


### 不敢開口、很害羞怎麼辦？


從 **腳本對話** 開始，先熟悉單字片語再開口。


對話中卡住就按右下角提示，直接照範例念出完整句，建立信心。


4.


### 我應該先學哪個系列？


依需求選擇：


-


日常口語：初級家教：日常 1–4


-


職場情境：初級家教：職場


-


喜歡劇情：初級旅行：日本行腳


-


想挑戰程度：闖關任務從銅牌開始


5.


### 怎麼把學到的單字存起來複習？


-


在任何對話訊息中，點選任一字或片語即可查看意思、例句與聽發音。


-


隨時可按儲存(如下圖)，詞語或例句會加入「已儲存的」頁面，之後可隨時回看。


-


系統會根據你的已儲存清單與曾經犯錯的弱點，智慧安排複習與加強練習。
