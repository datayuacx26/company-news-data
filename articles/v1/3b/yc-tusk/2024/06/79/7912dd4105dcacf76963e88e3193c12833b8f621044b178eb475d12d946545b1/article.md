# What's new in Tusk


We've been busy in June shipping features to make Tusk even more accommodating of your existing ticket creation workflow while also making the agent more accurate when reasoning and generating code.


## New releases


- Figma integration to extract mock-ups for context (shown above)
- Abstract semantic graph for finding relevant files
- Ability for agent to learn from past merged PRs when solving tasks
- Ability to ingest images in PR reviews
- Better support for using pre-commit hooks
- Improved precision of auto-triaging
- Enhanced code investigation agent
- Smoother onboarding flow
- New, snazzy[documentation page](https://docs.usetusk.ai/)
