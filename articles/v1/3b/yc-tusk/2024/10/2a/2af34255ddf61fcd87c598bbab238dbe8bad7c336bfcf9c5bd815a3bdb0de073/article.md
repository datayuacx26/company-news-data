# October '24 Changelog

# What's new in Tusk


Tusk sampling from multiple parallel runs and doing a pre-run check for complexity


In October, we've introduced the ability for Tusk to **sample from multiple parallel runs** for the ideal path, better match Figma components to your repo's components, released Automated Browser Testing to the wider public, and made optimizations to both code exploration and generation.


## New releases


- Ability to determine best path from multiple parallel agent runs
- Figma integration revamp to better find matching components
- Automated Browser Testing optimizations and self-healing
- LLM pre-run warnings for complex issues
- Support for new Claude 3.5 Sonnet
- Enhancements to codebase exploration and recursive agent
- Slack app to notify teams of merged Tusk PRs
- Improvements to code generation for large files using AST
- Ability to replicate any run’s output to a new PR
- UI/UX improvements to Dashboard and Activity Log to better manage issues
- Updated marketing website
