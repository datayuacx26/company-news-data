# What's new in Tusk


Tusk was[#1 SaaS Product of the Week](https://www.producthunt.com/posts/tusk-yc-w24?embed=true&utm_source=badge-top-post-topic-badge&utm_medium=badge&utm_souce=badge-tusk-yc-w24) on Product Hunt the week of Aug 12. Big shoutout to our community for your support! 🐘🥇


Improving agent reliability, steerability, and onboarding has been on our minds in August. We shipped a bunch of the features below in the lead-up to our Product Hunt launch. We're proud to say that it has given our new and existing customers a better experience of Tusk on both our free and paid plans.


## New releases


- Recursive Agent to improve reasoning
- Abstract syntax tree to improve code generation
- Custom repo instructions to tailor code generation
- Suggested Issues from project management app
- Improvements to addressing automated checks
- Ability to retry code generation with feedback
- Cleaner onboarding flow
- Improved issues table UX
