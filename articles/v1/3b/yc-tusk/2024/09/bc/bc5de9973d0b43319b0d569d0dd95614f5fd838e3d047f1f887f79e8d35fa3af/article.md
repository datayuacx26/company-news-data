# September '24 Changelog

# What's new in Tusk


In September, we launched the beta of[Automated Browser Testing](https://docs.usetusk.ai/browser-testing) , added support for OpenAI's newly-released[o1 models](https://openai.com/index/introducing-openai-o1-preview/) , and shipped features to improve Tusk's code generation quality and overall user experience.


## New releases


- Automated Browser Testing beta
- OpenAI o1 support
- Better guardrails for different task types
- Improved UX for comments in ticketing apps
- Introduced rich-text editor to description fields
- UI/UX improvements to Dashboard, Suggested Issues, and Settings pages
