# What's new in Tusk


Tusk now fits even more seamlesly into your engineering-product-design team's workflow with new features that make it easier to provide context to our agent.


## New releases


🔄 **Auto-address feedback** : Tusk automatically addresses errors from automated checks like your build and lint steps so that any PR it creates will pass your checks.


🩺 **AI triaging** : Tusk automatically looks at tickets in your ticketing software and flags those that it can create a PR for. If Tusk needs more context, the agent will prompt you with questions.


📹 **Video support** : Tusk ingests visual and audio input from Loom videos linked in your ticket to come up with more accurate code solutions.


🐛 **Bug reporting integrations** : We extract screen recordings from Jam and Bird Eats Bug to debug issues before generating code.
