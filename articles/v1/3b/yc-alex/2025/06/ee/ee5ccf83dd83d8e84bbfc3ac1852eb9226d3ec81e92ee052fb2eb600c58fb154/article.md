# Alex is free for the next 7 days!

To celebrate WWDC and showcase how far Alex has come, we’ve decided to make the app free for the next 7 days.


This means you can use any of our models like Claude Sonnet 4, OpenAI’s o3, and Gemini 2.5 Pro, without *any* limits! (It does not count against your message or code apply limits.)


**Build your app, automatically compile and fix errors, use the simulator, run reasoning models, add to agent memory, screenshot results, generate images, automatic web search, run terminal commands, and much more. All for free this week!**
