# Introducing Alex 3.3

Hello everyone!


In Alex 3.3, we’ve added:


- 📝 Planning Mode
- ☯️ Interleaved Thinking
- ⇥ Multiline Tab
- © Copy Request as markdown
- 👾 Customer Support Bot
- ✅ GitHub Issues & Linear for all tiers


Your browser does not support the video tag.


Let's dive into it 👇


## 📝 Planning Mode


We’re releasing a feature that significantly increases the quality of Alex’s output: Planning


When you give Alex a task, it will first write a detailed to-do list that will guide its generation over the period of the chat.


This means Alex will:


1. Think in the bigger picture
2. Never lose track of the original request
3. Give you an opportunity to iterate on its plan


Planning is enabled by default, and you don’t need to do anything to get it working!


## ☯️ Interleaved Thinking


One of the biggest improvements in this release. Alex can now decide to think on its own, when faced with a challenge.


This means you don’t need to prompt it to think by toggling. It will automatically reason about compiler issues, technical implementations, researching strategies on its own.


(And only when needed, rather than all the time.)


## ⇥ Multiline Tab


One of the biggest challenges with Xcode is its limitations for extensions. We cracked this in Alex 3.3, releasing an improvement to tab autocomplete that was previously impossible, and which none of our competitors have managed to solve.


With multiline tab, we can insert multiple lines of suggestions underneath your cursor without obstructing the code. So now you can just tab tab tab.


To enable multiline autocomplete, go to Settings > Features > Enable Multiline (alpha)


## 📝 Copy Request as Markdown


With this new button, Alex will copy your request (with all the files attached) directly to your clipboard.


This feature unlocks two new capabilities for Alex:


1. Using OpenAI’s o3 Pro on ChatGPT.com — The absolute best reasoning model in the market.
2. Using Gemini’s 1M context window on Gemini.com — (6.5x larger context than our limit)


Because of the obscenely high cost for o3 pro (~10x more expensive than sonnet), and gemini’s 1M context window, we can’t serve them in our app. But now you can easily drag folders into these web portals!


## 👾 In-App Customer Support Bot


We’ve released a free customer support bot for all our users!


This will:


1. Answer questions you have about Alex (with our up-to-date docs)
2. Report bugs to our team, and tell you if they’ve been reported before
3. Take feature requests
4. Learn more about some features you haven't tried yet!


It uses a really good model, so it offers super high quality responses (some even better than ours :)


## ✅ GitHub and Linear Issues — Now available to all!


This is a feature we released only to Premium users in the past, but now we’ve enabled it for everyone (even free tier!)


You can connect your GitHub and Linear accounts, and select tickets for Alex to complete. You can even create / edit tickets in the app itself.


## 💰 New Unlimited Plan


We’ve added a new unlimited plan!


With this plan, you don't have to worry about chat credits & top-ups anymore. It's $200/mo for one device, with no rate limits.


With unlimited, you can let the agent do its thing without worrying about losing credits. And if things don’t go well, start over again to achieve the best results with a clean slate.


We’ve also increased our Pro tier from 500 Chat Credits -> 600, at the same price of $30/mo.


We’re excited to push the boundaries of Xcode AI, and look forward to see what you all build with Alex!
