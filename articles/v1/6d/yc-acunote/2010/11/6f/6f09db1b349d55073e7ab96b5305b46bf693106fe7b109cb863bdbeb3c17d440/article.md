# Google Apps User Management

Now it is very simple to link your Google Apps users to Acunote using our new **Google Apps User Management** page. It uses Google Apps user provisioning API so first you should grant Acunote access to it. Please go to Acunote application details page on your Google Apps domain management page and click *Grant data access* link in the **Data access** section.


Later you can find this page in **Google Apps Integration** section of your organization profile.
