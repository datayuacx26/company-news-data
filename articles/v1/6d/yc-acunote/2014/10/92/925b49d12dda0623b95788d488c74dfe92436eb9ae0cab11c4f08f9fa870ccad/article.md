# Updated Acunote Integration with Google Apps

We have upgraded Acunote to use OAuth2 integration with Google Apps.


Previously our Google Apps Marketplace application used OpenID and OAuth1.0 integration with Google Apps. These were[deprecated](http://googledevelopers.blogspot.com/2012/04/changes-to-deprecation-policies-and-api.html) by Google.


We upgraded all existing users. So if you are using Google Apps integration you don't need to do anything. Nothing will change except Acunote gets a new icon in Google Apps grid menu.


If you are not yet using Google Apps integration and would you to, you can install from[Google Apps Marketplace](http://www.google.com/enterprise/marketplace/viewListing?productListingId=6008+351488712953467822) .
