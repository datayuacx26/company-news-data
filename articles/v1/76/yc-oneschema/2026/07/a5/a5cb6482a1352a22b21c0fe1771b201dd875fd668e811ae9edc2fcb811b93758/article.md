# What's new in OneSchema October 22'

This month we’ve rolled out some exciting new features, including our new Data Template Summary, UI Translation, and Even Better Error-Fixing. Read on for details about each update!


‍


## Data Template Summary


You can now customize the first pane of your CSV import experience to include a summary of the data you’d like your customer to import. You can include your required and optional fields and descriptions of the data the customer should upload.


We added the following optional customizations to empower you to create the ideal experience for your end users on the first pane:


- The header and subheader copy within the Uploader component can now be fully customized
- Show the required columns and their descriptions in a new InfoSideBar component
- Show the required and optional columns along with their descriptions in a new InfoSideBar component


You can learn more about how to enable these customizations[in our docs](https://docs.oneschema.co/docs/javascript#contentoptions) .


‍


## UI Translation


OneSchema now supports the ability to fully translate the UI into the language of your choosing. Internationalization is currently an enterprise-tier feature. Please reach out to us to discuss your team's i18n needs and desired language support.


Learn more about the configuration option[in our docs.](https://docs.oneschema.co/docs/javascript#languagecode)


‍


## Even Better Error-Fixing


OneSchema’s hallmark feature is ability to easily resolve errors during uploads. We’ve made substantial improvements to make it even easier to upload clean, well-formatted data.


- **Delete all rows with errors:** When dealing with large files, often the customer just wants to upload data that’s correct and forget about the rest. The user can now delete all rows with issues in a single click
- **Delete selected rows in bulk:** If you don’t want to delete all rows with errors, use the checkboxes to select the rows you want to delete in bulk
- **Filter to find errors:** We’ve added a “show error” button in the issues summary that when clicked, brings the error front-and-center. It’s never been easier to find errors in your file
