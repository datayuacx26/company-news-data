# Metric Charts 2.0

The metrics chart has been updated to include even more insights. Now you can perform different kinds of aggregation calculations, view a metric for the current time period, and compare the metric to the previous time period’s value


## Aggregation Calculations


Metrics can now be calculated using different aggregation calculations: sum, max, min, average


## Time Periods


Do you only care about a metric for the current time period? Now you can only include values from today, this week, this month, this quarter, or this year.


Additionally, you can compare the value from the current period to the previous period
