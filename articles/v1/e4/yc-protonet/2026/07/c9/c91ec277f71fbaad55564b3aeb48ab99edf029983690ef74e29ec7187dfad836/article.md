# SOUL 4.4 – CHOOSE BETWEEN EXPANDED AND LIST VIEW OF THE TODOS FEATURE

**SOUL 4.4 – Choose between expanded and List View of the Todos Feature:**


*Prerequisite for this update is an active SOUL+ contract and a Protonet server with SOUL version stable /xxx. You will see the version after logging* into your SOUL on the help page.


**This SOUL Version is required to use the New SOUL-Mobile App**


- ****On the Todo lists Feature, you can now choose between the classic expanded view and the new list view****


- **The check list counter remains visible at all resolutions:**


- **“My Todo Deadlines” Filter – you can now filter out the task deadlines from other users in your groups**


- Tasks don´t change positions after being assigned to a new user


- German Language version is complete


- The ‘Show all’ Groups drop down menu opens full


- Fixes issue with removing shared folders from trash


- It is now possible to upload photos to Todo Descriptions:


**Bug Fixes:**


- Notes feature does not return an error message when creating a new note
- Todo lists – several small fixes with expanded and pinned items
