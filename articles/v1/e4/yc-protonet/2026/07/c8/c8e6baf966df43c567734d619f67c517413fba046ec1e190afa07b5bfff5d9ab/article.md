# SOUL 4.6 – PRINT TASK DESCRIPTIONS AND STREAMS + BUGFIXES

**SOUL Stable/129 – Print Task Descriptions and streams + Bugfixes:**


***Prerequisite for this update is an active SOUL+ contract and a Protonet server with SOUL version stable /xxx. You will see the version after logging* into your SOUL on the help page.**


**New Features:**


- Added Print Functionality to the todo description and stream


- The new double check seen icon shows when all chat members have received the message
****


**Bug Fixes:**


- Accessing the “todo description updated” notification sometimes lead to the description disappearing


- Some workflows break file permission, that lead to sync conflicts, this would sometimes make files and folders invisible on finder/explorer-integration.


- Fixed the create a widget from an active topic function:


- Fixed public links not expiring when creating user gets deleted
