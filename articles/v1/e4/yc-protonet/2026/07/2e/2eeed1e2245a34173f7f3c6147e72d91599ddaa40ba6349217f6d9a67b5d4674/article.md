# SOUL 4.0 – 2FA, RICH EDITOR AND MUCH MORE

**SOUL 4.0 contains multiple improvements that will make your SOUL experience even more efficient.**


****


*Prerequisite for this update is an active SOUL+ contract and a Protonet server with SOUL version stable/xxx. You will see the version after logging into your SOUL on the help page.*


**Important Update Notice:**


Updating to SOUL 4 can take more than 30 minutes so please plan and communicate an according downtime with your users.


**Notes: new functions to create richer documents.**


- Insert pictures and links easily
- Create checklists within documents
- Insert Tables
- @-Tagging and more!


**New user permissions and access options for individual groups and private objects**


- It is now possible to give users access to individual objects, without having to invite them into a group.


**Two-factor authentication**


**Emojis**


- New emoji system – now all emojis (including new ones) are always available


**Input display in chat**


- “Typing Indicators” – follow live who is typing in the chat


**Preview on links**


- The preview function for links has been significantly improved


**SOUL entries in the browser history**


- SOUL objects are now finally displayed correctly in the browser history


****


**Object links**


- For the first time, individual objects can be linked in the chat or stream, the conversation partner no longer has to become part of the group in which the object is located


****


**Search Index**


- Revised search and indexing system


**Helpful additions to Chats:**


- Accurate message date and time
- Copy Direct Link to message
- Jump to Message
- “Seen by:” Message Status
- Ruby and Ruby on Rails have been updated, in the process we have drastically reduced memory consumption and long-term system stability.


**Further improvements:**


- The default search order is now newest results first
- Improved Calendar ‘.ics’ creation
- Improved indexing process for all SOUL objects
- Admin interface now shows the indexing status of all SOUL objects
- New API for the new SOUL Mobile App
- Accessing a user email address is limited to admin users only
