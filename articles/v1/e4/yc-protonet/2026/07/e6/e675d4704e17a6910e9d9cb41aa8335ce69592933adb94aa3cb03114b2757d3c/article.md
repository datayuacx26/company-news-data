# SOUL 2.20.3 – soul3/1510


14.03.2017


**Soul 2.20.3 – Bugfixes (soul3/1510) – 14.03.2017**


*This update is exclusively available for Protonet servers with SOUL version soul3/1xxx*


*You can check your SOUL version in SOUL on the Help page in the yellow box. The following information does not apply to servers with version stable/xxx.*


**News / Bugfixes**


- netconf, the command line utility to set static network address information has been fixed.
- Issues got fixed regarding the connection which is enabling the availablity of the server via protonet.info address


**Known cosmetical issues**


- Any changes in the system settings lead to a red error message, although the changes have been accepted. You can easily control this by navigating to another section within SOUL and then browse back.
