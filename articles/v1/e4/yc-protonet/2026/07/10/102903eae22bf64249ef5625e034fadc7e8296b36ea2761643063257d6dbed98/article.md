# Soul 2.20.4 – Important security updates and improvements

**Soul 2.20.4 – Important security updates and improvements (stable/102 & soul3/1511) – 13.07.2017**


**You receive an error message to contact Support during this update attempt**


**?**


Since software updates are only available for customers with a valid support contract or as part of SOUL+, please send a short message tosupport@protonet.com in the event of the error message “Please contact Support”. We will then provide access to the update.


**News and improvements**


- The reliability on sending email notifications via the standard service of Protonet was significantly improved.
- Update of the “Samba” service to solve the security gap:[CVE-2017-7494 – ” A remote code execution flaw”](https://www.samba.org/samba/security/CVE-2017-7494.html) or also known as Sambacry (only affects servers running version stable/xxx).
- Actions in the system settings are no longer acknowledged with a red error message even though the changes were actually implemented or actions were executed (only affects servers running version soul3/15xx)


**General information regarding the update process**


Please note that


- downloading updates may take some time depending on the size of the SOUL update you need and your own Internet connection
- servers are automatically being restarted to activate the update, thus all network connections in Finder / Explorer will be disconnected.
- Rebooting of a Protonet server can take up to 15 minutes


We therefore recommend to run the update during a period of time that normally requires minimal server access or to announce the timeout in advance.


If after waiting a reasonable amount of time after the update, the server is not yet available. Please refer to our network connection troubleshooting checklist before consulting the Support team:
[I’M HAVING TROUBLE CONNECTING TO THE PROTONET SOLUTION. WHAT SHOULD I DO?](https://support.protonet.info/en/faq/cat-faq/faq/#cant-reach-a-protonet-solution)
