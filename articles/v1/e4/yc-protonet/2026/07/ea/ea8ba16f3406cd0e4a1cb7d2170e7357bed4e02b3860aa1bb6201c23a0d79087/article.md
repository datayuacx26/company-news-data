# SOUL 2.50 – SYSTEM MESSAGES & MORE

**System wide message (stable/122)**


*Prerequisite for this update is an active SOUL+ contract and a Protonet server with SOUL version stable/xxx. You will see the version after logging into your SOUL on the help page.*


**System messages to all or only active users**


Now it is possible for SOUL Admins to contact all users off all groups at the same time. Go to “Settings a


**Last member in a chat can now leave the “unknown” window**


The last remaining user of a group chat was left “stuck”, with an “unknown” window that could not be closed. This update solves this problem.


Warning, the contained information will be permanently deleted after the last user leaves the conversation.


**Fixed pagination in topics, notes and shared folders. This solves the issues of some folders not being visible on at the bottom of long lists.**


**Added “reply to” into the “@” section of the notification bar**


**SOUL now detects linked objects in streams and allows direct access to them :**


- Increased speed and memory footprint for working with notifications
- Improvements and bugfixes to the todo lists area
- Reworked bi-directional sync, now uses <1% CPU and will be opened up for all users (not just admins)
- Calendar entries can now be made in real time through an external calendar
- Fixed breakout window bugs
- Further bug fixes on the System Trash
