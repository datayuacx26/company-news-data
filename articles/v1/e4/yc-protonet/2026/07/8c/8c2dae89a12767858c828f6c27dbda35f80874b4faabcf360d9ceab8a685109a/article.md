# SOUL 2.25 – GENERAL BUGFIXES AND PERFORMANCE IMPROVEMENTS

**SOUL 2.25 – General bug fixes and performance improvements**


*Prerequisite for this update is an active SOUL+ contract and a Protonet server with SOUL version stable /xxx. You will see the version after logging into your SOUL on the help page.*


###


###


In selecting the corrections for this update, we closely followed our customer feedback, which we received as feature requests, forum posts and support tickets.


**** **Here is a short summary. The full release notes follow.**


- The new divider design (delimiter), is not scrambling in the interface anymore. We designed a clearer structure, press “+” to add a new divider. We also did some preparatory work to enable flexible placement of new tasks (to follow in the next release)
- Subtasks: Rename now possible
- Subtasks: Creating, deleting, and renaming subtasks now generates a notification
- Task notifications are now working properly again
- The “My Tasks” area is now performing properly again and loads only search related results.
- The tasks are sometimes displayed twice Bug is fixed
- The link tab now also shows links that have no preview
- Sorting private task lists is now possible
- LDAP users can now also use their LDAP user data for the mobile apps
- LDAP users can now be converted to other roles like other users


*Also included in this release are preparations for to the Daily Digests, new breakout elements and automated test systems that will allow fewer bugs to creep into the future updates.*


**The next update is planned for mid-April!**
