# SOUL 4.7 – DESKTOP NOTIFICATIONS FIX, MORE CALENDAR EVENT COLORS AND MORE

**SOUL Stable/130 – Desktop Notifications fix, more calendar event colors and more**


***Prerequisite for this update is an active SOUL+ contract and a Protonet server with SOUL version stable /xxx. You will see the version after logging* into your SOUL on the help page.**


**New Feature:**


**More colors in calender**


We added additional colors for calendar events, Protonet SOUL now offers a total of 12 colors to better organize and distinguish your events.
**Bugfixes:**


**Public share links – security improvement**


When a single file was shared via public link, the page displayed a clickable ‘Protonet’ logo linking to the server’s login page. This exposed the domain and login endpoint. The link has been now removed to prevent unnecessary information disclosure.


**Desktop notifications**


Desktop notifications were not working due to recent browser changes affecting WebSocket behavior. This issue has been fixed, and notifications are working again.


**To-Do list order after user assignment**


Assigning a user to a To-Do item could cause the order of the list to change unexpectedly. This issue has been fixed, the ordering now remains consistent after assigning users.
