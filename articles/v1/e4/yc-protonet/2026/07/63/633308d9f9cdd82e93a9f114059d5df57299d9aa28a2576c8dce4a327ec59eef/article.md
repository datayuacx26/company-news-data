# SOUL 2.30 – FILTER PRIVATE MESSAGES

**New search functions in private messages and improved performance (stable/117)**


*Prerequisite for this update is an active SOUL+ contract and a Protonet server with SOUL version **stable** /xxx. You will see the version after logging into your SOUL on the help page.*


**Display all mentions in a message**


Scrolling through a private message in search of a mention has come to an end: At the push of a button you can now see who has addressed you directly with ***@John Doe*** and when. To display all your mentions, press the “@” button in a private message.


**Browse the current message**


We’ve done an own search for private messages. So you can easily find something from the past communication in this chat again. Just click on the magnifying glass and enter your search term.


**Further Improvements**


- Extensive improvements to ensure SOUL runs smoothly under all circumstances
- More preparatory API work for the new SOUL Mobile App
- Some minor bugs fixed


**ATTENTION! These changes require a hard browser refresh to work properly. Please do this after installing the update.**


**You can find instructions[HERE](https://en.scratch-wiki.info/wiki/Help:Hard_Refresh) on how to do that in your favorite Browser.**


We hope you enjoy these changes and, as always, we welcome your feedback and feature requests that you can submit or vote for[here](https://support.protonet.info/de/feature/) !
