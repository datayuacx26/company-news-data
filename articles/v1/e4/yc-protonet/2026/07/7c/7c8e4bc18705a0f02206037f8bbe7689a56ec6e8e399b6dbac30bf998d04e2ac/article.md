# SOUL 4.5 – CONNECT THE SOUL MOBILE APP, WINDOWS & WEBDAV + BUGFIXES

**SOUL Stable/128 – Connect the SOUL Mobile App and bug fixes:**


*Prerequisite for this update is an active SOUL+ contract and a Protonet server with SOUL version stable /xxx. You will see the version after logging* into your SOUL on the help page.


**New Feature:**


- ******You can now connect to SOUL-Mobile using the QR Code generator:******


[Bugfixes:](https://support.protonet.info/wp-content/uploads/2022/10/scanQRcode-3.gif)


- We updated our DAV authentication method, to comply with Microsoft Office´s newest safety standards. It is now again possible to save files directly from office into the Protonet Box.


- We fixed the Letsencrypt auto renew fail. The SSL certification will once again renew automatically after installing this update.


- Completed Task deadlines are now removed from the Calendar .ics sync. We also removed the “Deadline” tag, to make more space for the task´s title and added a link directing to the object in SOUL. Task deadlines from other users are now correctly removed when “My Tasks” is toggled when creating the connection.
