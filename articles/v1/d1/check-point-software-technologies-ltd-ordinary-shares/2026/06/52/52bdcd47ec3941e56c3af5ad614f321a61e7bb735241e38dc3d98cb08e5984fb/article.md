# New SAT Training Module: Shadow IT & Unapproved Tools

Help employees recognize the risks of unapproved workplace tools with a new Security Awareness Training module focused on Shadow IT.


Organizations continue to face growing risks from employees using unapproved applications, AI tools, browser extensions, file-sharing services, and personal accounts to solve everyday work challenges. The new Shadow IT & Unapproved Tools training module helps employees understand how these seemingly harmless shortcuts can expose company data and create security, privacy, and compliance risks.


The module teaches employees what Shadow IT is, how unapproved tools such as file-sharing services, AI applications, browser extensions, cloud services, personal accounts, and connected apps can introduce security, privacy, and compliance risks, and why approved processes matter. Employees learn how to evaluate whether a tool is safe to use for work, what questions to ask before using a new service, when to involve the IT department, and what steps to take if they have already used an unapproved tool.
