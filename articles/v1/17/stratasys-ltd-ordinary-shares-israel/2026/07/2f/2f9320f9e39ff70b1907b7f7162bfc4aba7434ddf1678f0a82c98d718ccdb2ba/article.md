# GrabCAD Print 1.115: TrueVoxel Enhancements for TrueDent Digital Dentures

### One Step Repair & Analysis


Repair and analysis are now combined into one step, reducing preparation to a single click before applying automated dental aesthetic details using TrueVoxel.


Previously, users completed repair and analysis as separate steps. With GrabCAD Print dental software version 1.115, the process is more streamlined, reducing clicks and making the TrueVoxel dental aesthetics preparation experience more intuitive.


What this means for labs:


- A simpler preparation flow


- Fewer manual steps before applying aesthetics


- A more efficient interface for TrueVoxel™ setup


This update is designed to make the experience cleaner and easier without changing the core output labs expect from TrueVoxel™.
