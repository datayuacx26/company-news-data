# Comment Faire un Audit SEO Complet (en 14 Étapes)

## Qu'est-ce qu'un Audit SEO ?


Un audit SEO est le processus consistant à évaluer dans quelle mesure votre site web est optimisé pour les moteurs de recherche. Il permet d'identifier les erreurs qui peuvent empêcher votre site d'être bien classé et les opportunités qui vous aideront à gagner en visibilité.


Un audit SEO couvre généralement des domaines comme :


- Indexation et navigabilité
- Expérience utilisateur
- Architecture du site
- Benchmarking des concurrents
- Recherche de mots clés
- SEO on-page
- Profil de backlinks


Il s'agit essentiellement d'un "bilan de santé" général d'un site web.


## Outils d'Audit SEO


Un audit de site web SEO efficace est basé sur des données concrètes sur la santé technique, le trafic et le profil de backlinks de votre site web (et des sites web de vos concurrents).


Les deux outils les plus importants qui vous aideront dans cette tâche sont :


- **[Google Search Console](https://search.google.com/search-console/welcome) :** un ensemble de tableaux de bord et de rapports de Google qui vous permet de surveiller et de corriger les problèmes liés à la présence de votre site web sur Google

Nous verrons plus en détail comment réaliser un audit SEO à l'aide de ces outils dans les prochaines étapes.

## Comment Faire un Audit SEO


## 1. Vérifiez les Problèmes d'Indexation


Les pages qui ne sont pas indexées ne figurent pas dans la base de données de Google. Google ne peut donc pas les classer.


Pour savoir si vos pages ont été indexées, vérifiez les problèmes directement dans Google Search Console.


Accédez au rapport " **Pages** " dans la section "Indexation" du menu de gauche. Vous y trouverez un graphique de toutes les pages en fonction de leur état d'indexation.


En dessous, vous trouverez une liste des raisons pour lesquelles les pages n'ont pas été indexées.


Passez en revue toutes les raisons énumérées, une par une. Inspectez les pages qui correspondent à ces raisons.


N'oubliez pas que toutes les pages ne doivent pas être indexées, mais uniquement celles que vous souhaitez voir apparaître dans les résultats de recherche. Il est donc[tout à fait normal que certaines URL ne soient pas indexées](https://www.searchenginejournal.com/google-not-indexing-site/416717/) .


Voici quelques exemples d'URL qui ne doivent pas être indexées :


- Pages avec des redirections
- Pages d'administration
- Pages alternatives avec balises canoniques
- Pages de flux


Si vous trouvez une page qui devrait être indexée mais qui ne l'est pas, corrigez le problème en suivant les[Directives de Google](https://support.google.com/webmasters/answer/7440203) . Une fois que c'est fait, cliquez sur le bouton " **Valider la correction** ".


Vous pouvez également saisir une URL spécifique dans la barre de recherche supérieure du tableau de bord de Google Search Console.


Vous verrez alors l'état de l'URL. Vous pouvez également demander à Google d'indexer l'URL en cliquant sur le bouton " **Demander une indexation** ".


Si vous avez considérablement modifié la page, vous pouvez demander une nouvelle indexation. Même si la page est déjà indexée.


Vous pouvez également trouver des problèmes d'indexation (et 140 autres problèmes de SEO technique) avec[Audit de site](https://fr.semrush.com/siteaudit/) .


Effectuez un crawl de votre site et dirigez-vous vers l'onglet " **Problèmes** ".


Il s'agit de toutes les erreurs, de tous les avertissements et de tous les avis qui entravent les performances SEO de votre site.


Sélectionnez maintenant " **Indexabilité** " dans le menu déroulant " **Catégorie** " pour ne voir que les problèmes d'indexation.

## 2. Vérifiez les Versions Dupliquées de votre Site


Il est essentiel de s'assurer que Google n'indexe qu'une seule version de votre site.


Votre site peut se trouver sur plusieurs versions d'une URL (en fonction de la présence ou non de WWW dans le domaine et de l'utilisation ou non de HTTPS).


Pour un moteur de recherche, ces versions sont toutes différentes :


- http://www.votresite.com
- http://votresite.com
- https://www.votresite.com
- https://votresite.com


Si votre site web fonctionne avec plusieurs de ces versions d'URL, cela peut poser de nombreux problèmes d'exploration, d'indexation et de classement. D'autant plus que Google les considérera comme des doublons.


De plus, le fait d'avoir plusieurs versions de votre site peut diluer le[PageRank](https://fr.semrush.com/blog/pagerank-google/) , ce qui risque d'avoir un impact négatif sur vos[classements SEO](https://fr.semrush.com/blog/ameliorer-seo/) .


Vous pouvez contrôler cela très facilement :


Il suffit de saisir toutes les versions de votre site dans un navigateur web.


Vous devriez être automatiquement redirigé vers la version préférée.


Par exemple, si votre version préférée de l'URL est https://votresite.com, vous devriez être redirigé vers elle si vous entrez une autre version dans votre navigateur.


Si vous pouvez accéder à votre site via plusieurs versions, utilisez une[redirection 301](https://fr.semrush.com/blog/redirections-301-htaccess/) pour les autres versions.

## 4. Vérifiez les Actions Manuelles


Si votre site enfreint les[règles de Google sur le spam](https://developers.google.com/search/docs/essentials/spam-policies?hl=fr) , il peut faire l'objet d'une action manuelle de la part de Google.


Une action manuelle signifie que les classements de votre site chuteront jusqu'à ce que Google révoque l'action. Il peut s'agir d'une action au niveau de la page ou de l'ensemble du site.


Voici quelques raisons pour lesquelles vous pouvez avoir reçu une action manuelle :


- Bourrage de mots clés
- Liens non naturels (à la fois vers et depuis votre site)
- Différents types de spam
- Contenu pauvre avec peu ou pas de valeur ajoutée


Vous pouvez vérifier si vous avez fait l'objet d'une action manuelle dans Google Search Console.


Dans le menu latéral de gauche, vous trouverez une section "Sécurité et actions manuelles" et, à l'intérieur de celle-ci, le lien "Actions manuelles".


Cliquez dessus et vous arriverez sur une page où vous trouverez l'état d'avancement de l'action.


Si tout va bien, vous verrez une coche verte indiquant qu'aucun problème n'a été détecté.


Si votre site fait l'objet d'une action manuelle, vous devez résoudre les problèmes et introduire une demande de réexamen. Pour plus d'informations, consultez le[guide Rapport sur les actions manuelles de Google](https://support.google.com/webmasters/answer/9044175?hl=fr) .


Par exemple, si vous avez fait l'objet d'une action manuelle à la suite de l'achat de backlinks ("Liens non naturels vers votre site"), vous devez vous débarrasser de ces backlinks, soit en contactant les webmasters, soit en les[désavouant](https://fr.semrush.com/blog/desavouer-des-liens/) .

## 6. Analysez la Vitesse de votre Site


Il est plus important que jamais que votre site se charge rapidement. La vitesse des pages est un[facteur de classement](https://www.searchenginejournal.com/ranking-factors/page-speed/) depuis longtemps. Elle peut donc vous aider à mieux vous classer dans Google.


De plus, il s'agit d'un facteur important pour l'expérience des utilisateurs. Si l'on considère le comportement des utilisateurs,[les données montrent](https://www.thinkwithgoogle.com/marketing-strategies/app-and-mobile/mobile-page-speed-new-industry-benchmarks/) que plus une page se charge lentement, plus l'utilisateur risque de quitter le site web.


Selon Think With Google, si le temps de chargement passe de :


- 1 à **3 secondes** , la probabilité d'un rebond **augmente de 32%**
- 1 à **5 secondes** , la probabilité d'un rebond **augmente de 90%**
- 1 à **6 secondes** , la probabilité d'un rebond **augmente de 106%**
- 1 à **10 secondes** , la probabilité d'un rebond **augmente de 123%**


Pour vérifier la vitesse de votre site, consultez le rapport **Performances** dans le tableau de bord d'[Audit de site](https://fr.semrush.com/siteaudit/) .


Vous y trouverez une liste de tous les problèmes affectant le temps de chargement de votre site.


Pour en savoir plus sur un problème et sur la manière de le résoudre, cliquez sur " **Explication et correction du problème** ".


Réglez autant de problèmes que possible. Vous devriez voir la vitesse de votre site (et ses classements) s'améliorer.

## 7. Analysez vos Core Web Vitals


En 2020, Google a[introduit](https://blog.chromium.org/2020/05/introducing-web-vitals-essential-metrics.html) trois nouvelles métriques liées à la vitesse des pages et à l'expérience utilisateur :


- **Largest Contentful Paint ([LCP](https://fr.semrush.com/blog/core-web-vitals-lcp/) ) :** mesure le temps nécessaire au chargement de la partie la plus volumineuse de la page
- **First Input Delay (FID) :** mesure le délai entre la première interaction de l'utilisateur avec une page et la réponse du navigateur à cette interaction
- **Cumulative Layout Shift (CLS) :** mesure l'importance de la modification de la présentation de la page pour l'utilisateur, ainsi que la stabilité visuelle


On les appelle les[Core Web Vitals](https://fr.semrush.com/blog/core-web-vitals/) ou Signaux Web essentiels.


Étant donné que les Core Web Vitals sont un facteur de classement, la vérification de ces métriques pour vos pages clés devrait certainement faire partie de votre audit de site web SEO.


Google Search Console vient encore une fois à la rescousse.


Accédez au rapport " **Signaux Web essentiels** " dans la section "Expérience" du menu de gauche.


Vous obtiendrez des rapports "Ordinateur" et "Mobile" répertoriant tous les problèmes et les pages affectées.


Ces rapports vous donneront un aperçu détaillé des problèmes que votre site peut rencontrer en lien avec les Core Web Vitals.


L'outil fait la distinction entre les pages qui présentent des problèmes graves ("mauvaises URL") et celles qui ont simplement besoin d'être améliorées.


Examinez les problèmes et suivez les instructions pour les résoudre.


Il existe également un rapport dédié à l'évaluation des Core Web Vitals dans[Audit de site](https://fr.semrush.com/siteaudit/) .


Il suffit de cliquer sur le widget " **Core Web Vitals** " dans le tableau de bord.


Vous obtiendrez une analyse de chaque métrique.


Comme ici :

Vous y trouverez toutes les métriques au niveau des pages et pourrez suivre vos progrès au fil du temps.


Vous pouvez également sélectionner manuellement 10 URL pour vérifier les problèmes liés aux Core Web Vitals. Il vous suffit de cliquer sur le bouton " **Modifier la liste** ".


Modifiez ensuite la liste comme vous le souhaitez. Et cliquez sur " **Enregistrer** ".


## 8. Analysez vos Liens Internes


Les liens internes sont un aspect essentiel du SEO, et ce pour trois raisons :


1. Ils aident les moteurs de recherche à explorer votre site web
2. Ils aident les utilisateurs à naviguer sur votre site web
3. Ils vous aident à diriger l'équité des liens (également appelée "autorité" ou "jus de lien") vers les pages les plus importantes.


[Audit de site](https://fr.semrush.com/siteaudit/) propose un rapport consacré aux problèmes de liens internes. Cliquez sur " **Liens internes** " dans la liste des "Rapports thématiques" :


Vous obtiendrez une liste de problèmes liés aux liens internes et des conseils sur la manière de les résoudre.


Le rapport vous donnera également une vue d'ensemble utile de vos pages sur la base de l' **Internal LinkRank** (ILR), une métrique qui mesure le degré d'interconnexion d'une page.


L'examen de chaque catégorie vous permettra d'identifier deux types de pages :


1. Les pages importantes qui n'ont pas assez de liens internes (afin que vous puissiez diriger plus de liens internes vers elles)
2. Les pages avec un bon ILR (afin que vous puissiez les utiliser pour distribuer du jus de lien à d'autres pages)

## 9. Vérifiez votre Trafic Organique


Le trafic organique correspond aux visiteurs qui arrivent sur votre site web après avoir cliqué sur des résultats de recherche non payants ("organiques").

Le rapport comporte quatre métriques principales.


La métrique la plus intéressante dans ce contexte est le "nombre total de clics", c'est-à-dire le nombre de fois où un utilisateur a cliqué sur votre site au cours de la période spécifiée.

## 10. Comparez-vous à vos Concurrents


Un bon audit SEO devrait vous aider à vous situer par rapport à vos concurrents.


Une bonne façon de commencer est d'utiliser Vue d'ensemble du domaine.


Tout d'abord, entrez votre domaine, votre pays et cliquez sur " **Recherche** ".


Rendez-vous ensuite sur l'onglet " **Comparaison des domaines** ".


Vous pouvez y sélectionner jusqu'à quatre domaines concurrents. Si vous n'êtes pas sûr de l'identité de vos principaux concurrents, choisissez les domaines suggérés par l'outil.


Cliquez ensuite sur " **Comparer** ".


L'outil vous fournira une comparaison solide des métriques clés des domaines sélectionnés. Vous aurez ainsi une bonne vue d'ensemble des lacunes et des points forts de votre activité.


Pour obtenir la meilleure vue d'ensemble, concentrez-vous sur les métriques suivantes :


- **Authority Score :** la qualité globale du domaine sur une échelle de 1 à 100 (basée sur les backlinks, le trafic de recherche et d'autres facteurs)
- **Trafic organique :** la quantité de trafic organique reçu par votre domaine
- **Mots clés organiques :** indique le nombre de mots clés pour lesquels le domaine est classé
- **Domaines référents :** le nombre de domaines différents qui pointent vers le domaine analysé (cela donne une meilleure image pour la comparaison que le nombre total de backlinks).


Dans les deux prochaines étapes, nous allons voir comment faire passer la recherche concurrentielle au niveau supérieur. Et tirer le meilleur parti des mots clés et des données sur les backlinks de vos concurrents.

- **Faibles :** mots clés pour lesquels vos concurrents sont mieux classés que vous


La liste révèlera probablement des opportunités cachées de mots clés que vous n'avez peut-être pas envisagées.

## 13. Auditez et Améliorez vos Pages Principales


Une exploration générale du site vous aidera à trouver des problèmes techniques **sur l'ensemble de votre site web** .


Toutefois, il est également utile d' **examiner de plus près certaines pages** (en particulier celles qui sont les plus importantes pour vous), d'analyser leurs performances et de trouver des moyens de les améliorer.


Il s'agit en fait d'un audit SEO on-page.
