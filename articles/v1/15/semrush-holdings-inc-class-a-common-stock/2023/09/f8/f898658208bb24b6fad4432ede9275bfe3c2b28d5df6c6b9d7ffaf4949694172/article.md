# Renove suas Listas de Produtos para SERPs com Estes Insights de E-Commerce

Para compreender melhor como os produtos aparecem nas Páginas de Resultados dos Mecanismos de Busca (SERP), a Semrush coletou sete mil consultas voltadas para produtos a fim de descobrir quais recursos são mais importantes para esse tipo de pesquisa.


## Recursos de SERP no Mobile e Desktop


A Semrush analisou cinco recursos relacionados a produtos e como eles aparecem no desktop e no mobile. São eles: Produtos Populares, Filtro de Produto, Refinar, Guia de Compra e Produtos Relacionados.


Entre as SERPs destacadas:


- A maioria dos recursos aparece tanto no mobile quanto no desktop em frequências similares
- Os Produtos Populares aparecem com mais frequência no mobile, em 79% das buscas por produtos
- O Filtro de Produto tem a maior diferença percentual entre mobile (36%) e desktop (61%)


O gráfico acima pode ajudar você a tomar decisões mais embasadas para focar nos recursos mais relevantes para seus clientes.


## Detalhamento dos Recursos de SERP para E-Commerce


### Produtos Populares


O recurso Produtos Populares mostra itens relevantes de várias lojas de e-commerce.


No desktop, o número máximo de itens na lista de produtos foi de 32, enquanto o mobile listou um máximo de dez. Isso significa que mais produtos podem aparecer no desktop em comparação com a busca mobile.


Realizar uma auditoria com o[Ecommerce Booster](https://pt.semrush.com/apps/ecommerce-booster/) pode ajudar você a criar um markup de dados estruturados para que seus produtos apareçam na seção Produtos Populares com mais frequência.


Em média, o mobile mostrou um número mais baixo de lojas únicas (três) em comparação com a pesquisa desktop, que mostrou cinco.


### Filtro de Produto


O recurso Filtro de Produto aparece no topo da SERP, mas apenas no desktop. Ele sugere palavras-chave que trazem mais clareza para a consulta.


### Refinar


O recurso Refinar contém uma lista de consultas relacionadas para restringir a busca de produtos por categorias.


O mobile mostra até 36 categorias, enquanto o desktop mostra até cinco.


No mobile, o recurso Refinar é menos voltado a produtos do que no desktop, e é similar ao recurso de palavras-chave relacionadas para pesquisas que não são voltadas a compras.


### Guia de Compra


O Guia de Compra é uma lista de perguntas sobre um produto relacionado à consulta. Assim como acontece com o recurso *As pessoas também perguntam* , você pode expandir cada bloco para aprender mais sobre um aspecto específico do produto.


Por padrão, apenas quatro itens são mostrados; clique em "Mais considerações" para ver outras perguntas. Em média, sete blocos aparecem tanto nos dispositivos mobile quando nos desktop.


O número médio de perguntas e a mediana de perguntas são iguais em todos os casos (7), tanto para desktop quanto para mobile *.*


### Produtos Relacionados


Similar aos Produtos Populares, o recurso Produtos Relacionados mostra uma variedade de itens relevantes em muitas lojas diferentes. Ao contrário da seção Produtos Populares, fornece mais informações sobre cada item e está formatada para estimular a comparação.

Quanto ao número médio de produtos, o desktop lista cinco itens, enquanto o mobile mostra quatro.


A maioria desses blocos contêm produtos com avaliações, enfatizando a importância de obter avaliações dos clientes para cada produto.
