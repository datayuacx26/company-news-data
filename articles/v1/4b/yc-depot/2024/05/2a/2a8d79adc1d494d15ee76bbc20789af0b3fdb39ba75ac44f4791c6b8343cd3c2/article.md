# Real time visualization and monitoring of GitHub Actions Runners & Jobs

Today, we're excited to announce our latest feature for our[Depot GitHub Actions Runners](https://depot.dev/products/github-actions) : real-time visualization and monitoring of your GitHub Actions Runners and Jobs.


This visualization is the first of many features we plan to build around GitHub Actions. We're excited to provide more insights and monitoring capabilities around your GitHub Actions workflows and runners. This initial step gives you a live view of your GitHub Actions jobs and runners across your organization using our runners.


With this new view inside your Depot GitHub Actions tab, you can see all the jobs and runners running in your GitHub organization that are powered by Depot. This view is updated in real time and provides a live view of the status of all your jobs and runners.


- See all of your Active Jobs that are currently queued or running with the associated label they've requested
- View all of your Active Runners that are currently online and either running jobs or waiting for work from GitHub
- You can also view all of your Completed Jobs further down, which gives you an idea of the jobs that have recently been completed


## What's next


Getting visibility into your jobs and runners across your entire GitHub organization is just the beginning. We're planning to add more features and insights about your GitHub Actions workflows when you are using Depot runners.
