# Faster image builds from Buildkite pipelines with Depot

We are excited to announce that we have launched a new[Buildkite integration guide](https://depot.dev/docs/container-builds/integrations/buildkite) that walks through how you can use Depot to get faster image builds from your existing Buildkite pipelines.


In addition, we have also added support for Buildkite and GitHub Actions OIDC authentication to` depot build` and` depot bake` . As a result, you can now use Depot to build images from your Buildkite pipelines without passing any Depot token if you have configured a trust relationship for your project. Check out ourOIDC authentication documentation for details on configuring a trust relationship for your project.


If you're interested in self-hosted Depot builders that can be used to run Docker image builds next your Buildkite agents, check out our[self-hosted builder documentation](https://depot.dev/docs/managed/overview) .
