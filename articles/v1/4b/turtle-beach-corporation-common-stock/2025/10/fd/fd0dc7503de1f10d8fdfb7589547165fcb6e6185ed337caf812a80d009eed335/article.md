## **How to Use Easy-Shift \[+\]™ on Compatible Keyboards**


### **Step-by-Step User Guide**


Setting up


Easy-Shift \[+\]™ technology


requires ROCCAT SWARM software and a compatible keyboard from Turtle Beach's ROCCAT collection.


Initial Setup Process


:


### **Step 1: Download and Install SWARM**


- Install the latest version of ROCCAT SWARM software from the official support portal


- Ensure full compatibility with current Easy Shift features


### **Step 2: Connect Your Hardware**


- Connect your compatible keyboard (such as Vulcan series) via USB


- Ensure proper recognition by SWARM software


### **Step 3: Assign Easy Shift to a Button**


1. Open SWARM software


2. Navigate to the Key Assignment tab


3. Select the button you want Easy Shift assigned to


4. For keyboards, this is typically the Caps Lock key by default


5. Note: Not every button or key is available for Easy Shift functionality


### **Step 4: Configure Secondary Functions**


After assigning Easy Shift to a button, you need to assign secondary functions to the keys you want to use in combination with Easy Shift.


For Keyboards:


1. Select the key you want to assign an Easy Shift function to


2. Find the desired function in the panel on the left


3. Drag and drop it onto the Easy Shift slot of the selected key


4. Available functions include hotkeys, macros, media control, and more
