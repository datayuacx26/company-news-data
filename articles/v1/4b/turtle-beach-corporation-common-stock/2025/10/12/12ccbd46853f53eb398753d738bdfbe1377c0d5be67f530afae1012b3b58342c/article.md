## **Setting Up Profile Storage: Platforms and Requirements**


### **PlayStation Profile Storage**


PlayStation's cloud storage system requires a PlayStation Plus subscription and provides 100GB of storage for PS5 game saves and an additional 100GB for PS4 saves. The system supports up to 1,000 PS4 save files and automatically syncs when games close or the console enters rest mode.


To enable


cloud game save synchronization


on PlayStation:


- Navigate to Settings > Saved Data and Game/App Settings


- Select either Saved Data (PS5) or Saved Data (PS4)


- Enable "Auto-Sync Saved Data" for PS5 games or "Auto-Upload" for PS4 games


- Configure rest mode settings to maintain internet connectivity


### **Xbox Cloud Storage**


Xbox provides automatic cloud save functionality for all Xbox Live accounts with a default per-user storage limit of 256MB and individual file limits of 64MB. Saves automatically sync when exiting games, with no additional local storage requirements for modern Xbox consoles.


Xbox Smart Delivery enhances this system by automatically detecting the optimal save version when transitioning between console generations, ensuring seamless compatibility between Xbox One and Series X|S devices.


### **Steam Cloud Configuration**


Steam Cloud offers cross-platform save synchronization for supported games, with developers configuring file quotas and supported platforms. The system automatically synchronizes files before and after gaming sessions, though not all Steam games support this feature.


To verify Steam Cloud support:


- Right-click the game in your Steam library


- Select "Properties" > "General" tab


- Ensure "Keep game saves in the Steam Cloud" is checked


### **Third-Party Publisher Solutions**


Many modern games implement their own


cross-device gaming profiles


independent of platform holders. Publishers like Ubisoft provide platform-agnostic cloud saves that work across PC, Xbox, PlayStation, and other platforms through their proprietary account systems, though implementation varies by title.
