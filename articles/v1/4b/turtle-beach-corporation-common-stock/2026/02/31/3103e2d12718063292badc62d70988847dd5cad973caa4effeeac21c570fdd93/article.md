# Hytale System Requirements: Minimum, Recommended and More

Hytale has now been fully released to players, and for many, this has been a long time coming, as the game has been in development for quite some time now.


With many eyeing the game, it'll be good to know what kind of hardware you'll need to run Hytale.


Here's all we know about the system requirements.


## Hytale System Requirements: Minimum, Recommended and More


Hytale was originally set to be released in 2021, just a year before Riot purchased the company, whose game at the time had over 2.5 million registrants.


Checking the system requirements for any game is a must these days, but thankfully, Hytale doesn't appear to be too demanding.


### Mininum


- OS


- Windows 11


- Windows 10 x64-architecture (version 1809)


- Linux x64-architecture (Kernel 6.15)


- Apple Silicon with macOS Tahoe (26.0)


- CPU


- Intel Core i5-7500 (or equivalent)


- AMD Ryzen 3 1200 (or equivalent)


- Apple M1 (any variant)


- RAM


- 8 GB


- GPU


- Integrated:


- Intel UHD Graphics 620


- AMD Radeon Vega 6


- Apple M1 (any variant)


- Dedicated:


- NVIDIA GTX 900 Series


- AMD Radeon 400 Series


- Intel Arc A-Series


### Recommended


- OS


- Windows 11


- Windows 10 x64-architecture (version 1809)


- Linux x64-architecture (Kernel 6.15)


- Apple Silicon with macOS Tahoe (26.0)


- CPU


- Intel Core i5-10400 (or equivalent)


- AMD Ryzen 5 3600 (or equivalent)


- Apple M2 (any variant)


- RAM


- 16 GB


- GPU


- Integrated:


- Intel Iris Xe Graphics


- AMD Radeon 660M


- Apple M2 (any variant)


- Dedicated:


- NVIDIA GTX 900 Series


- AMD Radeon 400 Series


- Intel Arc A-Series
