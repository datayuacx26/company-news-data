# Code Vein 2: All Companions

Bandai Namco is aiming to make a splash once again in 2026, as Code Vein 2 will be its first major release for the year.


Companions are similar to other party members we see in JRPGs, and in Code Vein 2, there are some brand new faces.


Here's all we know.


## Code Vein 2: All Companions


The souls-like genre has evolved over the years, and we've seen some standout titles emerge that aren't directly from FromSoftware.


Code Vein 2 strikes similar notes to these titles, along with traditional JRPG mechanics using a party-based system via companions.
