# Is Hytale Releasing On Console? Answered

Hytale was once a highly anticipated title that many gamers were looking forward to, and even more so when Riot Games acquired the studio back in 2020.


Now, the game has been released and before diving into the action we're going to run over all we know about the game being released on consoles.


Here's what we know.


## Is Hytale Releasing On Console? Answered


Hytale was originally set to be released back in 2021, just a year shy of when Riot purchased the company, whose game at the time had over 2.5 million registrants.


The game is now playable to everyone, well not echnically everyone, as indeed the game is NOT playable on PlayStation 5, Xbox or Nintendo Switch consoles at the current time.


The developers behind[Hytale](https://hytale.com/news/2025/12/hytale-s-1st-faq) noted in their FAQ that they do intend on releasing the game on consoles later down the line:


*"No, the early access of Hytale will only be on PC (MAC and Linux still TBD). We are planning for a console release at a later stage, but this requires a lot of work on backend systems to make this a reality, so its not something we want to invest resources into right now. For now, we would like to focus on making a good game first."*
