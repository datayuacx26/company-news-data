# Arc Raiders Expedition 2: All Resource Requirements and More

[Arc Raiders](https://www.turtlebeach.com/blog/category/guides?tag=Arc%20Raiders) is the newest title from Embark Studios, and it's one that has attracted players who never thought they'd try an extraction shooter.


Players looking to refresh their progress and start from zero, will want to know when the next Departure Window or Wipe is.


But, you're going to want to ensure you have all of the necessary resources needed in order to complete the project.


## Arc Raiders Expedition 2: All Resource Requirements and More


While many extraction shooters share the same common elements with one another, there are some aspects that Arc Raiders does differently.


Wipes are one of these aspects, as opposed to games such as Tarkov, players will have the option to completely reset their progress if they manage to complete the Expedition Project in time.


This time around, players will need the following materials in order to complete their project.
