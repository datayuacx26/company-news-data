# Is There A PvE Only Game Mode In Arc Raiders? Answered

[Arc Raiders](https://www.turtlebeach.com/blog/category/guides?tag=Arc%20Raiders) is the newest title from Embark Studios, and it's one that has attracted players who never thought they'd try an extraction shooter.


PvE has been a major focus of the community thus far, and with there being some imminent Arcs, we're going to run over what we know about a PvE mode in Arc Raiders.


## Is There A PvE Only Game Mode In Arc Raiders? Answered


While many extraction shooters share the same common elements with one another, there are some aspects that Arc Raiders does differently.


PvE is one of these aspects, as while it is technically PvPvE, you'll find yourself in a lot more Arc encounters than actual players.


However, while it would certainly be easier and more convenient if you never had to worry about other players when completing quests, it is a part of the game.


So, no, there is not any PvE only mode in Arc Raiders at the moment, and we don't know as of now what Embark has planned for the future. But,they may add some PvE elements in the form of limited time modes and so on.
