## [August 3, 2026](https://deepnote.com/changelog/2026-08-03)


##


[Introducing Deepnote Agent Workspace](https://deepnote.com/changelog/2026-08-03#introducing-deepnote-agent-workspace)


Deepnote Agent Workspace is a shared place where people and agents work on the same data.


##


[Skills, agents, and apps in one workspace](https://deepnote.com/changelog/2026-08-03#skills-agents-and-apps-in-one-workspace)


Agent Workspace has three building blocks, connected through Deepnote’s integrations and workspace permissions.


- **Skills** capture knowledge and procedures, including the sources and permissions an agent can use.
- **Agents** are notebooks with a runtime and instructions. Build them interactively, run them on a schedule, or trigger them through the API.
- **Apps** deliver the result to people who do not need to open a notebook, using the workspace’s integrations and permissions.


##


[Work with agents wherever the request starts](https://deepnote.com/changelog/2026-08-03#work-with-agents-wherever-the-request-starts)


Agent Workspace is available from Deepnote and through the tools teams already use.


- In Deepnote
- From Codex, Claude Code, or any IDE via[MCP](https://deepnote.com/docs/deepnote-mcp)
- In[Slack](https://deepnote.com/docs/slack)
- From the terminal
- Headlessly through the[API](https://deepnote.com/docs/deepnote-api)


Each surface connects to the same workspace context. Agents can use the notebooks, integrations, and permissions the data team already maintains rather than starting from an empty conversation.
