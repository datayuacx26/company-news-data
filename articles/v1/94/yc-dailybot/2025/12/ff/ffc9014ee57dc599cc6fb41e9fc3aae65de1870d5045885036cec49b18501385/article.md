# Dailybot | December Updates - New extensions, smarter summaries, and more automation power · Changelog

This month we’ve shipped a major update that brings Dailybot closer to where you work. We’ve added browser and VS Code check-ins, AI summary reports, and new automations to help remote teams run async standups directly in chat.


Key highlights include our new Browser Extension for one-click check-ins from any web page, VS Code and Cursor extensions for developers, AI-powered Smart Summaries for instant team overviews, and new triggers and actions to automate team rituals end-to-end.
