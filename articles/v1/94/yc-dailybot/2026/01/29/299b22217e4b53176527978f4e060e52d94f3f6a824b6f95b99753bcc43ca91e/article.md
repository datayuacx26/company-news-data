# Dailybot | Check in directly from your IDE with VS Code and Cursor · Changelog

We know developers live in their code editors. That’s why we built native extensions for **VS Code** and **Cursor** that bring Dailybot check-ins directly into your IDE. No more switching to Slack or Teams just to submit your standup — do it right where you’re already working.


The extensions integrate seamlessly into your editor sidebar, showing pending check-ins, recent team updates, and quick-response forms. Developers can submit their daily updates, view team summaries, and even interact with Dailybot AI — all without leaving their editor.


## How to get started


Getting set up takes less than a minute. Install the extension from the VS Code Marketplace or Cursor’s extension panel, sign in with your Dailybot account, and you’re ready to go. The extension will automatically show your pending check-ins and notifications.


- **Sidebar panel** — view pending check-ins, recent team updates, and notifications in a dedicated sidebar
- **Quick response forms** — submit check-in answers with inline forms, auto-populated with context from your recent commits
- **Status bar indicator** — a subtle status bar item shows when you have pending check-ins
- **Command palette** — access Dailybot commands through Ctrl+Shift+P (or Cmd+Shift+P on Mac)
- **Git-aware context** — the extension can auto-suggest updates based on your recent commits and branch activity


## Built for developer workflows


We designed the IDE extensions to fit naturally into developer workflows. Check-ins can be pre-filled with context from your recent Git activity, making it faster than ever to share what you’ve been working on. The extension supports both VS Code and Cursor, with identical functionality and a clean, minimal UI that doesn’t get in the way.


The VS Code and Cursor extensions are available now on all Dailybot plans. Install them from the marketplace and start checking in from your editor today.
