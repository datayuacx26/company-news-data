# Quantum and Veeam: Elevating Backup Resilience with ActiveScale

Quantum’s ActiveScale Cold Storage platform is featured in the latest Veeam Object Storage Partner[Showcase](https://community.veeam.com/blogs-and-podcasts-57/veeam-object-storage-partner-showcase-part-4-11918) , demonstrating how the partnership delivers advanced backup and affordable long-term data retention.


## Seamless Integration for Modern Data Protection


ActiveScale is Veeam Ready certified for object storage, supporting Veeam’s Archive Tier for secure, cost-effective air-gapped retention of backup data. The solution provides multi-layered protection, high performance, and operational simplicity, enabling organizations to prepare, protect, and recover business-critical applications with confidence.


## Key Benefits of Quantum ActiveScale Cold Storage with Veeam


- **Cyber Resilience**
ActiveScale delivers robust protection against threats, supporting rapid recovery and air-gapped cold storage for backup data.


- **Fast Recovery Across Storage Classes**
The platform supports rapid restores from flash, disk, and tape, meeting demanding recovery SLAs and enabling direct-to-archive workflows for Veeam backups.


- **Cost-Effective Long-Term Retention**
ActiveScale Cold Storage offers cold storage at a fraction of the cost of the public cloud, with no egress fees or slow retrievals.


- **On-Premises Control**
Customers retain full control over their data, leveraging Quantum’s expertise in object storage and tape, and avoiding unpredictable public cloud costs.


## Technology Highlights


- **2-Dimensional Erasure Coding**
Quantum’s patented 2-dimensional erasure coding ensures high durability and storage efficiency for tape-based cold storage.


- **Veeam Smart Object Storage API (SOSAPI)**
The SOSAPI enables integration between Veeam and object storage platforms like ActiveScale, allowing Veeam to efficiently manage object storage repositories.


- **Proven Industry Adoption**
Widely deployed by enterprise backup teams for scalable, resilient long-term data protection.


## Conclusion


The Quantum-Veeam partnership empowers organizations to achieve cyber resilience, simplify backup operations, and unlock new efficiencies for long-term data protection. The joint solution delivers advanced integration, cost savings, and robust security for modern backup environments.
