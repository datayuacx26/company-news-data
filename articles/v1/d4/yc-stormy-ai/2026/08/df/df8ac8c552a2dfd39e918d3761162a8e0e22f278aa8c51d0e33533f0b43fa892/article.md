# Crown SC 5700 Event Light vs Service Light: The Manual’s Escalation Boundary

## The icon alone is not the whole instruction


The event-light block tells the operator to look at the message display for instructions. The service-light block tells the operator that service is required. In both cases, a cropped warning icon throws away decisive context. A useful record keeps the indicator and the display message together.


The annotated page makes the boundary visible without inventing a code table. Blue marks the operator-correctable branch. Red marks the service-required branch. The underlying words, diagram, and display remain the primary evidence.
