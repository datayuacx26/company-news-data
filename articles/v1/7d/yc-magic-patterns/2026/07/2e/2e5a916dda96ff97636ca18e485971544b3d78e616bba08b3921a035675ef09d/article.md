# GPT-5.6 is now available in Magic Patterns

GPT-5.6 is now available in Magic Patterns. It produces stronger first drafts, works through errors more reliably, and follows detailed visual direction with fewer revisions.


It is also considerably more cost-efficient than Anthropic's Fable 5. In our testing, comparable tasks used **2.5x fewer credits** while still producing polished, interactive designs.


# From a prompt to a complete design


We asked GPT-5.6 to design a command center for a global shipping company. It organized vessel locations, customs holds, port congestion, and urgent shipments into a usable operations view. The cyberpunk direction carried through the maps, tables, and status indicators without getting in the way of the information.


PROMPT


Create a logistics command center for a global shipping company. Track vessels, delayed containers, customs holds, port congestion, and priority shipments. Use a cyberpunk operations-room aesthetic with dark maps, neon route lines, dense tables, alert panels, and live status indicators.


The same improvement showed up in a Fashion Week production workspace. GPT-5.6 brought runway order, look approvals, fittings, garment samples, and venue tasks into one coherent design. It handled the editorial direction with confidence, using contact sheets and handwritten details without making the workspace harder to use.


PROMPT


Create a production workspace for a fashion house preparing for Fashion Week. Include a visual runway order, look approvals, model fittings, garment sample tracking, venue tasks, and VIP seating. Use an editorial luxury aesthetic inspired by fashion magazines, with oversized typography, contact sheets, handwritten annotations, and restrained black, cream, and red colors. Make every section interactive.


For the last test, we gave it a quieter visual direction. The hotel revenue cockpit balanced occupancy forecasts and competitor pricing with the restrained look of a luxury hospitality brand. It produced a polished, responsive design while keeping sudden demand changes and VIP booking alerts easy to spot.


PROMPT


Create a revenue management dashboard for a luxury hotel group. Include occupancy forecasts, room pricing, local event demand, competitor rates, and VIP booking alerts. Use deep navy and champagne gold, with restrained charts and details inspired by a hotel concierge desk.
