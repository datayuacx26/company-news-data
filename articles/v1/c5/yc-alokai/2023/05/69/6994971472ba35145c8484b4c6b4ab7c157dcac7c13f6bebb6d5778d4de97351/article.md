# Sanity and Stripe now enabled on Alokai with React

Alokai, a[Frontend as a Service](https://alokai.com/blog/frontend-as-a-service) (FEaaS) that delivers custom eCommerce storefronts at a fraction of the cost and time, today released new JavaScript framework integrations that enable Sanity and Stripe to work with React storefront architectures.


##### Reduce time-to-market with Alokai


[GET A DEMO](https://alokai.com/request-demo)


The new integrations will help retailers using Alokai’s FEaaS for their online stores to accelerate time to market and, since they require no maintenance, save frontend developers’ time.


Both now join Alokai’s family of fully[agnostic JavaScript framework](https://alokai.com/javascript-framework-agnostic-guide) integrations, which include commercetools, SAP Commerce Cloud, Contentful and Contentstack.


The Sanity integration allows developers to build content management interfaces that maximize experience, and impact, and optimize efficiency across marketing, support, eCommerce, and more.


The Stripe integration works with commercetools, and provides a simple and secure way for businesses to process transactions, manage billing, and handle subscriptions.


Alokai currently provides[over 30 integrations](https://docs.vuestorefront.io/v2/integrations/) with state-of-the-art headless CMSes, payment systems, and search and analytics tools.


For more information, see our[Sanity documentation](https://docs.vuestorefront.io/sdk-sanity/) and[Stripe documentation](https://docs.vuestorefront.io/stripe-commercetools-sdk/) .
