# Claude subscription update for Conductor


**TL;DR:** Anthropic has delayed the subscription updates to Claude plans. You can keep using your Claude plan in Conductor with no additional limitations.


## What happened


On May 13, Anthropic[announced subscription updates for Claude Agent SDK usage](https://support.claude.com/en/articles/15036540-use-the-claude-agent-sdk-with-your-claude-plan) in third-party tools like Conductor.


Conductor uses native Claude Code, but we do so through the Claude Agent SDK, so that policy applied to us.


On June 15, Anthropic announced that those changes are delayed indefinitely. You can continue to use your Claude plan with Conductor as normal.


## What this means for you


No action is required.


- You can keep using your Claude subscription in Conductor the same way you do today.
- We will continue working with the Anthropic team.
- We will notify you if anything changes.


Thank you for your support. We're excited to keep shipping improvements to Conductor.
