# Service Management: Stay on top of every request and download certificates in bulk

As request volumes grow, finding the right information and keeping track of every case becomes more challenging. The **Service Management** module introduces new features that help agents, approvers, and administrators find information faster, monitor requests, and manage large workloads more efficiently.


## Download multiple certificates in just a few steps


You can now generate bulk PDF downloads of certificates directly from the admin panel by filtering requests by status and date.


With this enhancement, administrators can:


- **Select the date range and request status** to include in the download.
- **Generate all certificates in a single process** , without downloading them one by one.
- **Receive all files in a single compressed folder via email** for easier management.


This makes it much faster and more organized to retrieve large volumes of documentation.


## See what needs your attention


To make it easier to stay on top of daily activity, **Service Management** now includes **notification badges in the module menu** that highlight pending work based on each user’s role.


With this update:


- **Approvers** can see how many requests are waiting for approval.
- **Agents** receive indicators for new requests, assigned tasks, and recent activity on the cases they manage.
- **Employees** can quickly identify updates to their own requests.


These indicators update automatically across both web and mobile, giving everyone a real-time view of pending activity.


## Find requests faster


As the number of requests increases, locating a specific case can become time-consuming. New search and filtering options make it easier to find requests and employees using multiple criteria, without scrolling through long lists.


These improvements allow you to:


- **Filter approval requests by service, requester, date, or status** to focus on the most relevant cases.
- **Search approvals by requester name or request number** instead of browsing long lists.
- **Find employees by name or internal ID** for faster identification.


This helps agents and approvers spend less time searching and more time resolving requests.


## Built for everyday operations


From activity badges to bulk certificate downloads and more powerful search capabilities, these updates support the daily work of agents, approvers, and administrators.


Explore these new features in Humand and start putting them to work.
