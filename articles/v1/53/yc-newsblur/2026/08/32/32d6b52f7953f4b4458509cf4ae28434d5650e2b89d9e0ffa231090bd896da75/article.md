# Global Shared Stories - block stories from a user?

I really like the new shared stories view - it’s a nice feed of interesting articles I usually haven’t seen. It’s especially useful when I’ve read all my subscriptions but am bored and want more to read


That said, one frustration I have is amidst the good content is the occasional item that is pure nonsense. As much as I like hearing diverse opinions, I don’t need articles that are hateful, racist, or offensive. Just not my jam.


It would be nice if I could just hide articles shared by a given user entirely. I have blocked the user but that didn’t accomplish much (I didn’t really expect that to affect the feed tbh). My ideal would be something like - if user X shared the article, I don’t want to see it. IMO this is a good balance of control that allows me to curate my experience.


I get that might be a weird or difficult feature to implement, so I understand if you don’t. But it would allow me to be comfortable re-enabling and enjoying the GSS feed again.


There is story training which IIRC can be used on GSS to hide stories, but this stuff is so out of scope for the things I read the stories don’t get filtered effectively because I don’t encounter this level of delusion in the things I actively select to subscribe to. It would be an ongoing effort to train away this week’s conspiracy theory. Ie, it’s a pretty rapidly shifting target so I’d be constantly seeing and training away new \[redacted\].


And again just because that’s a lot of words - I don’t want to impact the site’s content globally, I just want a way to do this for myself.
