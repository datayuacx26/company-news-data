# AI Scribe for Hello Note

With our powerful EHR sync feature, syncing your notes from Hippo Scribe to Hello Note is a breeze—it only takes two seconds! Here's a detailed step-by-step guide on how to set up your Hippo Scribe template to sync notes directly into your Hello Note 2.0!


1: If you haven't, follow[this guide](https://intercom.help/hipposcribe/en/articles/9362492-how-to-install-chrome-extension) to install our chrome extension.


2: Go to the page where you usually input notes in Hello Note 2.0


3: In our Chrome Extension, navigate to the session that you want to sync to Hello Note


4: Click the **Sync to EHR** button, and you will see all the section with the same name sync'ed to Hello Note.


5: In order to sync the right section to Hello Note, make sure the section name in Hippo Scribe is the same as the text boxes in Hello Note
