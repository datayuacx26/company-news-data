# Sendbird Business Messaging wins API World’s award for Best Communications API

We are thrilled to announce that[Sendbird Business Messaging](https://sendbird.com/products/business-messaging) has won the Best Communication API award presented by API World! The trophy was presented to Sendbird representatives during the award ceremony at the Santa Clara Convention Center held on the evening of Nov 5, 2024. This recognition of our[communications API platform](https://sendbird.com/communications-api-platform-x) celebrates Sendbird’s commitment to empowering businesses with reliable and powerful business communication tech.

Sendbird is in great company, with other notable winners including Stack Overflow (Best AI API), Oracle Hospitality (Best Business Software API), US Bank (Best Finance API), Postman (Best in API Management), and Boomi (Best in IPaaS).


## What is API World?


According to their[official website](https://apiworld.co/) , API World is the world’s largest API conference and expo. It serves as a platform for developers and technical leaders to connect, share knowledge, and explore advancements in API-related tech. The in-person event, held in Santa Clara, CA, from November 5 - 7, featured an expo, conferences, keynotes, and workshops aimed to help engineers and software architects exchange ideas and delve deeper into topics like computer vision, backend-as-a-service, AI APIs, APIs for microservices, modern authorization models, and many[more tech topics](https://apiworld.co/conference/) .
