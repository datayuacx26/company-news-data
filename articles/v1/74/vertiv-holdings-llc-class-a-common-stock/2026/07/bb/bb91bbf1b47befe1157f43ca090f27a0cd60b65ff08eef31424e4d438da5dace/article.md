# Vertiv Introduces Family of Commercial-Grade Open Source Management Firmware Solutions

**Huntsville, Alabama** \[Sept. 24, 2019\] – Vertiv today introduced the[Avocent® Core Insight family of embedded management firmware solutions](https://www.vertiv.com/en-us/products/monitoring-control--management/avocent-embedded-management-systems/) , which allows developers to build applications to help IT and Network administrators deploy, monitor, and provide secure remote management to hardware such as servers, network, storage and IoT devices. The Avocent Core Insight embedded Linux packages include a commercial-ready implementation of the OpenBMC open-source project for baseboard management controllers (BMCs) to simplify development. The family of solutions is available now worldwide.


Manufacturers and firmware engineers today must meet the rapid development and deployment needs of enterprise, hyperscale and edge environments while facing internal pressures around security risks, shrinking resources, cost reductions, code quality and faster time-to-feature requirements. Avocent Core Insight provides Solution Development Kits (SDKs) with full source code access, documentation, tools and premium expert support to help meet those development and deployment needs. he Avocent Core Insight stack can be rapidly customized and integrated as a hardened OpenBMC solution for cloud-scale deployments. It also may be efficiently scaled through advanced applications for Redfish API deployment and data visualization, and provides secure remote management via video and serial over HTML5 for enterprise and edge environments


“Avocent has been developing embedded management solutions for more than 20 years with decades of participation in the open source community,” said Patrick Quirk, vice president and general manager for Vertiv’s Avocent business. “We recognize that building a better technology foundation for our customers requires us to open our firmware and drive transparency in the software. Legacy firmware SDKs make solutions difficult to build, maintain and keep secure. That’s why we’re embracing OpenBMC as a common platform for our applications and publishing select Avocent Core Insight components as open source on our public GitHub for easy sharing.”


Avocent Core Insight delivers the industry’s most advanced firmware security technology, including Avocent® Security Manager, hardware Trusted Platform Module support, and an industry first integration of RunSafe Security’s patented cyber-hardening product, Alkemist.


“With the launch of Avocent® Core Insight, Vertiv is clearly demonstrating its leadership, innovation and focus on security,” said RunSafe CEO and founder, Joe Saunders. “With the launch of Avocent Core Insight, Vertiv is the first and only organization to release an OpenBMC solution with function-level randomization that eliminates an entire class of attack vectors. Now network engineers and enterprises have access to cyber resilient firmware when deploying servers and edge devices.” Additional information about these security capabilities is available at[Vertiv.com](https://www.vertiv.com/4a5b3b/globalassets/documents/case-studies/vertiv-avocent-defense-against-bmc-cyber-attacks-wp-na-en-web_278827_0.pdf)


.


Avocent Core Insight builds on the Avocent legacy of providing embedded management systems for global server, storage and switch manufacturers, and IT management hardware and software solutions, such a Keyboard Video Mouse switches, console servers, and *Trellis™* data center infrastructure management software.


Avocent Core Insight can be licensed as a bundled offering or purchased as individual components, providing maximum flexibility and scalability. The product family includes:


- Avocent Core Insight Platform, a commercial grade BMC firmware stack based on OpenBMC, ensuring reliable and stable performance that significantly reduces hardware porting time and lowers Bill-of-Material (BOM) costs while simplifying enterprise scalability
- Avocent Core Insight Engine, a portable and scalable development and runtime solution that consumes any backend data source and generates Redfish APIs offering the fastest query response times available. The Core Insight Engine supports the most current DMTF Redfish Schemas and advanced APIs, Core Insight Dashboard and a Schema-Inspector for test and debug.
- Avocent Core Insight Dashboard, a management console included with Core Insight Engine that auto-discovers any Redfish targets, collects data, and builds custom dashboards for data visualization.
- Avocent® Core Insight Console, the industry-leading remote access application providing secure management and control of video, and serial output and mounting of media with HTML5 consoles for virtual KVM, serial redirection, and virtual media sessions.


For more information on Avocent Core Insight and other IT management systems from Vertiv, visit[Vertiv.com](https://www.vertiv.com/en-us/)
