# Product Update #18

We've been running a bunch of customer sessions lately, and one we have lined up for Friday next week (May 22, 11:30a ET) is leveraging Claude Code for custom reports using Stardex data - if you'd like to join, just hit reply and we'll add you to the list.


Here's what shipped in April:


## Confidential Searches


If you have a search which needs to stay confidential (board level, internal hires), you can now mark a search as confidential and restrict visibility so only the people working on it can see it.


## Client Share with PDF Reports


When you share candidates with a client, you can now pick exactly which sections show up (bio, work history, assessments, notes, etc.) and export the whole thing as a clean PDF. Works for a single candidate or as a full multi-candidate report. Support for more customization of visible candidate data is coming soon to the client sharable links (portal) as well.


## Webhooks Support


If you've wanted to wire Stardex into Slack, an internal dashboard, or your own workflow tooling, webhooks are now live on the v1 API. Subscribe to a wide range of events like new candidate, stage change, placement created, and more. Let us know if you would like to see anything


## New Chrome Extension + Resume Uploads


We have updated the extension to have a full page sidebar view. This is going to enable us to make the extension way more capable moving forward. For example, you can now upload resumes directly from the extension while sourcing, so you don't have to bounce back to the app.


## Team Capacity Board Updates


You can now filter the capacity board by job status, so you're only looking at active engagements without retainer-paused or archived jobs muddying the counts. We also cleaned up some deduplication bugs in the totals.


## Internal research agent improvements


We improved some of the default filters available on candidates in the internal research agent, allowing you to hide candidates already in a search, prioritize recently active candidates, and hide previously viewed candidates. Coming soon: the ability to reject candidates as "not a fit" and guide the system to update it's criteria.


## Quality of Life


-


GDPR compliance suite is live: DSR handling, data packet exports, Article 14 notices, retention policies, and ROPA. Useful if you're working with EU candidates or clients.


-


Audit log now includes archived records, so you can see what was archived, by whom, and when, and ability to unarchive.


-


Calendar events now show up in the command menu (right panel) so you can jump straight to a meeting.


-


Cmd/Ctrl+click now opens jobs, deals, contacts, and companies in a new tab.


-


Better Microsoft Calendar support - invites now force-send so attendees actually get them.


-


Meeting transcripts captured by the Stardex notetaker now have better timestamp support so you can search through call transcripts more easily.


-


Added a reports tab on the search page to view metrics specific to that search without having to jump into the separate reports section.
