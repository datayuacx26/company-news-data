# Prueba la API de Fintoc con tus propios datos, directo desde los docs

## El problema que resolvemos


Hasta ahora, probar la API de Fintoc requería un flujo manual: copiar tu API key desde el dashboard, pegarla en los docs o en tu herramienta favorita, y luego ir y venir entre pestañas para validar los resultados. Esto generaba fricción, especialmente para equipos que están evaluando la plataforma o integrándose.


## Qué cambia


Ahora, al visitar la documentación de Fintoc, verás una opción para iniciar sesión con tu cuenta del dashboard. Una vez autenticado:


- **Tus API keys se cargan automáticamente** en los ejemplos de la documentación. No más copiar y pegar.
- **Puedes ejecutar llamadas a la API con tus propios recursos** , probando endpoints con datos reales de tu cuenta.
- **Los resultados de tus pruebas se reflejan en el dashboard de Fintoc** , manteniendo todo sincronizado.
- **Tu historial de pruebas queda disponible** directamente en la documentación, permitiéndote retomar donde dejaste.


## Para quién es


- **Desarrolladores** que prueban endpoints durante la integración.
- **Equipos en evaluación** que quieren ver la API funcionando con sus propios datos.


## Pruébalo ahora


Visita[la documentación de Fintoc](https://docs.fintoc.com/docs/welcome) , haz login y empieza a probar. Si aún no tienes cuenta, puedes crearla desde ahí.


*Esta funcionalidad es completamente opcional. Los docs siguen funcionando exactamente igual sin autenticarse.*
