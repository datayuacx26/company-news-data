## 5-AXIS CNC PROGRAMMING: ROTARY ANGLES OR TOOL VECTORS?


When programming in[5-axis](https://info.hurco.com/en-us/5-axis-cnc-machining-5-sided-full-5-axis-with-hurco?utm_source=Catch-All-Vanity&utm_medium=URL&utm_campaign=5-Axis&utm_content=Unleash-Your-True-Potential) , we have two distinct options that we can use to command rotary moves and positions. We can output the data using either rotary angles or tool vectors. Although each one has its pros and cons, I (Mike Cope) prefer to configure a postprocessor to output these rotary commands as IJK tool vectors, instead of the more common ABC-axis rotary angles.


[READ BLOG](https://blog.hurco.com/blog/bid/309807/5-axis-programming-programming-with-tool-vectors)
