# It’s public! Tiptap 3.0 beta is here

## **What's new?**


A lot has changed since version 2.0, too much to put into a quick paragraph. You’ll find improvements that make your life easier, and new features that open doors to possibilities you didn't even know you needed.


Curious? Good. You can explore everything we've packed into Tiptap 3.0 in our[what’s new guide](https://next.tiptap.dev/docs/resources/whats-new) . If you're already using Tiptap 2.X, use our[migration guide](https://next.tiptap.dev/docs/guides/upgrade-tiptap-v2) to smoothly upgrade to 3.0.


And because transparency matters (and we know you love poking around), dive straight into the code on our[GitHub repository](https://github.com/ueberdosis/tiptap) .


## **But wait, is it stable?**


Fair question. We labeled it as beta because, honestly, some minor things might still shift before we call it fully stable. However, this version brings a lot of improvements and new features over V2, and it's solid and well tested.


In other words: Tiptap 3.0 Beta is yours now. Get it and build cool things with it!


Happy building!


Team Tiptap
