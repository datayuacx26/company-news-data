# New Integration: Igloohome

This week, we are super excited to release our official Igloohome integration! You can now connect and control all Igloohome locks, including the popular padlocks and keyboxes. We’re thrilled to be working with the Igloo team and see what you guys build with their devices.


Resources:


- Check out our Getting Started with Igloohome Guide
- View the[full list of supported Igloohome devices](https://www.seam.co/manufacturers/igloohome)


## About Igloohome


Based in Singapore, and with offices in the United States, China, and Indonesia, Igloohome is one of the newer entrants in the smart lock and access market. Yet despite only being in business for a few short years, Igloohome is already establishing itself as one of the best smart locks brands in the world, with a wide portfolio of products ranging from deadbolts and mortise, to padlocks and cellular-connected devices. Through our interactions with the Igloohome team, we’ve already found them to be generous, kind, and sharp individuals. We are thrilled to be able to partner with them.


## How Does the Igloohome Integration Work


All Seam API users can now request Connect Webviews to link an Igloohome account. Once an account is linked, you will be able to retrieve all devices tied to the account, and you can now begin using the Seam API to control those devices. We’ve also worked with the Igloohome team to ensure that this requires no additional setup on the Igloohome side.


As far as supported functions, the API will let you create access codes, lock/unlock, and retrieve events or device properties. Note that real time actions and events/properties require for the device to be connected to the internet via the Igloohome bridge. For offline devices, you will still be able to program temporary access codes using[Igloohome’s algopins](https://www.igloohome.co/en-SG/how-it-works) .
