# New Integration: 4Suites


Seam is excited to release our official 4Suites integration! You can now connect and control 4Suites locks to unlock doors and issue wallet passes.


## About 4Suites


Based in Holland, and with offices in the United States, 4Suites provides a suite of hospitality locks and software tools. Their product line consists of connected locks, readers, and retrofit devices to connect offline legacy devices such as Assa Abloy Vingcard devices.


## How Does the 4Suites Integration Work


All Seam API users can now link a 4Suites account. Once an account and site is linked, all devices tied to the account will be returned via Seam and can immediately be used to issue commands and access credentials.


For the launch, available functions primarily focus on online status, basic device properties, and API unlock calls. Later on, Seam will add support for Google and Apple Wallet when they become fully available.


## Getting Started


Go to the Seam Developer Console and click on “+ Add Device”, select 4Suites, and follow the onboarding steps. Once connected, make sure to check out our` locks` capability API documentation for controlling 4Suites devices.
