# New Integration: Tedee

This week, we are super excited to release our official Tedee integration! You can now connect and control all Tedee locks. We’re thrilled to be working with the Tedee team and see what you guys build with their devices.


Resources:


- Check out our[Getting Started with Tedee Guide](https://docs.seam.co/latest/device-and-system-integration-guides/tedee-locks)
- View the[full list of supported Tedee devices](https://www.seam.co/manufacturers/tedee)


## About Tedee


Tedee Sp. z o.o., based in Poland, is a company that specializes in smart home security solutions. The company was founded with the goal of providing innovative and secure solutions for door access. Tedee smart locks typically offer features like mobile app control, remote access, and integration with smart home ecosystems. They aim to make home security more convenient and connected through their products. Their flagship product, the Tedee Smart Lock, installs on top of existing lock cylinders, and operates as a key-turner. Tedee combines advanced features such as keyless entry, remote access control, and intelligent monitoring capabilities, providing users with a seamless and secure way to manage access to their homes. With a sleek and modern design, Tedee aims to revolutionize the traditional lock industry by offering smart, connected solutions that prioritize both convenience and safety for homeowners.


## How Does the Tedee Integration Work


All Seam API users can now request Connect Webviews to link an Tedee account. Once an account is linked, you will be able to retrieve all devices tied to the account, and you can now begin using the Seam API to control those devices. We’ve also worked with the Tedee team to ensure that this requires no additional setup on the Tedee side.


As far as supported functions, the API will let you create access codes, lock/unlock, and retrieve events or device properties. Note that real time actions and events/properties require for the device to be connected to the internet via the Tedee bridge.
