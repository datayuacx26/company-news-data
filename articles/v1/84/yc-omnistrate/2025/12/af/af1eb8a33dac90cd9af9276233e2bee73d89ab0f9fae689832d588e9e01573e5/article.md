# Omnistrate Platform Update (October/November 2025)

## 🚀 Exciting New Features in Omnistrate


### Cross-Region Disaster Recovery


Get ready for Enterprise-Grade Data Resiliency! We're introducing powerful new **Volume Snapshots** . A snapshot is an instantaneous, point-in-time, read-only copy of your persistent disk's state. Unlike instance-bound backups, these snapshots are completely independent of your instance's lifecycle, empowering you to effortlessly copy them across regions for ultimate Cross-Region Disaster Recovery (DR). The best part? If you're already using our automated backup services, this game-changing DR capability is available with zero additional configuration.


### Precision Custom Autoscaling


While Omnistrate already offers robust automated scaling, the new **Custom Autoscaling** feature delivers granular control for scenarios where the automatic option doesn't provide enough flexibility. This hands-on approach ensures you gain the precise control needed for complex workloads, maximizing efficiency and making cost optimization a breeze.


### Single Command Deploy


Supercharge your Developer Velocity with the Single-Command Deploy. Stop wrestling with complex deployment pipelines. Our enhanced[deploy command](https://ctl.omnistrate.cloud/omnistrate-ctl_deploy/) is your one-stop solution to deploy your application. Simply focus on writing incredible code, and let Omnistrate automate the packaging and secure deployment directly into your own cloud account—all with one effortless command and no infrastructure setup needed.


## Additional Improvements


### Build Faster


- **Strict Compose Schema Validation** : We've rolled out strict validation for your Compose schema. This critical enhancement ensures configuration integrity, enabling faster debugging, precise validation, and reliable version tracking to significantly streamline your pre-deployment workflow.
- **Enhanced Secrets Support for Helm** : We've added better support for injecting secrets into Helm chart values. This feature facilitates the secure injection of sensitive data into your Helm-managed services, protecting confidential information throughout the deployment cycle.


### Improved Operations


- **Deployment Cell Workflow** : Operational visibility is significantly enhanced. The new workflow provides detailed information on deployment cell management, empowering platform teams to efficiently troubleshoot deployment problems.


### More Options for FinOps


- **Affiliation Code Support** : To provide enhanced financial tracking and partnership management, we've implemented new support for setting an affiliation code. This crucial feature allows you to seamlessly map a unique affiliation code to customer subscriptions.
- **Usability Improvements to Query Subscription Usage Information** : We've made significant usability improvements to how you can query and access subscription usage information. This enhancement simplifies the data retrieval process, providing a more intuitive and efficient experience for FinOps teams and platform administrators.


### Improve Your Customer UX


- **Scoped API Parameters per Cloud Provider** : To improve your customer experience, we've implemented support for scoped API parameters per cloud provider. This feature allows you to define configurations that are only relevant to a specific cloud environment, simplifying your API calls by removing unnecessary or conflicting parameters, and ensuring a cleaner, more tailored experience for multi-cloud deployments.


Additional documentation on these and other features[can be found here](http://docs.omnistrate.com/) .
