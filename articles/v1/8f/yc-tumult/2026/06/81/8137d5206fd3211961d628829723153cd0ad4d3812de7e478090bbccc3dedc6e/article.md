# Tumult Hype 4.1.21 Update Now Available

[Tumult Hype](https://tumult.com/hype/) 4.1.21 is a general bugfix update. It is compatible from macOS 10.10 to 26 Tahoe. We recommend everyone upgrade.


### What’s new in Tumult Hype 4.1.21:


- Fixed a Tahoe issue where thumbnail generation would cause a window to briefly appear
- Changed the default GIF encoding engine to use Apple’s built-in encoder
- Added Zen, Helium, and Dia browsers to the preview menu and ignored Puppeteer


[Read the complete 4.1.21 change list here](https://tumult.com/hype/documentation/#4.1.21) .


Tumult Hype 4.1.21 is a free update if you purchased a previous v4 version (Standard or Professional editions).[Upgrade discounts](https://tumult.com/hype/support/upgrade-discounts/) are available for previous v1-v3 versions and you can read about[what’s new in Tumult Hype 4.1](https://tumult.com/hype/whats-new/4.1/) .

### v4.x.x -> v4.1.21 Upgrade Instructions:


#### How to upgrade theMac App Store version:


1. Open the App Store by choosing the **Apple > App Store…** menu item
2. Make sure you are signed in via the Store menu
3. Click onyour account on the bottom-left of the App Store window (or the Purchases tab on top if on macOS prior to 10.14)
4. If you have not already automatically upgraded, press Command-R to refresh and then click the Update button located next to Hype


#### How to upgrade the[Tumult Store](https://tumult.com/store/) direct-download version:


1. Open the Hype 4 application
2. Choose the **Hype > Check for Updates…** menu item (if not automatically prompted to update)
3. Install the update and relaunch
