# 2025.21 – Numbered Lists, Chocolate and Matcha Themes, Calendar Polishing, Nips and Tucks.

# Numbered List


Long requested by the very organized Workflowy user, you can now easily turn any item into a Numbered list! Great for er, putting things in order.


Find it in the Item menu, Slash Command (` /number` ), or by pressing` Ctrl` +` Alt` +` 0` on PC (` Cmd` +` Opt` +` 0` on Mac).


# Themes


We’ve added two new[themes](https://workflowy.com/learn/settings/#change-appearance) to bring some seasonal warmth; Matcha and Chocolate.


**Available to all Workflowy users** in the Settings > Theme dropdown.


# Calendar


- We’ve polished the[Calendar](https://workflowy.com/learn/calendar/) again to smooth off some rough little edges:
- The Calendar Picker now clearly shows **dates that contain nodes** , making it easier to see which days are already busy.
- You can **toggle Found Dates** from being displayed in the Calendar.
- Toggling **Friendly Date Names** no longer triggers a full Calendar reorganization.
- We’ll now show a warning before updating your Calendar if you have changed Calendar **Year, Month, or Week** with a new name or note. This prevents you from accidentally wiping out your carefully crafted content.
- Fixed an issue that caused **duplicate calendar dates** when migrating a node with both a date and time tag.


# Boards UI Improvements


We polished the look and feel of[Boards](https://workflowy.com/learn/boards/) . This includes fixing the **sub-column padding** issue that made the text inside cards look vertically off-center, making sure **numbered lists** display properly, and correcting **arrow positioning on mobile** .


# API Support


External tools can now better integrate, as we’ve added support for **parsing markdown dates** and **[content formatting](https://beta.workflowy.com/api-reference/#formatting)**


# General Quality of Life


- **Inline searches** (like in` /Move to` ) now use natural dates again.
- The **“Home” bullet** now appears in inline search results, making it faster to drop items back at the top.
- Fixed **mobile auto-scrolling** on new lines—text will no longer jump too high and disappear above the keyboard when you press **Enter** .
- Fixed that annoying **iPad** bug where you had to double-tap on UI controls to expand, collapse, and zoom.
- Fixed the **153 error** when playing embedded YouTube videos.
