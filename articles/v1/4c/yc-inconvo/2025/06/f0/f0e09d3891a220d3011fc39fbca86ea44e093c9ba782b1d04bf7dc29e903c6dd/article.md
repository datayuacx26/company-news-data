# Inconvo 1.0

We’re excited to announce Inconvo 1.0.


It includes everything you need to ship an analytics assistant for your application fast.


- Conversations API
- Semantic Modelling
- Evaluation Mode
- Query Monitoring


### Conversations API


We’re proud to release our first stable API with the[Conversations API](https://inconvo.com/docs/api-reference/conversations/answer/create) . It has everything you need for conversational analysis, with the ability to create answers, attach feedback, and retrieve conversations.


### Semantic Modelling


Give your analytics assistant access to *your business context* with features including:


- Data access controls
- Context filters
- Table prompts
- Computed columns
- Column units


### Evaluation Mode


This interface allows you to see into Inconvo’s thought process when it is creating an answer.


This puts you in control by providing a feedback loop so that you can update the Semantic Model to steer Inconvo in the right direction if required.


### Query Monitoring


You can now explore analytics conversations from your application directly in Inconvo. Easily filter for conversations with feedback and quickly access conversation summaries.


### Looking forward


This launch was a major milestone, laying the groundwork for the future. We’re excited to keep making conversational analytics easy by delivering more great features for you.
