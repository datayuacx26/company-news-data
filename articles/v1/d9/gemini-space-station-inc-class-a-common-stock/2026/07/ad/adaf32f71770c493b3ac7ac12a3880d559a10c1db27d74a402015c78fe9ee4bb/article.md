# Leveling Up Gemini’s Websocket API Infrastructure

### API Latency Matters


At Gemini, we are committed to building a fair and efficient market for all crypto traders. We believe reliable and low latency API access to our trading systems is necessary for all market participants. To improve our trading experience, Gemini has invested in upgrading API infrastructure and building new APIs to provide direct, real-time access to crypto markets.


### New Websocket API


Gemini is rolling out a better, more streamlined version of our Websocket API. The new Websocket API enables users to stream order book updates, trades, and price movements efficiently with the lowest possible latency, while also providing order entry and order updates, and other real-time information.


### Highlights


- **Low Latency:** The new Websocket API runs on top of Gemini’s new state-of-the-art messaging infrastructure, providing the lowest possible latency for both market data and order entry.
- **Easy Access:** With the new API infrastructure, customers can connect to Gemini’s trading system via multiple pathways, either through the public internet, through dedicated connections on AWS, or via the fastest and latest VPC peering infrastructure.
- **Streamlined Experience:** The new Websocket API uses a market-standard messaging format, enables efficient processing on the receiver side and offers a much smoother onboarding and integration experience.

- Fast, accurate and up-to-date view of the order book.
- Reliable performance during periods of high market volatility.
- Scalable API for frequent and high volume trading.


### Looking Ahead


This websocket upgrade is a critical step in Gemini’s broader commitment to serving the next generation of traders and investors, and we will be rolling out new features soon to serve this audience, including updated Websocket API support for trading perpetuals and tokenized stocks.
