## What Is Cypher Chat Agent?


Cypher Chat Agent is a natural language AI assistant built directly into the Cypher app. Instead of tapping through menus, you simply type what you want done — and it gets done.


**Examples:**


- “Lock my card”
- “Send 100 USDC to Alex”
- “Bridge ETH to Base”
- “Show my spending this month”
- “Increase my card spending limit”


The agent understands the intent and helps execute the action instantly and securely. Users don’t have to move to 6 different pages and 12 different clicks to enable it.

## Your Security, Guaranteed


We know you’re trusting us with your money. Here’s how we keep you protected:


**Does the agent access my private keys?** Never. The agent interacts only with the Cypher app layer, so your private keys remain encrypted and inaccessible to it at all times.


**Can it make transactions without my approval?** No. Any transaction that moves funds always requires explicit confirmation from you before it executes.


**What if I send a wrong message?** The agent confirms the intent before acting on any sensitive action. You always have a chance to cancel before it’s executed.


**What data does the agent see?** Only data tied to your Cypher account — your card, transactions, and balances. No third-party data access, ever.

## Frequently Asked Questions


**What is Cypher Chat Agent?** Cypher Chat Agent is an AI-powered crypto and card management assistant built directly into the Cypher app. It allows users to manage crypto payments, cards, spending, and assets using natural language.


**Is Cypher Chat Agent free to use?** Yes, completely. Cypher Chat Agent is available to all Cypher users through the latest app update at no additional cost. If you already have the Cypher app, simply update and it’s there waiting for you.


**Which cryptocurrencies does the agent support?** The agent supports all cryptocurrencies and tokens available within the Cypher ecosystem, including assets across multiple supported chains. If you can hold it in your Cypher wallet, you can manage it through the agent.


**Can the agent bridge assets across blockchains?** Yes. Bridging assets across supported chains is available directly through a conversational command — no need to use a separate bridge interface or copy-paste contract addresses. Just tell the agent where you want your assets and it will walk you through it.


**Is Cypher Chat Agent available on iOS and Android?** Yes. Cypher Chat Agent is fully available on both iOS and Android through the latest version of the Cypher app, available on the App Store and Google Play Store.


**Can the agent execute transactions automatically?** No. Any transaction involving the movement of funds requires your explicit approval before execution. The agent is designed to act on your behalf — but never without your direct confirmation first.
