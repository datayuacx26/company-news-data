# Integrating Edmentum with your student information system: 2025 Setup Guide

Setting up Edmentum with your existing Student Information System (SIS) requires understanding the platform's integration capabilities and available connection methods. This guide walks through the technical implementation process and demonstrates how Scout automates Edmentum integration for California independent study programs.


## Edmentum SIS Integration Options


### Direct Integration Methods


Edmentum provides SSO capabilities (ClassLink, Clever, Google, Microsoft, SAML) and supports automated rostering, plus custom API integrations for districts with specialized needs.


- **Single Sign-On (SSO):** Streamlined access via secure credential exchange
- **Automated Rostering:** Loading/updating rosters across district systems
- **Custom API:** Proprietary API for tailored integrations


### Enhanced Clever Integration


Clever-based rostering enables bi-directional data exchange through API and Edmentum Student Data Exchange (ESDE), including multi-program mapping for a single school location.


### Genius SIS Built-in Integration


For schools using Genius SIS, native integration provides automatic user management, real-time enrollment sync, integrated transcripts/reporting, and direct course request workflows.


## Implementation Steps


### Step 1: Choose Your Integration Method


- Existing SIS + SSO (IdP)
- Clever/ClassLink for automated rostering
- Genius SIS native integration
- Custom API integration for unique needs


### Step 2: Configure Data Exchange


- Student enrollment and roster sync
- Course assignments and grades
- Progress tracking
- Compliance reporting data


### Step 3: Test and Validate


Verify end-to-end data flow and user access. Ensure integrations automate time-consuming tasks to support accuracy and consistency of student data.
