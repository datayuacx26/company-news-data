# Batch test re-runs and expanded integrations

January 28, 2026


[Batch test re-runs and expanded integrations](https://www.openlayer.com/changelog/batch-test-re-runs-and-expanded-integrations)


We now support re-running tests in batch on Openlayer, so that you can recalculate results when new data is added retroactively. In addition, we’ve added a ton of new integrations – Ruby and Strands Agents SDKs, Gemini API and Copilot Studio integrations, and more – so that Openlayer fits in seamlessly with the workflows you’re already running. As always, we’ve made continuous improvements to the UI and docs, so your experience will be even smoother. Read the full list below.
