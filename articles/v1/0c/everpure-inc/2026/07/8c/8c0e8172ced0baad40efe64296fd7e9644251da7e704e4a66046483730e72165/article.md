# Everpure Cloud Azure Native for Azure VMs Delivers Fully Managed Enterprise Block Storage Solution

### Summary


Now generally available, Everpure Cloud Azure Native for Azure Virtual Machines (VMs) is a fully managed block storage service natively integrated into Azure, helping organizations reduce cloud storage costs, simplify operations, and support business-critical Azure VM workloads.


Today, we’re announcing the general availability of **Everpure Cloud Azure Native for Azure Virtual Machines (VMs)** , a fully managed, enterprise-grade block storage service that lets you provision, manage, and attach storage volumes directly to Microsoft Azure VM workloads using familiar Azure workflows.


Last year, we launched Everpure Cloud Azure Native with support for[Azure VMware Solution](https://blog.everpuredata.com/solutions/pure-storage-cloud-azure-native-ga/) , bringing the enterprise storage capabilities of the Everpure platform to VMware workloads running in Azure. Purpose-built for storage-intensive VMware environments, the service delivers independent storage scaling and can reduce cloud storage costs by up to 40% for AVS deployments. Today, we’re extending those same capabilities to Azure Virtual Machines, delivering an Azure-native enterprise block storage experience to a broader range of business-critical workloads across the Azure ecosystem.


## **Enterprise storage for Azure VM workloads**


Organizations are increasingly choosing Azure to modernize business-critical applications, taking advantage of Microsoft’s high-performance infrastructure and scalable cloud platform. As more storage-intensive workloads, including databases and analytics platforms, move to Azure, organizations are looking for ways to maximize storage efficiency, maintain predictable performance, and streamline storage operations as they scale.


To address these needs, the general availability of Everpure Cloud Azure Native for Azure VMs marks the latest milestone in Everpure’s ongoing collaboration with Microsoft through the Azure Native ISV program. Building on Everpure Cloud Azure Native support for Azure VMware Solution and FlashArray integration with Azure Local, it extends Everpure’s unified data plane into Azure, helping customers move closer to the Everpure Enterprise Data Cloud with a consistent way to manage data and deliver storage services across data centers and Azure.


Everpure’s enterprise storage capabilities have already delivered measurable results for customers. As part of its hybrid cloud transformation with Microsoft and Everpure,[Mars, Incorporated](https://www.everpuredata.com/customers/mars.html) used Everpure Cloud Dedicated to achieve 18:1 data reduction, nine times its expected compression ratio, and is on track to reduce cloud storage costs by up to 50%, freeing resources to invest in strategic initiatives such as AI. Everpure Cloud Azure Native for Azure VMs now brings these same proven capabilities available for Azure VM workloads through a native Azure experience. Built on the Purity operating environment that powers Everpure’s storage platform, the service provides always-on data reduction, enterprise-grade snapshots, high availability, and flexible scaling to help organizations optimize storage utilization, improve cost efficiency, and simplify storage operations.


## What we built, and how it works


*Figure 1: Unblock enterprise-scale.*


We didn’t start from a blank page.[Everpure Cloud Dedicated](https://www.everpuredata.com/content/dam/pdf/en/solution-briefs/sb-pure-storage-cloud-dedicated.pdf) has given customers a path to run Purity OS in their own Azure subscriptions for years. Those deployments gave us direct visibility into how enterprises actually consume cloud storage at scale: which workload types drive the most cost, where provisioned vs. written gaps accumulate, how storage and compute sizing decisions interact under real production load. Everpure Cloud Azure Native is the next evolution of that foundation, the same proven efficiency and data services, now delivered with no infrastructure to deploy, size, or manage. The insights from Everpure Cloud Dedicated customers shaped this service directly, from the performance architecture to its operational model.


The result is a fundamentally different cost and operational model. Inline deduplication, compression, and thin provisioning mean you pay for data written, not capacity reserved, driving up to 40% lower storage TCO compared to alternative storage solutions. There is no storage infrastructure to run or maintain, and host configuration is streamlined. Azure VM Extension automates iSCSI host setup for Windows and Linux, removing the need for manual configuration or scripting and completing deployment in minutes


## What does Azure Native Independent Software Vendor (ISV) mean?


Everpure Cloud Azure Native is one of a select few software solutions built collaboratively with Microsoft.


*Figure 2: Built natively into the Azure ecosystem.*


Everpure Cloud Azure Native for Azure VMs is managed entirely through the tools your teams already use: the Azure Portal, ARM templates, Bicep, and Terraform. It lives in your Azure subscription, inside your own virtual network; storage traffic stays private, with no public endpoint and no egress charges. Access control integrates with Microsoft Entra ID, **** so identity and permissions work the same way they do across the rest of your Azure environment.


Purchasing and billing run through Microsoft Marketplace, consolidating storage spend into a single Azure invoice. Every dollar spent counts toward your Microsoft Azure Consumption Commitment (MACC), which matters to any organization working within an Azure commit.


When something needs attention **,** support is led by Everpure, and backed **** by Microsoft, **** so you’re not navigating between a storage vendor and a cloud provider to figure out who owns the problem. That’s not a minor detail. It’s the difference between hours and days of resolution time on a storage incident.
