# Introducing Neighborhoods & Support for Cisco Spaces WiFi Data

### We’re excited to announce the release of Neighborhoods, allowing you to further segment and monitor utilization within specific areas, plus the ability to analyze WiFi data alongside VergeSense sensor data.


By empowering workplace leaders with tools for neighborhood planning, VergeSense has reimagined how to respond to additional space requests, proactively implement new space design decisions, and improve space availability. With the introduction of Neighborhoods, space planners can get even more granular floor level data to make informed and impactful planning decisions. Plus, we’re excited to announce the ability to ingest and analyze


[Cisco Spaces WiFi data.](https://www.vergesense.com/product/cisco-spaces-wifi-beta)


#### Introducing Neighborhoods


We're


excited to help workplace leaders and space planners with the ability to segment and monitor utilization of specific Neighborhoods within a floor. In addition to being able to designate Space Groups and Space Types, you’ll now be able to configure Neighborhoods on a floor which allow you to use VergeSense to monitor the number of people in a defined Neighborhood in real-time, the capacity usage of that Neighborhood, and the estimated seats available within a specific Neighborhood. Neighborhoods can also be used to monitor traffic through entrances and exits, and you can view Spaces data to understand what spaces people are using within a Neighborhood. You’ll also be able to use Space Groups to understand how specific business units or functions use space in one or multiple floors.


You’ll also be able to show Neighborhood real-time availability information on live Kiosk view, making it super easy for employees to find available space. By supplementing your historical neighborhood usage data with real-time Neighborhood data, you’ll be able to be proactive about neighborhood planning decisions.


#### Analyzing Cisco Spaces WiFi Data with VergeSense


Over the past year, we’ve been updating VergeSense to include more workplace decision support tools, all in one place. That’s why we’re thrilled to announce that VergeSense now supports the analysis of Cisco Spaces WiFi data, which allows you to use the floor-level WiFi data you already have to make occupancy decisions alongside VergeSense data.


By partnering with Cisco, we’ve built an integration that allows you to analyze your Cisco Spaces WiFi data for visibility into things like real-time availability and utilization within Neighborhoods. Our out-of-the box integration with Cisco Spaces extracts person count information from existing WiFi telemetry to help you understand building, floor, and neighborhood utilization.
