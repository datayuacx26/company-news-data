# Announcing MentraOS 2.0 and Our $8M Raise

## MentraOS 2.0 Launch


MentraOS (previously called AugmentOS) is how you get smart glasses apps and how you build smart glasses apps. You can get it now at[MentraGlass.com/OS](https://mentraglass.com/OS)


If you want to explore the apps available for MentraOS, checkout the Mentra Store:[Apps.MentraGlass.com](https://apps.mentraglass.com/)


If you want to build smart glasses apps using the open-source smart glasses SDK, checkout the developer documentation:[Docs.MentraGlass.com](https://docs.mentraglass.com/)


## Mentra Raises $8M Seed


At the same time, we’re announcing we raised $8M to build the OS for smart glasses - backed by the founders of Android, YouTube, Pebble, Y Combinator, and more (see image below).


This raise will enable us to build the open source software and hardware needed to usher in the next personal computer.
