# Dart v7.10 – Custom agents, Jules coding agent, and better MCP

Dart v7.10 is here, and the massive update is that you can now build tailored AI agents right within Dart that follows your guidelines, executes your workflows, and uses the exact models you prefer! Alongside this, we’ve added Google’s Jules for coding and a helpful skill to streamline your most complex projects.[View our full changelog here](https://changelog.dartai.com/) .


## Custom agents & Jules


You are no longer limited to pre-set configurations. You can now build the exact AI agent you need.


- Build[custom agents](https://app.dartai.com/agents) by entering specific guidelines, setting their unique workflows, and choosing their preferred chat model.
- Set the "thinking level" and specific AI model for both[custom skills](https://app.dartai.com/?settings=skills) and agents to ensure they approach tasks with the right amount of depth.
- We’ve added[Jules](https://app.dartai.com/agents) , Google's AI coding agent, to help automate technical workflows and expand your development capabilities.
- Agent guidelines now support rich markdown formatting for clear, structured instructions.


To learn more about custom agents and see some examples[check out this article](https://help.dartai.com/en/articles/14625768-custom-agents) .


## New AI skill & MCP upgrades


We’re making it easier to turn big ideas into actionable plans.


- Our new AI skill helps you instantly divide large, complex tasks into manageable pieces
- We’ve upgraded our[Model Context Protocol (MCP)](https://app.dartai.com/?settings=mcp) so you can interact with the Dart interface directly from within platforms like Claude and ChatGPT


## More improvements


- Fixed a bug where pressing Cmd + Up inside the document editor would accidentally switch tasks
- Updated the strikethrough keyboard shortcut to Cmd + Shift + S for easier access
- Fixed a visual issue where scrollbars were not displaying correctly in Safari and other browsers
- Resolved multiple visual alignment and layout shifting issues on board view cards
- Cleaned up document previews by removing interactive hover effects, making them clearly read-only
- Fixed a formatting issue where AI-generated lists had excessive spacing between items
- Improved the reliability of creating nested lists in documents
- Restored the loading spinner when documents are syncing to keep you informed of the save status
- Improved markdown parsing to better handle and automatically format bare URLs
- Added helpful tooltips to icon-only buttons for better clarity
- Fixed an issue where notifications were displaying incorrectly or failing to clear when their associated tasks were moved to the trash
- Added clarifying text to statuses on board cards to make them easier to read at a glance
