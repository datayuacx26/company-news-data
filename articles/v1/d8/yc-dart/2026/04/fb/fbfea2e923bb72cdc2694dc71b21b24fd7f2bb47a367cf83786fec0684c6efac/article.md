# Dart v7.9 – Dynamic scheduling, faster boards, and smarter AI chat

We’re back with Dart v7.9, an update focused on making your scheduling more flexible and your workspace faster. From smarter date filtering to major performance boosts in our board layout.


‍[View our full changelog here](https://changelog.dartai.com/) .


## Dynamic scheduling & date filters


Managing complex timelines is now much easier. Our Roadmap and Calendar layouts have been upgraded with new filter options for "Start date" and "End date."


- To stay consistent with date ranges, the[Due date property](https://app.dartai.com/?settings=properties) now automatically renames to "Dates" whenever a range is enabled
- We’ve improved[task notifications](https://app.dartai.com/?settings=notifications) to be more accurate and helpful, powered by our new detailed history system


## Performance at scale


For those of you managing massive workspaces, we’ve drastically improved the scrolling performance and smoothness of board columns and swimlanes. Navigating hundreds of tasks now feels faster and smoother.


## AI agents & chat enhancements


Dart AI is getting faster and more refined to match your workflow.


- Improved internal agent workflows for smoother task automation
- Refined the[AI chat](https://app.dartai.com/) interface so user messages dynamically shrink in width to fit their content perfectly
- Upgraded underlying chat data models to track conversation history and improve overall chat speed


## More improvements


- Improved list formatting and text handling throughout the document editor
- Fixed a bug where technical documentation formatting could occasionally be displayed incorrectly in Docs
- Fixed an issue where pasting markdown text was not applying the correct styling
- Fixed a bug where adding a link via the floating text toolbar was occasionally unresponsive
- Fixed a visual bug where placeholder text was not displaying correctly in empty documents
- Fixed an issue where tasks from deleted spaces or databases were not properly appearing in the trash
- Fixed a bug that caused tasks to visually overlap when dragging to change their order in the board view
- Fixed interaction issues with collapsed columns and the new task button in board views
- Fixed an issue where some videos and media files could not be opened properly in the viewer
- Fixed a bug where refreshing the skills page would temporarily hide linked items
- Fixed an issue where files attached to folders were not behaving as expected
- Fixed a minor visual alignment bug with homepage widgets
- Improved the syncing speed and reliability of onboarding tutorial statuses


There is a lot of polish in this one to make Dart feel snappier. If you have any questions about the new date filters or the performance upgrades just email us!
