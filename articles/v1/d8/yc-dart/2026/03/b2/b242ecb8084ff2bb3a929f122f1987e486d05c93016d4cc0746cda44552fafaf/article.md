# Dart v7.5 – Agent workspaces, GitHub copilot, and fullscreen AI chat

We’re back with Dart v7.5, and this one is all about giving your[AI agents](https://app.dartai.com/agents) a promotion. We’ve moved them out of the settings and right into your main navigation, making your automated teammates easier to reach than ever.[View our full changelog here](https://changelog.dartai.com/) .


## Agent workspaces & GitHub copilot


[Agents](https://app.dartai.com/agents) have officially graduated to the main navigation bar. In addition:


- You can now add GitHub copilot as an official AI agent within Dart
- We’ve added a dedicated prompt field to fine-tune how your agents behave, plus a fallback chat method for when things get complex
- Upgraded to GPT-Image-1.5 for assignments, with a new tool that allows agents to intelligently reuse your existing image attachments


## AI chat fullscreen & persistent settings


You can now toggle the[AI chat](https://app.dartai.com/) to fullscreen, giving you all the room you need for deep brainstorming sessions without the cramped side-panel feel.


- We’ve added user defaults for AI models and "thinking" levels. Your preferred settings will now persist across every session
- We’ve overhauled the Task overlay so it no longer blocks your chat panel. You can now view your task details and talk to the AI simultaneously
- "Retrieved skill" tool calls now include explicit links, so you know exactly which automation your agent is running


## Seamless attachments & text editing


We've made a bunch of improvements to typing in docs and descriptions as well as how attachments are handled both in AI Chat and in tasks.


- You can now copy raw text directly from chat messages and comments
- Full checklist functionality is now supported directly inside Dart docs
- Resolved issues with accidentally deleting re-used attachments across multiple tasks
- We’ve fixed those pesky bugs where text styling would jump around or descriptions would disappear when using entity links


## More improvements


- Standardized icons and colors for t-shirt size estimates for better visual hierarchy
- Added a "revert to default" button for skill prompts so you can experiment without fear
- Updated our Stripe integration to fix deactivation and billing bugs
- Improved tracking for field updates to ensure your work isn't overwritten when collaborating in real-time.
- Fixed the "sticky header" issues and resolved layout shifts that occurred during page loads
- Fixed overlapping headers and improved image thumbnail generation within the chat
- Resolved bugs where the leftbar refactoring caused navigation hiccups
