# Dart v7.6 – Gemini models, tables, and embedded chat

Today we’re rolling out Dart v7.6. This update brings an expansion to our AI capabilities with Google Gemini support, highly requested doc and description upgrades like supporting tables, and new ways to access chat throughout your workspace.


‍[View our full changelog here](https://changelog.dartai.com/) .


## Gemini models & per-user settings


We are expanding our AI lineup with full support for Google Gemini models, available right alongside Anthropic's Claude and OpenAI's models.


- You can now use the per-user model picker to set your personal default[AI model](https://app.dartai.com/?settings=dart-ai) and "thinking level," ensuring your preferred setup persists every time you log in
- Generate images directly in the[AI chat](https://app.dartai.com/) interface and seamlessly save them straight to your tasks and documents
- We've made internal improvements to AI chat to help you easily discover and trigger the right AI skills


## Tables & editor upgrades


We’ve added full support for tables via either highlighting text to open the editor menu, or using markdown. With this you can now make your own tables or copy/paste them in to docs and descriptions. They'll also appear appropriately if generated by AI.


- A new attachment button is now conveniently located right next to the dictate button for rapid file uploads
- The emoji typeahead has a much cleaner appearance and significantly more autocomplete options
- We've improved how markdown images are handled when pasting or importing from external sources


## Embedded chat & API expansion


We’re bringing the AI directly to where your work is happening. You can now trigger embedded AI chat flows directly from subtasks and inline text.


In addition we’ve split the[Public API](https://app.dartai.com/?settings=cli) and AI/[MCP](https://app.dartai.com/?settings=mcp) API into distinct services, which significantly improves performance and rate limiting for your automated workflows.


## More improvements


- We've redesigned the settings structure to make it much easier to navigate, especially on mobile devices
- You can now pin your most-used[AI skills](https://app.dartai.com/?settings=skills) for instant access
- When duplicating tasks, custom status properties now copy over correctly, while size estimations automatically reset to prevent accidental carryover
- Decreased instances of concurrent write conflicts when multiple teammates edit a task simultaneously
- Fixed a bug where tapping a push notification failed to open the associated task
- Resolved a bug where typing a new comment while editing an old one would accidentally merge the text
- Fixed multiple spreadsheet export failures, horizontal rule formatting issues, and visual bugs causing nested elements to bounce on load
- Resolved layout issues where browser search (Cmd+F) blocked task overlay buttons
