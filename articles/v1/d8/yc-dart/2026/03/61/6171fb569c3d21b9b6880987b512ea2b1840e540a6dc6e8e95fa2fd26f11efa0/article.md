# Dart v7.8 – AI chat and agents updates, cover image, dictation improvements

We're keeping the momentum going with this update bringing more autonomy to your AI agents, visual upgrades like board cover images, and a much smarter, more reliable dictation experience across your workspace.
[View our full changelog here](https://itsdart.us14.list-manage.com/track/click?u=6ffefa993304e3b4b9d967039&id=f88d879e3e&e=44ec99aaf7) .


## AI agents & chat upgrades


Your AI agents are getting more interactive. Agents can now leave follow-up comments when they successfully finish an assigned task, keeping you fully in the loop without you having to ask.


- We've launched a new[AI agents](https://itsdart.us14.list-manage.com/track/click?u=6ffefa993304e3b4b9d967039&id=9e83a79201&e=44ec99aaf7) landing page and improved the in-app interface for managing your agents and webhooks
- The[AI chat](https://itsdart.us14.list-manage.com/track/click?u=6ffefa993304e3b4b9d967039&id=74b7f52ee5&e=44ec99aaf7) text box now dynamically grows to fit your longer messages, giving you the room you need to type out complex prompts
- We’ve refined the visual presentation and layout of[AI skill suggestions](https://itsdart.us14.list-manage.com/track/click?u=6ffefa993304e3b4b9d967039&id=5a58312501&e=44ec99aaf7) to make tool discovery even easier


## UI polish & cover images


We’ve brought more visual organization to your workflow.


- Tasks in the board layout can now display a cover image using the image attached to your task, making it instantly easier to scan your boards visually
- We've standardized text colors and rounded the table formatting buttons for a more polished, consistent feel
- Improved the appearance of the teammates widget specifically for Mozilla Firefox users


## Docs & smarter dictation


Writing and dictating in Dart is now smoother and much more reliable.


- We've added smart checks so dictation only begins recording when your microphone is fully ready, cutting out frustrating missed words
- Upgraded the speech-to-text interface to work flawlessly directly inside task descriptions
- Simplified the[document editor](https://itsdart.us14.list-manage.com/track/click?u=6ffefa993304e3b4b9d967039&id=e6145a87b3&e=44ec99aaf7) layout on mobile devices for a much cleaner, distraction-free writing experience
- Improved file readability scanning to ensure uploaded attachments are fully accessible before saving


## More improvements


- Prevented multiple rapid submissions on external forms to avoid duplicate entry spam
- Resolved an issue that could cause the app to slow down when switching between list and board views
- Removed the redundant word "Completed" from the subtasks progress bar to save screen space
- Fixed a bug in the board layout where new tasks created in the unprioritized column would not display immediately
- Improved data handling for webhook templates making external integrations much smoother
- Fixed a visual issue where tooltip arrows were slightly misaligned
- Fixed a bug where agent tooltips were appearing empty on hover
- Fixed an issue that could trigger unexpected errors when clicking on task links
- Fixed a layout issue where onboarding tutorial messages were overlapping the signup box
- Fixed a bug where pasting links into task descriptions was occasionally unresponsive
- Fixed a visual bug that caused layouts to accidentally overlap when dragging or resizing screen elements
- Fixed the floating text toolbar so it correctly stays synced even if you temporarily click away from the editor
- Fixed a bug where empty tables in documents were accidentally getting trimmed or deleted
