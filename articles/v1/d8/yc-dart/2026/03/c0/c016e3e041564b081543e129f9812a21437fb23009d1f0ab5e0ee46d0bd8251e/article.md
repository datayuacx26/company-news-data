# Dart v7.3 – Command center, Swimlanes, and mobile polish

We just rolled out Dart v7.3, an update focused on speed, visualization, and polishing the core experience. From a brand new Command center to powerful Swimlanes, we’ve added tools to help you move faster than ever.


## Command center & shortcuts


We’ve replaced the old command bar with a powerful, custom-built Command center. It’s designed for keyboard-first navigation, making it significantly easier to create tasks, jump to views, and execute commands instantly.


- Access it anywhere by pressing **Cmd+K** (or **Ctrl+K** )
- Use the robust new system of keyboard shortcuts
- Navigate submenus and multiselect items with ease


## Swimlanes in board layout


Organize your work visually with the new[Swimlanes](https://help.dartai.com/en/articles/9662870-board-layout#h_e5660ce3cc) . You can now group your boards horizontally by assignee, priority, or custom properties. It’s the perfect way to visualize work in a matrix and instantly spot bottlenecks or capacity issues.


## Faster AI agents


Our AI is getting a major speed boost. Agents can now run multiple tools simultaneously via parallel tool calls, making Dart AI chat significantly more responsive.


- Richer summaries of what the AI is doing
- Better handling of attachments within the chat interface
- Improved validation and formatting for complex queries


## Markdown & editor improvements


We’ve refined the writing experience to make communication clearer. You can now support images directly within markdown, and we've improved nested blockquotes so replying to specific parts of a thread is seamless.


## Mobile improvements


- Settings redesign: A refactored sidebar and optimized layout make finding what you need easier, especially on mobile
- Mobile fixes: We've polished the mobile experience, ensuring board names are editable and settings views never feel cramped


## More improvements


- You can now reply directly to Dart email notifications to add comments to tasks without opening the app
- User exports now include timezones to help large teams coordinate better across regions
- Implemented caching for typeaheads, making searches for assignees and tags instant
- When selecting multiple tags or assignees, your search query now persists so you can select multiple items in a row
- Improved parsing to strip out email signatures more aggressively, keeping your tasks clutter-free
- Tooltips, menus, and floating UI elements are smoother and better managed
- Optimized memory management for long sessions and upgraded our backend infrastructure for better stability
- PDF and HTML exports now have better bullet point spacing and image sizing
