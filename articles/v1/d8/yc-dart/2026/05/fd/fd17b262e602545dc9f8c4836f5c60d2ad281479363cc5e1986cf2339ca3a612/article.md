# Dart v7.12 – Devin & Nanobot, local agent execution, and Early Access

Dart v7.12 is officially live, taking agentic workflows to the next level. This update introduces powerhouse integrations for Devin and Nanobot, a local agent execution mode, and the launch of **Early Access** , a new opt-in channel where you can try our most experimental AI features before anyone else. Agent memory is live in Early Access today, with more cutting-edge features landing soon. Want in? Just reply to this email and we'll flip it on for your workspace. In exchange, we'd love to hear what you think as you try it out.


[View our full changelog here](https://changelog.dartai.com/)


## Devin, nanobot & local agent execution modes


- Added official integrations for Devin and Nanobot agents, expanding automated engineering and operations capabilities
- Added a new local execution mode so agents can securely run tasks on your own machine
- Added direct chat with any AI agent in your workspace, just like messaging a teammate
- Added support for multiple independent copies of the same built-in agent, with configurable language settings
- Upgraded voice-to-text with a more accurate recognition model
- Increased Claude model limits for larger files
- Refined comment reply triggers to reduce unnecessary notifications


To learn more about agents and see some examples[check out this article](https://help.dartai.com/en/articles/14625768-custom-agents) .


## Structured collaboration & task workflows


We've added highly requested quality-of-life updates to keep project handoffs clean and precise.


- Added a new reviewer property to assign teammates for reviewing and approving completed work
- Added automatic completion timestamps with millisecond precision and advanced filtering support
- Added clickable agent mentions that navigate directly to their profile
- Added Shift + paste support (Cmd/Ctrl + Shift + V) to paste plain text without formatting


## More improvements


- Fixed a bug where dragging subtasks between board columns was occasionally not working
- Fixed an issue where the scroll bar in the task comments section was unclickable in Chrome
- Fixed navigation issues when backing out of the Inbox, Search, and Trash, and when switching boards in fullscreen mode
- Fixed a bug where moving tasks between lists would incorrectly inflate point totals
- Restored the ability to use the Escape key to close fullscreen image and media previews
- Fixed issues with user profile cards, @-mention dropdowns, and profile tooltips resizing unexpectedly on hover
- Fixed a bug where responding to email threads with multiple recipients wasn't routing correctly
- Fixed a bug where grouped list rows were failing to update their item counts automatically
- Fixed an issue preventing users from dragging dartboards into entirely empty spaces
- Fixed bugs with the undo and redo functionality inside the document editor
- Fixed chat-related issues with unread indicators, new thread loading states, title updates, and linked chat history deletion
- Fixed occasional errors and stability issues when interacting with Claude AI models
